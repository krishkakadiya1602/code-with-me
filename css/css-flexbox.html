CSS Flexbox

Learn how to create flexible and responsive layouts using CSS Flexbox

Introduction to CSS Flexbox

CSS Flexbox, also called the Flexible Box Layout, is a CSS layout system used to arrange elements inside a container.

Flexbox makes it easier to align, distribute, resize, and organize elements horizontally or vertically.

Flexbox is especially useful for:
  • Navigation bars
  • Card layouts
  • Centering elements
  • Responsive layouts
  • Buttons and menus
  • Page sections

Creating a Flex Container

To create a flex container, use: 

.container {
    display: flex;
}

The direct children of a flex container automatically become flex items. 

<div class="container">

    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>

</div>

4. align-self

The align-self property allows an individual flex item to override the container's align-items setting. 

.item {
    align-self: flex-end;
}
Tip: Use align-self when one particular flex item needs different alignment from the other items.

5. flex-wrap

By default, flex items try to remain on one line. The flex-wrap property allows items to move to a new line when necessary. 

.container {
    display: flex;
    flex-wrap: wrap;

7. flex-grow

The flex-grow property controls how much a flex item can grow compared with other items.

8. flex-shrink

The flex-shrink property defines how much an item can shrink when there is not enough space. 

.item {
    flex-shrink: 1;
}
The default value of flex-shrink is 1.

9. flex-basis

The flex-basis property defines the initial size of a flex item before extra space is distributed. 

.item {
    flex-basis: 200px;
}

It can be used instead of setting an initial width or height depending on the flex direction.

10. flex Shorthand

The flex property is a shorthand for: 

flex-grow
flex-shrink
flex-basis

Example:

.item {
    flex: 1 1 200px;
}

You can also use: 

.item {
    flex: 1;
}

11. order

The order property changes the visual order of flex items. 

.item1 {
    order: 3;
}

.item2 {
    order: 1;

12. align-content

The align-content property controls the spacing between multiple flex lines.

It is useful when flex-wrap: wrap creates multiple rows or columns. 

.container {
    display: flex;
    flex-wrap: wrap;
    align-content: center;
}
Remember:
align-items aligns items on a line.
align-content controls multiple flex lines.

13. flex-flow

The flex-flow property is a shorthand for flex-direction and flex-wrap. 

.container {
    flex-flow: row wrap;
}

Center an Element with Flexbox

One of the most useful features of Flexbox is easily centering an element horizontally and vertically. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
Perfectly Centered

Flexbox Card Layout Example

Flexbox can be used to create responsive card layouts. 

.cards {
    display: flex;
    gap: 20px;
    flex-wrap: wrap;
}

.card {
    flex: 1 1 250px;
}
