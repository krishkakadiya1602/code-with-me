CSS Flexbox

Learn how to create flexible, responsive and well-aligned layouts using CSS Flexbox.

1. What is CSS Flexbox?

CSS Flexbox, also known as Flexible Box Layout, is a CSS layout system that makes it easier to arrange elements inside a container.

Flexbox is especially useful when you need to align elements horizontally or vertically.

Important: Flexbox works with two types of elements:

Flex Container: The parent element.
Flex Items: The child elements inside the container. 
.container {
    display: flex;
}

2. display: flex

To start using Flexbox, apply display: flex; to the parent element. 

.container {
    display: flex;
}

3. flex-direction

The flex-direction property determines the direction in which flex items are placed.

Value Description
row Items are placed from left to right.
row-reverse Items are placed from right to left.
column Items are placed from top to bottom.
column-reverse Items are placed from bottom to top. 
.container {
    display: flex;
    flex-direction: column;
}

4. justify-content

The justify-content property controls the alignment of flex items along the main axis.

Value Description
flex-start Items start from the beginning.
flex-end Items move to the end.
center Items are centered.
space-between Equal space is placed between items.
space-around Space is placed around items.
space-evenly Equal space is placed everywhere. 
.container {
    display: flex;
    justify-content: center;
}

5. align-items

The align-items property controls the alignment of flex items along the cross axis. 

.container {
    display: flex;
    align-items: center;
}

Common Values

  • stretch
  • flex-start
  • flex-end
  • center
  • baseline

6. flex-wrap

By default, flex items try to stay on one line. The flex-wrap property allows items to move to another line. 

.container {
    display: flex;
    flex-wrap: wrap;
}
Value Description
nowrap Items remain on one line.
wrap Items move to new lines.
wrap-reverse Items wrap in reverse direction.

7. gap

The gap property creates space between flex items. 

.container {
    display: flex;
    gap: 20px;
}

8. flex-grow

The flex-grow property determines how much a flex item can grow compared to other items. 

.item1 {
    flex-grow: 1;
}

.item2 {
    flex-grow: 2;
}
Tip: A larger flex-grow value means the item can receive more available space.

9. flex-shrink

The flex-shrink property determines how much a flex item can shrink when there is not enough space. 

.item {
    flex-shrink: 1;
}

10. flex-basis

The flex-basis property defines the initial size of a flex item. 

.item {
    flex-basis: 200px;
}

11. align-self

The align-self property allows one particular flex item to have a different alignment. 

.item {
    align-self: center;
}

12. flex Shorthand

The flex property is a shorthand for three properties:

  • flex-grow
  • flex-shrink
  • flex-basis
.item {
    flex: 1 1 200px;
}

13. Flexbox Properties

Property Purpose
display Creates a flex container.
flex-direction Controls the direction of items.
justify-content Aligns items on the main axis.
align-items Aligns items on the cross axis.
flex-wrap Controls whether items wrap.
gap Creates space between items.
flex-grow Controls item growth.
flex-shrink Controls item shrinking.
flex-basis Sets initial item size.
align-self Changes alignment of an individual item.

🎯 Key Points

  • Flexbox is used to create flexible layouts.
  • Use display: flex; on the parent element.
  • flex-direction controls the direction of items.
  • justify-content controls main-axis alignment.
  • align-items controls cross-axis alignment.
  • flex-wrap allows items to move to new lines.
  • gap creates space between flex items.
  • Flexbox is very useful for responsive web design.
Remember: Flexbox is mainly used for one-dimensional layouts, either a row or a column.
