11. How to Build a CSS Project

  1. Decide what you want to build.
  2. Create the HTML structure.
  3. Add CSS styles.
  4. Add colors and typography.
  5. Add spacing using margin and padding.
  6. Use Flexbox or Grid for layout.
  7. Add hover and transition effects.
  8. Make the project responsive.
  9. Test the project on different screen sizes.

12. Make Your Projects Responsive

A responsive website works properly on desktops, tablets and mobile phones. 

@media (max-width: 768px) {

    .container {
        width: 95%;
    }

    .cards {
        grid-template-columns: 1fr;
    }

}
Remember: Always test your project on both desktop and mobile screen sizes.
