CSS Selectors

Learn how CSS selectors identify HTML elements and allow you to apply styles to specific elements.

What are CSS Selectors?

CSS selectors are used to select the HTML elements that you want to style.

After selecting an HTML element, CSS applies properties and values to that element.

selector { property : value ; }
Example:

p { color: blue; }

Here, p is the selector. It selects all paragraph elements.

Types of CSS Selectors

CSS provides many types of selectors. The most commonly used selectors are:

  • Universal Selector
  • Element Selector
  • Class Selector
  • ID Selector
  • Grouping Selector
  • Descendant Selector
  • Child Selector
  • Attribute Selector
  • Pseudo-class Selector
  • Pseudo-element Selector

1. Universal Selector

The universal selector selects all HTML elements.

It is represented by an asterisk: *

CSS 
* {
    margin: 0;
    padding: 0;
}

This rule applies to all elements on the page.

Common use: The universal selector is often used as part of a CSS reset.

2. Element Selector

An element selector selects HTML elements by their tag name.

CSS 
p {
    color: blue;
}

This selects all <p> elements.

3. Class Selector

A class selector selects elements that have a particular class attribute.

A class selector begins with a dot: .

HTML 
<p class="important">
    Important information
</p>
CSS 
.important {
    color: red;
    font-weight: bold;
}

This paragraph uses a class selector.

Important: The same class can normally be used on multiple HTML elements.

4. ID Selector

An ID selector selects an element using its ID attribute.

An ID selector begins with: #

HTML 
<h1 id="main-title">
    Welcome to CSS
</h1>
CSS 
#main-title {
    color: green;
    text-align: center;
}

Welcome to CSS

Remember: An ID is intended to identify a specific element. For reusable styles, classes are generally more appropriate.

5. Grouping Selector

The grouping selector allows you to apply the same styles to multiple selectors.

CSS 
h1,
h2,
p {
    color: blue;
}

The same color will be applied to h1, h2 and p elements.

6. Descendant Selector

A descendant selector selects elements that are inside another element.

CSS 
div p {
    color: purple;
}

This selects all paragraphs that are descendants of a div.

This paragraph is inside the div.

7. Child Selector

The child selector selects elements that are direct children of another element.

CSS 
div > p {
    color: orange;
}

The > symbol means direct child.

Direct child paragraph.

8. Attribute Selector

Attribute selectors select elements based on their attributes.

Example

CSS 
input[type="text"] {
    border: 2px solid blue;
}

This selects input elements whose type attribute is "text".

9. Pseudo-class Selector

A pseudo-class selects an element based on a special state.

One common example is :hover.

CSS 
button:hover {
    background-color: blue;
    color: white;
}

When the user moves the mouse over the button, the hover styles are applied.

Other Common Pseudo-classes

  • :hover
  • :focus
  • :active
  • :visited
  • :first-child
  • :last-child
  • :nth-child()

10. Pseudo-element Selector

Pseudo-elements allow you to style a specific part of an element.

Common pseudo-elements include:

  • ::before
  • ::after
  • ::first-letter
  • ::first-line
CSS 
p::first-letter {
    color: red;
    font-size: 40px;
}

This example demonstrates the first-letter pseudo-element.

Combining Selectors

CSS selectors can be combined to target elements more specifically.

Element + Class 

p.note {
    color: blue;
}

This selects only paragraph elements having the class "note".

Class + Class 

.box.highlight {
    border: 2px solid red;
}

This selects an element that has both classes.

CSS Selectors Summary

Selector Example Meaning
Universal * Selects all elements.
Element p Selects all p elements.
Class .box Selects elements with class box.
ID #header Selects the element with that ID.
Grouping h1, p Selects multiple types.
Descendant div p Selects p inside div.
Child div > p Selects direct child p.
Attribute input[type="text"] Selects elements by attribute.
Pseudo-class a:hover Selects an element in a state.
Pseudo-element p::first-letter Selects part of an element.

Key Points to Remember

  • CSS selectors choose which HTML elements will receive styles.
  • The universal selector is *.
  • Element selectors use HTML tag names.
  • Class selectors begin with ..
  • ID selectors begin with #.
  • Commas can group multiple selectors.
  • A space creates a descendant selector.
  • The > symbol selects direct children.
  • Attribute selectors target elements according to their attributes.
  • Pseudo-classes describe special element states.
  • Pseudo-elements style specific parts of elements.
