CSS Lists

Learn how to style HTML lists using CSS

1. What are CSS Lists?

HTML lists are used to display a collection of related items. CSS allows us to change the appearance of these lists.

CSS can change list markers, positions, spacing, colors, backgrounds, and more.

Important: HTML creates the list structure, while CSS controls how the list looks.

2. Types of HTML Lists

There are three commonly used types of HTML lists.

List Type HTML Element Example
Unordered List <ul> • Item
Ordered List <ol> 1. Item
Description List <dl> Term - Description

5. list-style-type

The list-style-type property specifies the type of marker used for a list.

Unordered List Markers

ul {
    list-style-type: disc;
}

Common values include:

  • disc
  • circle
  • square
  • none

Example

ul {
    list-style-type: square;
}

12. list-style-position

The list-style-position property controls where the list marker appears.

Outside

ul {
    list-style-position: outside;
}

Inside

ul {
    list-style-position: inside;
}
  • This is an example of a list item with the marker positioned inside the content area.

13. list-style-image

The list-style-image property allows you to use an image as a list marker. 

ul {
    list-style-image: url("icon.png");
}
Make sure the image path is correct when using an image as a list marker.

14. list-style Shorthand

The list-style property is a shorthand property for list styling. 

ul {
    list-style: square inside;
}

You can combine list-style properties in one declaration.

15. Adding Space to Lists

You can use margin and padding to control spacing.

17. Horizontal List

Lists can be displayed horizontally using display: inline or display: inline-block.

    display: inline-block;

18. Lists for Navigation Menus

HTML lists are frequently used to create navigation menus. 

<ul class="menu">

    <li><a href="#">Home</a></li>
    <li><a href="#">Courses</a></li>
    <li><a href="#">About</a></li>

</ul>
.menu {
    list-style: none;
}

.menu li {
    display: inline-block;
    margin-right: 20px;
}

.menu a {
    text-decoration: none;
    color: #2563eb;
}

.menu a:hover {
    color: #dc2626;
}

20. List Hover Effect

CSS hover effects can make list items interactive. 

li {
    padding: 10px;
    transition: 0.3s;
}

li:hover {
    background-color: #eff6ff;
    padding-left: 20px;
}

21. CSS List Properties Summary

Property Purpose

list-style-position Controls marker position
list-style-image Uses an image as the marker
list-style Shorthand for list properties
margin Controls outside spacing
padding Controls inside spacing
display Controls list item layout

23. Key Points

  • Use list-style: none; to remove default markers.
