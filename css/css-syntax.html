Learn the basic syntax of CSS

What is CSS Syntax?

CSS syntax defines how CSS rules are written. A CSS rule contains a selector and a declaration block.

Basic CSS Syntax

selector {
    property: value;
}

Example: 

p {
    color: blue;
    font-size: 20px;
}

CSS Selector

The selector selects the HTML element that you want to style. 

h1 {
    color: red;
}

CSS Property

A property defines what style you want to change. 

color
font-size
background-color
margin
padding

CSS Value

A value specifies the setting for a CSS property. 

color: blue;
font-size: 20px;
