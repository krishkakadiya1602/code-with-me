CSS Syntax

Learn the basic structure of CSS, including selectors, properties, values and declarations.

What is CSS Syntax?

CSS syntax is the set of rules that defines how CSS code is written. Every CSS rule follows a specific structure.

A CSS rule usually contains a selector, one or more properties, and their values.

Basic CSS Syntax:

selector { property: value; }

For example, if we want to make all paragraph text blue, we can write:

CSS Example 
p {
    color: blue;
}

CSS Syntax Structure

The basic structure of a CSS rule looks like this:

selector { property : value ; }

Example

CSS 
h1 {
    color: blue;
}

In this example:

  • h1 is the selector.
  • color is the property.
  • blue is the value.
  • The entire color: blue; is a declaration.

1. CSS Selector

A selector identifies the HTML element that you want to style.

For example:

CSS 
p {
    color: red;
}

Here, p is the selector. It selects all paragraph elements.

Common Selectors

  • Element selector: p
  • Class selector: .box
  • ID selector: #header
  • Universal selector: *

2. CSS Property

A property specifies what aspect of an HTML element you want to change.

Examples of CSS properties include:

  • color
  • background-color
  • font-size
  • margin
  • padding
  • width
  • height
  • border
Example 
h1 {
    color: blue;
}

In this example, color is the property.

3. CSS Value

A value defines what the property should be set to.

Example 
h1 {
    color: blue;
}

Here:

  • Property = color
  • Value = blue

Different properties can have different types of values.

More Examples 
p {
    color: red;
    font-size: 20px;
}

.box {
    width: 300px;
    height: 200px;
}

body {
    background-color: lightgray;
}

4. CSS Declaration

A CSS declaration consists of a property and its value.

property : value ;

Example: 

color: blue;

This is one CSS declaration.

Tip: Always put a colon : between the property and value, and normally finish the declaration with a semicolon ;.

5. CSS Declaration Block

A declaration block contains one or more CSS declarations inside curly braces { }.

Example 
p {
    color: blue;
    font-size: 18px;
    line-height: 1.6;
}

The declarations inside this block are:

  • color: blue;
  • font-size: 18px;
  • line-height: 1.6;

Multiple CSS Properties

You can use multiple properties inside one CSS rule.

CSS 
h1 {
    color: blue;
    font-size: 40px;
    text-align: center;
    background-color: lightgray;
}

This example changes four things about the heading:

  • Text color
  • Font size
  • Text alignment
  • Background color

CSS Class Syntax

A class selector starts with a period ..

HTML 
<p class="text">
    Hello CSS
</p>
CSS 
.text {
    color: blue;
    font-size: 20px;
}

The CSS rule applies to the HTML element having the class text.

CSS ID Syntax

An ID selector starts with a hash symbol #.

HTML 
<h1 id="title">
    Welcome
</h1>
CSS 
#title {
    color: green;
    font-size: 35px;
}

Universal Selector

The universal selector * selects all HTML elements. 

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

This technique is commonly used as a CSS reset.

Grouping Selectors

You can apply the same CSS rules to multiple selectors by separating them with commas. 

h1,
h2,
p {
    color: blue;
}

The same color will be applied to h1, h2 and p elements.

CSS Comments

Comments are used to explain CSS code. They are ignored by the browser. 

/* This is a CSS comment */

p {
    color: blue;
}

CSS comments begin with /* and end with */.

Common CSS Syntax Errors

Beginners often make small syntax mistakes. Here are some common examples.

Missing Colon 

p {
    color blue;
}

Correct version: 

p {
    color: blue;
}

Missing Semicolon

Although the last declaration can sometimes work without a semicolon, it is good practice to use semicolons. 

p {
    color: blue;
    font-size: 18px;
}

Missing Curly Braces

CSS declarations must normally be inside curly braces. 

p {
    color: blue;
}
Remember: CSS is sensitive to correct syntax. Check your selector, colon, value, semicolon and curly braces when something does not work.

CSS Syntax Summary

Part Example Meaning
Selector p Selects the HTML element.
Property color Defines what to change.
Value blue Defines the setting.
Declaration color: blue; Property and value together.
Declaration Block { color: blue; } Contains CSS declarations.

Key Points to Remember

  • CSS rules contain selectors and declaration blocks.
  • A declaration contains a property and a value.
  • Use a colon between a property and its value.
  • Use a semicolon to separate declarations.
  • Use curly braces to contain declarations.
  • Class selectors start with ..
  • ID selectors start with #.
  • The universal selector is *.
  • CSS comments use /* */.
