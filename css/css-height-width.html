CSS Height and Width

Learn how to control the height and width of HTML elements using CSS.

1. What are CSS Height and Width?

The CSS height and width properties are used to control the size of HTML elements.

The width property controls how wide an element is, while the height property controls how tall an element is.

Example:
You can use CSS to make a box 300 pixels wide and 200 pixels high.

2. CSS Width Property

The width property sets the width of an element.

Example: 
.box {
    width: 300px;
}

In this example, the element will have a width of 300 pixels.

3. CSS Height Property

The height property sets the height of an element.

Example: 
.box {
    height: 200px;
}

The element will have a height of 200 pixels.

4. Using Height and Width Together

You can use both properties at the same time. 

.box {
    width: 300px;
    height: 200px;
    background-color: lightblue;
}
The element will be 300px wide and 200px high.

5. Height and Width in Pixels

Pixels (px) are one of the most commonly used CSS units. 

.box {
    width: 400px;
    height: 250px;
}

Pixels provide a fixed size.

6. Height and Width Using Percentage

You can use percentages to make an element relative to its parent element. 

.box {
    width: 50%;
    height: 50%;
}
50% width means the element will take approximately half of its parent's available width.

7. CSS max-width

The max-width property defines the maximum width an element can have. 

.container {
    width: 100%;
    max-width: 1000px;
}

This is very useful for creating responsive websites.

8. CSS min-width

The min-width property defines the minimum width of an element. 

.box {
    min-width: 200px;
}

The element will not become smaller than 200px.

9. CSS max-height

The max-height property defines the maximum height of an element. 

.box {
    max-height: 300px;
}

The element will not become taller than 300px.

10. CSS min-height

The min-height property defines the minimum height of an element. 

.box {
    min-height: 200px;
}

The element will always have at least 200px of height.

11. CSS auto Value

The auto value allows the browser to automatically calculate the size. 

.box {
    width: auto;
    height: auto;
}
Tip:
The default value for height and width depends on the element and its display behavior.

12. Viewport Units

CSS also provides viewport units for responsive sizing.

vw

vw means viewport width. 

.box {
    width: 50vw;
}

vh

vh means viewport height. 

.box {
    height: 50vh;
}
1vw = 1% of viewport width.
1vh = 1% of viewport height.

13. Common CSS Size Units

Unit Meaning Example
px Pixels width: 300px;
% Percentage of parent width: 50%;
em Relative to font size width: 20em;
rem Relative to root font size width: 20rem;
vw Viewport width width: 50vw;
vh Viewport height height: 50vh;

14. Height, Width and box-sizing

The box-sizing property controls how the total width and height of an element are calculated. 

* {
    box-sizing: border-box;
}

With border-box, padding and border are included inside the specified width and height.

Recommended:
Many modern websites use box-sizing: border-box; for easier layout control.

15. Width vs Height

Property Purpose Example
width Controls horizontal size width: 300px;
height Controls vertical size height: 200px;
min-width Sets minimum width min-width: 200px;
max-width Sets maximum width max-width: 1000px;
min-height Sets minimum height min-height: 200px;
max-height Sets maximum height max-height: 500px;

17. Key Points to Remember

  • width controls the horizontal size of an element.
  • height controls the vertical size of an element.
  • min-width defines the minimum width.
  • max-width defines the maximum width.
  • min-height defines the minimum height.
  • max-height defines the maximum height.
  • You can use units such as px, %, em, rem, vw and vh.
  • max-width is very useful for responsive websites.
  • box-sizing: border-box makes width and height easier to control.
