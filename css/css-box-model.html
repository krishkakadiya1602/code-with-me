CSS Box Model

Understand content, padding, border and margin

Introduction to CSS Box Model

Every HTML element on a webpage is treated as a rectangular box by CSS.

This is called the CSS Box Model. It describes how the size and spacing of an element are calculated.

The CSS Box Model contains four parts:

1. Content
2. Padding
3. Border
4. Margin

1. CSS Box Model Diagram

The following example shows the four layers of the CSS Box Model.

2. Content

Content is the actual information inside an HTML element.

Content can be text, images, videos, buttons or other HTML elements. 

div {
    width: 300px;
    height: 150px;
}
This is the content area.

3. Padding

Padding is the space between the content and the border. 

div {
    padding: 20px;
}
Content with 30px padding

4. Border

The border surrounds the padding and content. 

div {
    border: 5px solid blue;
}
Content + Padding + Border

5. Margin

Margin is the space outside the border of an element. 

div {
    margin: 30px;
}
This element has margin.

6. Box Model Size Calculation

With the default content-box model, the total width of an element can include: 

Total Width =
Content Width
+ Left Padding
+ Right Padding
+ Left Border
+ Right Border
+ Left Margin
+ Right Margin

For example: 

width: 300px;
padding-left: 20px;
padding-right: 20px;
border-left: 5px;
border-right: 5px;

The content width is 300px, while padding and border add additional space to the overall size when using content-box.

7. box-sizing Property

The box-sizing property controls how the width and height of an element are calculated.

content-box

box-sizing: content-box;

This is the default CSS behavior. The declared width applies to the content area.

Content-box

border-box

box-sizing: border-box;

With border-box, the declared width includes content, padding and border.

Border-box

8. Recommended Box-Sizing Rule

A commonly used CSS rule is: 

* {
    box-sizing: border-box;
}

This makes sizing easier to manage because the declared width and height include padding and border.

Tip: Many modern websites use box-sizing: border-box for predictable layouts.

9. Important Box Model Properties

Property Purpose
width Controls the width of the element
height Controls the height of the element
padding Creates space inside the element
border Creates a boundary around the element
margin Creates space outside the element
box-sizing Controls how width and height are calculated

10. Padding vs Margin

Padding Margin
Space inside the border Space outside the border
Part of the element's box Separates the element from other elements
Can have background color Does not belong to the content area

CSS Box Model - Key Points

  • Every HTML element is treated as a box.
  • The CSS Box Model contains content, padding, border and margin.
  • Padding creates space inside the border.
  • Margin creates space outside the border.
  • Border surrounds the content and padding.
  • The box-sizing property controls how element dimensions are calculated.
  • border-box includes padding and border within the declared width and height.
  • Understanding the Box Model is important for creating accurate CSS layouts.
