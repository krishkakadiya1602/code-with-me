CSS Colors

Learn how to use colors in CSS

Introduction to CSS Colors

Colors are an important part of web design. CSS allows you to change the color of text, backgrounds, borders and many other elements.

CSS provides several different ways to specify colors, including color names, HEX values, RGB, RGBA, HSL and HSLA.

Remember: CSS colors can be used with properties such as color, background-color and border-color.

1. CSS Color Names

CSS supports many predefined color names.

For example: 

p {
    color: red;
}

h1 {
    color: blue;
}

div {
    background-color: green;
}

Common Color Names

Red
Blue
Green
Orange
Purple
Black

2. HEX Colors

HEX stands for hexadecimal. HEX colors start with a # symbol.

A HEX color normally contains six hexadecimal characters. 

h1 {
    color: #ff0000;
}

p {
    color: #0000ff;
}

div {
    background-color: #00ff00;
}
Example:
#ff0000 = Red
#00ff00 = Green
#0000ff = Blue
#000000 = Black
#ffffff = White

3. RGB Colors

RGB means Red, Green and Blue.

RGB uses three values between 0 and 255. 

p {
    color: rgb(255, 0, 0);
}

h2 {
    color: rgb(0, 0, 255);
}

div {
    background-color: rgb(0, 255, 0);
}
RGB Value Color
rgb(255, 0, 0) Red
rgb(0, 255, 0) Green
rgb(0, 0, 255) Blue
rgb(0, 0, 0) Black
rgb(255, 255, 255) White

4. RGBA Colors

RGBA is an extension of RGB. The A stands for Alpha.

Alpha controls the transparency of a color. Its value can range from 0 to 1. 

div {
    background-color: rgba(255, 0, 0, 0.5);
}

In the example above, the red color has 50% transparency.

5. HSL Colors

HSL stands for Hue, Saturation and Lightness. 

h1 {
    color: hsl(0, 100%, 50%);
}

p {
    color: hsl(240, 100%, 50%);
}

HSL Components

Component Meaning
Hue The color itself
Saturation Intensity of the color
Lightness Brightness of the color

6. HSLA Colors

HSLA is similar to HSL but also includes an Alpha value for transparency. 

div {
    background-color: hsla(240, 100%, 50%, 0.5);
}

The last value controls the transparency.

7. CSS Color Properties

Colors can be applied to different CSS properties. 

/* Text color */

p {
    color: blue;
}


/* Background color */

body {
    background-color: lightgray;
}


/* Border color */

div {
    border: 2px solid red;
}

CSS Colors - Key Points

  • CSS supports many predefined color names.
  • HEX colors start with #.
  • RGB uses Red, Green and Blue values.
  • RGBA adds transparency to RGB.
  • HSL uses Hue, Saturation and Lightness.
  • HSLA adds transparency to HSL.
  • Colors can be used for text, backgrounds and borders.
