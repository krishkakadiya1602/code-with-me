CSS Icons

Learn how to add and style icons using CSS and Font Awesome.

1. What are CSS Icons?

Icons are small graphical symbols used to represent actions, objects or information on a website.

Examples include home, search, user, heart, email, phone and social media icons.

CSS can be used to control the size, color, spacing and position of icons.

2. Using Font Awesome Icons

Font Awesome is a popular icon library that provides thousands of icons.

Add the Font Awesome CSS file inside the <head> section: 

<link rel="stylesheet"
href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css">

Then use an icon with an <i> element: 

<i class="fa-solid fa-house"></i>

3. Changing Icon Size

You can change the size of an icon using the CSS font-size property. 

.icon {
    font-size: 40px;
}

4. Changing Icon Color

Use the CSS color property to change an icon's color. 

.icon {
    color: blue;
}

5. Adding Space Between Icons

You can use margin to create space between icons. 

.icon {
    margin-right: 15px;
}

6. Icons Inside Buttons

Icons can be combined with text inside buttons. 

<button>
    <i class="fa-solid fa-download"></i>
    Download
</button>

7. Icons Inside Links

Icons can also be used with navigation links. 

<a href="#">
    <i class="fa-solid fa-house"></i>
    Home
</a>

10. Icon Hover Effect

CSS pseudo-classes such as :hover can be used to change an icon when the user moves the mouse over it. 

.icon {
    color: gray;
    font-size: 40px;
}

.icon:hover {
    color: blue;
}

11. Animated Icons

Font Awesome provides animation classes such as spinning icons. 

<i class="fa-solid fa-spinner fa-spin"></i>

<i class="fa-solid fa-house fa-sm"></i>

<i class="fa-solid fa-house fa-lg"></i>

<i class="fa-solid fa-house fa-2x"></i>

<i class="fa-solid fa-house fa-3x"></i>

13. Accessibility and Icons

When an icon communicates important information, make sure its meaning is available to users who cannot see the icon.

For decorative icons, you can use aria-hidden="true". 

<i class="fa-solid fa-house"
   aria-hidden="true">
</i>
Best Practice:
Do not rely only on an icon to communicate an important action. Add text or an accessible label when appropriate.

15. Key Points to Remember

  • Icons can make websites easier to understand and navigate.
  • Font Awesome provides a large collection of icons.
  • Use font-size to change icon size.
  • Use color to change icon color.
  • Use margin to add space between icons.
  • Icons can be placed inside buttons and links.
  • CSS :hover can create interactive icon effects.
  • Font Awesome supports animated icons.
  • Use accessible labels or text when an icon represents an important action.
