CSS Introduction

Learn the basics of CSS and start styling your websites.

What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to style and design web pages. It controls the appearance of HTML elements such as colors, fonts, spacing, borders, layouts, and backgrounds.

Important: HTML is used to create the structure of a webpage, while CSS is used to make that webpage beautiful and attractive.

Why Do We Use CSS?

CSS helps us control the visual appearance of HTML documents.

  • Change text colors
  • Change background colors
  • Change font size and font style
  • Add borders
  • Add margins and padding
  • Create responsive layouts
  • Create attractive websites

Simple CSS Example

Here is a simple example of CSS: 

<!DOCTYPE html>
<html>

<head>

<style>

h1 {
    color: blue;
}

p {
    font-size: 20px;
}

</style>

</head>

<body>

<h1>Hello CSS</h1>

<p>CSS makes websites beautiful.</p>

</body>

</html>

CSS Syntax

A CSS rule contains a selector, property, and value. 

selector {
    property: value;
}

Example 

p {
    color: red;
    font-size: 20px;
}

In this example, p is the selector, color and font-size are properties, and red and 20px are values.

Ways to Add CSS

There are three common ways to add CSS to an HTML document.

1. Inline CSS 

<p style="color: red;">
    Hello World
</p>

2. Internal CSS 

<style>

p {
    color: blue;
}

</style>

3. External CSS 

<link rel="stylesheet" href="style.css">

Benefits of CSS

  • Saves time
  • Makes websites attractive
  • Allows reusable styles
  • Makes website maintenance easier
  • Supports responsive design
  • Separates content from presentation
