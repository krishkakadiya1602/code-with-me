CSS Introduction

Learn what CSS is, why we use it, how CSS works and how to style HTML pages.

What is CSS?

CSS stands for Cascading Style Sheets.

CSS is a stylesheet language used to describe how HTML elements should look on a web page.

With CSS, we can control colors, fonts, spacing, borders, backgrounds, layouts, animations and responsive designs.

Main Points

  • CSS stands for Cascading Style Sheets.
  • CSS is used to style HTML elements.
  • CSS can change colors and fonts.
  • CSS can control spacing and sizing.
  • CSS can create page layouts.
  • CSS can make websites responsive.
  • CSS can add visual effects and animations.

Why Do We Use CSS?

HTML is mainly used to create the structure of a web page.

CSS is used to make that structure beautiful and visually attractive.

Example

Without CSS: 

<h1>Welcome to My Website</h1>
<p>This is my website.</p>

With CSS we can change the color, size, font and alignment of these elements.

CSS Syntax

A CSS rule consists of a selector, property and value. 

selector {
    property: value;
}

Example 

p {
    color: blue;
    font-size: 20px;
}

In this example, p is the selector.

color and font-size are properties.

blue and 20px are their values.

Simple CSS Example 

<!DOCTYPE html>
<html>

<head>

<style>

h1 {
    color: blue;
    text-align: center;
}

p {
    color: green;
    font-size: 18px;
}

</style>

</head>

<body>

<h1>Hello CSS!</h1>

<p>
    I am learning CSS.
</p>

</body>

</html>

Ways to Add CSS

1. Inline CSS 

<p style="color: red;">
    Hello World
</p>

2. Internal CSS 

<style>

p {
    color: red;
}

</style>

3. External CSS 

<link rel="stylesheet"
      href="style.css">
