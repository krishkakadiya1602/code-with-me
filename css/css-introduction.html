```
CSS Introduction

Learn how CSS is used to style and design web pages.

```
```

What is CSS?

CSS stands for Cascading Style Sheets. CSS is used to style and design HTML web pages.

HTML creates the structure of a webpage, while CSS controls how that webpage looks.

Example:

HTML can create a heading, while CSS can change its color, size, font, background and position.

```
```

Why Do We Use CSS?

CSS makes websites attractive, readable and responsive.

  • Change text colors
  • Change font sizes
  • Add backgrounds
  • Create layouts
  • Add spacing and borders
  • Design buttons
  • Create responsive websites
  • Create animations and visual effects
```
```

HTML vs CSS

HTML and CSS work together, but they have different purposes.

HTML: Creates the structure of the webpage.

CSS: Styles and designs the webpage.

```
```

CSS Syntax

A basic CSS rule contains a selector, property and value. 

selector {
property: value;
```

}
```

Example

p {
color: blue;
font-size: 20px;
```

}
```

In this example, p is the selector, color and font-size are properties, and blue and 20px are their values.

```
```

Three Ways to Add CSS

1. Inline CSS

Inline CSS is written directly inside an HTML element. 

<p style="color: red;">
Hello World
```
```

2. Internal CSS

Internal CSS is written inside the <style> element. 

<style>
```

p {
color: blue;
}
```

3. External CSS

External CSS is stored in a separate CSS file. 

<link rel="stylesheet" href="style.css">
```
```

CSS Selectors

Selectors are used to select HTML elements that we want to style.

Element Selector

p {
color: green;
```

}
```

Class Selector

.title {
color: red;
```

}
```

ID Selector

#heading {
color: blue;
```

}
```

CSS Properties

CSS properties control different visual aspects of an HTML element.

  • color - Changes text color
  • background-color - Changes background color
  • font-size - Changes text size
  • font-family - Changes the font
  • margin - Creates outside spacing
  • padding - Creates inside spacing
  • border - Adds a border
  • width - Controls width
  • height - Controls height
```
