CSS Overflow

Learn how to control content that is too large for an element

1. What is CSS Overflow?

The CSS overflow property controls what happens when content is too large to fit inside an element.

Overflow commonly occurs when an element has a fixed width or height and its content is larger than the available space. 

.box {
    overflow: value;
}
Important: The overflow property is especially useful for containers, long text, tables, images, and responsive layouts.

2. CSS Overflow Values

Value Description
visible Content is displayed outside the element
hidden Extra content is clipped
scroll Scrollbars are provided
auto Scrollbars appear when necessary

3. overflow: visible

visible is the default overflow value. Content can extend outside the element. 

.box {
    overflow: visible;
}
This content is wider than the parent container. Because overflow is set to visible, the content can extend outside the parent element.
With overflow: visible, content may overlap other elements.

4. overflow: hidden

The hidden value clips content that extends outside the element. 

.box {
    overflow: hidden;
}
This content is larger than the parent container. The extra content is hidden because overflow is set to hidden.
Use case: overflow: hidden is often used to prevent content from escaping a container.

5. overflow: scroll

The scroll value adds scrollbars so users can view the overflowing content. 

.box {
    overflow: scroll;
}
This content is larger than the container. Use the scrollbars to view the complete content.

6. overflow: auto

The auto value adds scrollbars only when they are needed. 

.box {
    overflow: auto;
}
This content is wider than the parent element. Because overflow is auto, a scrollbar appears when necessary.
Tip: overflow: auto is commonly useful for responsive containers.

7. overflow-x

The overflow-x property controls horizontal overflow. 

.box {
    overflow-x: auto;
}

For example, a wide table can be placed inside a horizontally scrollable container.

This is a wide content area. Scroll horizontally to see all the content. This technique is useful for responsive tables.

9. overflow-x and overflow-y Together

You can control horizontal and vertical overflow separately. 

.box {
    overflow-x: auto;
    overflow-y: hidden;
}

This is useful when you want horizontal scrolling but don't want vertical scrolling.

10. Overflow Shorthand

You can specify different overflow values for the horizontal and vertical directions. 

.box {
    overflow: hidden auto;
}

In this example:

  • The first value controls horizontal overflow.
  • The second value controls vertical overflow.

11. text-overflow

The text-overflow property controls how text that does not fit inside a container is displayed. 

.text {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}
This is a very long line of text that does not fit inside the container.
Ellipsis: The ... indicates that some text has been hidden.

12. white-space and Overflow

The white-space property can be combined with overflow to control long text. 

.text {
    white-space: nowrap;
    overflow: hidden;
}

nowrap prevents the text from wrapping to a new line.

13. Overflow with Images

Large images can cause horizontal overflow on small screens. 

img {
    max-width: 100%;
    height: auto;
}
Responsive Tip: Using max-width: 100% helps prevent images from becoming wider than their containers.

14. Overflow with Tables

Wide tables can create horizontal scrolling on small screens. 

.table-container {
    overflow-x: auto;
}

15. Overflow and Child Elements

Overflow can affect how child elements that extend outside their parent are displayed. 

.parent {
    width: 300px;
    height: 150px;
    overflow: hidden;
}

This is commonly useful for cards, image containers, and components with fixed dimensions.

16. Practical Card Example

Here is an example of using overflow with a card. 

.card {
    width: 300px;
    height: 150px;
    overflow: auto;
    padding: 20px;
    border: 2px solid #2563eb;
}

17. Overflow Values Comparison

Value Overflow Content Scrollbar
visible Shown outside No
hidden Clipped No
scroll Available by scrolling Yes
auto Available when necessary When needed

18. Common Uses of CSS Overflow

  • Scrollable containers
  • Responsive tables
  • Long text containers
  • Image galleries
  • Cards with fixed dimensions
  • Navigation areas
  • Preventing content from overflowing
  • Mobile-friendly layouts

19. CSS Overflow Properties Summary

Property Purpose
overflow Controls overflow in both directions
overflow-x Controls horizontal overflow
overflow-y Controls vertical overflow
text-overflow Controls overflowing text
white-space Controls how whitespace and wrapping work

21. Key Points

  • The overflow property controls content that is larger than its container.
  • visible allows content to extend outside the element.
  • hidden clips overflowing content.
  • scroll provides scrollbars.
  • auto provides scrollbars when necessary.
  • overflow-x controls horizontal overflow.
  • overflow-y controls vertical overflow.
  • text-overflow can display an ellipsis for overflowing text.
  • Overflow is very useful for responsive websites.
