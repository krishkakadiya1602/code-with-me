CSS Grid

Learn how to create powerful two-dimensional layouts using CSS Grid.

1. What is CSS Grid?

CSS Grid is a powerful CSS layout system used to create rows and columns on a web page.

Grid makes it easy to create complex and responsive website layouts without using floats or complicated positioning.

Important: CSS Grid is a two-dimensional layout system because it can control both rows and columns.

2. CSS Grid Container

To create a grid, first set the display property to grid. 

.container {
    display: grid;
}

The element with display: grid becomes the grid container.

3. Grid Columns

The grid-template-columns property defines the number and size of columns. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
}

The fr unit represents a fraction of the available space.

4. Using repeat()

The repeat() function allows you to create multiple columns easily. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}
Tip: repeat(3, 1fr) means three equal columns.

7. Grid Rows

The grid-template-rows property defines the size of rows. 

.container {
    display: grid;
    grid-template-rows: 100px 200px;
}

8. CSS Grid Gap

The gap property creates space between rows and columns. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

9. CSS Grid Lines

Grid items can be positioned using grid lines. 

.item {
    grid-column: 1 / 3;
}

This makes the item occupy columns from line 1 to line 3.

10. Grid Column Span

The span keyword allows an item to occupy multiple columns. 

.item {
    grid-column: span 2;
}

11. Grid Row Span

The grid-row property can be used to make an item occupy multiple rows. 

.item {
    grid-row: span 2;
}

12. CSS Grid Template Areas

grid-template-areas allows you to create named areas for your layout. 

.container {
    display: grid;

    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}

Then assign areas to individual elements: 

.header {
    grid-area: header;
}

.sidebar {
    grid-area: sidebar;
}

.main {
    grid-area: main;
}

.footer {
    grid-area: footer;

13. Auto Grid Columns

The auto value allows the browser to determine the size automatically. 

.container {
    display: grid;
    grid-template-columns: auto auto auto;
}

14. The fr Unit

The fr unit represents a fraction of the available space. 

.container {
    display: grid;
    grid-template-columns: 1fr 2fr;
}

In this example, the second column gets twice as much space as the first column.

15. minmax()

The minmax() function defines a minimum and maximum size for a grid track. 

.container {
    display: grid;
    grid-template-columns:
        repeat(3, minmax(150px, 1fr));
}

16. Responsive CSS Grid

CSS Grid can automatically create responsive layouts using auto-fit and minmax(). 

.container {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(200px, 1fr));

    gap: 20px;
}
This technique is commonly used for responsive cards, product grids, image galleries and dashboard layouts.

17. Aligning Grid Items

justify-items

.container {
    justify-items: center;
}

align-items

.container {
    align-items: center;
}

place-items

.container {
    place-items: center;
}

18. justify-content

The justify-content property controls the horizontal position of the entire grid. 

.container {
    justify-content: center;
}

Common values:

  • start
  • end
  • center
  • space-between
  • space-around
  • space-evenly

19. align-content

The align-content property controls the vertical position of the entire grid. 

.container {
    align-content: center;
}

20. CSS Grid vs Flexbox

CSS Grid Flexbox
Two-dimensional layout One-dimensional layout
Rows and columns Row or column
Useful for page layouts Useful for component layouts
Controls both dimensions Primarily controls one dimension

22. CSS Grid Properties

Property Purpose
display: grid Creates a grid container
grid-template-columns Defines columns
grid-template-rows Defines rows
gap Creates space between grid items
grid-column Controls column position
grid-row Controls row position
grid-area Assigns an item to a named area
grid-template-areas Creates named layout areas
justify-items Aligns items horizontally
align-items Aligns items vertically
justify-content Aligns the complete grid horizontally
align-content Aligns the complete grid vertically

24. Key Points

  • CSS Grid is a two-dimensional layout system.
  • Use display: grid to create a grid container.
  • Use grid-template-columns to create columns.
  • Use grid-template-rows to create rows.
  • Use gap to add space between grid items.
  • Use grid-column and grid-row to position items.
  • Use grid-template-areas for named layouts.
  • Use auto-fit and minmax() for responsive grids.
