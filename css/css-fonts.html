CSS Fonts

Learn how to style text using CSS font properties.

1. What are CSS Fonts?

CSS fonts are used to control the appearance of text on a web page.

You can use CSS to change the font family, font size, font style, font weight and other font properties.

Common CSS Font Properties:
  • font-family
  • font-size
  • font-style
  • font-weight
  • font-variant
  • font-stretch
  • font

2. CSS font-family

The font-family property specifies the font used for text. 

body {
    font-family: Arial, sans-serif;
}

This text uses Arial.

Font Family Example

h1 {
    font-family: Georgia, serif;
}

p {
    font-family: Arial, sans-serif;
}
It is a good practice to provide a fallback font after the main font.

3. Serif Fonts

Serif fonts have small decorative strokes at the ends of letters. 

p {
    font-family: Georgia, serif;
}

This is an example of a serif font.

4. Sans-serif Fonts

Sans-serif fonts do not have decorative strokes. They are commonly used for websites. 

p {
    font-family: Arial, sans-serif;
}

This is an example of a sans-serif font.

5. Monospace Fonts

In a monospace font, every character has approximately the same width. 

code {
    font-family: "Courier New", monospace;
}

This is a monospace font.

6. CSS font-size

The font-size property controls the size of text. 

h1 {
    font-size: 40px;
}

p {
    font-size: 18px;
}

Large Heading

This paragraph has an 18px font size.

Common font-size units include px, em, rem, %, vw and more.

7. CSS font-style

The font-style property specifies whether text should be normal, italic or oblique. 

p {
    font-style: italic;
}

This text is italic.

Common Values

  • normal — normal text
  • italic — italic text
  • oblique — slanted text

8. CSS font-weight

The font-weight property controls how thick or bold the text appears. 

h1 {
    font-weight: bold;
}

p {
    font-weight: 400;
}

Common Values

Value Description
normal Normal font weight
bold Bold text
100 - 900 Specific font weight

This text uses font-weight: 700.

9. CSS font-variant

The font-variant property can be used to display text using small capital letters. 

p {
    font-variant: small-caps;
}

This text uses small caps.

10. CSS font-stretch

The font-stretch property controls whether a supported font appears narrower or wider. 

p {
    font-stretch: expanded;
}
Note:
The effect depends on whether the selected font contains the required width variations.

11. Using Google Fonts

Google Fonts provides many free web fonts that can be used on websites.

First, add the Google Fonts stylesheet inside the <head> section. 

<link
    href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap"
    rel="stylesheet">

Then use the font in CSS: 

body {
    font-family: "Poppins", sans-serif;
}

This text uses the Poppins Google Font.

12. CSS Font Fallbacks

It is useful to provide multiple fonts so the browser can use another font if the first one is unavailable. 

body {
    font-family: Arial, Helvetica, sans-serif;
}

The browser tries the fonts from left to right.

Best Practice:
Always include a generic font family such as serif, sans-serif or monospace as a fallback.

13. CSS font Shorthand

The font property can combine several font properties into one declaration. 

p {
    font: italic bold 18px Arial, sans-serif;
}

This example combines:

  • font-style
  • font-weight
  • font-size
  • font-family
The font-size and font-family values are important parts of the shorthand syntax.

14. Responsive Font Size

You can use viewport units to make font sizes responsive. 

h1 {
    font-size: 5vw;
}

The font size changes according to the width of the browser window.

Using clamp()

h1 {
    font-size: clamp(28px, 5vw, 60px);
}
clamp() allows you to define a minimum, preferred and maximum font size.

15. CSS Font Properties Summary

Property Purpose Example
font-family Sets the font type font-family: Arial;
font-size Sets text size font-size: 20px;
font-style Sets normal or italic style font-style: italic;
font-weight Controls thickness font-weight: bold;
font-variant Controls font variation font-variant: small-caps;
font-stretch Controls font width font-stretch: expanded;
font Shorthand for font properties font: bold 20px Arial;

17. Key Points to Remember

  • Use font-family to choose a font.
  • Use font-size to change text size.
  • Use font-style for italic or oblique text.
  • Use font-weight to control text thickness.
  • Use font-variant for font variations such as small caps.
  • Use font-stretch when the selected font supports different widths.
  • Use Google Fonts to add additional web fonts.
  • Use fallback fonts to improve compatibility.
  • Use clamp() for responsive font sizes.
  • The font property can combine several font properties.
