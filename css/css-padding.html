CSS Padding

Learn how to create space inside HTML elements

Introduction to CSS Padding

Padding is the space between an element's content and its border.

You can use padding to create more space around text, images, buttons, cards and other HTML elements.

Important: Padding creates space inside an element, while margin creates space outside an element.

1. Basic CSS Padding

The padding property is used to add space inside an element. 

div {
    padding: 20px;
}
This box has 30px padding.

2. Different Padding Values

Increasing the padding value creates more space between the content and the border.

Small Padding - 10px
Medium Padding - 30px
Large Padding - 50px 
.small {
    padding: 10px;
}

.medium {
    padding: 30px;
}

.large {
    padding: 50px;
}

3. Padding for Individual Sides

CSS allows you to set padding separately for the top, right, bottom and left sides. 

div {
    padding-top: 40px;
    padding-right: 20px;
    padding-bottom: 40px;
    padding-left: 60px;
}
Different padding on each side.

4. Padding Shorthand

The padding shorthand property can define all four sides in one line.

One Value

padding: 20px;

All four sides receive 20px padding.

Two Values

padding: 20px 40px;

The first value applies to top and bottom. The second value applies to left and right.

Three Values

padding: 10px 20px 30px;

The values apply to:

  • Top = 10px
  • Left and Right = 20px
  • Bottom = 30px

Four Values

padding: 10px 20px 30px 40px;

The values apply clockwise:

  • Top = 10px
  • Right = 20px
  • Bottom = 30px
  • Left = 40px

5. Padding with Border

Padding creates space between the content and the border. 

div {
    padding: 30px;
    border: 4px solid blue;
}
Content

6. Padding and Width

Padding can affect the total size of an element. The box-sizing property can be used to control this behavior.

Content Box

.box {
    box-sizing: content-box;
    width: 300px;
    padding: 30px;
    border: 5px solid blue;
}
Content-box example

Border Box

.box {
    box-sizing: border-box;
    width: 300px;
    padding: 30px;
    border: 5px solid purple;
}
Border-box example

7. Padding Units

Padding can be specified using different CSS units.

Unit Example Description
px padding: 20px; Fixed pixel size
% padding: 5%; Percentage-based padding
em padding: 2em; Relative to font size
rem padding: 2rem; Relative to root font size

8. CSS Padding Properties

Property Purpose
padding Sets padding on all sides
padding-top Sets top padding
padding-right Sets right padding
padding-bottom Sets bottom padding
padding-left Sets left padding

CSS Padding - Key Points

  • Padding creates space inside an element.
  • The padding property sets padding on all four sides.
  • You can use padding-top, padding-right, padding-bottom and padding-left separately.
  • Padding shorthand can set multiple sides in one declaration.
  • Padding can be combined with borders.
  • Padding can affect the total size of an element.
  • box-sizing: border-box helps keep the declared width inclusive of padding and border.
  • Padding does not accept negative values.
