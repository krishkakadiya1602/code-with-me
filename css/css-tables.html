CSS Tables

Learn how to style HTML tables using CSS

Introduction to CSS Tables

HTML tables are used to display information in rows and columns.

CSS can be used to make tables more attractive and easier to read.

Common CSS table properties:

border
border-collapse
width
padding
text-align
vertical-align
background-color
border-spacing
table-layout

1. Basic CSS Table

You can use CSS to add borders and spacing to an HTML table. 

table {
    width: 100%;
    border-collapse: collapse;
}

th,
td {
    border: 1px solid black;
    padding: 10px;
}

2. Border Collapse

The border-collapse property controls whether table borders are separated or collapsed into one border. 

table {
    border-collapse: collapse;
}

3. Table Width

The width property controls the width of a table. 

table {
    width: 100%;
}

Using 100% makes the table fill the available width of its container.

4. Table Padding

Padding creates space inside table cells. 

th,
td {
    padding: 15px;
}
Property Example
padding: 5px Small spacing
padding: 15px Medium spacing
padding: 25px Large spacing

5. Table Text Alignment

The text-align property controls the horizontal alignment of text. 

th {
    text-align: center;
}

td {
    text-align: left;
}
Left Center Right
Left aligned Center aligned Right aligned

6. Vertical Alignment

The vertical-align property controls the vertical position of content inside a table cell. 

td {
    vertical-align: middle;
}
Top Middle Bottom
Top aligned Middle aligned Bottom aligned

7. Striped Tables

You can use :nth-child() to create alternating row colors. 

tr:nth-child(even) {
    background-color: #f2f2f2;
}

8. Table Hover Effect

The :hover pseudo-class can highlight a row when the user moves the mouse over it. 

tr:hover {
    background-color: #dbeafe;
}

10. Table Layout

The table-layout property controls how column widths are calculated. 

table {
    table-layout: fixed;
    width: 100%;
}

11. Border Spacing

The border-spacing property controls the distance between table cell borders. 

table {
    border-spacing: 10px;
}
Note:
Border spacing is most useful when border-collapse: separate is being used.

12. Important CSS Table Properties

Property Purpose
border Creates borders around table cells
border-collapse Controls collapsed or separate borders
border-spacing Controls space between cells
width Controls table width
height Controls table height
padding Creates space inside cells
text-align Controls horizontal text alignment
vertical-align Controls vertical alignment
background-color Changes table or cell background
table-layout Controls column layout behavior

13. Responsive Tables

On small screens, wide tables may not fit. A container with overflow-x: auto can allow horizontal scrolling. 

.table-container {
    overflow-x: auto;
}

table {
    width: 100%;
}

CSS Tables - Key Points

  • CSS can make HTML tables more attractive and easier to read.
  • Use border-collapse: collapse to combine table borders.
  • Use padding to create space inside cells.
  • Use text-align for horizontal alignment.
  • Use vertical-align for vertical alignment.
  • :nth-child() can create striped rows.
  • :hover can create interactive row effects.
  • border-spacing controls the space between table cells when borders are separate.
  • table-layout: fixed provides more predictable column sizing.
  • Use overflow-x: auto to make wide tables easier to use on small screens.
