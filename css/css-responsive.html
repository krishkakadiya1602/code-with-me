Introduction to Responsive Web Design

Responsive Web Design means creating websites that automatically adjust their layout and content according to the size of the user's screen.

A responsive website should work properly on mobile phones, tablets, laptops and desktop computers.

Responsive design helps websites:
  • Fit different screen sizes
  • Improve mobile usability
  • Provide better user experience
  • Avoid unnecessary horizontal scrolling
  • Adapt layouts automatically

1. The Viewport

The viewport is the visible area of a webpage inside the browser window.

The following meta tag is important for responsive websites: 

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

It tells the browser to use the device's actual width and set the initial zoom level to 1.

Important: Add the viewport meta tag to responsive HTML pages.

2. CSS Media Queries

Media queries allow you to apply different CSS styles depending on screen size or other device characteristics. 

@media (max-width: 768px) {

    body {
        background: lightblue;
    }

}

The CSS inside this media query applies when the viewport is 768px wide or narrower.

3. max-width

The max-width property prevents an element from becoming wider than a specified size. 

.container {
    width: 100%;
    max-width: 1100px;
    margin: auto;
}
This technique is commonly used for website content containers.

4. Use Percentage Widths

Percentage-based widths allow elements to resize according to the available space. 

.box {
    width: 80%;
}

Compared with a fixed width such as width: 800px, percentages are more flexible on different screens.

5. Responsive Images

Images should not become wider than their container. 

img {
    max-width: 100%;
    height: auto;
}

This allows images to shrink when the screen becomes smaller while maintaining their proportions.

Recommended:
max-width: 100%;
height: auto;

6. Responsive Layout with Flexbox

Flexbox is useful for creating layouts that can automatically adapt to different screen sizes. 

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.card {
    flex: 1 1 250px;
}

7. Responsive Layout with CSS Grid

CSS Grid can create responsive layouts using flexible columns. 

.container {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(200px, 1fr));
    gap: 20px;
}

8. Responsive Breakpoints

Breakpoints are screen sizes where the website layout changes to provide a better experience. 

/* Tablet and smaller */

@media (max-width: 768px) {

    /* CSS here */

}


/* Mobile */

@media (max-width: 480px) {

    /* CSS here */

}

9. Mobile-First Design

Mobile-first design means creating the basic design for small screens first and then adding styles for larger screens. 

/* Mobile styles */

.card {
    width: 100%;
}


/* Larger screens */

@media (min-width: 768px) {

    .card {
        width: 50%;
    }

}
Tip: Mobile-first design can make responsive CSS easier to organize.

10. min-width

The min-width media query applies styles when the viewport is at least the specified width. 

@media (min-width: 768px) {

    .container {
        display: flex;
    }

}

11. max-width Media Query

The max-width media query applies styles when the viewport is at or below a specified width. 

@media (max-width: 768px) {

    .menu {
        display: block;
    }

}

12. Responsive Navigation

A navigation menu can change from a horizontal layout on desktop to a vertical layout on smaller screens. 

.nav {
    display: flex;
    gap: 20px;
}


/* Mobile */

@media (max-width: 600px) {

    .nav {
        flex-direction: column;
    }

}

13. Responsive Tables

Large tables can cause horizontal scrolling on small screens. One solution is to place the table inside a horizontally scrollable container. 

.table-container {
    overflow-x: auto;
}

table {
    min-width: 600px;
}

14. Responsive Text

Text sizes can be adjusted using media queries or flexible CSS units. 

h1 {
    font-size: 40px;
}

@media (max-width: 600px) {

    h1 {
        font-size: 30px;
    }

}

CSS functions such as clamp() can also be useful for fluid text sizing. 

h1 {
    font-size: clamp(28px, 5vw, 50px);
}

15. Fluid Containers

A fluid container can use percentage width while limiting its maximum size. 

.container {
    width: 90%;
    max-width: 1200px;
    margin: auto;
}
This pattern works well for many responsive website layouts.

Common Responsive Design Techniques

  • Use the viewport meta tag.
  • Use flexible widths.
  • Use max-width where appropriate.
  • Make images responsive.
  • Use Flexbox for flexible layouts.
  • Use CSS Grid for responsive grids.
  • Use media queries.
  • Use mobile-first design.
  • Avoid unnecessary fixed widths.
  • Test websites on different screen sizes.
