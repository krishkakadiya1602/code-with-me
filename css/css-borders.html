CSS Borders

Learn how to create and style borders with CSS

Introduction to CSS Borders

CSS borders are used to create a visible boundary around HTML elements.

You can control the border's style, width, color, and rounded corners using CSS properties.

Basic Border Syntax: 
selector {
    border: width style color;
}

1. CSS Border Style

The border-style property defines the style of the border. 

border-style: solid;

Common Border Styles

Solid Border
Dashed Border
Dotted Border
Double Border
Groove Border
Ridge Border
Inset Border
Outset Border

2. CSS Border Width

The border-width property controls the thickness of the border. 

div {
    border-style: solid;
    border-width: 5px;
}

You can use values such as:

  • 1px
  • 2px
  • 5px
  • 10px

3. CSS Border Color

The border-color property sets the color of the border. 

div {
    border-style: solid;
    border-width: 4px;
    border-color: blue;
}

You can use color names, HEX, RGB, RGBA, HSL, and other CSS color formats.

4. CSS Border Shorthand

Instead of writing three separate properties, you can use the border shorthand property. 

div {
    border: 5px solid blue;
}

The order is normally: 

border: width style color;
Example: 
border: 3px dashed red;
This creates a 3px red dashed border.

5. Individual Border Sides

You can style each side of an element separately. 

div {
    border-top: 3px solid red;
    border-right: 3px solid blue;
    border-bottom: 3px solid green;
    border-left: 3px solid orange;
}
Different border on every side

6. CSS Border Radius

The border-radius property is used to make rounded corners. 

div {
    border: 4px solid blue;
    border-radius: 20px;
}
This box has rounded corners.

Creating a Circle

You can create a circle by using border-radius: 50%.

Circle 
.circle {
    width: 150px;
    height: 150px;
    border-radius: 50%;
}

CSS Borders - Key Points

  • The border property creates a border around an element.
  • border-style defines the border style.
  • border-width controls border thickness.
  • border-color changes the border color.
  • The shorthand property can combine width, style and color.
  • Individual sides can be styled separately.
  • border-radius creates rounded corners.
  • border-radius: 50% can be used to create circular elements.
