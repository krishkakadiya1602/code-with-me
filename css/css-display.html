CSS Display

Learn how the CSS display property controls the layout of elements

1. What is the CSS Display Property?

The CSS display property specifies how an HTML element should be displayed on a webpage.

It is one of the most important CSS properties for controlling webpage layouts. 

selector {
    display: value;
}
Important: The display property can change an element from block to inline, hide an element, or create modern layouts using Flexbox and Grid.

2. Common Display Values

Value Purpose
block Displays an element as a block element
inline Displays an element inline
inline-block Inline element that can have width and height
none Removes the element from the page layout
flex Creates a Flexbox container
grid Creates a CSS Grid container

3. display: block

A block element starts on a new line and normally takes the full available width.

Common block elements include: div, p, h1, section and header. 

div {
    display: block;
}

4. display: inline

Inline elements do not start on a new line. They take only the width required by their content.

Common inline elements include span, a and strong. 

span {
    display: inline;
}

With display: inline, width and height generally do not work as they do for block elements.

5. display: inline-block

inline-block combines characteristics of inline and block elements.

Multiple elements can appear on the same line while still allowing width and height. 

div {
    display: inline-block;
    width: 180px;
    height: 80px;
}

6. display: none

The display: none property hides an element completely. 

.hidden {
    display: none;
}

Note: display: none removes the element from the page layout.

7. display: none vs visibility: hidden

These two properties both hide elements, but they behave differently.

Property Element Hidden? Space Remains?
display: none Yes No

8. display: flex

The display: flex property creates a Flexbox container.

Flexbox is useful for arranging elements in rows or columns. 

.container {
    display: flex;
}

9. Flex Direction

The flex-direction property controls the direction of flex items. 

.container {
    display: flex;
    flex-direction: row;
}

Common values:

  • row
  • row-reverse
  • column
  • column-reverse

10. display: grid

The display: grid property creates a CSS Grid container.

CSS Grid is useful for creating rows and columns. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);

11. display: table

CSS also provides table-related display values. 

.container {
    display: table;
}

.item {
    display: table-cell;
}

These values can imitate table layouts, although modern layouts generally use Flexbox or Grid.

12. Width and Height with Display

Width and height behave differently depending on the display value. 

.box {
    display: inline-block;
    width: 200px;
    height: 100px;
}

An inline element can be changed into a block element using CSS.

16. Block vs Inline vs Inline-Block

Feature Block Inline Inline-Block
New line Yes No No
Full width Usually No No
Width/Height Yes Limited Yes
Same line No Yes Yes

17. Common Use of Display

The display property is useful when creating:

  • Navigation bars
  • Card layouts
  • Responsive websites
  • Menus
  • Buttons
  • Image galleries
  • Flexbox layouts
  • Grid layouts

18. CSS Display Properties Summary

Display Description
block Starts on a new line and takes available width
inline Stays on the same line and takes required width
inline-block Inline layout with width and height support
none Hides the element and removes its layout space
flex Creates a Flexbox layout
grid Creates a Grid layout

20. Key Points

  • The display property controls how an element is displayed.
  • display: block creates a block element.
  • display: inline keeps elements on the same line.
  • display: inline-block combines inline layout with width and height support.
  • display: none hides an element and removes its layout space.
  • display: flex creates a Flexbox container.
  • display: grid creates a Grid container.
  • Display properties are essential for creating responsive website layouts.
