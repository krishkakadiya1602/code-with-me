How to Add CSS

Learn the three different ways to add CSS to HTML.

1. What is Adding CSS?

CSS can be added to an HTML document in different ways. The three main methods are:

  • Inline CSS
  • Internal CSS
  • External CSS
Important: External CSS is commonly used for larger websites because one CSS file can style many HTML pages.

2. Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute.

Syntax

<element style="property: value;">
    Content
</element>

Example

HTML 
<h1 style="color: blue;">
    Hello World
</h1>

Another Example

<p style="color: red; font-size: 20px;">
    This is a paragraph.
</p>
Note: Inline CSS is useful for small changes, but using too much inline CSS can make your HTML difficult to maintain.

3. Internal CSS

Internal CSS is written inside the <style> element.

The <style> element is normally placed inside the HTML <head>.

Example

<!DOCTYPE html>

<html>

<head>

    <style>

        h1 {
            color: blue;
        }

        p {
            color: green;
        }

    </style>

</head>

<body>

    <h1>Hello World</h1>

    <p>Welcome to CSS.</p>

</body>

</html>
Internal CSS is useful when the CSS is mainly needed for a single HTML page.

4. External CSS

External CSS means creating a separate CSS file and connecting it to an HTML file.

The CSS file normally has the .css extension.

Step 1 — Create CSS File

Create a file called: 

style.css

Step 2 — Write CSS

h1 {
    color: blue;
}

p {
    color: green;
}

button {
    background: black;
    color: white;
    padding: 10px;
}

Step 3 — Connect CSS to HTML

<link rel="stylesheet" href="style.css">

Complete Example

<!DOCTYPE html>

<html>

<head>

    <title>My Website</title>

    <link rel="stylesheet"
          href="style.css">

</head>

<body>

    <h1>Welcome</h1>

    <p>This page uses external CSS.</p>

</body>

</html>

5. External CSS File Structure

A simple website can have the following structure: 

my-website/
│
├── index.html
│
└── css/
    └── style.css

If the CSS file is inside a folder called css, the HTML link becomes: 

<link rel="stylesheet"
      href="css/style.css">

6. Inline vs Internal vs External CSS

Method Location Best Use
Inline CSS Inside HTML element Small individual changes
Internal CSS Inside <style> Single HTML page
External CSS Separate .css file Websites with multiple pages

7. Understanding the <link> Tag

The following code connects an external CSS file to an HTML document: 

<link rel="stylesheet" href="style.css">

rel="stylesheet"

The rel attribute tells the browser that the linked file is a stylesheet.

href="style.css"

The href attribute specifies the location of the CSS file.

8. Using Multiple CSS Files

You can connect multiple CSS files to one HTML page. 

<link rel="stylesheet" href="reset.css">

<link rel="stylesheet" href="style.css">

<link rel="stylesheet" href="responsive.css">

This can help organize larger websites.

10. Key Points

  • CSS can be added using Inline CSS.
  • CSS can be added using Internal CSS.
  • CSS can be added using External CSS.
  • Inline CSS uses the style attribute.
  • Internal CSS uses the <style> element.
  • External CSS uses a separate .css file.
  • The <link> element connects an external CSS file to HTML.
