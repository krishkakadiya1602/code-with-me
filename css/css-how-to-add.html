How To Add CSS

Learn three different ways to add CSS to HTML.

How to Add CSS

There are three main ways to add CSS to an HTML document.

  • Inline CSS
  • Internal CSS
  • External CSS
Tip: External CSS is commonly used for larger websites because one CSS file can style multiple HTML pages.

1. Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute.

Example 

<h1 style="color: blue;">
    Hello World
</h1>

Another Example 

<p style="color: red; font-size: 20px;">
    This is a paragraph.
</p>

Inline CSS is useful when you want to apply a style to one specific element.

2. Internal CSS

Internal CSS is written inside the <style> element in the HTML document's <head> section.

Example 

<!DOCTYPE html>

<html>

<head>

<style>

h1 {
    color: blue;
}

p {
    color: green;
    font-size: 20px;
}

</style>

</head>

<body>

<h1>
    Hello World
</h1>

<p>
    This is a paragraph.
</p>

</body>

</html>

Internal CSS is useful when styles are needed for only one HTML page.

3. External CSS

External CSS is written in a separate CSS file and connected to an HTML page using the <link> element.

HTML File 

<!DOCTYPE html>

<html>

<head>

<link rel="stylesheet" href="style.css">

</head>

<body>

<h1>
    Hello World
</h1>

<p>
    This is my website.
</p>

</body>

</html>

CSS File: style.css 

h1 {
    color: blue;
}

p {
    color: green;

    font-size: 20px;
}

External CSS is the most common method for larger websites because the same stylesheet can be used on multiple pages.

Comparison of CSS Methods

Method Location Common Use
Inline CSS style attribute One element
Internal CSS <style> tag One page
External CSS Separate .css file Multiple pages

Which Method Should You Use?

The method depends on your project.

  • Use Inline CSS for very small, specific styles.
  • Use Internal CSS when styling one HTML page.
  • Use External CSS when building websites with multiple pages.
