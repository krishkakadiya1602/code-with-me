CSS Margins

Learn how to create space outside HTML elements using CSS margins.

1. What are CSS Margins?

The CSS margin property is used to create space around the outside of an HTML element.

Margins create space between an element and other elements around it.

Remember: Margin creates space outside the element, while padding creates space inside the element.

2. CSS margin Property

The margin property can be used to set space around all four sides of an element. 

div {
    margin: 20px;
}

This adds a 20px margin to the top, right, bottom, and left sides.

margin: 30px;

3. Individual Margin Properties

CSS provides four separate properties for controlling each side of an element.

  • margin-top
  • margin-right
  • margin-bottom
  • margin-left 
div {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 40px;
}
margin-left: 60px

4. Margin with Four Values

When four values are used, they are applied in this order:

  1. Top
  2. Right
  3. Bottom
  4. Left
div {
    margin: 10px 20px 30px 40px;
}

The values mean: 

Top    = 10px
Right  = 20px
Bottom = 30px
Left   = 40px

5. Margin with Three Values

When three values are used: 

div {
    margin: 10px 20px 30px;
}

The browser interprets them as: 

Top    = 10px
Right  = 20px
Bottom = 30px
Left   = 20px

6. Margin with Two Values

When two values are used: 

div {
    margin: 10px 20px;
}

The browser interprets them as: 

Top    = 10px
Bottom = 10px

Right  = 20px
Left   = 20px

7. Margin with One Value

When one value is used, the same margin is applied to all four sides. 

div {
    margin: 20px;
}

This means: 

Top    = 20px
Right  = 20px
Bottom = 20px
Left   = 20px

8. Using margin: auto

The auto value can be used to horizontally center a block element. 

.box {
    width: 60%;
    margin: auto;
}
This box is horizontally centered.
For horizontal centering with margin: auto, the element normally needs a defined width.

9. Negative Margins

CSS also allows negative margin values. 

div {
    margin-top: -20px;
}

Negative margins can move an element closer to, or overlap with, another element.

Use carefully: Negative margins can be useful in specific layouts, but excessive use can make a layout difficult to maintain.

10. Margin Collapsing

Vertical margins between certain block elements can sometimes collapse into a single margin. 

.box1 {
    margin-bottom: 30px;
}

.box2 {
    margin-top: 20px;
}

The resulting vertical space is not always 50px. In common block-flow situations, the margins can collapse so the larger margin determines the space.

Margin collapsing mainly concerns vertical margins in normal block flow. Horizontal margins do not collapse in the same way.

11. Margin vs Padding

Margin Padding
Creates space outside the element. Creates space inside the element.
Creates distance between elements. Creates distance between content and border.
Background does not extend into the margin. Background extends through the padding area. 
.box {
    margin: 20px;
    padding: 20px;
}

12. Margin Units

Margins can use different CSS units.

Pixels

div {
    margin: 20px;
}

Percentage

div {
    margin: 5%;
}

em

div {
    margin: 2em;
}

rem

div {
    margin: 2rem;
}
Choose the unit based on the layout you are building. Pixels are common for fixed spacing, while relative units can help create flexible layouts.

13. CSS Margin Properties Summary

Property Purpose Example
margin Sets margin on multiple sides. margin: 20px;
margin-top Sets top margin. margin-top: 20px;
margin-right Sets right margin. margin-right: 20px;
margin-bottom Sets bottom margin. margin-bottom: 20px;
margin-left Sets left margin. margin-left: 20px;

15. Key Points

  • Margin creates space outside an element.
  • The margin property can control all four sides.
  • You can use margin-top, margin-right, margin-bottom, and margin-left.
  • One margin value applies to all four sides.
  • Two values control vertical and horizontal margins.
  • Four values follow the order: top, right, bottom, left.
  • margin: auto can horizontally center a block element with a suitable width.
  • Negative margins are allowed.
  • Some vertical margins can collapse.
