CSS Text

Learn how to style and control text using CSS.

1. What is CSS Text?

CSS provides several properties for controlling the appearance and layout of text.

Using CSS text properties, you can change text color, alignment, decoration, capitalization, spacing, indentation and shadows.

Common CSS Text Properties:
  • color
  • text-align
  • text-decoration
  • text-transform
  • text-indent
  • letter-spacing
  • word-spacing
  • line-height
  • text-shadow
  • direction

2. CSS Text Color

The color property is used to change the color of text. 

p {
    color: blue;
}

This text is blue.

Using Hex Color

h1 {
    color: #2563eb;
}

Using RGB Color

p {
    color: rgb(255, 0, 0);
}

3. CSS text-align

The text-align property controls the horizontal alignment of text. 

h1 {
    text-align: center;
}

Common Values

Value Description
left Aligns text to the left.
right Aligns text to the right.
center Centers the text.
justify Stretches text so lines have equal width. 
h1 {
    text-align: center;
}

p {
    text-align: justify;
}

4. CSS text-decoration

The text-decoration property adds or removes decorations from text. 

h1 {
    text-decoration: underline;
}

Common Values

  • underline — adds a line below text.
  • overline — adds a line above text.
  • line-through — draws a line through text.
  • none — removes decoration.
.underline {
    text-decoration: underline;
}

.overline {
    text-decoration: overline;
}

.deleted {
    text-decoration: line-through;
}

.no-decoration {
    text-decoration: none;
}

5. CSS text-transform

The text-transform property controls the capitalization of text. 

.uppercase {
    text-transform: uppercase;
}

.lowercase {
    text-transform: lowercase;
}

.capitalize {
    text-transform: capitalize;
}
Value Result
uppercase ALL LETTERS BECOME UPPERCASE
lowercase all letters become lowercase
capitalize First Letter Of Each Word

6. CSS text-indent

The text-indent property is used to indent the first line of a paragraph. 

p {
    text-indent: 50px;
}

This paragraph has a 50px first-line indentation. Text indentation is commonly used in articles, documents and paragraphs.

7. CSS letter-spacing

The letter-spacing property controls the space between characters. 

h1 {
    letter-spacing: 5px;
}

SPACED TEXT

Increasing letter spacing too much can make text difficult to read.

8. CSS word-spacing

The word-spacing property controls the space between words. 

p {
    word-spacing: 15px;
}

CSS makes websites beautiful.

9. CSS line-height

The line-height property controls the vertical space between lines of text. 

p {
    line-height: 1.8;
}

CSS is used to style web pages. Line height can make paragraphs easier to read by adding space between lines.

A suitable line-height can improve the readability of paragraphs and articles.

10. CSS text-shadow

The text-shadow property adds a shadow effect to text. 

h1 {
    text-shadow: 2px 2px 5px gray;
}

Text Shadow Example

The first value controls the horizontal shadow position, the second controls the vertical position, and the third controls blur.

11. CSS direction

The direction property specifies the text direction. 

.text {
    direction: rtl;
}

Common values are:

  • ltr — left to right
  • rtl — right to left

12. CSS white-space

The white-space property controls how spaces and line breaks inside text are handled. 

.text {
    white-space: nowrap;
}

One useful value is nowrap, which prevents text from automatically wrapping to a new line.

13. Text Overflow

CSS can be used to control text that is too long for its container. 

.text {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}
The ellipsis value can display ... when text is cut off.

14. CSS Text Properties Summary

Property Purpose Example
color Changes text color color: blue;
text-align Aligns text text-align: center;
text-decoration Adds text decoration text-decoration: underline;
text-transform Changes capitalization text-transform: uppercase;
text-indent Indents first line text-indent: 30px;
letter-spacing Controls character spacing letter-spacing: 2px;
word-spacing Controls word spacing word-spacing: 10px;
line-height Controls line spacing line-height: 1.8;
text-shadow Adds shadow to text text-shadow: 2px 2px 4px gray;
direction Controls text direction direction: rtl;

16. Key Points to Remember

  • Use color to change text color.
  • Use text-align to align text.
  • Use text-decoration to add underline, overline or line-through.
  • Use text-transform to change capitalization.
  • Use text-indent to indent the first line of a paragraph.
  • Use letter-spacing to control character spacing.
  • Use word-spacing to control space between words.
  • Use line-height to control space between lines.
  • Use text-shadow to add a shadow effect.
