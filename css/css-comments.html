CSS Comments

Learn how to write comments in CSS and why they are useful.

1. What are CSS Comments?

CSS comments are notes written inside CSS code. They are used to explain the code to developers.

The browser ignores CSS comments when it applies styles to a webpage.

Important: CSS comments are not displayed as visible content on the webpage.

2. CSS Comment Syntax

A CSS comment starts with /* and ends with */.

CSS 
/* This is a CSS comment */

Everything between /* and */ is treated as a comment.

3. Single-Line CSS Comment

You can write a comment on one line. 

/* Change the heading color */

h1 {
    color: blue;
}

The browser ignores the comment and applies the CSS rule normally.

4. Multi-Line CSS Comments

CSS comments can also cover multiple lines. 

/*
   This is a multi-line comment.

   It can contain multiple lines
   of explanation.
*/

body {
    background: lightblue;
}
Multi-line comments are useful when you want to explain a larger section of CSS code.

5. Comments Inside CSS Code

You can place comments before CSS rules to explain what the rules do. 

/* Website heading */

h1 {
    color: darkblue;
    font-size: 40px;
}


/* Website paragraph */

p {
    color: gray;
    font-size: 18px;
}

6. Temporarily Disable CSS

Comments can be used to temporarily disable a CSS property or rule without deleting it. 

h1 {
    color: blue;

    /* font-size: 50px; */

    font-weight: bold;
}

In this example, font-size: 50px; is commented out, so the browser does not apply it.

7. Commenting Out a Complete CSS Rule

You can temporarily disable an entire CSS rule. 

/*
h1 {
    color: red;
    font-size: 50px;
}
*/

p {
    color: green;
}

The browser ignores the complete h1 rule.

8. Using Comments to Organize CSS

Comments can make a large CSS file easier to understand and organize. 

/* =========================
   HEADER
========================= */

header {
    background: black;
    color: white;
}


/* =========================
   NAVIGATION
========================= */

nav {
    display: flex;
    justify-content: space-between;
}


/* =========================
   FOOTER
========================= */

footer {
    background: #111827;
    color: white;
}
Organizing a large stylesheet with comments makes it easier to find different sections of your CSS.

9. Using Comments for Documentation

Comments can explain why a particular CSS rule exists. 

/* Keep the navigation visible
   while scrolling */

nav {
    position: sticky;
    top: 0;
}

This helps another developer understand the purpose of the code.

10. What to Avoid

Avoid writing unnecessary comments for very obvious CSS rules. 

/* Set color to blue */

h1 {
    color: blue;
}

This comment does not provide much additional information because the CSS rule is already obvious.

Tip: Write comments that explain the purpose, reason, or important information about the code.

11. CSS Comments Summary

Feature Example Purpose
Single-line comment /* Comment */ Short explanation
Multi-line comment /* Multiple lines */ Larger explanations
Disabled CSS /* color: red; */ Temporarily disable code
Section comment /* HEADER */ Organize CSS

13. Key Points

  • CSS comments start with /* and end with */.
  • Comments are ignored by the browser.
  • Comments can contain one or multiple lines.
  • Comments can explain CSS code.
  • Comments can temporarily disable CSS code.
  • Comments can help organize large CSS files.
  • Good comments should provide useful information.
