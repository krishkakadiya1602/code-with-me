CSS Position

Learn how to position HTML elements using CSS

Introduction to CSS Position

The CSS position property is used to control how an element is positioned on a webpage.

It allows you to place elements normally, move them relative to their original position, position them relative to a parent element, keep them fixed on the screen, or make them sticky while scrolling.

CSS position values:
static, relative, absolute, fixed, sticky

CSS Position Syntax

selector {
    position: value;
}

Example:

.box {
    position: relative;
    top: 20px;
    left: 30px;
}

1. position: static

static is the default position of every HTML element.

Static elements follow the normal flow of the document. 

.box {
    position: static;
}
With static positioning, the top, right, bottom, and left properties do not affect the element.

2. position: relative

A relatively positioned element remains in the normal document flow but can be moved from its original position. 

.box {
    position: relative;
    top: 25px;
    left: 40px;
}

Live Example

Relative

The element is moved 25px down and 40px to the right from its original position.

3. position: absolute

An absolutely positioned element is removed from the normal document flow.

It is positioned relative to its nearest positioned ancestor. Usually, the parent is given position: relative. 

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 20px;
    right: 20px;
}

Live Example

Absolute

4. position: fixed

A fixed element stays in the same position relative to the browser window.

Even when the page is scrolled, the fixed element remains in the same place. 

.box {
    position: fixed;
    bottom: 20px;
    right: 20px;
}
Fixed positioning is commonly used for:
  • Floating buttons
  • Chat buttons
  • Back-to-top buttons
  • Fixed navigation bars

5. position: sticky

The sticky position behaves like a normal element until a specified scrolling position is reached.

After reaching that position, the element sticks to the specified location. 

.title {
    position: sticky;
    top: 0;
}

Position with Top, Right, Bottom and Left

When using relative, absolute, fixed, or sticky positioning, you can use these properties to control the element's location. 

.box {
    position: absolute;

    top: 20px;
    right: 30px;
    bottom: 10px;
    left: 40px;
}
top → moves the element down
right → moves the element left
bottom → moves the element up
left → moves the element right

z-index with Position

The z-index property controls which positioned element appears in front of another. 

.box {
    position: relative;
    z-index: 10;
}

A higher z-index generally places an element above another overlapping element.

Important: z-index is most useful when elements overlap. It is commonly used with positioned elements.

CSS Position Values Comparison

static    → Default position

relative  → Moves relative to its original position

absolute  → Positioned relative to a positioned ancestor

fixed     → Fixed relative to the browser window

sticky    → Sticks while scrolling after reaching a position

Common Uses of CSS Position

  • Creating dropdown menus
  • Creating badges on cards
  • Floating buttons
  • Fixed navigation bars
  • Sticky headings
  • Overlapping images and text
  • Modal windows
  • Notification badges
