CSS Links

Learn how to style HTML links using CSS

1. What are CSS Links?

Links are used to connect one webpage to another webpage, website, file, section, or resource.

In HTML, links are created using the <a> element. 

<a href="https://example.com">
    Visit Example
</a>

CSS allows us to change the color, size, decoration, background, border, and other styles of links.

2. Basic Link Styling

We can use the color property to change the color of a link. 

a {
    color: blue;
}
This is a styled link

3. Removing the Underline

By default, most browser links have an underline. We can remove it using text-decoration: none; 

a {
    text-decoration: none;
}
Link without underline

4. CSS Link Hover

The :hover pseudo-class is used when the mouse pointer moves over a link. 

a:hover {
    color: red;
    text-decoration: underline;
}
Move your mouse over this link

5. CSS Link States

CSS provides different states for links.

State Meaning
:link A normal unvisited link
:visited A link that the user has already visited
:hover When the mouse pointer is over the link
:active When the link is being clicked

6. Styling Different Link States

a:link {
    color: blue;
}

a:visited {
    color: purple;
}

a:hover {
    color: red;
}

a:active {
    color: green;
}
Important:

A common recommended order is: :link → :visited → :hover → :active

7. Link Background Color

You can add a background color to links. 

a {
    background-color: #2563eb;
    color: white;
    padding: 10px 15px;
    text-decoration: none;
}
Button Style Link

8. Links with Borders

CSS borders can be used to create button-like links. 

a {
    color: #2563eb;
    border: 2px solid #2563eb;
    padding: 10px 15px;
    text-decoration: none;
    border-radius: 5px;
}

9. Link Padding

Padding creates space inside the link. 

a {
    padding: 10px 20px;
}
Tip: Padding is useful when creating navigation buttons and menu links.

10. Link as a Button

You can style an anchor element so that it looks like a button. 

a.button {
    display: inline-block;
    background-color: #2563eb;
    color: white;
    padding: 12px 20px;
    text-decoration: none;
    border-radius: 6px;
}

a.button:hover {
    background-color: #1d4ed8;
}

11. Navigation Links

CSS is commonly used to create navigation menus. 

.navbar a {
    color: white;
    text-decoration: none;
    padding: 15px;
}

.navbar a:hover {
    background-color: #2563eb;
}

12. External Links

External links point to another website. 

<a href="https://www.google.com">
    Google
</a>

13. Internal Links

Internal links connect pages within the same website. 

<a href="about.html">
    About Us
</a>

14. Open Link in a New Tab

Use target="_blank" to open a link in a new browser tab. 

<a href="https://example.com"
   target="_blank"
   rel="noopener noreferrer">

    Open Website

</a>
Note: When using target="_blank", using rel="noopener noreferrer" is a good security practice.

15. Image as a Link

An image can also be placed inside an anchor element. 

<a href="https://example.com">

    <img src="image.jpg"
         alt="Example Image"
         width="200">

</a>

16. CSS Link Transition

The transition property can make hover effects smoother. 

a {
    color: #2563eb;
    transition: 0.3s;
}

a:hover {
    color: #dc2626;
}

17. CSS Links Live Editor

Try changing the CSS code and click Run Code.


18. Key Points

  • Use a to style links.
  • Use :link for normal links.
  • Use :visited for visited links.
  • Use :hover for mouse hover effects.
  • Use :active when a link is clicked.
  • Use text-decoration: none to remove underlines.
  • Use padding to create space inside links.
  • Use background-color and border to create button-style links.
  • Use transition for smooth effects.
