CSS Backgrounds

Learn how to add colors, images, gradients, and other background effects with CSS.

1. What are CSS Backgrounds?

CSS background properties are used to control the background of HTML elements.

You can use CSS backgrounds to add colors, images, gradients, patterns, and other visual effects.

Common CSS background properties:
  • background-color
  • background-image
  • background-repeat
  • background-position
  • background-size
  • background-attachment
  • background

2. CSS background-color

The background-color property is used to set the background color of an element.

CSS 
body {
    background-color: lightblue;
}

Example

div {
    background-color: yellow;
}
This box has a light blue background.

3. CSS background-image

The background-image property is used to add an image as the background of an element. 

body {
    background-image: url("image.jpg");
}

The url() function specifies the location of the image.

Example

.box {
    background-image: url("background.jpg");
}
Important: Make sure the image path is correct. A wrong image path will prevent the browser from displaying the background image.

4. CSS background-repeat

By default, a background image can repeat. The background-repeat property controls this behavior.

Common Values

  • repeat - repeats horizontally and vertically.
  • repeat-x - repeats horizontally.
  • repeat-y - repeats vertically.
  • no-repeat - does not repeat. 
body {
    background-image: url("image.jpg");
    background-repeat: no-repeat;
}

5. CSS background-position

The background-position property specifies the position of a background image. 

body {
    background-image: url("image.jpg");
    background-repeat: no-repeat;
    background-position: center;
}

Common Values

  • left
  • right
  • top
  • bottom
  • center

Example

.box {
    background-position: center center;
}

6. CSS background-size

The background-size property controls the size of a background image.

cover

The cover value makes the image cover the entire element. 

body {
    background-image: url("image.jpg");
    background-size: cover;
}

contain

The contain value scales the image so the complete image is visible. 

body {
    background-image: url("image.jpg");
    background-size: contain;
}

Specific Size

.box {
    background-size: 300px 200px;
}

7. CSS background-attachment

The background-attachment property determines whether the background image scrolls with the page.

scroll

body {
    background-attachment: scroll;
}

fixed

body {
    background-attachment: fixed;
}

With fixed, the background image remains fixed while the page content scrolls.

8. CSS Background Shorthand

Instead of writing several background properties, you can combine them using the background shorthand property. 

body {
    background: lightblue url("image.jpg")
               no-repeat center / cover;
}

The shorthand property can make CSS code shorter, although separate properties can sometimes be easier to read.

9. CSS Linear Gradient

A linear gradient creates a smooth transition between colors. 

div {
    background: linear-gradient(
        to right,
        blue,
        purple
    );
}
Linear Gradient Example

Multiple Colors

div {
    background: linear-gradient(
        to right,
        red,
        yellow,
        green
    );
}

10. CSS Radial Gradient

A radial gradient creates a circular or elliptical color transition. 

div {
    background: radial-gradient(
        circle,
        lightblue,
        blue
    );
}
Radial Gradient Example

11. Multiple Background Images

CSS allows you to use multiple background images on the same element. 

div {
    background-image:
        url("image1.png"),
        url("image2.png");
}

The first image is placed on top of the second image.

12. CSS Background Properties Summary

Property Purpose Example
background-color Sets background color background-color: blue;
background-image Adds background image background-image: url("image.jpg");
background-repeat Controls image repetition background-repeat: no-repeat;
background-position Sets image position background-position: center;
background-size Controls image size background-size: cover;
background-attachment Controls scrolling behavior background-attachment: fixed;
background Shorthand property background: blue;

14. Key Points

  • Use background-color to add a background color.
  • Use background-image to add a background image.
  • Use background-repeat to control image repetition.
  • Use background-position to position the background image.
  • Use background-size to control image size.
  • Use background-attachment to control background scrolling.
  • Use linear-gradient() for linear color gradients.
  • Use radial-gradient() for radial color gradients.
  • The background property can combine multiple background settings.
