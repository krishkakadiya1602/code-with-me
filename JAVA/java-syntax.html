Java Syntax

Learn the basic structure and syntax of a Java program.

What is Java Syntax?

Java syntax is a set of rules that defines how Java programs should be written. Every Java program follows a particular structure so that the Java compiler can understand and execute it.

Understanding Java syntax is important because it helps you write correct and readable Java programs.

Basic Structure of a Java Program

A simple Java program generally contains a class and a main() method.

Example 
public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, World!");

    }

}

Understanding the Syntax

1. public

public is an access modifier. It allows the class or method to be accessed from other classes.

2. class

The class keyword is used to create a class in Java.

Example 
public class Main {

}

3. Main

Main is the name of the class. The class name should normally match the Java file name when the class is public.

4. main() Method

The main() method is the starting point of a standard Java application. 

public static void main(String[] args) {

}

5. System.out.println()

System.out.println() is used to print text or values to the console. 

System.out.println("Hello Java!");

6. Semicolon ;

Most Java statements end with a semicolon ;. 

System.out.println("Hello Java!");

7. Curly Braces { }

Curly braces are used to define the beginning and ending of classes, methods and other blocks of code. 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello");

    }

}

Java Comments

Comments are used to explain code. Java provides single-line and multi-line comments.

Single-Line Comment

// This is a Java comment

System.out.println("Hello Java!");

Multi-Line Comment

/*
   This is a
   multi-line comment
*/

System.out.println("Hello Java!");

Java is Case-Sensitive

Java is case-sensitive. This means uppercase and lowercase letters are treated differently. 

int number = 10;
int Number = 20;
Note: number and Number are two different identifiers in Java.

Java Identifiers

Identifiers are names used for classes, variables, methods and other elements in a Java program.

Valid Examples

int age;
String studentName;
double totalMarks;

Invalid Examples

int 123age;
int student-name;

An identifier cannot start with a number and should not contain characters such as -.

Java Naming Conventions

  • Class names generally use PascalCase.
  • Variable names generally use camelCase.
  • Method names generally use camelCase.
  • Use meaningful names for variables and methods.
Example 
public class StudentDetails {

    String studentName;

    void displayStudent() {

        System.out.println(studentName);

    }

}

Important Java Syntax Rules

  • Java is case-sensitive.
  • Most statements end with a semicolon.
  • Classes are defined using curly braces.
  • Methods are defined inside classes.
  • The main() method is the entry point of a standard Java application.
  • String values are written inside double quotes.
  • Characters are written inside single quotes.
  • Java keywords cannot be used as identifiers.
