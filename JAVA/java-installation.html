Java Installation

Before you start writing and running Java programs, you need to install the Java Development Kit (JDK) on your computer.

The JDK provides the tools required to develop, compile and run Java applications.

What is JDK?

JDK stands for Java Development Kit. It is a software package used to develop Java applications.

JDK = Development tools + JRE + JVM

The JDK includes tools such as the Java compiler and the Java runtime environment required for developing Java programs.

Step 1: Download Java JDK

Download a suitable JDK distribution for your operating system.

You can use an OpenJDK distribution such as Eclipse Temurin.

Download Java JDK

Step 2: Install Java on Windows

1

Download the JDK

Download the Windows installer for the JDK from a trusted JDK distribution website.

2

Open the Installer

Open the downloaded installer file and follow the installation instructions.

3

Choose Installation Location

Select the installation location or keep the default location provided by the installer.

4

Complete Installation

Click the install button and wait until the installation process is completed.

Step 3: Verify Java Installation

After installing Java, open Command Prompt or Terminal and type:

java --version

If Java is installed correctly, the terminal should display the installed Java version.

Check the Java Compiler

You can also check whether the Java compiler is available by running:

javac --version

java is used to run Java programs, while javac is the Java compiler used to compile Java source code.

Step 4: Create Your First Java Program

Create a file named:

Main.java

Add the following code: 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, Java!");

    }

}

Step 5: Compile the Program

Open the terminal in the folder where Main.java is located.

Run the following command:

javac Main.java

If there are no errors, Java will create a compiled class file named:

Main.class

Step 6: Run the Java Program

After compiling the program, run:

java Main

You should see:

Hello, Java!

Common Installation Problem

'java' is not recognized as an internal or external command

This usually means Java is not installed correctly or the Java executable is not available through your system PATH.

Java Installation Summary

  1. Download a JDK.
  2. Install the JDK on your computer.
  3. Open Command Prompt or Terminal.
  4. Run java --version.
  5. Run javac --version.
  6. Create a Java file.
  7. Compile it using javac.
  8. Run it using java.
