Java Introduction

Java is a popular, high-level, object-oriented programming language used to build many types of applications.

Java was developed by Sun Microsystems and was first released in 1995. Today, Java is widely used for web applications, desktop applications, enterprise software, Android development, and many other types of software.

What is Java?

Java is a programming language designed to be simple, object-oriented, secure and portable.

Java principle: "Write Once, Run Anywhere."

Java programs are compiled into bytecode. This bytecode can run on any system that has a Java Virtual Machine (JVM).

Features of Java

  • Simple and easy to learn
  • Object-oriented
  • Platform independent
  • Secure
  • Portable
  • Robust
  • Multithreaded
  • High performance with JVM optimizations

Where is Java Used?

Java is used in many areas of software development.

  • Web applications
  • Desktop applications
  • Enterprise applications
  • Android applications
  • Banking and financial systems
  • Cloud applications
  • Big data technologies
  • Backend development

Your First Java Program

A basic Java program can look like this: 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, World!");

    }

}

Understanding the Program

  • public class Main creates a Java class named Main.
  • main() is the starting point of a Java application.
  • System.out.println() prints text to the output.

Basic Java Syntax

Java statements usually end with a semicolon ;. 

int age = 20;

System.out.println(age);

Java Comments

Comments are used to explain code and are ignored by the Java compiler. 

// This is a single-line comment

/*
   This is a
   multi-line comment
*/
