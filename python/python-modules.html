Python Modules

Learn how to organize and reuse Python code with modules

What is a Python Module?

A module is a Python file containing code that can be reused in another Python program.

A module can contain functions, variables, classes and other Python code.

Simple definition: A Python module is simply a .py file containing reusable Python code.

Example

# mymodule.py

def greeting(name):
    print("Hello", name)

The file mymodule.py is a Python module.

Why Use Modules?

Modules help developers organize large Python programs into smaller and reusable files.

  • Code can be reused.
  • Large programs become easier to manage.
  • Code can be organized into separate files.
  • Functions and classes can be shared between programs.
  • It becomes easier to maintain the project.
  • Modules help avoid repeating the same code.

Importing a Module

We use the import keyword to use a module.

mymodule.py

def greeting(name):
    print("Hello", name)

main.py

import mymodule

mymodule.greeting("Krish")

Output:

Hello Krish

Accessing Functions from a Module

After importing a module, use the module name followed by a dot . and the function name. 

import mymodule

mymodule.greeting("Rahul")

Here, greeting() belongs to the mymodule module.

Variables in a Module

A module can also contain variables.

mymodule.py

name = "Krish"
age = 20

main.py

import mymodule

print(mymodule.name)
print(mymodule.age)

Output:

Krish
20

Classes in a Module

Modules can contain classes as well as functions and variables.

mymodule.py

class Student:

    def __init__(self, name):
        self.name = name

    def show_name(self):
        print(self.name)

main.py

import mymodule

student = mymodule.Student("Krish")

student.show_name()

Output:

Krish

Creating an Alias

You can create a shorter name for a module using the as keyword. 

import mymodule as mm

mm.greeting("Krish")

In this example, mm is an alias for mymodule.

Aliases are useful when a module has a long name or when you want to make your code shorter.

Using from ... import

You can import only a specific function or variable from a module. 

from mymodule import greeting

greeting("Krish")

When using from ... import, you can call the imported function directly without writing the module name.

Importing Multiple Items

Multiple functions or variables can be imported from a module. 

from mymodule import greeting, name

print(name)
greeting("Krish")

You can also import multiple modules. 

import math
import random
import datetime

Built-in Python Modules

Python provides many modules that are already available. These are called built-in or standard-library modules.

Module Purpose Example
math Mathematical operations sqrt(), pi
random Generate random values randint()
datetime Work with dates and times datetime.now()
os Operating system operations getcwd()
json Work with JSON data dumps()
statistics Statistical calculations mean()

Python math Module

The math module provides mathematical functions and constants. 

import math

print(math.sqrt(25))
print(math.pi)
print(math.ceil(4.2))
print(math.floor(4.8))

Output:

5.0
3.141592653589793
5
4

Python random Module

The random module is used to generate random values. 

import random

number = random.randint(1, 10)

print(number)

The number will be randomly selected between 1 and 10.

Random Choice

import random

colors = ["Red", "Blue", "Green"]

print(random.choice(colors))

Python datetime Module

The datetime module is useful for working with dates and times. 

import datetime

current_time = datetime.datetime.now()

print(current_time)

This displays the current date and time.

Python os Module

The os module provides functions for interacting with the operating system. 

import os

print(os.getcwd())

getcwd() returns the current working directory.

Python json Module

The json module is used to work with JSON data. 

import json

student = {
    "name": "Krish",
    "age": 20
}

data = json.dumps(student)

print(data)

Output:

{"name": "Krish", "age": 20}

Using dir()

The dir() function can be used to find the names defined inside a module. 

import math

print(dir(math))

This returns a list of names such as functions, constants and other attributes available in the module.

Creating Your Own Module

You can create your own Python module by creating a file ending with .py.

Step 1: Create mymodule.py

def add(a, b):
    return a + b


def multiply(a, b):
    return a * b

Step 2: Create main.py

import mymodule

print(mymodule.add(10, 5))
print(mymodule.multiply(10, 5))

Output:

15
50

Reloading a Module

Python normally imports a module once during a program run. The importlib module can be used to reload a module. 

import mymodule
import importlib

importlib.reload(mymodule)
Module reloading is mainly useful during development when you change a module and want to load the updated version.

Where Python Searches for Modules

When Python imports a module, it searches locations available through Python's module search path. 

import sys

print(sys.path)

The sys.path list shows directories where Python looks for modules.

Module vs Function

Module Function
A Python file containing reusable code A block of reusable code that performs a task
Can contain functions, classes and variables Usually performs one specific operation
Example: math Example: sqrt()

Important Rules to Remember

  1. A module is usually a Python .py file.
  2. Use import to import a module.
  3. Use from ... import to import specific items.
  4. Use as to create a module alias.
  5. Python provides many useful standard-library modules.
  6. You can create your own custom modules.
  7. Modules help organize and reuse code.

Common Mistakes

  • Using the wrong module name.
  • Forgetting to import the module.
  • Using a function that does not exist in the module.
  • Saving the module with the wrong filename.
  • Using a filename that conflicts with a standard module.
  • Forgetting the module name when accessing its functions.
Example: If you write import math, use math.sqrt(25), not just sqrt(25), unless you specifically imported sqrt.

Practical Example: Calculator Module

Let's create a simple calculator module.

calculator.py

def add(a, b):
    return a + b


def subtract(a, b):
    return a - b


def multiply(a, b):
    return a * b


def divide(a, b):
    return a / b

main.py

import calculator

print("Addition:", calculator.add(10, 5))
print("Subtraction:", calculator.subtract(10, 5))
print("Multiplication:", calculator.multiply(10, 5))
print("Division:", calculator.divide(10, 5))

Output:

Addition: 15
Subtraction: 5
Multiplication: 50
Division: 2.0
This approach allows the calculator functions to be reused in multiple Python programs.
