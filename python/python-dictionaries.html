Python Dictionaries

Learn how to store and manage data using Python dictionaries.

What is a Python Dictionary?

A dictionary in Python is a collection used to store data in key-value pairs.

Dictionaries are written using curly brackets { }. 

student = {
    "name": "Krish",
    "age": 20,
    "course": "BSc IT"
}

print(student)
Important: Dictionary keys must be unique. Values can be of different data types.

Creating a Dictionary

You can create a dictionary by placing key-value pairs inside curly brackets. 

person = {
    "name": "Krish",
    "age": 20,
    "city": "Surat"
}

print(person)

Empty Dictionary

my_dict = {}

print(my_dict)

Using dict()

student = dict(
    name="Krish",
    age=20,
    course="BSc IT"
)

print(student)

Dictionary Key-Value Pairs

Every item in a dictionary contains two parts:

  • Key - identifies the data.
  • Value - stores the actual data.
student = {
    "name": "Krish",
    "age": 20
}

Here, name and age are keys, while Krish and 20 are values.

Access Dictionary Values

You can access a dictionary value by using its key. 

student = {
    "name": "Krish",
    "age": 20,
    "course": "BSc IT"
}

print(student["name"])
print(student["age"])
Output:
Krish
20

Using get()

student = {
    "name": "Krish",
    "age": 20
}

print(student.get("name"))
print(student.get("age"))
Tip: The get() method can return None instead of raising an error when a key does not exist.

Change Dictionary Values

Dictionary values can be changed by referring to their keys. 

student = {
    "name": "Krish",
    "age": 20
}

student["age"] = 21

print(student)

Using update()

student = {
    "name": "Krish",
    "age": 20
}

student.update({"age": 21})

print(student)

Add Dictionary Items

You can add a new key-value pair by assigning a value to a new key. 

student = {
    "name": "Krish",
    "age": 20
}

student["city"] = "Surat"

print(student)

Add Multiple Items

student.update({
    "course": "BSc IT",
    "year": 2026
})

print(student)

Remove Dictionary Items

Using pop()

student = {
    "name": "Krish",
    "age": 20,
    "city": "Surat"
}

student.pop("age")

print(student)

Using popitem()

student = {
    "name": "Krish",
    "age": 20,
    "city": "Surat"
}

student.popitem()

print(student)

Using del

student = {
    "name": "Krish",
    "age": 20
}

del student["age"]

print(student)

Using clear()

student = {
    "name": "Krish",
    "age": 20
}

student.clear()

print(student)

Dictionary Length

Use the len() function to find the number of key-value pairs. 

student = {
    "name": "Krish",
    "age": 20,
    "city": "Surat"
}

print(len(student))
Output: 3

Check if a Key Exists

Use the in keyword to check whether a key exists. 

student = {
    "name": "Krish",
    "age": 20
}

if "name" in student:
    print("Name exists")

Using not in

if "city" not in student:
    print("City does not exist")

Loop Through a Dictionary

Loop Through Keys

student = {
    "name": "Krish",
    "age": 20,
    "city": "Surat"
}

for key in student:
    print(key)

Loop Through Values

for value in student.values():
    print(value)

Loop Through Keys and Values

for key, value in student.items():
    print(key, value)

Python Dictionary Methods

Method Description
clear() Removes all dictionary items.
copy() Returns a copy of the dictionary.
fromkeys() Creates a dictionary using specified keys.
get() Returns the value of a specified key.
items() Returns key-value pairs.
keys() Returns all keys.
pop() Removes an item using its key.
popitem() Removes the last inserted item.
setdefault() Returns a value and inserts the key if it does not exist.
update() Updates the dictionary with new items.
values() Returns all values.

keys(), values() and items()

keys()

student = {
    "name": "Krish",
    "age": 20
}

print(student.keys())

values()

print(student.values())

items()

print(student.items())

Copy a Dictionary

Use the copy() method to create a copy of a dictionary. 

student = {
    "name": "Krish",
    "age": 20
}

student2 = student.copy()

print(student2)

Using dict()

student2 = dict(student)

print(student2)

Nested Dictionaries

A dictionary can contain another dictionary. This is called a nested dictionary. 

students = {
    "student1": {
        "name": "Krish",
        "age": 20
    },

    "student2": {
        "name": "Rahul",
        "age": 21
    }
}

print(students)

Access Nested Dictionary

print(students["student1"]["name"])
print(students["student2"]["age"])

Dictionary with Different Data Types

Dictionary values can contain different types of data. 

person = {
    "name": "Krish",
    "age": 20,
    "marks": 85.5,
    "is_student": True,
    "subjects": ["Python", "JavaScript", "CSS"]
}

print(person)

Duplicate Dictionary Keys

Dictionary keys must be unique. If the same key is used more than once, the last value replaces the previous value. 

student = {
    "name": "Krish",
    "age": 20,
    "age": 21
}

print(student)
Remember: Duplicate keys are not stored as separate dictionary items.

setdefault()

The setdefault() method returns the value of a key. If the key does not exist, it adds the key with a specified value. 

student = {
    "name": "Krish",
    "age": 20
}

student.setdefault("city", "Surat")

print(student)

fromkeys()

The fromkeys() method creates a new dictionary from a sequence of keys. 

keys = ("name", "age", "city")

student = dict.fromkeys(keys)

print(student)

Using a Default Value

keys = ("name", "age", "city")

student = dict.fromkeys(keys, "Unknown")

print(student)

Practical Example

The following example stores student information using a dictionary. 

student = {
    "name": "Krish",
    "age": 20,
    "course": "BSc IT",
    "city": "Surat",
    "marks": 85
}

print("Name:", student["name"])
print("Course:", student["course"])
print("Marks:", student["marks"])
