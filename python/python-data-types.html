Python Data Types

Learn the different types of data used in Python

What are Data Types?

In Python, a data type defines the kind of value stored in a variable. For example, a number, text, list, or dictionary can have different data types.

Python automatically determines the data type when you assign a value to a variable.

Example:
age = 20 is an integer, while name = "Krish" is a string.

Main Python Data Types

1. int

Used for whole numbers.

age = 20

2. float

Used for decimal numbers.

price = 99.50

3. str

Used for text.

name = "Krish"

4. bool

Used for True or False values.

is_student = True

5. list

Ordered and changeable collection.

numbers = [1, 2, 3]

6. tuple

Ordered and unchangeable collection.

data = (10, 20, 30)

7. set

Unordered collection of unique values.

items = {1, 2, 3}

8. dict

Stores data using key-value pairs.

student = {"name": "Krish"}

9. NoneType

Represents the absence of a value.

result = None

1. Integer (int)

The int data type is used to store whole numbers without decimal points. 

age = 20
year = 2026
marks = 85

print(age)
print(year)
print(marks)

2. Float (float)

The float data type is used to store numbers containing decimal points. 

price = 99.50
height = 5.8
percentage = 87.5

print(price)
print(height)
print(percentage)

3. String (str)

A string is a sequence of characters. Strings are written inside single or double quotation marks. 

name = "Krish"
language = 'Python'

print(name)
print(language)

4. Boolean (bool)

The Boolean data type has only two possible values: True and False. 

is_student = True
is_logged_in = False

print(is_student)
print(is_logged_in)

5. List

A list is an ordered and changeable collection of values. Lists are written using square brackets. 

fruits = ["Apple", "Banana", "Mango"]

print(fruits)
print(fruits[0])

6. Tuple

A tuple is an ordered collection that cannot be changed after it is created. 

numbers = (10, 20, 30)

print(numbers)
print(numbers[1])

7. Set

A set is an unordered collection of unique values. Duplicate values are automatically removed. 

numbers = {10, 20, 20, 30, 30}

print(numbers)
Note: Sets do not store duplicate values.

8. Dictionary

A dictionary stores data in key-value pairs. 

student = {
    "name": "Krish",
    "age": 20,
    "course": "BSc IT"
}

print(student)
print(student["name"])

9. NoneType

None represents the absence of a value. 

result = None

print(result)

Checking Data Type with type()

Python provides the type() function to find the data type of a value. 

age = 20
price = 99.50
name = "Krish"
student = True

print(type(age))
print(type(price))
print(type(name))
print(type(student))
Output:

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
