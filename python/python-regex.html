Python Regular Expressions

Learn how to search, match, extract, split, and replace text using Regex.

What is Regex?

Regex stands for Regular Expression.

A regular expression is a pattern used to search and manipulate text. Python provides the built-in re module for working with regular expressions.

Simple Definition: Regex is a pattern that helps you find specific text or patterns inside a string.

Example

import re

text = "I am learning Python."

result = re.search("Python", text)

print(result)

Importing the re Module

Python's regular expression functionality is available through the built-in re module. 

import re

You do not need to install the module separately.

re.search()

The re.search() function searches the entire string for the first location where the pattern matches. 

import re

text = "I am learning Python."

result = re.search("Python", text)

if result:
    print("Python found!")
else:
    print("Python not found.")

Output:

Python found!

re.match()

The re.match() function checks for a match only at the beginning of the string. 

import re

text = "Python is easy."

result = re.match("Python", text)

if result:
    print("Match found!")
else:
    print("No match.")

Output:

Match found!
Difference: re.match() checks the beginning, while re.search() searches throughout the string.

re.findall()

The re.findall() function returns all non-overlapping matches as a list. 

import re

text = "Python is powerful. Python is easy."

result = re.findall("Python", text)

print(result)

Output:

['Python', 'Python']

re.finditer()

The re.finditer() function returns an iterator containing match objects. 

import re

text = "Python Python"

matches = re.finditer("Python", text)

for match in matches:
    print(match.start(), match.end())

Output:

0 6
7 13

re.split()

The re.split() function splits a string wherever the pattern matches. 

import re

text = "Python,HTML,CSS,JavaScript"

result = re.split(",", text)

print(result)

Output:

['Python', 'HTML', 'CSS', 'JavaScript']

re.sub()

The re.sub() function replaces matching text with another value. 

import re

text = "I like Java."

result = re.sub("Java", "Python", text)

print(result)

Output:

I like Python.

Regex Special Characters

Regular expressions use special characters to define patterns.

Pattern Meaning
. Matches any character except newline.
^ Matches the beginning of a string.
$ Matches the end of a string.
* Matches zero or more repetitions.
+ Matches one or more repetitions.
? Matches zero or one repetition.
{m,n} Matches between m and n repetitions.
[] Matches one character from a set.
| Represents OR.
() Creates a group.

Character Sets

Square brackets [] are used to define a set of characters.

Example

import re

text = "cat bat rat"

result = re.findall("[cbr]at", text)

print(result)

Output:

['cat', 'bat', 'rat']

Common Character Sets

Pattern Meaning
[abc] Matches a, b, or c.
[a-z] Matches lowercase letters.
[A-Z] Matches uppercase letters.
[0-9] Matches digits.
[^abc] Matches characters except a, b, and c.

Regex Metacharacters

Pattern Meaning Example
\d Any digit 0-9
\D Any non-digit abc
\w Word character A-Z, a-z, 0-9, _
\W Non-word character @, #, !
\s Whitespace character Space
\S Non-whitespace character A, 1, @

Finding Digits

The \d pattern matches digits. 

import re

text = "My age is 20 and my score is 95."

numbers = re.findall(r"\d+", text)

print(numbers)

Output:

['20', '95']
The r before the string creates a raw string, which is useful when writing regex patterns containing backslashes.

Finding Words

The \w pattern matches word characters. 

import re

text = "Hello Python_123!"

result = re.findall(r"\w+", text)

print(result)

Output:

['Hello', 'Python_123']

Finding Whitespace

import re

text = "Python is easy"

result = re.findall(r"\s", text)

print(len(result))

The pattern \s matches whitespace characters such as spaces and tabs.

Regex Quantifiers

Quantifiers specify how many times a pattern should occur.

Quantifier Meaning
* Zero or more
+ One or more
? Zero or one
{3} Exactly 3 times
{2,5} Between 2 and 5 times

Example

import re

text = "aa aaa aaaa"

result = re.findall(r"a{2,4}", text)

print(result)

Output:

['aa', 'aaa', 'aaaa']

^ and $

The ^ symbol matches the beginning of a string.

The $ symbol matches the end of a string. 

import re

text = "Python is easy"

result = re.search(r"^Python", text)

if result:
    print("String starts with Python")

Output:

String starts with Python

Regex Groups

Parentheses () are used to create groups. 

import re

text = "Name: Krish, Age: 20"

result = re.search(r"Name: (\w+), Age: (\d+)", text)

if result:
    print("Name:", result.group(1))
    print("Age:", result.group(2))

Output:

Name: Krish
Age: 20

Email Validation Example

Regex can be used to check whether text follows a basic email pattern. 

import re

email = "student@example.com"

pattern = r"^[\w.-]+@[\w.-]+\.\w+$"

if re.match(pattern, email):
    print("Valid email")
else:
    print("Invalid email")

Output:

Valid email
Regex-based email checks can validate a basic format, but they do not prove that an email address actually exists.

Phone Number Example

import re

phone = "9876543210"

pattern = r"^\d{10}$"

if re.match(pattern, phone):
    print("Valid 10-digit phone number")
else:
    print("Invalid phone number")

Output:

Valid 10-digit phone number

Regex Flags

Flags modify how a regular expression behaves.

re.IGNORECASE

It makes matching case-insensitive. 

import re

text = "Python PYTHON python"

result = re.findall("python", text, re.IGNORECASE)

print(result)

Output:

['Python', 'PYTHON', 'python']

Common Flags

Flag Purpose
re.IGNORECASE Ignore uppercase/lowercase differences.
re.MULTILINE Change how ^ and $ work with multiple lines.
re.DOTALL Allow . to match newline characters.

re.compile()

The re.compile() function creates a reusable regular expression pattern. 

import re

pattern = re.compile(r"\d+")

text = "My numbers are 10 and 20."

result = pattern.findall(text)

print(result)

Output:

['10', '20']

Practical Example: Extract Numbers

import re

text = """
Product A costs 500 rupees.
Product B costs 750 rupees.
Product C costs 1200 rupees.
"""

prices = re.findall(r"\d+", text)

print(prices)

Output:

['500', '750', '1200']

Python Regex Quick Reference

Function Purpose
re.search() Search for a pattern anywhere in a string.
re.match() Match a pattern at the beginning.
re.findall() Find all matching results.
re.finditer() Return an iterator of match objects.
re.split() Split a string using a pattern.
re.sub() Replace matching text.
re.compile() Create a reusable regex pattern.

Important Points to Remember

  • Regex means Regular Expression.
  • Python provides the built-in re module.
  • Use re.search() to search for a pattern.
  • Use re.match() to check the beginning.
  • Use re.findall() to find all matches.
  • Use re.split() to split text.
  • Use re.sub() to replace text.
  • Use raw strings such as r"\d+" for regex patterns containing backslashes.
  • Regex is useful for searching, extracting, validating, and replacing text.
