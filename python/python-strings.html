Python Strings

Learn how to create, access and manipulate strings in Python

What is a String?

A string is a sequence of characters used to store text in Python. Strings can contain letters, numbers, symbols and spaces.

Strings are written inside single quotes, double quotes or triple quotes.

Example:

name = "Krish"
language = 'Python'

Creating Strings

You can create a string using single quotes or double quotes. 

name = "Krish"
city = 'Surat'

print(name)
print(city)

Single Quotes and Double Quotes

Python allows you to use both single and double quotation marks to create strings. 

name1 = "Krish"
name2 = 'Krish'

print(name1)
print(name2)
Both examples create a string. The choice between single and double quotes is mostly a matter of style and context.

Triple Quotes

Triple quotes can be used to create strings that span multiple lines. 

message = """Hello!
Welcome to Code With Me.
Learn Python step by step."""

print(message)

String Indexing

Each character in a string has an index number. Python uses zero-based indexing, which means the first character has index 0. 

name = "Python"

print(name[0])
print(name[1])
print(name[2])
print(name[5])
Output:

P
y
t
n

Negative Indexing

Python also supports negative indexing. The last character has index -1. 

name = "Python"

print(name[-1])
print(name[-2])
print(name[-3])

String Slicing

String slicing allows you to extract a part of a string.

The basic syntax is: 

string[start:end]
name = "Python"

print(name[0:3])
print(name[2:6])
print(name[:4])
print(name[2:])
The ending index is not included in the result.

String Length

The len() function returns the number of characters in a string. 

name = "Python"

print(len(name))

String Concatenation

Concatenation means joining two or more strings together. The + operator can be used for this. 

first_name = "Krish"
last_name = "Kakadiya"

full_name = first_name + " " + last_name

print(full_name)

String Repetition

You can repeat a string using the * operator. 

message = "Hello "

print(message * 3)

Changing Letter Case

upper()

Converts all characters to uppercase. 

text = "hello python"

print(text.upper())

lower()

Converts all characters to lowercase. 

text = "HELLO PYTHON"

print(text.lower())

title()

Converts the first letter of each word to uppercase. 

text = "learn python programming"

print(text.title())

Common Python String Methods

Method Description Example
upper() Converts string to uppercase "hello".upper()
lower() Converts string to lowercase "HELLO".lower()
title() Capitalizes each word "hello world".title()
strip() Removes spaces from beginning and end " hello ".strip()
replace() Replaces text "Hi".replace("Hi", "Hello")
split() Splits a string into a list "A B C".split()
find() Finds the position of text "Python".find("t")
count() Counts occurrences "banana".count("a")
startswith() Checks the beginning of a string "Python".startswith("Py")

strip() Method

The strip() method removes whitespace from the beginning and end of a string. 

name = "   Krish   "

print(name)
print(name.strip())

replace() Method

The replace() method replaces one piece of text with another. 

text = "I like Java"

new_text = text.replace("Java", "Python")

print(new_text)

split() Method

The split() method divides a string into a list. 

text = "Python is easy"

words = text.split()

print(words)

find() Method

The find() method returns the position of the first occurrence of a specified value. 

text = "Hello Python"

print(text.find("Python"))

Python f-Strings

f-strings provide a convenient way to insert variables and expressions inside strings. 

name = "Krish"
age = 20

message = f"My name is {name} and I am {age} years old."

print(message)
Tip: Put f before the opening quotation mark and use curly brackets {} for variables.

Escape Characters

Escape characters are special characters used inside strings.

Escape Character Meaning
\n New line
\t Tab
\\ Backslash
\" Double quotation mark
\' Single quotation mark 
print("Hello\nPython")
print("Name:\tKrish")

Checking Text in a String

The in operator checks whether a value exists inside a string. 

text = "Python is easy"

print("Python" in text)
print("Java" in text)

Strings are Immutable

Strings in Python are immutable. This means that individual characters of an existing string cannot be changed directly. 

text = "Python"

# This will cause an error:
# text[0] = "J"

print(text)

Instead, you can create a new string. 

text = "Python"

new_text = "J" + text[1:]

print(new_text)
