Python Classes

Learn Classes and Object-Oriented Programming in Python

What are Python Classes?

A class in Python is a blueprint for creating objects. It defines the properties and behaviors that objects created from the class can have.

Python supports Object-Oriented Programming (OOP). Classes and objects are important parts of OOP.

Simple idea: A class is like a blueprint, while an object is something created from that blueprint.

Example

class Student:
    name = "Krish"
    age = 20

student1 = Student()

print(student1.name)
print(student1.age)

Output:

Krish
20

Creating a Class

We use the class keyword to create a class. 

class Car:
    brand = "Toyota"
    color = "White"

Here, Car is the name of the class.

Class names are commonly written using PascalCase, such as Student, Car, and BankAccount.

Creating an Object

An object is an instance of a class. 

class Student:
    name = "Krish"

student1 = Student()

print(student1.name)

Output:

Krish

In this example, student1 is an object of the Student class.

The __init__() Method

The __init__() method is a special method that is automatically called when a new object is created.

It is commonly used to initialize object attributes. 

class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Krish", 20)

print(student1.name)
print(student1.age)

Output:

Krish
20

The self Parameter

The self parameter refers to the current object. 

class Student:

    def __init__(self, name):
        self.name = name

student1 = Student("Krish")

print(student1.name)
Important: self is used to access attributes and methods belonging to the current object.

Class Attributes and Instance Attributes

Class Attribute

A class attribute is shared by all objects of the class. 

class Student:
    school = "ABC School"

student1 = Student()
student2 = Student()

print(student1.school)
print(student2.school)

Instance Attribute

Instance attributes belong to individual objects. 

class Student:

    def __init__(self, name):
        self.name = name

student1 = Student("Krish")
student2 = Student("Rahul")

print(student1.name)
print(student2.name)

Methods in a Class

A method is a function that belongs to a class. 

class Student:

    def __init__(self, name):
        self.name = name

    def introduce(self):
        print("My name is", self.name)

student1 = Student("Krish")

student1.introduce()

Output:

My name is Krish

Multiple Methods

A class can contain multiple methods. 

class Calculator:

    def add(self, a, b):
        return a + b

    def subtract(self, a, b):
        return a - b

calculator = Calculator()

print(calculator.add(10, 5))
print(calculator.subtract(10, 5))

Output:

15
5

Modifying Object Properties

You can change the value of an object's attribute. 

class Student:

    def __init__(self, name):
        self.name = name

student1 = Student("Krish")

print(student1.name)

student1.name = "Rahul"

print(student1.name)

Output:

Krish
Rahul

Deleting Object Properties

The del keyword can be used to delete an object property. 

class Student:

    def __init__(self, name):
        self.name = name

student1 = Student("Krish")

del student1.name
After deleting the property, trying to access student1.name will produce an error.

Deleting an Object

You can delete an entire object using the del keyword. 

class Student:
    pass

student1 = Student()

del student1

Empty Classes

If you want to create a class without adding any properties or methods yet, use the pass statement. 

class Student:
    pass

The pass statement prevents Python from producing an error because the class body is empty.

Inheritance

Inheritance allows one class to inherit properties and methods from another class. 

class Animal:

    def speak(self):
        print("Animal makes a sound")


class Dog(Animal):

    def bark(self):
        print("Dog barks")


dog = Dog()

dog.speak()
dog.bark()

Output:

Animal makes a sound
Dog barks
Inheritance is an important Object-Oriented Programming concept. You will learn more about it in the next Python inheritance lesson.

Real-World Example

Suppose we want to represent a bank account using Python. We can create a class containing account information and methods. 

class BankAccount:

    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

    def show_balance(self):
        print("Owner:", self.owner)
        print("Balance:", self.balance)


account = BankAccount("Krish", 5000)

account.deposit(2000)

account.show_balance()

Output:

Owner: Krish
Balance: 7000

Object-Oriented Programming

Python classes are used to build object-oriented programs. Important OOP concepts include:

  • Class - Blueprint for objects
  • Object - Instance of a class
  • Encapsulation - Combining data and methods
  • Inheritance - Reusing code from another class
  • Polymorphism - Same interface with different behavior
  • Abstraction - Hiding unnecessary implementation details

Common Mistakes

  • Forgetting the colon after the class declaration.
  • Incorrect indentation inside the class.
  • Forgetting self in instance methods.
  • Using an attribute that has not been created.
  • Confusing a class with an object.
  • Calling an instance method without creating an object.
Tip: Python uses indentation to define blocks of code, so indentation is especially important when working with classes.

Important Rules to Remember

  1. Use the class keyword to define a class.
  2. Create objects by calling the class.
  3. Use __init__() to initialize object data.
  4. Use self to access instance attributes and methods.
  5. Methods are functions defined inside a class.
  6. One class can create many objects.
  7. Classes are the foundation of Python OOP.
