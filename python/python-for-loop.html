Python For Loop

Learn how to repeat code using Python for loops.

Introduction to Python For Loop

A for loop is used to repeat a block of code for each item in a sequence or iterable.

Python for loops can be used with:

  • Lists
  • Tuples
  • Strings
  • Dictionaries
  • Sets
  • Ranges
Example: If you have a list of five fruits, a for loop can automatically process each fruit one by one.

1. Python For Loop Syntax

The basic syntax of a Python for loop is: 

for variable in sequence:
    # code to execute

Example

fruits = ["apple", "banana", "mango"]

for fruit in fruits:
    print(fruit)

Output:

apple
banana
mango

2. Using range()

The range() function generates a sequence of numbers.

Example

for number in range(5):
    print(number)

Output:

0
1
2
3
4
Remember: range(5) starts from 0 and stops before 5.

3. range() with Start and Stop

You can provide a starting value and an ending value. 

for number in range(1, 6):
    print(number)

Output:

1
2
3
4
5

The ending value is not included.

4. range() with Step

The third argument of range() specifies the step. 

for number in range(0, 11, 2):
    print(number)

Output:

0
2
4
6
8
10

5. Reverse For Loop

A negative step can be used to count backwards. 

for number in range(5, 0, -1):
    print(number)

Output:

5
4
3
2
1

6. Loop Through a String

A for loop can process each character of a string. 

word = "Python"

for character in word:
    print(character)

Output:

P
y
t
h
o
n

7. Loop Through a List

numbers = [10, 20, 30, 40, 50]

for number in numbers:
    print(number)

Output:

10
20
30
40
50

8. Loop Through a Tuple

colors = ("red", "green", "blue")

for color in colors:
    print(color)

Output:

red
green
blue

9. Loop Through a Set

numbers = {10, 20, 30}

for number in numbers:
    print(number)
Note: Sets are unordered, so the output order is not guaranteed.

10. Loop Through a Dictionary

Loop Through Keys

student = {
    "name": "Krish",
    "age": 20,
    "course": "BSc IT"
}

for key in student:
    print(key)

Loop Through Values

for value in student.values():
    print(value)

Loop Through Keys and Values

for key, value in student.items():
    print(key, ":", value)

11. Using enumerate()

The enumerate() function provides both the index and the value. 

fruits = ["apple", "banana", "mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)

Output:

0 apple
1 banana
2 mango

12. Using break

The break statement stops the loop immediately. 

for number in range(1, 10):

    if number == 5:
        break

    print(number)

Output:

1
2
3
4

13. Using continue

The continue statement skips the current iteration and continues with the next one. 

for number in range(1, 6):

    if number == 3:
        continue

    print(number)

Output:

1
2
4
5

14. For Loop with else

Python allows an else block with a for loop. 

for number in range(5):
    print(number)
else:
    print("Loop completed.")

Output:

0
1
2
3
4
Loop completed.
The else block runs when the loop finishes normally.

15. Nested For Loop

A loop inside another loop is called a nested loop. 

for i in range(1, 4):

    for j in range(1, 4):
        print(i, j)

Output:

1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3

16. Multiplication Table

A for loop can be used to create a multiplication table. 

number = 5

for i in range(1, 11):
    print(number, "x", i, "=", number * i)

Output:

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50

17. Calculate Sum Using For Loop

numbers = [10, 20, 30, 40, 50]

total = 0

for number in numbers:
    total = total + number

print("Total:", total)

Output:

Total: 150

18. Print Even Numbers

for number in range(1, 11):

    if number % 2 == 0:
        print(number)

Output:

2
4
6
8
10

19. Print Odd Numbers

for number in range(1, 11):

    if number % 2 != 0:
        print(number)

Output:

1
3
5
7
9

20. Simple Star Pattern

for i in range(1, 6):
    print("*" * i)

Output:

*
**
***
****
*****

21. Search for an Item

numbers = [10, 20, 30, 40, 50]

search = 30

for number in numbers:

    if number == search:
        print("Number found!")
        break

Output:

Number found!

For Loop Quick Reference

Feature Example Purpose
Basic loop for x in items: Loop through items
range() range(5) Generate numbers
break break Stop the loop
continue continue Skip an iteration
else for...else Run after normal completion
Nested loop for inside for Repeat loops inside loops

Important Points

  • A for loop repeats code for each item in an iterable.
  • Python for loops use indentation.
  • range() is commonly used with for loops.
  • break stops a loop.
  • continue skips the current iteration.
  • A for loop can have an else block.
  • For loops can be nested inside other loops.
  • Lists, tuples, strings, sets and dictionaries can be iterated.
