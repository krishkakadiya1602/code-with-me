Python Installation

Learn how to download and install Python on your computer and verify that Python is working correctly.

Installing Python

Before you start writing Python programs on your computer, you need to install Python.

Python is available for major operating systems including Windows, macOS and Linux.

Important: When installing Python on Windows, make sure you select the option to add Python to the PATH environment variable during installation.

What You Need

  • ✔ A computer or laptop
  • ✔ Internet connection
  • ✔ Windows, macOS or Linux
  • ✔ Enough storage space for Python

Install Python on Windows

Follow these steps to install Python on a Windows computer.

1

Visit the Python Website

Open your web browser and visit the official Python website.

Download Python
2

Download Python

On the Python downloads page, choose the latest Python version available for your operating system.

Click the Windows download option to download the Python installer.

3

Open the Installer

After the download is complete, open the Python installer.

You will see the Python setup window.

4

Add Python to PATH

Before starting the installation, look for the option:

Add python.exe to PATH
Select this option if it is available.

Adding Python to PATH makes it easier to run Python commands from the Command Prompt or terminal.

5

Install Python

Click the installation button and wait for the installation process to finish.

When the installation is completed, close the installer.

Check Python Installation

After installing Python, you should verify that it is installed correctly.

Open Command Prompt on Windows and type:

python --version

If Python is installed correctly, the command will display the installed Python version.

Example: 
Python 3.x.x

The exact version number may be different depending on the Python version installed on your computer.

Open the Python Interpreter

You can start the Python interpreter from the terminal by entering:

python

You should then see the Python prompt: 

>>>

Run Your First Python Program

After opening the Python interpreter, type: 

print("Hello, World!")

Press Enter.

Python will display:

Output: 
Hello, World!

Python IDLE

Python also includes an application called IDLE.

IDLE provides a simple environment where beginners can write and run Python programs.

What can you do with IDLE?

  • Write Python code.
  • Run Python programs.
  • Test small Python commands.
  • Learn Python interactively.

Using a Code Editor

As you learn Python, you may also use a code editor or integrated development environment (IDE).

Popular choices include editors and IDEs that support Python development.

Tip: Beginners can start with a simple editor and later explore more advanced development environments.

Python on macOS and Linux

Python is also available for macOS and Linux.

The installation process can be different depending on your operating system and distribution.

After installation, you can verify Python from a terminal using:

python3 --version

Common Installation Problems

1. 'python' is not recognized

If Windows cannot find the Python command, Python may not have been added to PATH.

2. Python version is not displayed

Check that Python was installed correctly and try opening a new Command Prompt window.

3. Multiple Python versions

If more than one Python installation exists on your computer, the command used to start Python can depend on your operating-system configuration.

Important Points

  • Python can be installed on Windows, macOS and Linux.
  • Download Python from the official Python website.
  • On Windows, adding Python to PATH can make terminal usage easier.
  • Use python --version to check Python on many Windows installations.
  • Use python3 --version on systems where Python 3 is invoked with the python3 command.
  • The print() function can be used to test your Python installation.
