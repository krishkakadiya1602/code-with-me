Python Syntax

Learn the basic rules and structure of Python code with simple examples.

What is Python Syntax?

Python syntax refers to the rules that define how Python programs should be written.

Python is designed to have a simple and readable syntax. This makes it easier for beginners to understand and write programs.

Remember: Python uses indentation to organize blocks of code. Correct indentation is an important part of Python syntax.

Simple Python Program

The following program displays a message on the screen: 

print("Hello, World!")

The print() function displays the text inside the parentheses.

Output: 
Hello, World!

Python Statements

A statement is an instruction that Python can execute. 

name = "Krish"
print(name)

Here, the first line stores a value in a variable and the second line displays the value.

Multiple Statements

Python programs can contain multiple statements. Normally, each statement is written on a separate line. 

name = "Krish"
age = 20

print(name)
print(age)
Output: 
Krish
20

Python Indentation

Indentation means adding spaces at the beginning of a line of code.

Python uses indentation to define a block of code.

Correct Indentation

if 10 > 5:
    print("10 is greater than 5")

Incorrect Indentation

if 10 > 5:
print("10 is greater than 5")
Important: The code inside an if block must be indented.

How Much Indentation?

Four spaces are commonly used for each indentation level. 

if True:
    print("This is inside the if block")

Be consistent with indentation throughout your program.

Python Comments

Comments are notes written inside a program. Python ignores comments when executing the code.

A single-line comment starts with the # symbol. 

# This is a comment
print("Hello")

Comments can help explain what your code does.

Multi-Line Comments

Python does not have a special multi-line comment syntax. Triple-quoted strings are sometimes used for documentation or multi-line text. 

"""
This is a multi-line
string used as documentation.
"""

print("Python")
Tip: For normal comments, use #. For documentation, Python provides docstrings.

Python Variables

Variables are used to store data. 

name = "Krish"
age = 20

print(name)
print(age)

Python does not require you to declare the variable type separately.

Python Strings

A string is a sequence of characters. Strings can be written using single or double quotation marks. 

name = "Code With Me"

print(name)

Single quotes can also be used: 

name = 'Code With Me'

print(name)

Python Code Blocks

A code block is a group of statements that belong together. Python uses indentation to identify these blocks. 

age = 20

if age >= 18:
    print("You are an adult.")
    print("You can continue learning Python.")

Both print statements belong to the if block because they have the same indentation.

Python is Case-Sensitive

Python is case-sensitive. This means uppercase and lowercase letters are treated as different characters. 

name = "Krish"
Name = "Patel"

print(name)
print(Name)
Important: name and Name are two different variable names.
