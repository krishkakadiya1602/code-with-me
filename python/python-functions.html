Python Functions

Learn how to create reusable blocks of code using Python functions.

Introduction to Python Functions

A function is a reusable block of code that performs a specific task.

Functions help make programs:

  • Reusable
  • Organized
  • Easier to understand
  • Easier to maintain
  • Less repetitive
Example: Instead of writing the same code multiple times, you can place it inside a function and call that function whenever you need it.

1. Creating a Function

Python uses the def keyword to create a function.

Syntax

def function_name():
    # code to execute

Example

def greet():
    print("Hello, welcome to Python!")

greet()

Output:

Hello, welcome to Python!

2. Calling a Function

After creating a function, you need to call it to execute its code. 

def message():
    print("Learning Python is fun!")

message()

Here, message() calls the function.

3. Function Parameters

Parameters are variables written inside the function definition. 

def greet(name):
    print("Hello", name)

greet("Krish")

Output:

Hello Krish

4. Multiple Parameters

A function can have multiple parameters. 

def add(a, b):
    print(a + b)

add(10, 20)

Output:

30

5. Function Arguments

Values passed to a function when it is called are called arguments. 

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student("Krish", 20)

Output:

Name: Krish
Age: 20

6. Return Statement

The return statement sends a value back from a function. 

def add(a, b):
    return a + b

result = add(10, 20)

print(result)

Output:

30

7. Returning Multiple Values

Python functions can return multiple values. 

def calculate(a, b):
    return a + b, a - b, a * b

addition, subtraction, multiplication = calculate(10, 5)

print(addition)
print(subtraction)
print(multiplication)

Output:

15
5
50

8. Default Parameter

A parameter can have a default value. 

def greet(name="Guest"):
    print("Hello", name)

greet()
greet("Krish")

Output:

Hello Guest
Hello Krish

9. Keyword Arguments

Keyword arguments allow you to specify parameter names when calling a function. 

def student(name, age):
    print("Name:", name)
    print("Age:", age)

student(age=20, name="Krish")

Output:

Name: Krish
Age: 20

10. Positional Arguments

Positional arguments are matched according to their position. 

def student(name, age):
    print(name)
    print(age)

student("Krish", 20)

11. Arbitrary Arguments: *args

Use *args when you don't know how many positional arguments will be passed. 

def total(*numbers):

    result = 0

    for number in numbers:
        result += number

    return result

print(total(10, 20, 30, 40))

Output:

100

12. Arbitrary Keyword Arguments: **kwargs

Use **kwargs when you want to accept multiple keyword arguments. 

def student_info(**details):

    for key, value in details.items():
        print(key, ":", value)

student_info(
    name="Krish",
    age=20,
    course="BSc IT"
)

Output:

name : Krish
age : 20
course : BSc IT

13. Passing a List to a Function

def show_fruits(fruits):

    for fruit in fruits:
        print(fruit)

my_fruits = ["Apple", "Banana", "Mango"]

show_fruits(my_fruits)

Output:

Apple
Banana
Mango

14. Function with if...else

def check_age(age):

    if age >= 18:
        return "Adult"
    else:
        return "Minor"

print(check_age(20))

Output:

Adult

15. Local and Global Variables

Local Variable

A variable created inside a function is generally local to that function. 

def example():

    message = "Hello"

    print(message)

example()

Global Variable

A variable created outside a function has global scope. 

message = "Hello Python"

def show_message():
    print(message)

show_message()

16. global Keyword

The global keyword can be used when you need to modify a global variable inside a function. 

count = 0

def increase():

    global count

    count += 1

increase()

print(count)

Output:

1

17. Recursion

A function that calls itself is called a recursive function. 

def countdown(number):

    if number == 0:
        return

    print(number)

    countdown(number - 1)

countdown(5)

Output:

5
4
3
2
1
Recursive functions must have a condition that eventually stops the recursion.

18. Factorial Using Function

def factorial(number):

    result = 1

    for i in range(1, number + 1):
        result *= i

    return result

print(factorial(5))

Output:

120

19. Lambda Function

A lambda function is a small anonymous function.

Syntax

lambda arguments: expression

Example

square = lambda x: x * x

print(square(5))

Output:

25

20. Lambda with Multiple Arguments

add = lambda a, b: a + b

print(add(10, 20))

Output:

30

21. Built-in Python Functions

Python already provides many useful built-in functions.

Function Purpose Example
print() Displays output print("Hello")
len() Returns length len("Python")
max() Returns largest value max(10, 20)
min() Returns smallest value min(10, 20)
sum() Returns total sum([1, 2, 3])
type() Returns data type type(10)

22. Function Documentation

A function can contain a documentation string called a docstring. 

def greet(name):
    """This function greets a person."""
    print("Hello", name)

greet("Krish")

23. Practical Example

The following function calculates a student's result. 

def calculate_result(marks):

    total = sum(marks)
    average = total / len(marks)

    if average >= 40:
        result = "Pass"
    else:
        result = "Fail"

    return total, average, result


marks = [70, 80, 65, 75]

total, average, result = calculate_result(marks)

print("Total:", total)
print("Average:", average)
print("Result:", result)

Output:

Total: 290
Average: 72.5
Result: Pass

Important Points

  • Use def to define a function.
  • Call a function using its name followed by parentheses.
  • Parameters receive values passed to a function.
  • Arguments are the actual values passed during a function call.
  • Use return to return a result.
  • Functions can have default parameters.
  • *args accepts multiple positional arguments.
  • **kwargs accepts multiple keyword arguments.
  • Variables inside functions can have local scope.
  • Lambda functions are small anonymous functions.
  • A recursive function calls itself.
