Python File Handling

Learn how to create, read, write, append and manage files with Python

What is File Handling?

File handling is the process of creating, reading, writing, updating and deleting files using Python.

Files allow programs to store information permanently so that the data can be used again after the program finishes.

Simple idea: Variables store data temporarily while files can store data permanently on a storage device.

Common File Operations

  • Create a file
  • Open a file
  • Read a file
  • Write to a file
  • Append data to a file
  • Close a file
  • Delete a file

Opening a File

Python provides the built-in open() function for opening files.

Syntax

open("filename", "mode")

Example

file = open("example.txt", "r")

print(file.read())

file.close()

Here, example.txt is opened in read mode.

Python File Modes

The mode tells Python what you want to do with the file.

Mode Meaning
r Read the file
w Write to the file
a Append data to the file
x Create a new file
b Binary mode
t Text mode
+ Read and write mode
Important: Opening an existing file with w mode can overwrite its existing contents.

Reading a File

Use read() to read the contents of a file. 

file = open("example.txt", "r")

content = file.read()

print(content)

file.close()

Reading a Specific Number of Characters

You can provide a number to read() to read a specific number of characters. 

file = open("example.txt", "r")

content = file.read(10)

print(content)

file.close()

The example reads the first 10 characters from the file.

Using readline()

The readline() method reads one line from a file. 

file = open("example.txt", "r")

print(file.readline())

file.close()

Reading Multiple Lines

file = open("example.txt", "r")

print(file.readline())
print(file.readline())
print(file.readline())

file.close()

Using readlines()

The readlines() method returns all lines as a list. 

file = open("example.txt", "r")

lines = file.readlines()

print(lines)

file.close()

Reading a File Using a Loop

You can loop through a file to read it line by line. 

file = open("example.txt", "r")

for line in file:
    print(line)

file.close()
Reading a file line by line can be useful when working with large files.

Writing to a File

Use w mode to write data to a file. 

file = open("example.txt", "w")

file.write("Hello from Python!")

file.close()

If the file does not exist, Python can create it.

Warning: w mode replaces the existing contents of a file.

Writing Multiple Lines

You can use \n to create new lines. 

file = open("students.txt", "w")

file.write("Krish\n")
file.write("Rahul\n")
file.write("Amit\n")

file.close()

The file will contain: 

Krish
Rahul
Amit

Appending to a File

Use a mode to add new content to the end of a file. 

file = open("students.txt", "a")

file.write("Neha\n")

file.close()

Existing content remains unchanged and the new data is added at the end.

Creating a New File

The x mode is used to create a new file. 

file = open("newfile.txt", "x")

file.close()
If the file already exists, using x mode will cause an error.

Using the with Statement

The with statement is the recommended way to work with files in Python. 

with open("example.txt", "r") as file:
    content = file.read()

print(content)

Python automatically closes the file when the with block finishes.

Best practice: Prefer with open(...) when working with files because it handles closing the file automatically.

Writing Using with

with open("example.txt", "w") as file:
    file.write("Python File Handling")

Appending Using with

with open("example.txt", "a") as file:
    file.write("\nThis is another line.")

File Position

Python keeps track of the current position inside an open file.

tell()

The tell() method returns the current file position. 

with open("example.txt", "r") as file:

    print(file.tell())

    file.read(5)

    print(file.tell())

seek()

The seek() method changes the current file position. 

with open("example.txt", "r") as file:

    file.seek(0)

    print(file.read())

File Encoding

You can specify an encoding when opening a text file. 

with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)

UTF-8 is commonly used for text files because it supports many languages and characters.

Handling File Errors

A file may not exist or may not be accessible. You can handle these errors using try and except. 

try:

    with open("example.txt", "r") as file:
        print(file.read())

except FileNotFoundError:

    print("File not found.")
Error handling makes your program safer when working with files that may be missing or unavailable.

Deleting a File

The os module can be used to delete files. 

import os

os.remove("example.txt")
Be careful: Make sure the file is the correct file before deleting it.

Checking Whether a File Exists

You can use os.path.exists() to check whether a file exists. 

import os

if os.path.exists("example.txt"):
    print("File exists")
else:
    print("File does not exist")

Renaming a File

The os.rename() function can be used to rename a file. 

import os

os.rename("oldname.txt", "newname.txt")

Copying a File

The shutil module provides functions for copying files. 

import shutil

shutil.copy("example.txt", "backup.txt")

This creates a copy of example.txt named backup.txt.

Common File Methods

Method Purpose
read() Reads file contents
readline() Reads one line
readlines() Reads lines into a list
write() Writes data to a file
writelines() Writes multiple strings
seek() Changes file position
tell() Returns current file position
close() Closes the file

Practical Example: Student File

The following program stores student information in a file. 

student_name = "Krish"
student_age = 20
student_course = "BSc IT"

with open("student.txt", "w") as file:

    file.write("Student Name: " + student_name + "\n")
    file.write("Age: " + str(student_age) + "\n")
    file.write("Course: " + student_course)

print("Student information saved successfully.")

The program creates a file named student.txt and stores the student's information inside it.

File handling is commonly used for saving configuration, reports, logs, user information and other persistent data.

Important Rules to Remember

  1. Use open() to open a file.
  2. Use the correct file mode for the operation.
  3. Use read() to read file contents.
  4. Use write() to write data.
  5. Use a mode to append data.
  6. Use with for safer file handling.
  7. Use os for operations such as deleting and renaming files.
  8. Handle possible file errors using exception handling.

Common Mistakes

  • Forgetting to close a file when not using with.
  • Using w mode when you actually want to preserve existing data.
  • Trying to read a file that does not exist.
  • Using an incorrect file path.
  • Forgetting to convert numbers to strings before concatenating them.
  • Deleting a file without checking its name or path.
Remember: Always be careful when using w mode because it can replace existing file contents.
