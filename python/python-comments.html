Python Comments

Learn how to use comments in Python to explain, organize and document your code.

What are Python Comments?

Comments are notes written inside a Python program. They are ignored by Python when the program is executed.

Comments are useful for explaining what your code does. They can also make programs easier for other developers to understand and maintain.

Remember: Comments do not normally change the output of a Python program. They are written for people reading the code.

Single-Line Comments

In Python, a single-line comment starts with the # symbol. 

# This is a comment
print("Hello, World!")

Python ignores everything after the # symbol on that line.

Comment Before Code

You can write a comment before a line of code to explain what the code does. 

# Display a welcome message
print("Welcome to Code With Me!")
Output: 
Welcome to Code With Me!

Comments at the End of a Line

A comment can also be written after a Python statement. 

print("Hello")  # Display Hello

Python executes the print() statement and ignores the comment.

Using Multiple Comments

You can use multiple comments in the same program. 

# Store the user's name
name = "Krish"

# Store the user's age
age = 20

# Display the information
print(name)
print(age)
Output: 
Krish
20

Commenting Out Code

Comments can temporarily disable a line of code. 

print("Line 1")

# print("Line 2")

print("Line 3")

The second print() statement will not execute because it is commented out.

Output: 
Line 1
Line 3

Multi-Line Documentation

Python does not have a separate multi-line comment syntax like some other programming languages.

Triple-quoted strings can be used for multi-line documentation, especially as docstrings. 

"""
This is a multi-line
documentation string.
"""

print("Python")
Important: Triple-quoted strings are strings in Python. They are commonly used as documentation strings (docstrings), rather than being treated as a special comment syntax.

Function Docstrings

A docstring can be placed inside a function to describe what the function does. 

def greet():
    """Display a greeting message."""
    print("Hello!")

greet()
Output: 
Hello!

Class Documentation

Docstrings can also be used inside classes to describe their purpose. 

class Student:
    """Represents a student."""

    pass

This documentation can be accessed by Python tools and developers.

Why Use Comments?

  • Comments explain what code does.
  • Comments make code easier to understand.
  • Comments can help with code maintenance.
  • Comments can temporarily disable code.
  • Comments can provide useful information to other developers.
  • Docstrings can document functions and classes.

Good Comments

A good comment explains something useful that may not be obvious from the code itself. 

# Convert the temperature from Celsius to Fahrenheit
fahrenheit = (celsius * 9 / 5) + 32

The comment explains the purpose of the calculation.

Avoid Unnecessary Comments

Comments should add useful information. Avoid comments that simply repeat obvious code.

For example:

# Store 10 in x
x = 10

The code is already simple enough to understand without this comment.

Tip: Write clear code first, and use comments when they provide additional context.

Python Comment Syntax

Type Syntax Purpose
Single-line comment # Comment Write a comment on one line
Inline comment x = 10 # Value Comment after code
Docstring """Text""" Document functions, classes or modules
