Python While Loop

Learn how to repeat code while a condition is true.

What is a While Loop?

A while loop repeatedly executes a block of code as long as a specified condition is True.

It is useful when you do not know exactly how many times a loop should execute. 

count = 1

while count <= 5:
    print(count)
    count += 1
Output:
1
2
3
4
5

While Loop Syntax

while condition:
    # code to execute
    # update the condition

The condition is checked before every iteration of the loop. If it is True, the loop body runs.

Important: Make sure the condition eventually becomes False. Otherwise, the loop can continue forever.

Simple While Loop Example

number = 1

while number <= 5:
    print("Number:", number)
    number += 1

The variable number starts at 1. After every iteration, its value increases by 1.

Using a Counter

A counter variable is commonly used with while loops. 

count = 0

while count < 5:
    print("Hello")
    count += 1

Here, Hello is printed five times.

Countdown Example

A while loop can also be used to count backwards. 

number = 5

while number >= 1:
    print(number)
    number -= 1

print("Blast Off!")
Output:
5
4
3
2
1
Blast Off!

Using break

The break statement immediately stops a loop. 

number = 1

while number <= 10:
    print(number)

    if number == 5:
        break

    number += 1
The loop stops when number becomes 5.

Using continue

The continue statement skips the current iteration and moves to the next iteration. 

number = 0

while number < 5:
    number += 1

    if number == 3:
        continue

    print(number)
Output:
1
2
4
5

While Loop with else

Python allows an else block with a while loop. The else block executes when the loop finishes normally. 

number = 1

while number <= 3:
    print(number)
    number += 1
else:
    print("Loop completed")
Output:
1
2
3
Loop completed

While else with break

If the loop ends because of break, the else block does not execute. 

number = 1

while number <= 5:
    print(number)

    if number == 3:
        break

    number += 1
else:
    print("Loop completed")
Because the loop ends with break, the else block is skipped.

Infinite While Loop

An infinite loop occurs when the condition never becomes False. 

while True:
    print("This is an infinite loop")
Warning: Do not run an infinite loop unless you intentionally use break or another mechanism to stop it.

Stopping an Infinite Loop

while True:
    command = input("Enter quit to stop: ")

    if command == "quit":
        break

While Loop with User Input

A while loop can repeatedly ask the user for input. 

password = ""

while password != "1234":
    password = input("Enter password: ")

print("Access granted")

Calculate Sum Using While Loop

number = 1
total = 0

while number <= 5:
    total += number
    number += 1

print("Total:", total)
Output: Total: 15

Multiplication Table

A while loop can be used to generate a multiplication table. 

number = 5
i = 1

while i <= 10:
    print(number, "x", i, "=", number * i)
    i += 1

Nested While Loops

A while loop inside another while loop is called a nested while loop. 

i = 1

while i <= 3:
    j = 1

    while j <= 3:
        print(i, j)
        j += 1

    i += 1

While Loop vs For Loop

Feature While Loop For Loop
Condition Based Yes Usually sequence/range based
Known Number of Iterations Not always necessary Usually known
Counter Required Often Usually handled automatically
Infinite Loop Possibility Yes Possible with suitable conditions
Best Use Repeat until a condition changes Iterate over a sequence/range

Common While Loop Mistakes

1. Forgetting to Update the Variable

number = 1

while number <= 5:
    print(number)

# number never changes
This can create an infinite loop.

2. Wrong Condition

number = 10

while number < 5:
    print(number)
    number += 1

The loop does not execute because the condition is initially False.

3. Incorrect Indentation

number = 1

while number <= 5:
    print(number)
    number += 1

Python uses indentation to define the loop body.

Important Rules of While Loops

  • The while keyword starts the loop.
  • The condition must evaluate to True or False.
  • Use a colon : after the condition.
  • Indent the code inside the loop.
  • Update the loop variable when necessary.
  • break stops the loop.
  • continue skips an iteration.
  • An else block can be used with while.
  • Be careful with infinite loops.

Practical Example: Number Guessing

A while loop is useful for repeatedly asking the user to guess a number. 

secret = 7
guess = 0

while guess != secret:
    guess = int(input("Guess the number: "))

    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")

print("Correct!")
