Python Variables

Learn how to create, assign, change and use variables in Python programs.

What is a Variable?

A variable is a name that refers to a value stored by a Python program.

Variables are useful for storing information such as names, ages, prices, numbers and other data.

Example: 
name = "Krish"

Here, name is the variable and "Krish" is the value assigned to it.

Creating Variables

In Python, you can create a variable by assigning a value to a name using the = operator. 

name = "Krish"
age = 20
country = "India"

Python automatically determines the type of value being assigned.

Printing Variables

You can use the print() function to display the value of a variable. 

name = "Krish"

print(name)
Output: 
Krish

Variables Can Store Different Types of Data

A variable can store different types of values. 

name = "Krish"
age = 20
height = 5.8
is_student = True

These variables store a string, integer, floating-point number and Boolean value.

String Variables

A string variable stores text. 

name = "Code With Me"

print(name)

Strings can use either single or double quotation marks. 

name1 = "Python"
name2 = 'Programming'

print(name1)
print(name2)

Integer Variables

Integer variables store whole numbers. 

age = 20
year = 2026

print(age)
print(year)

Float Variables

Float variables store numbers that contain decimal values. 

price = 99.99
height = 5.8

print(price)
print(height)

Boolean Variables

Boolean variables have one of two values: True or False. 

is_student = True
is_logged_in = False

print(is_student)
print(is_logged_in)

Creating Multiple Variables

Python allows you to create multiple variables in different ways.

Separate Assignment

name = "Krish"
age = 20
city = "Ahmedabad"

Multiple Assignment

name, age, city = "Krish", 20, "Ahmedabad"

print(name)
print(age)
print(city)

Assigning the Same Value to Multiple Variables

You can assign the same value to multiple variables in one statement. 

x = y = z = 100

print(x)
print(y)
print(z)
Output: 
100
100
100

Changing Variable Values

A variable's value can be changed after it has been created. 

age = 20

print(age)

age = 21

print(age)
Output: 
20
21

Checking Variable Type

The type() function can be used to find the type of a value. 

name = "Krish"
age = 20
height = 5.8

print(type(name))
print(type(age))
print(type(height))
Example Output: 
<class 'str'>
<class 'int'>
<class 'float'>

Python Variable Names

Variable names should clearly describe the data they store. 

student_name = "Krish"
student_age = 20

Using descriptive names makes your program easier to read.

Rules for Python Variable Names

  • A variable name must start with a letter or underscore.
  • A variable name cannot start with a number.
  • A variable name can contain letters, numbers and underscores.
  • Variable names are case-sensitive.
  • Python keywords cannot be used as variable names.

Valid Variable Names

name = "Krish"
student_name = "Krish"
age2 = 20
_student = "Python"
student123 = "Code"

Invalid Variable Names

The following examples are invalid variable names: 

2name = "Krish"
student-name = "Krish"
student name = "Krish"
Tip: Use underscores instead of spaces or hyphens. 
student_name = "Krish"

Variables are Case-Sensitive

Python treats uppercase and lowercase letters as different. 

name = "Krish"
Name = "Patel"

print(name)
print(Name)
Remember: name and Name are two different variables.

Local and Global Variables

Variables created outside a function are generally available in the surrounding/global scope. 

name = "Krish"

def greet():
    print(name)

greet()

A variable created inside a function normally belongs to that function's local scope. 

def greet():
    message = "Hello"
    print(message)

greet()
