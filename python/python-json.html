Python JSON

Learn how to work with JSON data in Python.

What is JSON?

JSON stands for JavaScript Object Notation.

JSON is a popular format used to store and exchange data between applications, websites, servers, and APIs.

Simple Definition: JSON is a text-based format used to represent structured data.

Example JSON

{
    "name": "Krish",
    "age": 20,
    "course": "B.Sc IT"
}

JSON Data Types

JSON supports several common data types:

JSON Type Example
String "Krish"
Number 20
Boolean true / false
Object {"name": "Krish"}
Array ["HTML", "CSS", "Python"]
Null null

Python json Module

Python provides a built-in json module for working with JSON data.

You can import it using:

import json
You do not need to install the json module because it is included with Python.

json.loads()

The json.loads() function converts a JSON string into a Python object. 

import json

json_data = '{"name": "Krish", "age": 20}'

data = json.loads(json_data)

print(data)

Output:

{'name': 'Krish', 'age': 20}
Remember: loads means load string.

Accessing JSON Data

After converting JSON into a Python dictionary, you can access its values using keys. 

import json

json_data = '{"name": "Krish", "age": 20}'

data = json.loads(json_data)

print(data["name"])
print(data["age"])

Output:

Krish
20

json.dumps()

The json.dumps() function converts a Python object into a JSON string. 

import json

student = {
    "name": "Krish",
    "age": 20,
    "course": "B.Sc IT"
}

json_data = json.dumps(student)

print(json_data)

Output:

{"name": "Krish", "age": 20, "course": "B.Sc IT"}
Remember: dumps means dump string.

Pretty Printing JSON

You can use the indent parameter to make JSON easier to read. 

import json

student = {
    "name": "Krish",
    "age": 20,
    "course": "B.Sc IT"
}

print(json.dumps(student, indent=4))

Output:

{
    "name": "Krish",
    "age": 20,
    "course": "B.Sc IT"
}

Sorting JSON Keys

The sort_keys=True option sorts dictionary keys alphabetically. 

import json

student = {
    "course": "B.Sc IT",
    "name": "Krish",
    "age": 20
}

print(json.dumps(student, indent=4, sort_keys=True))

Python Objects to JSON

Python objects can be converted to JSON using json.dumps().

Python JSON

JSON to Python

JSON data can be converted into Python objects using json.loads(). 

import json

json_data = '''
{
    "name": "Krish",
    "age": 20,
    "skills": ["Python", "HTML", "CSS"]
}
'''

data = json.loads(json_data)

print(type(data))
print(data["skills"])

Output:

<class 'dict'>
['Python', 'HTML', 'CSS']

Working with JSON Arrays

JSON arrays are converted into Python lists. 

import json

json_data = '["HTML", "CSS", "JavaScript", "Python"]'

languages = json.loads(json_data)

for language in languages:
    print(language)

Output:

HTML
CSS
JavaScript
Python

Nested JSON

JSON objects can contain other objects and arrays. 

import json

json_data = '''
{
    "student": {
        "name": "Krish",
        "age": 20,
        "skills": [
            "Python",
            "HTML",
            "CSS"
        ]
    }
}
'''

data = json.loads(json_data)

print(data["student"]["name"])
print(data["student"]["skills"][0])

Output:

Krish
Python

Modify JSON Data

After converting JSON to a Python dictionary, you can modify the data like a normal dictionary. 

import json

json_data = '{"name": "Krish", "age": 20}'

data = json.loads(json_data)

data["age"] = 21
data["city"] = "Gujarat"

print(json.dumps(data, indent=4))

Output:

{
    "name": "Krish",
    "age": 21,
    "city": "Gujarat"
}

Working with JSON Files

Python can read and write JSON data directly to files.

Writing JSON to a File

import json

student = {
    "name": "Krish",
    "age": 20,
    "course": "B.Sc IT"
}

with open("student.json", "w") as file:
    json.dump(student, file, indent=4)

Reading JSON from a File

import json

with open("student.json", "r") as file:
    data = json.load(file)

print(data)

json.load()

The json.load() function reads JSON data from a file. 

import json

with open("data.json", "r") as file:
    data = json.load(file)

print(data)
json.load() works with a file, while json.loads() works with a JSON string.

json.dump()

The json.dump() function writes Python data into a JSON file. 

import json

data = {
    "name": "Krish",
    "age": 20
}

with open("data.json", "w") as file:
    json.dump(data, file, indent=4)
json.dump() writes to a file, while json.dumps() returns a JSON string.

Four Important JSON Functions

Function Purpose
json.loads() JSON string → Python object
json.dumps() Python object → JSON string
json.load() JSON file → Python object
json.dump() Python object → JSON file

JSON and APIs

JSON is commonly used when applications exchange data through APIs.

For example, a server may send information like: 

{
    "id": 101,
    "name": "Krish",
    "course": "Python",
    "completed": true
}

Python can convert this JSON response into dictionaries and lists so the data can be processed easily.

Handling Invalid JSON

Invalid JSON can cause a json.JSONDecodeError. 

import json

try:
    data = json.loads('{"name": "Krish"')

except json.JSONDecodeError:
    print("Invalid JSON data.")

Output:

Invalid JSON data.

Practical Example

The following example creates student information, converts it to JSON, and then reads the data again. 

import json

student = {
    "name": "Krish",
    "age": 20,
    "course": "B.Sc IT",
    "skills": [
        "Python",
        "HTML",
        "CSS"
    ]
}

json_data = json.dumps(student, indent=4)

print("JSON Data:")
print(json_data)

data = json.loads(json_data)

print("\nStudent Name:", data["name"])
print("Course:", data["course"])

Important Points to Remember

  • JSON stands for JavaScript Object Notation.
  • Python provides the built-in json module.
  • Use json.loads() for JSON strings.
  • Use json.dumps() to create JSON strings.
  • Use json.load() to read JSON files.
  • Use json.dump() to write JSON files.
  • JSON objects are converted to Python dictionaries.
  • JSON arrays are converted to Python lists.
  • JSON is widely used by APIs and web applications.
