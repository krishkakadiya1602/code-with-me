Python Lambda

Learn small anonymous functions using the lambda expression.

What is a Lambda Function?

A lambda function is a small anonymous function in Python. It can have any number of arguments, but it can contain only one expression.

Lambda functions are useful when you need a simple function for a short period of time. 

square = lambda x: x * x

print(square(5))
Output: 25

Lambda Syntax

lambda arguments: expression

For example:

add = lambda a, b: a + b

print(add(10, 5))
  • lambda is the keyword.
  • a, b are the arguments.
  • a + b is the expression.
  • The result of the expression is returned automatically.

Lambda vs Normal Function

Normal Function

def square(x):
    return x * x

print(square(5))

Lambda Function

square = lambda x: x * x

print(square(5))
Lambda functions are generally used for short and simple operations. Use a normal def function when the logic is larger or needs to be reused clearly.

Lambda with One Argument

double = lambda x: x * 2

print(double(10))
Output: 20

Lambda with Multiple Arguments

A lambda function can accept multiple arguments. 

add = lambda a, b: a + b

print(add(10, 20))

Three Arguments

multiply = lambda a, b, c: a * b * c

print(multiply(2, 3, 4))
Output: 24

Lambda with if-else

A lambda expression can contain a conditional expression. 

check = lambda x: "Positive" if x > 0 else "Negative"

print(check(10))
print(check(-5))
Output:
Positive
Negative

Lambda for Even and Odd

check = lambda x: "Even" if x % 2 == 0 else "Odd"

print(check(10))
print(check(7))

Lambda with map()

The map() function applies a function to every item in an iterable. 

numbers = [1, 2, 3, 4, 5]

squares = list(map(lambda x: x * x, numbers))

print(squares)
Output: [1, 4, 9, 16, 25]

Lambda with filter()

The filter() function selects items that satisfy a condition. 

numbers = [1, 2, 3, 4, 5, 6]

even_numbers = list(
    filter(lambda x: x % 2 == 0, numbers)
)

print(even_numbers)
Output: [2, 4, 6]

Lambda with reduce()

The reduce() function repeatedly applies a function to the items of an iterable and produces a single result.

It is available from Python's functools module. 

from functools import reduce

numbers = [1, 2, 3, 4, 5]

total = reduce(
    lambda a, b: a + b,
    numbers
)

print(total)
Output: 15

Lambda with sorted()

Lambda functions can be used as the key argument of sorted(). 

students = [
    ("Krish", 85),
    ("Rahul", 72),
    ("Amit", 91)
]

students.sort(key=lambda student: student[1])

print(students)
The list is sorted according to the marks stored at index 1.

Lambda with Dictionaries

Lambda functions are useful when sorting dictionaries or dictionary items. 

students = {
    "Krish": 85,
    "Rahul": 72,
    "Amit": 91
}

result = sorted(
    students.items(),
    key=lambda item: item[1]
)

print(result)

Lambda Returning Another Lambda

A lambda function can return another function. 

def multiplier(n):
    return lambda x: x * n

double = multiplier(2)

print(double(10))
Output: 20

Practical Example: Calculate Square

square = lambda number: number * number

number = 8

print("Square:", square(number))

Practical Example: Find Maximum

maximum = lambda a, b: a if a > b else b

print(maximum(20, 15))
Output: 20

Practical Example: Calculate Price with Tax

price_with_tax = lambda price: price + (price * 0.18)

print(price_with_tax(1000))
Output: 1180.0

Characteristics of Lambda Functions

Feature Lambda Function
Keyword lambda
Function Name Usually anonymous
Number of Arguments Can have multiple arguments
Expressions One expression
Return Automatically returns expression result
Common Uses map(), filter(), sorted(), reduce()

Advantages of Lambda Functions

  • Useful for short functions.
  • Can make simple operations concise.
  • Useful with map().
  • Useful with filter().
  • Useful with sorted().
  • Useful with reduce().
  • Can be passed as a function argument.

Limitations of Lambda Functions

  • Only one expression is allowed.
  • Complex logic can become difficult to read.
  • They are not suitable for large functions.
  • Normal def functions are often clearer for complex logic.
Tip: Use lambda functions when they make the code simpler. Do not use them just to make every function shorter.

Important Lambda Rules

  • Use the lambda keyword.
  • Arguments are written before the colon.
  • The expression is written after the colon.
  • A lambda can accept multiple arguments.
  • A lambda contains one expression.
  • The expression result is returned automatically.
  • Lambda functions are often used with built-in functions.
