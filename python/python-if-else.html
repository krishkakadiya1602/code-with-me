Python If Else

Learn how to make decisions in Python using conditional statements.

Introduction to Python If Else

In Python, conditional statements are used to make decisions based on conditions.

The most commonly used conditional statements are:

  • if
  • elif
  • else
Example: If a student's marks are greater than or equal to 40, the student passes. Otherwise, the student fails.

1. Python if Statement

The if statement executes a block of code when a condition is true.

Syntax

if condition:
    # code to execute

Example

age = 18

if age >= 18:
    print("You are an adult.")

Output:

You are an adult.

2. Indentation in Python

Python uses indentation to define a block of code. Usually, four spaces are used. 

age = 20

if age >= 18:
    print("Adult")
    print("You can vote.")
Important: Do not forget indentation after an if statement.

3. Python if...else Statement

The else block runs when the if condition is false.

Syntax

if condition:
    # if block
else:
    # else block

Example

age = 15

if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

Output:

You are a minor.

4. Python if...elif...else

The elif statement is used when you want to check multiple conditions.

Syntax

if condition1:
    # code
elif condition2:
    # code
else:
    # code

Example

marks = 75

if marks >= 90:
    print("Grade A+")
elif marks >= 75:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
else:
    print("Grade C")

Output:

Grade A

5. Multiple elif Statements

You can use multiple elif statements when there are many conditions. 

marks = 82

if marks >= 90:
    print("Excellent")
elif marks >= 80:
    print("Very Good")
elif marks >= 70:
    print("Good")
elif marks >= 60:
    print("Average")
else:
    print("Need Improvement")

Output:

Very Good

6. If Else with Comparison Operators

Comparison operators are commonly used with conditions.

Operator Meaning Example
== Equal to 5 == 5
!= Not equal to 5 != 3
> Greater than 8 > 5
< Less than 3 < 7
>= Greater than or equal to 10 >= 10
<= Less than or equal to 5 <= 10

Example

number = 10

if number > 5:
    print("Number is greater than 5")

7. If Else with Logical Operators

Python provides logical operators such as and, or, and not.

Using and

age = 20
has_id = True

if age >= 18 and has_id:
    print("Access allowed")
else:
    print("Access denied")

Using or

day = "Sunday"

if day == "Saturday" or day == "Sunday":
    print("Weekend")
else:
    print("Weekday")

Using not

logged_in = False

if not logged_in:
    print("Please login.")

8. Nested if Statement

An if statement inside another if statement is called a nested if statement. 

age = 20
has_id = True

if age >= 18:
    if has_id:
        print("You can enter.")
    else:
        print("ID is required.")
else:
    print("You are under 18.")

Output:

You can enter.

9. Check Even or Odd

We can use an if...else statement to check whether a number is even or odd. 

number = 8

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")

Output:

Even number

10. Check Positive, Negative or Zero

number = -5

if number > 0:
    print("Positive")
elif number < 0:
    print("Negative")
else:
    print("Zero")

Output:

Negative

11. Python One-Line if...else

Python allows you to write a simple if...else statement in one line. 

age = 20

message = "Adult" if age >= 18 else "Minor"

print(message)

Output:

Adult

12. If Else with Strings

username = "admin"

if username == "admin":
    print("Welcome Admin")
else:
    print("Welcome User")

Output:

Welcome Admin

13. If Else with Membership Operators

The in operator can be used to check whether an item exists in a sequence. 

fruits = ["apple", "banana", "mango"]

if "mango" in fruits:
    print("Mango is available.")
else:
    print("Mango is not available.")

Output:

Mango is available.

14. If Else with User Input

You can use conditional statements together with input(). 

age = int(input("Enter your age: "))

if age >= 18:
    print("You are eligible.")
else:
    print("You are not eligible.")
Note: input() returns text, so int() is used when we need a number.

Important Points

  • Use if to test a condition.
  • Use elif to test additional conditions.
  • Use else when all previous conditions are false.
  • Python uses indentation to define code blocks.
  • Conditions usually return either True or False.
  • You can combine conditions using and, or, and not.
  • You can use nested if statements for more complex decisions.
  • Python also supports a one-line conditional expression.
