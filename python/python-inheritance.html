Python Inheritance

Learn how one class can inherit properties and methods from another class.

What is Inheritance?

Inheritance is an important concept of Object-Oriented Programming (OOP) in Python.

It allows a child class to use the properties and methods of another class called the parent class.

Simple Definition: Inheritance allows a new class to reuse code from an existing class.

Basic Structure

class Parent:
    def method(self):
        print("Parent method")


class Child(Parent):
    pass


obj = Child()
obj.method()

Parent Class and Child Class

The class whose properties and methods are inherited is called the Parent Class.

The class that inherits from the parent class is called the Child Class. 

class Animal:
    def eat(self):
        print("Animal is eating")


class Dog(Animal):
    pass


dog = Dog()
dog.eat()

Output:

Animal is eating

Simple Inheritance Example

class Person:
    def show_name(self):
        print("My name is Krish")


class Student(Person):
    def study(self):
        print("I am studying Python")


student = Student()

student.show_name()
student.study()

Output:

My name is Krish
I am studying Python
The Student class can use both its own method and the inherited method from Person.

Types of Inheritance

Python supports several types of inheritance:

  1. Single Inheritance
  2. Multiple Inheritance
  3. Multilevel Inheritance
  4. Hierarchical Inheritance
  5. Hybrid Inheritance

1. Single Inheritance

Single inheritance means one child class inherits from one parent class. 

class Parent:
    def parent_method(self):
        print("Parent method")


class Child(Parent):
    def child_method(self):
        print("Child method")


obj = Child()

obj.parent_method()
obj.child_method()

Output:

Parent method
Child method

2. Multiple Inheritance

Multiple inheritance means one child class inherits from more than one parent class. 

class Father:
    def father_method(self):
        print("Father method")


class Mother:
    def mother_method(self):
        print("Mother method")


class Child(Father, Mother):
    pass


obj = Child()

obj.father_method()
obj.mother_method()

Output:

Father method
Mother method

3. Multilevel Inheritance

In multilevel inheritance, a class inherits from another class which itself inherits from another class. 

class Grandparent:
    def grandparent_method(self):
        print("Grandparent")


class Parent(Grandparent):
    def parent_method(self):
        print("Parent")


class Child(Parent):
    def child_method(self):
        print("Child")


obj = Child()

obj.grandparent_method()
obj.parent_method()
obj.child_method()

Output:

Grandparent
Parent
Child

4. Hierarchical Inheritance

Hierarchical inheritance occurs when multiple child classes inherit from the same parent class. 

class Animal:
    def eat(self):
        print("Animal eats")


class Dog(Animal):
    def bark(self):
        print("Dog barks")


class Cat(Animal):
    def meow(self):
        print("Cat meows")


dog = Dog()
dog.eat()
dog.bark()

cat = Cat()
cat.eat()
cat.meow()

5. Hybrid Inheritance

Hybrid inheritance is a combination of two or more types of inheritance. 

class A:
    def method_a(self):
        print("Class A")


class B(A):
    def method_b(self):
        print("Class B")


class C(A):
    def method_c(self):
        print("Class C")


class D(B, C):
    def method_d(self):
        print("Class D")


obj = D()

obj.method_a()
obj.method_b()
obj.method_c()
obj.method_d()

Inheritance with Constructor

A child class can define its own constructor using __init__(). 

class Person:
    def __init__(self, name):
        self.name = name


class Student(Person):
    def show(self):
        print("Name:", self.name)


student = Student("Krish")
student.show()

Output:

Name: Krish

Using super()

The super() function is used to call methods or the constructor of the parent class. 

class Person:
    def __init__(self, name):
        self.name = name


class Student(Person):
    def __init__(self, name, course):
        super().__init__(name)
        self.course = course

    def display(self):
        print("Name:", self.name)
        print("Course:", self.course)


student = Student("Krish", "B.Sc IT")
student.display()

Output:

Name: Krish
Course: B.Sc IT

Method Overriding

Method overriding happens when a child class provides its own version of a method that already exists in the parent class. 

class Animal:
    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):
    def sound(self):
        print("Dog barks")


dog = Dog()
dog.sound()

Output:

Dog barks

Practical Example

Here is a simple example of inheritance using employees. 

class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def display(self):
        print("Name:", self.name)
        print("Salary:", self.salary)


class Manager(Employee):
    def display_role(self):
        print("Role: Manager")


manager = Manager("Krish", 50000)

manager.display()
manager.display_role()

Output:

Name: Krish
Salary: 50000
Role: Manager

Method Resolution Order (MRO)

When multiple inheritance is used, Python needs to determine the order in which classes are searched for a method.

This order is called Method Resolution Order (MRO). 

class A:
    pass


class B(A):
    pass


class C(A):
    pass


class D(B, C):
    pass


print(D.mro())

Output:

[<class '__main__.D'>,
 <class '__main__.B'>,
 <class '__main__.C'>,
 <class '__main__.A'>,
 <class 'object'>]

Advantages of Inheritance

  • Code can be reused.
  • Reduces duplicate code.
  • Makes programs easier to organize.
  • Supports code extension.
  • Helps implement Object-Oriented Programming.
  • Makes large applications easier to maintain.

Important Points to Remember

  • Inheritance allows a child class to reuse parent class code.
  • Parent class is also called a base or superclass.
  • Child class is also called a derived or subclass.
  • Use class Child(Parent): for inheritance.
  • Use super() to access parent functionality.
  • Python supports multiple inheritance.
  • Child classes can override parent methods.
  • Python uses MRO to determine method lookup order.
