Python Exceptions

Learn how to handle errors and exceptions safely in Python.

What is an Exception?

An exception is an error that occurs while a Python program is running.

If an exception is not handled, the program may stop and display an error message.

Simple Definition: Exception handling allows us to detect and handle errors without suddenly stopping the program.

Example

number = 10
result = number / 0

print(result)

The above program produces a ZeroDivisionError because a number cannot be divided by zero.

Errors and Exceptions

Python programs can encounter different types of problems.

Type Description
Syntax Error Occurs when Python syntax is written incorrectly.
Exception Occurs while the program is running.
Logical Error Program runs but produces an incorrect result.

try and except

The try block contains code that may produce an exception.

The except block handles the exception. 

try:
    number = 10 / 0
except:
    print("An error occurred")

Output:

An error occurred
Use try for risky code and except to handle the error.

Handling a Specific Exception

It is usually better to specify the type of exception you want to handle. 

try:
    number = 10 / 0
except ZeroDivisionError:
    print("You cannot divide by zero.")

Output:

You cannot divide by zero.

Handling Multiple Exceptions

You can use multiple except blocks to handle different exceptions. 

try:
    number = int(input("Enter a number: "))
    result = 10 / number
    print(result)

except ValueError:
    print("Please enter a valid number.")

except ZeroDivisionError:
    print("Number cannot be zero.")

Using Exception as e

You can store the exception object in a variable using as. 

try:
    number = 10 / 0

except ZeroDivisionError as e:
    print("Error:", e)

Output:

Error: division by zero

try, except and else

The else block runs when no exception occurs. 

try:
    number = 10 / 2

except ZeroDivisionError:
    print("Cannot divide by zero.")

else:
    print("Result:", number)

Output:

Result: 5.0

Structure

try:
    # Code that may cause an exception

except:
    # Code executed if an exception occurs

else:
    # Code executed if no exception occurs

finally

The finally block always executes, whether an exception occurs or not. 

try:
    number = 10 / 2
    print(number)

except ZeroDivisionError:
    print("Division error.")

finally:
    print("Program finished.")

Output:

5.0
Program finished.
Important: finally is commonly used for cleanup operations such as closing files or releasing resources.

Complete Exception Handling Structure

try:
    # Risky code

except SomeError:
    # Handle error

else:
    # Runs when there is no error

finally:
    # Always runs

Common Python Exceptions

Exception Meaning
ValueError Invalid value is used.
TypeError Operation is performed on an inappropriate type.
ZeroDivisionError Number is divided by zero.
IndexError Invalid list or sequence index is used.
KeyError Dictionary key does not exist.
NameError Variable or name is not defined.
FileNotFoundError Requested file cannot be found.
AttributeError Object does not have the requested attribute.
ImportError Required module cannot be imported.

ValueError Example

try:
    age = int("hello")
except ValueError:
    print("Invalid number.")

Output:

Invalid number.

TypeError Example

try:
    result = "10" + 5

except TypeError:
    print("Cannot add string and integer.")

Output:

Cannot add string and integer.

IndexError Example

numbers = [10, 20, 30]

try:
    print(numbers[5])

except IndexError:
    print("Index does not exist.")

Output:

Index does not exist.

KeyError Example

student = {
    "name": "Krish",
    "age": 20
}

try:
    print(student["city"])

except KeyError:
    print("The key does not exist.")

Output:

The key does not exist.

raise Statement

The raise statement allows you to manually create an exception. 

age = 15

if age < 18:
    raise ValueError("You must be 18 or older.")

In this example, the program manually raises a ValueError.

Using raise with try-except

try:
    age = 15

    if age < 18:
        raise ValueError("Age must be 18 or above.")

except ValueError as e:
    print("Error:", e)

Output:

Error: Age must be 18 or above.

Custom Exceptions

Python allows you to create your own exception classes. 

class AgeError(Exception):
    pass


age = 15

try:
    if age < 18:
        raise AgeError("Age must be 18 or older.")

except AgeError as e:
    print("Error:", e)

Output:

Error: Age must be 18 or older.

Exception Handling with Files

Exception handling can be useful when working with files. 

try:
    file = open("example.txt", "r")
    content = file.read()
    print(content)

except FileNotFoundError:
    print("File was not found.")

finally:
    print("File operation completed.")
The finally block can be useful for cleanup operations.

Nested try-except

A try-except block can also be placed inside another try block. 

try:
    print("Outer try")

    try:
        number = 10 / 0

    except ZeroDivisionError:
        print("Inner exception handled.")

except:
    print("Outer exception handled.")

Output:

Outer try
Inner exception handled.

Best Practices

  • Handle specific exceptions whenever possible.
  • Do not use an empty except unnecessarily.
  • Use meaningful error messages.
  • Use finally for cleanup operations.
  • Use custom exceptions when they improve clarity.
  • Do not hide errors without a good reason.
  • Keep exception handling simple and readable.
Tip: Avoid using only except: when you know the specific exception that may occur.

Practical Example: Calculator

try:
    first = float(input("Enter first number: "))
    second = float(input("Enter second number: "))

    result = first / second

    print("Result:", result)

except ValueError:
    print("Please enter valid numbers.")

except ZeroDivisionError:
    print("Cannot divide by zero.")

finally:
    print("Calculator finished.")

except Handles an exception.
else Runs when no exception occurs.
finally Runs whether an exception occurs or not.
raise Manually raises an exception.
Exception Base class for many built-in exceptions.
