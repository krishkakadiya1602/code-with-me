Python Datetime

Learn how to work with dates, times and time differences in Python

What is the datetime Module?

Python provides the datetime module for working with dates and times.

It can be used to get the current date and time, create specific dates, format dates, compare dates and calculate differences between dates.

Simple idea: The datetime module helps Python programs work with dates and times.

Importing datetime

import datetime

Getting the Current Date

Use datetime.date.today() to get today's date. 

import datetime

today = datetime.date.today()

print(today)

Example output:

2026-09-23

Getting the Current Date and Time

Use datetime.datetime.now() to get the current local date and time. 

import datetime

current = datetime.datetime.now()

print(current)

The exact output depends on the date and time when the program is executed.

Creating a Date Object

You can create a specific date using the date() constructor. 

import datetime

birthday = datetime.date(2005, 5, 15)

print(birthday)

Output:

2005-05-15

The order is: year, month, day.

Accessing Date Information

You can access individual parts of a date using attributes. 

import datetime

date = datetime.date(2026, 9, 23)

print(date.year)
print(date.month)
print(date.day)

Output:

2026
9
23

Creating a Time Object

The time() class can represent a time. 

import datetime

time = datetime.time(14, 30, 45)

print(time)

Output:

14:30:45

Accessing Time Values

import datetime

time = datetime.time(14, 30, 45)

print(time.hour)
print(time.minute)
print(time.second)

Creating a datetime Object

The datetime() class can represent both date and time. 

import datetime

event = datetime.datetime(2026, 12, 25, 10, 30, 0)

print(event)

Output:

2026-12-25 10:30:00

Formatting Dates with strftime()

The strftime() method converts a date or datetime into a formatted string. 

import datetime

now = datetime.datetime.now()

formatted = now.strftime("%d-%m-%Y")

print(formatted)

Common Formatting Codes

Code Meaning
%Y Four-digit year
%y Two-digit year
%m Month as a number
%d Day of the month
%A Full weekday name
%a Short weekday name
%B Full month name
%b Short month name
%H Hour in 24-hour format
%M Minute
%S Second

More Date Formatting Examples

import datetime

now = datetime.datetime.now()

print(now.strftime("%Y-%m-%d"))
print(now.strftime("%d/%m/%Y"))
print(now.strftime("%B %d, %Y"))
print(now.strftime("%A"))
print(now.strftime("%H:%M:%S"))

Formatting is useful when displaying dates in a user-friendly format.

Converting a String to a Date

The strptime() method converts a string into a datetime object. 

import datetime

date_string = "23-09-2026"

date = datetime.datetime.strptime(
    date_string,
    "%d-%m-%Y"
)

print(date)

Output:

2026-09-23 00:00:00

Using timedelta

timedelta represents a duration or difference between dates and times. 

import datetime

today = datetime.date.today()

future_date = today + datetime.timedelta(days=7)

print(today)
print(future_date)

This example calculates the date seven days from today.

Subtracting Dates

import datetime

date1 = datetime.date(2026, 9, 23)
date2 = datetime.date(2026, 9, 30)

difference = date2 - date1

print(difference.days)

Output:

7

Adding Days

import datetime

today = datetime.date.today()

tomorrow = today + datetime.timedelta(days=1)

print("Today:", today)
print("Tomorrow:", tomorrow)

Adding Weeks

import datetime

today = datetime.date.today()

next_week = today + datetime.timedelta(weeks=1)

print(next_week)

Working with Months

A month does not have a fixed number of days, so adding a month is different from adding a fixed number of days.

For many simple programs, you can use timedelta for day-based calculations. 

import datetime

date = datetime.date(2026, 9, 23)

after_30_days = date + datetime.timedelta(days=30)

print(after_30_days)
Note: Thirty days is not always the same as one calendar month.

Comparing Dates

Date objects can be compared using comparison operators. 

import datetime

date1 = datetime.date(2026, 9, 23)
date2 = datetime.date(2026, 12, 25)

if date1 < date2:
    print("date1 comes before date2")
else:
    print("date1 comes after date2")

Output:

date1 comes before date2

Finding the Day of the Week

The weekday() method returns a number representing the day of the week. 

import datetime

date = datetime.date(2026, 9, 23)

print(date.weekday())

The result is between 0 and 6, where Monday is 0.

Using isoweekday()

print(date.isoweekday())

Here, Monday is 1 and Sunday is 7.

Replacing Date or Time Values

The replace() method can create a new datetime object with selected values changed. 

import datetime

date = datetime.datetime(2026, 9, 23)

new_date = date.replace(year=2027)

print(new_date)

UTC Date and Time

Python also provides ways to work with UTC date and time. 

from datetime import datetime, timezone

current_utc = datetime.now(timezone.utc)

print(current_utc)
UTC is a common reference time used by applications and computer systems around the world.

Important datetime Classes

Class Purpose
date Represents a date
time Represents a time
datetime Represents date and time together
timedelta Represents a duration or time difference
timezone Represents a timezone

Practical Example: Age Calculator

The datetime module can be used to calculate someone's age. 

from datetime import date

birth_date = date(2005, 5, 15)
today = date.today()

age = today.year - birth_date.year

if (today.month, today.day) < (birth_date.month, birth_date.day):
    age -= 1

print("Age:", age)

This compares the birthday with today's date to calculate the completed age.

Practical Example: Event Countdown

from datetime import date

today = date.today()
event_date = date(2026, 12, 25)

remaining = event_date - today

print("Days remaining:", remaining.days)
This technique can be used for countdowns, deadlines, appointments and event management systems.

Common Mistakes

  • Forgetting to import the datetime module.
  • Using the wrong date format with strptime().
  • Confusing date, time and datetime.
  • Using a string when a date object is required.
  • Forgetting that months and days have different ranges.
  • Confusing local time with UTC.
Tip: Always check the expected date format before converting strings into datetime objects.

Important Rules to Remember

  1. Import the datetime module before using it.
  2. Use date when you only need a date.
  3. Use time when you only need a time.
  4. Use datetime when you need both date and time.
  5. Use strftime() to format datetime values.
  6. Use strptime() to convert formatted strings to datetime.
  7. Use timedelta for date and time differences.
  8. Use timezone-aware datetime values when timezone information matters.
