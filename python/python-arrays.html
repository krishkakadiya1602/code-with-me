Python Arrays

Learn how to store and work with multiple values in Python.

Introduction to Python Arrays

An array is a collection of multiple values stored together. In Python, lists are commonly used for array-like operations.

Python also provides an array module for storing elements of the same type.

Important: For most beginner Python programs, lists are the easiest and most commonly used way to store collections of values.

1. Creating an Array Using a List

You can create a list using square brackets []. 

numbers = [10, 20, 30, 40, 50]

print(numbers)

Output:

[10, 20, 30, 40, 50]

2. Python array Module

Python's built-in array module can be used when you want an array containing values of the same type. 

from array import array

numbers = array("i", [10, 20, 30, 40])

print(numbers)

Here, "i" represents signed integers.

For general-purpose programming, Python lists are usually more flexible than arrays from the array module.

3. Array Indexing

Each element has an index. Python indexes start from 0. 

numbers = [10, 20, 30, 40]

print(numbers[0])
print(numbers[1])
print(numbers[2])
print(numbers[3])

Output:

10
20
30
40

4. Negative Indexing

Negative indexes allow you to access elements from the end of an array-like list. 

numbers = [10, 20, 30, 40]

print(numbers[-1])
print(numbers[-2])

Output:

40
30

5. Updating an Array Element

You can change a list element by using its index. 

numbers = [10, 20, 30, 40]

numbers[1] = 25

print(numbers)

Output:

[10, 25, 30, 40]

6. Adding an Element with append()

The append() method adds an element to the end of a list. 

numbers = [10, 20, 30]

numbers.append(40)

print(numbers)

Output:

[10, 20, 30, 40]

7. Adding an Element with insert()

The insert() method adds an element at a specific position. 

numbers = [10, 20, 40]

numbers.insert(2, 30)

print(numbers)

Output:

[10, 20, 30, 40]

8. Adding Multiple Elements with extend()

numbers = [10, 20, 30]

numbers.extend([40, 50, 60])

print(numbers)

Output:

[10, 20, 30, 40, 50, 60]

9. Removing an Element with remove()

The remove() method removes the first matching value. 

numbers = [10, 20, 30, 40]

numbers.remove(30)

print(numbers)

Output:

[10, 20, 40]

10. Removing an Element with pop()

The pop() method removes an element using its index. 

numbers = [10, 20, 30, 40]

removed = numbers.pop(2)

print("Removed:", removed)
print(numbers)

Output:

Removed: 30
[10, 20, 40]

11. Using del

The del keyword can remove an element or a range of elements. 

numbers = [10, 20, 30, 40]

del numbers[1]

print(numbers)

Output:

[10, 30, 40]

12. Clear an Array

The clear() method removes all elements from a list. 

numbers = [10, 20, 30]

numbers.clear()

print(numbers)

Output:

[]

13. Find Array Length

Use len() to find the number of elements. 

numbers = [10, 20, 30, 40, 50]

print(len(numbers))

Output:

5

14. Loop Through an Array

numbers = [10, 20, 30, 40]

for number in numbers:
    print(number)

Output:

10
20
30
40

15. Loop Using Index

numbers = [10, 20, 30, 40]

for i in range(len(numbers)):
    print(numbers[i])

Output:

10
20
30
40

16. Using enumerate()

The enumerate() function gives both the index and value. 

fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)

Output:

0 Apple
1 Banana
2 Mango

17. Searching an Array

The in operator checks whether a value exists. 

numbers = [10, 20, 30, 40]

if 30 in numbers:
    print("30 is present")
else:
    print("30 is not present")

Output:

30 is present

18. Finding an Element's Index

The index() method returns the position of a value. 

numbers = [10, 20, 30, 40]

position = numbers.index(30)

print(position)

Output:

2

19. Counting Elements

The count() method returns how many times a value occurs. 

numbers = [10, 20, 10, 30, 10]

print(numbers.count(10))

Output:

3

20. Sorting an Array

The sort() method sorts a list in ascending order. 

numbers = [50, 20, 40, 10, 30]

numbers.sort()

print(numbers)

Output:

[10, 20, 30, 40, 50]

21. Reverse an Array

numbers = [10, 20, 30, 40]

numbers.reverse()

print(numbers)

Output:

[40, 30, 20, 10]

22. Copying an Array

Use copy() to create a shallow copy of a list. 

numbers = [10, 20, 30]

new_numbers = numbers.copy()

print(new_numbers)

Output:

[10, 20, 30]

23. Array Slicing

Slicing allows you to access a portion of a list. 

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])

Output:

[20, 30, 40]

24. Reverse Using Slicing

numbers = [10, 20, 30, 40, 50]

print(numbers[::-1])

Output:

[50, 40, 30, 20, 10]

25. Common Array/List Methods

Method Purpose Example
append() Add an item at the end numbers.append(60)

extend() Add multiple items numbers.extend([70, 80])
remove() Remove a value numbers.remove(20)
pop() Remove using index numbers.pop(0)
clear() Remove all items numbers.clear()
index() Find position numbers.index(30)

26. Python List vs Array

Feature List array Module
Syntax [10, 20, 30] array("i", [10, 20, 30])
Data Types Can contain different types Same type
Flexibility High More type-specific
Common Usage Very common Specialized cases

27. Practical Example: Find Largest Number

numbers = [25, 10, 45, 30, 60]

largest = numbers[0]

for number in numbers:

    if number > largest:
        largest = number

print("Largest:", largest)

Output:

Largest: 60

28. Practical Example: Calculate Average

marks = [70, 80, 65, 90, 75]

total = sum(marks)

average = total / len(marks)

print("Total:", total)
print("Average:", average)

Output:

Total: 380
Average: 76.0

Important Points

  • Python lists are commonly used for array-like collections.
  • List indexes start from 0.
  • Negative indexes access elements from the end.
  • Use append() to add an item.
  • Use remove() to remove a value.
  • Use pop() to remove an item by index.
  • Use len() to find the number of elements.
  • Use sort() to sort a list.
  • Use reverse() to reverse a list.
  • Use in to check whether a value exists.
  • The array module provides typed arrays.
