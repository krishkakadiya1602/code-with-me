Python PIP

Learn how to install, manage and use Python packages with PIP

What is PIP?

PIP is the standard package-management tool commonly used to install and manage Python packages from the Python Package Index (PyPI).

Python has many useful packages that provide additional functionality. PIP makes it easy to install these packages in your Python environment.

Simple idea: PIP helps you install and manage additional Python libraries and packages.

Example

pip install requests

Checking Whether PIP is Installed

You can check whether PIP is available by opening a terminal or command prompt. 

pip --version

Example output:

pip 25.x.x from ... (python 3.x)
If the command displays a PIP version, PIP is available from that command environment.

Using PIP Through Python

On some systems, it is useful to run PIP through the Python interpreter. 

python -m pip --version

This can help ensure that PIP is associated with the Python interpreter you are using.

Installing a Package

Use pip install followed by the package name. 

pip install requests

This tells PIP to install the requests package.

Using python -m pip

python -m pip install requests
You can replace requests with the package you want to install.

Upgrading a Package

You can upgrade an installed package using --upgrade. 

pip install --upgrade requests

Or: 

python -m pip install --upgrade requests

Uninstalling a Package

Use pip uninstall to remove an installed package. 

pip uninstall requests

PIP may ask you to confirm the removal.

Make sure you are uninstalling the correct package, especially when working inside a project environment.

Listing Installed Packages

Use pip list to display installed packages. 

pip list

The output normally includes package names and their versions.

Getting Package Information

The pip show command displays information about an installed package. 

pip show requests

It can display information such as the package version, location and dependencies.

Finding Packages

Modern PIP workflows generally use the Python Package Index website or other package documentation to find packages.

After finding a package, install it using its package name. 

pip install package-name
Always check the package documentation and project information before installing third-party packages.

Using requirements.txt

A requirements.txt file can contain the packages required by a Python project.

Example requirements.txt

requests
numpy
pandas

Installing from requirements.txt

pip install -r requirements.txt

This allows a project to install its listed dependencies together.

Installing a Specific Version

You can request a specific package version using ==. 

pip install requests==2.32.0

This is useful when a project requires a particular version of a dependency.

Version Constraints

PIP supports version specifiers for expressing dependency requirements. 

pip install "requests>=2.30"

Another example: 

pip install "requests<3"
When using comparison symbols such as < or >, quoting the requirement can avoid problems with some shells.

Using pip freeze

The pip freeze command displays installed packages in a requirements-style format. 

pip freeze

Saving the Output

pip freeze > requirements.txt

This saves the package versions into requirements.txt.

Installing Project Dependencies

If a project already contains a requirements.txt file, you can install its dependencies with: 

pip install -r requirements.txt
This is commonly used when setting up an existing Python project on another computer.

PIP and Virtual Environments

Python projects often use virtual environments so that each project can have its own dependencies.

Create a Virtual Environment

python -m venv myenv

Windows

myenv\Scripts\activate

macOS / Linux

source myenv/bin/activate

After activation, packages installed with PIP are installed into that environment.

The next lesson in this course explains Python virtual environments in more detail.

Common PIP Commands

Command Purpose
pip --version Show PIP version
pip install package Install a package
pip uninstall package Remove a package
pip install --upgrade package Upgrade a package
pip list List installed packages
pip show package Show package information
pip freeze Display installed packages in requirements format
pip install -r requirements.txt Install project dependencies

Example: Installing and Using Requests

Step 1: Install the Package

pip install requests

Step 2: Import It

import requests

Step 3: Use It

response = requests.get("https://example.com")

print(response.status_code)

The package provides additional functionality that is not part of Python's basic language syntax.

Why Use PIP?

  • Install third-party Python packages.
  • Upgrade packages when needed.
  • Remove packages from an environment.
  • View installed packages.
  • Manage project dependencies.
  • Install packages from a requirements file.
  • Work with isolated virtual environments.

PIP Best Practices

  1. Use a virtual environment for individual projects.
  2. Keep project dependencies documented.
  3. Use requirements.txt when appropriate.
  4. Check package documentation before installing it.
  5. Keep dependencies updated according to project needs.
  6. Use the correct Python environment before running PIP.
Important: Installing a package with PIP does not automatically make it available in every Python environment on your computer.

Common PIP Problems

1. pip is not recognized

If your terminal cannot find the pip command, try running PIP through Python: 

python -m pip --version

2. Package Not Found

Check that the package name is correct and that you are using the intended Python environment.

3. Permission Error

A virtual environment can often avoid the need for installing project packages globally.

4. Wrong Python Environment

Check which Python interpreter is active before installing packages.

Important Rules to Remember

  1. PIP is used to manage Python packages.
  2. Use pip install package to install packages.
  3. Use pip uninstall package to remove packages.
  4. Use pip list to view installed packages.
  5. Use pip show package for package information.
  6. Use pip freeze to record installed package versions.
  7. Use requirements.txt to document dependencies.
  8. Virtual environments help isolate project dependencies.

Summary

  • pip list shows installed packages.
