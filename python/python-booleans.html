Python Booleans

Learn True, False, Boolean Operators and Conditions

What Are Booleans in Python?

A Boolean is a data type that can have only two values: True or False.

Booleans are commonly used when making decisions in a Python program. 

is_student = True
```

is_teacher = False

print(is_student)
print(is_teacher)
```

Output:

True
```

False
```
Important: Python Boolean values must be written as True and False with a capital first letter.

Boolean Data Type

The Boolean data type in Python is called bool. 

x = True
```

y = False

print(type(x))
print(type(y))
```

Output:

<class 'bool'>
```
```

Booleans from Comparisons

Comparison operators return a Boolean value. 

print(10 > 5)
```

print(10 < 5)
print(10 == 10)
print(10 != 10)
```

Output:

True
```

False
True
False
```
Operator Meaning Example Result
== Equal to 10 == 10 True
!= Not equal to 10 != 5 True
> Greater than 10 > 5 True
< Less than 10 < 5 False
>= Greater than or equal to 10 >= 10 True
<= Less than or equal to 5 <= 10 True

Booleans with if Statements

Boolean values are commonly used with if statements. 

age = 20
```

if age >= 18:
print("You are an adult.")
```

Output:

You are an adult.

The comparison age >= 18 returns True, so the code inside the if block executes.

Boolean Variables

You can store Boolean values inside variables. 

is_logged_in = True
```

is_admin = False

print(is_logged_in)
print(is_admin)
```

Output:

True
```

False
```

Boolean variables are useful for representing states such as logged in/not logged in, active/inactive and available/unavailable.

and Operator

The and operator returns True only when both conditions are True. 

age = 20
```

has_id = True

print(age >= 18 and has_id)
```

Output:

True
A B A and B
True True True
True False False
False True False
False False False

or Operator

The or operator returns True when at least one condition is True. 

has_email = True
```

has_phone = False

print(has_email or has_phone)
```

Output:

True
A B A or B
True True True
True False True
False True True
False False False

not Operator

The not operator reverses a Boolean value. 

is_logged_in = False
```

print(not is_logged_in)
```

Output:

True
A not A
True False
False True

Python bool() Function

The bool() function converts a value into a Boolean value. 

print(bool(1))
```

print(bool(0))
print(bool("Hello"))
print(bool(""))
```

Output:

True
```

False
True
False
```
Simple rule: Many non-empty and non-zero values are treated as True, while zero, empty values and None are treated as False.

Truthy and Falsy Values

Python automatically treats certain values as False when they are used in a Boolean context.

Common Falsy Values

  • False
  • None
  • 0
  • 0.0
  • "" - empty string
  • Empty lists, tuples, sets and dictionaries
print(bool(0))
```

print(bool(""))
print(bool([]))
print(bool(None))
```

Output:

False
```

False
False
False
```

Common Truthy Values

print(bool(1))
```

print(bool("Python"))
print(bool([1, 2, 3]))
```

Output:

True
```

True
True

Boolean Expressions

A Boolean expression is an expression that produces either True or False. 

x = 10
```

y = 20

result = x < y

print(result)
```

Output:

True

More Examples

print(5 == 5)
```

print(10 > 20)
print(15 <= 20)
print(25 != 25)
```

Output:

True
```

False

Combining Boolean Operators

You can combine multiple conditions using and, or and not. 

age = 20
```

has_id = True

if age >= 18 and has_id:
print("Entry allowed")
else:
print("Entry denied")
```

Output:

Entry allowed

Boolean Results from is and is not

The is and is not operators test object identity and return Boolean results. 

x = None
```

print(x is None)
print(x is not None)
```

Output:

True
```

False
```
Note: is checks whether two references point to the same object. For comparing values, use operators such as ==.

Boolean Results from Membership Operators

The in and not in operators also return Boolean values. 

languages = ["Python", "JavaScript", "HTML"]
```

print("Python" in languages)
print("Java" in languages)
```

Output:

True
```

False
```

Python Booleans - Summary

  • Python has two Boolean values: True and False.
  • The Boolean data type is called bool.
  • Comparison operations return Boolean values.
  • and requires both conditions to be true.
  • or requires at least one condition to be true.
  • not reverses a Boolean value.
  • bool() converts a value to a Boolean.
  • Zero, empty values and None are commonly falsy.
  • Non-zero and non-empty values are commonly truthy.
  • Booleans are frequently used with if statements.
