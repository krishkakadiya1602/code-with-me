Python Tuples

Learn how to create, access and work with tuples in Python

What is a Tuple?

A tuple is a collection of values in Python. Tuples are ordered and immutable, which means that their elements cannot be changed after the tuple is created.

Tuples are written using round brackets ().

Example:

numbers = (10, 20, 30)

Characteristics of Tuples

Ordered

Tuple elements maintain their order.

Immutable

Tuple elements cannot be changed after creation.

Allow Duplicates

A tuple can contain duplicate values.

Different Data Types

A tuple can contain different types of values.

Creating a Tuple

A tuple can be created by placing values inside parentheses. 

fruits = ("Apple", "Banana", "Mango")

print(fruits)

Creating a Tuple Without Parentheses

Parentheses are optional in many tuple assignments. Python recognizes comma-separated values as a tuple. 

numbers = 10, 20, 30

print(numbers)
print(type(numbers))

Single Item Tuple

When creating a tuple with only one item, you must include a comma after the item. 

number = (10,)

print(number)
print(type(number))
Important:

(10) is an integer, while (10,) is a tuple.

Tuple with Different Data Types

A tuple can contain strings, integers, floats, booleans and other Python objects. 

student = (
    "Krish",
    20,
    7.5,
    True
)

print(student)

Tuple Indexing

Tuple elements can be accessed using their index number. Python uses zero-based indexing. 

fruits = ("Apple", "Banana", "Mango")

print(fruits[0])
print(fruits[1])
print(fruits[2])

Negative Indexing

Negative indexes can be used to access elements from the end of a tuple. 

fruits = ("Apple", "Banana", "Mango")

print(fruits[-1])
print(fruits[-2])
print(fruits[-3])

Tuple Slicing

Slicing is used to extract a portion of a tuple. 

numbers = (10, 20, 30, 40, 50)

print(numbers[1:4])
print(numbers[:3])
print(numbers[2:])
print(numbers[-3:])
The ending index is not included in the slice.

Finding Tuple Length

The len() function returns the number of elements in a tuple. 

numbers = (10, 20, 30, 40)

print(len(numbers))

Checking if an Item Exists

The in operator can be used to check whether a value exists inside a tuple. 

fruits = ("Apple", "Banana", "Mango")

print("Apple" in fruits)
print("Orange" in fruits)

Tuple Methods

Since tuples are immutable, they have fewer methods than lists. Two commonly used tuple methods are count() and index().

Method Description Example
count() Counts how many times a value occurs. numbers.count(10)
index() Returns the index of the first occurrence. numbers.index(10)

count() Method

The count() method returns the number of times a value appears in a tuple. 

numbers = (10, 20, 10, 30, 10)

print(numbers.count(10))

index() Method

The index() method returns the position of the first occurrence of a value. 

fruits = ("Apple", "Banana", "Mango")

print(fruits.index("Banana"))

Tuples are Immutable

Once a tuple has been created, its elements cannot be changed. 

numbers = (10, 20, 30)

# This will cause an error:
# numbers[0] = 100

print(numbers)
Remember:

Lists are mutable, while tuples are immutable.

Tuple Concatenation

You can join two tuples using the + operator. 

tuple1 = (1, 2, 3)
tuple2 = (4, 5, 6)

result = tuple1 + tuple2

print(result)

Tuple Repetition

The * operator can be used to repeat a tuple. 

numbers = (1, 2)

result = numbers * 3

print(result)

Tuple Packing

Tuple packing means putting multiple values into a single tuple. 

student = "Krish", 20, "BSc IT"

print(student)

Tuple Unpacking

Tuple unpacking means assigning the elements of a tuple to separate variables. 

student = ("Krish", 20, "BSc IT")

name, age, course = student

print(name)
print(age)
print(course)

Using * for Unpacking

An asterisk can be used to collect multiple remaining values into a list during tuple unpacking. 

numbers = (10, 20, 30, 40, 50)

first, *middle, last = numbers

print(first)
print(middle)
print(last)

Loop Through a Tuple

You can use a for loop to access every item in a tuple. 

fruits = ("Apple", "Banana", "Mango")

for fruit in fruits:
    print(fruit)

Nested Tuples

A tuple can contain another tuple. This is called a nested tuple. 

numbers = (
    (1, 2),
    (3, 4),
    (5, 6)
)

print(numbers[0])
print(numbers[1][1])

Tuple vs List

Feature Tuple List
Syntax (1, 2, 3) [1, 2, 3]
Mutable No Yes
Ordered Yes Yes
Duplicates Allowed Allowed
Methods Fewer More

Converting List to Tuple

The tuple() function can convert an iterable such as a list into a tuple. 

numbers_list = [10, 20, 30]

numbers_tuple = tuple(numbers_list)

print(numbers_tuple)
print(type(numbers_tuple))

Converting Tuple to List

The list() function can convert a tuple into a list. 

numbers_tuple = (10, 20, 30)

numbers_list = list(numbers_tuple)

print(numbers_list)
print(type(numbers_list))

  • Tuples can contain different data types.
  • Tuple indexes start from 0.
  • Negative indexing can be used.
  • Tuples support slicing.
  • The count() method counts occurrences.
  • The index() method finds an item's index.
