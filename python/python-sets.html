Python Sets

Learn how to create, modify and perform operations on Python Sets

What is a Set in Python?

A set is a collection used to store multiple values in a single variable.

Sets are unordered, unindexed and do not allow duplicate values.

Important: A set is created using curly brackets { } or the set() function. 
fruits = {"Apple", "Banana", "Mango"}
```

print(fruits)
```

The order of items displayed in a set is not guaranteed.

Creating a Set

You can create a set by placing items inside curly brackets. 

numbers = {10, 20, 30, 40}
```

print(numbers)
```

Output contains:

10
```

20
30
40
```
Note: Sets are unordered, so you should not rely on a particular display order.

Sets Do Not Allow Duplicate Values

If duplicate values are added to a set, Python keeps only one copy of each value. 

numbers = {10, 20, 20, 30, 30, 30}
```

print(numbers)
```

The result contains only unique values. 

{10, 20, 30}
Useful: Sets are commonly used when you need to remove duplicate values from a collection.

Finding Set Length

The len() function returns the number of unique items in a set. 

fruits = {"Apple", "Banana", "Mango"}
```

print(len(fruits))
```

Output:

3

Different Data Types in a Set

A set can contain values of different data types. 

my_set = {
"Python",
100,
25.5,
True
```

}

print(my_set)
```

Sets can contain values such as strings, integers, floats and Boolean values.

Using the set() Function

You can use the set() function to create a set from another iterable. 

numbers = [10, 20, 20, 30, 30]
```

unique_numbers = set(numbers)

print(unique_numbers)
```

Output contains:

{10, 20, 30}

Creating an Empty Set

To create an empty set, use set(). 

my_set = set()
```

print(my_set)
```

Output:

set()
Important: {} creates an empty dictionary, not an empty set.

Adding Items to a Set

The add() method adds one item to a set. 

fruits = {"Apple", "Banana"}
```

fruits.add("Mango")

print(fruits)
```

The set now contains Apple, Banana and Mango.

Adding Multiple Items

The update() method adds multiple items from another iterable. 

fruits = {"Apple", "Banana"}
```

more_fruits = {"Mango", "Orange"}

fruits.update(more_fruits)

print(fruits)
```

Both sets are combined and duplicate values are ignored.

Removing Items from a Set

Using remove()

The remove() method removes a specified item. 

fruits = {"Apple", "Banana", "Mango"}
```

fruits.remove("Banana")

print(fruits)
```
Note: remove() raises a KeyError if the specified item does not exist.

Using discard()

The discard() method also removes an item, but it does not raise an error if the item does not exist. 

fruits = {"Apple", "Banana", "Mango"}
```

fruits.discard("Orange")

print(fruits)
```

Using pop()

The pop() method removes and returns an arbitrary item from a set. 

fruits = {"Apple", "Banana", "Mango"}
```

item = fruits.pop()

print(item)
print(fruits)
```
Important: Because sets are unordered, you should not assume which item pop() will remove.

Clear a Set

The clear() method removes all items from a set. 

fruits = {"Apple", "Banana", "Mango"}
```

fruits.clear()

print(fruits)
```

Output:

set()

Delete a Set

The del keyword can delete the entire set variable. 

fruits = {"Apple", "Banana", "Mango"}
```

del fruits
```

After deletion, the variable fruits no longer exists.

Checking if an Item Exists

You can use the in keyword to check whether an item exists in a set. 

fruits = {"Apple", "Banana", "Mango"}
```

print("Banana" in fruits)
print("Orange" in fruits)
```

Output:

True
```

False
```

Using not in

print("Orange" not in fruits)

Output:

True

Loop Through a Set

You can use a for loop to access each item in a set. 

fruits = {"Apple", "Banana", "Mango"}
```

for fruit in fruits:
print(fruit)
```
Remember: Because sets are unordered, the order in which the items are printed is not guaranteed.

Set Union

Union combines all unique items from two sets.

Using | Operator

set1 = {1, 2, 3}
```

set2 = {3, 4, 5}

result = set1 | set2

print(result)
```

Result contains:

{1, 2, 3, 4, 5}

Using union()

result = set1.union(set2)
```

print(result)
```

Set Intersection

Intersection returns items that exist in both sets. 

set1 = {1, 2, 3, 4}
```

set2 = {3, 4, 5, 6}

result = set1 & set2

print(result)
```

Output:

{3, 4}

Using intersection()

result = set1.intersection(set2)
```

print(result)
```

Set Difference

Difference returns items that are present in the first set but not in the second set. 

set1 = {1, 2, 3, 4}
```

set2 = {3, 4, 5, 6}

result = set1 - set2

print(result)
```

Output:

{1, 2}

Using difference()

result = set1.difference(set2)
```

print(result)
```

Symmetric Difference

Symmetric difference returns items that are in either set, but not in both. 

set1 = {1, 2, 3, 4}
```

set2 = {3, 4, 5, 6}

result = set1 ^ set2

print(result)
```

Output:

{1, 2, 5, 6}

Using symmetric_difference()

result = set1.symmetric_difference(set2)
```

print(result)
```

Checking Subsets

A set is a subset of another set when every item in the first set also exists in the second set. 

set1 = {1, 2}
```

set2 = {1, 2, 3, 4}

print(set1.issubset(set2))
```

Output:

True

Checking Supersets

A set is a superset when it contains every item of another set. 

set1 = {1, 2, 3, 4}
```

set2 = {1, 2}

print(set1.issuperset(set2))
```

Output:

True

Checking Disjoint Sets

Two sets are disjoint when they have no common items. 

set1 = {1, 2, 3}
```

set2 = {4, 5, 6}

print(set1.isdisjoint(set2))
```

Output:

True

Copying a Set

The copy() method creates a shallow copy of a set. 

fruits = {"Apple", "Banana", "Mango"}
```

new_fruits = fruits.copy()

print(new_fruits)
```

You can also use the set() constructor. 

new_fruits = set(fruits)
```

print(new_fruits)
```

Common Python Set Methods

Method Description
add() Adds an item to the set.
update() Adds items from another iterable.
remove() Removes a specified item.
discard() Removes an item without raising an error if absent.
pop() Removes and returns an arbitrary item.
clear() Removes all items.
union() Returns all unique items from both sets.
intersection() Returns common items.
difference() Returns items only in the first set.
symmetric_difference() Returns items that are in either set, but not both.
issubset() Checks whether a set is a subset.
issuperset() Checks whether a set is a superset.
isdisjoint() Checks whether two sets have no common items.
copy() Creates a copy of the set.

Removing Duplicates from a List

A common use of sets is removing duplicate values from a list. 

numbers = [10, 20, 20, 30, 30, 40]
```

unique_numbers = list(set(numbers))

print(unique_numbers)
```
Note: Converting a list to a set removes duplicates, but because sets are unordered, the original ordering should not be relied upon.

student1 = {

student2 = {

{'Python', 'CSS'}
