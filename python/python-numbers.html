Python Numbers

Learn Integers, Floats, Complex Numbers and Number Operations

What Are Numbers in Python?

Numbers are one of the most important data types in Python. They are used to store numerical values and perform mathematical calculations.

Python mainly provides three types of numbers:

  • int - Integer numbers
  • float - Decimal numbers
  • complex - Complex numbers
Example: Python can work with positive numbers, negative numbers, decimal numbers and complex numbers.

1. Integer (int)

An integer is a whole number without a decimal point. Integers can be positive, negative or zero. 

x = 10
```

y = -20
z = 0

print(x)
print(y)
print(z)
```

Output:

10
```

-20
0
```
Remember: Python integers do not have a fixed small size like some other programming languages. They can grow to very large values, limited mainly by available memory.

2. Float (float)

A float represents a number containing a decimal point. 

price = 99.99
```

temperature = 36.5
height = 5.8

print(price)
print(temperature)
print(height)
```

Output:

99.99
```

36.5
5.8
```

Negative Float

x = -25.75
```

print(x)
```

Output:

-25.75

3. Complex Numbers

A complex number contains a real part and an imaginary part. Python uses j to represent the imaginary part. 

x = 3 + 5j
```

print(x)
```

Output:

(3+5j)

Real and Imaginary Parts

x = 3 + 5j
```

print(x.real)
print(x.imag)
```

Output:

3.0
```

5.0
```

Checking Number Type

You can use the type() function to find the data type of a number. 

x = 100
```

y = 25.5
z = 2 + 3j

print(type(x))
print(type(y))
print(type(z))
```

Output:

<class 'int'>

Arithmetic Operations

Python provides several operators for performing mathematical calculations.

Operator Name Example Result
+ Addition 10 + 5 15
- Subtraction 10 - 5 5
* Multiplication 10 * 5 50
/ Division 10 / 5 2.0
// Floor Division 10 // 3 3
% Modulus 10 % 3 1
** Exponentiation 2 ** 3 8

Addition

a = 20
```

b = 30

result = a + b

print(result)
```

Output:

50

Subtraction

a = 50
```

b = 20

result = a - b

print(result)
```

Output:

30

Multiplication

a = 10
```

b = 5

result = a * b

print(result)
```

Output:

50

Division

The / operator performs division and returns a float value. 

a = 10
```

b = 4

result = a / b

print(result)
```

Output:

2.5

Floor Division

The // operator performs floor division. It returns the floor of the division result. 

a = 10
```

b = 3

print(a // b)
```

Output:

3
Note: Floor division is not simply "remove the decimal part". For negative values, Python floors toward negative infinity. 
print(-10 // 3)

Output:

-4

Modulus Operator (%)

The modulus operator returns the remainder after division. 

a = 10
```

b = 3

print(a % b)
```

Output:

1

Checking Even and Odd Numbers

number = 10
```

if number % 2 == 0:
print("Even number")
else:
print("Odd number")
```

Output:

Even number

Exponentiation (**)

The ** operator is used to calculate powers. 

result = 2 ** 3
```

print(result)
```

Output:

8

This means: 

2 × 2 × 2 = 8

Number Type Conversion

Python provides functions such as int(), float() and complex() to convert values between number types.

Convert Float to Integer

x = 10.8
```

y = int(x)

print(y)
```

Output:

10
Important: Converting a float to int removes the fractional part. It does not round the number.

Convert Integer to Float

x = 10
```

y = float(x)

print(y)
```

Output:

10.0

Convert Integer to Complex

x = 10
```

y = complex(x)

print(y)
```

Output:

(10+0j)

Useful Number Functions

abs()

The abs() function returns the absolute value of a number. 

number = -25
```

print(abs(number))
```

Output:

25

round()

The round() function rounds a number. 

number = 15.678
```

print(round(number))
```

Output:

16

pow()

The pow() function can be used to calculate powers. 

result = pow(2, 4)
```

print(result)
```

Output:

16

min() and max()

numbers = [10, 25, 5, 40, 15]
```

print(min(numbers))
print(max(numbers))
```

Output:

5
```

40
```

sum()

numbers = [10, 20, 30]
```

print(sum(numbers))
```

Output:

60

Large Numbers and Underscores

Python allows underscores inside numeric literals to make large numbers easier to read. 

population = 1_000_000
```

print(population)
```

Output:

1000000

The underscores do not change the value of the number.

Scientific Notation

Python supports scientific notation using e or E. 

x = 5e3
```

print(x)
```

Output:

5000.0

Another example:

x = 2.5e2
```

print(x)
```

Output:

250.0

Numbers can be compared using comparison operators. 

a = 20

b = 10

print(a > b)
print(a < b)
print(a == b)
print(a != b)
```

Output:

True
```

False

True

Python Numbers - Summary

  • int is used for whole numbers.
  • float is used for decimal numbers.
  • complex is used for complex numbers.
  • + performs addition.
  • - performs subtraction.
  • * performs multiplication.
  • / performs division.
  • // performs floor division.
  • % returns the remainder.
  • ** calculates powers.
  • type() checks the type of a value.
  • int(), float(), complex() can convert numeric values.
