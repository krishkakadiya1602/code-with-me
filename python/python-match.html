Python Match Statement

Learn pattern matching with match and case in Python.

What is the Python Match Statement?

The match statement is used for pattern matching in Python. It was introduced in Python 3.10.

It can be used when you want to compare a value against multiple possible patterns. 

day = 2

match day:
    case 1:
        print("Monday")
    case 2:
        print("Tuesday")
    case 3:
        print("Wednesday")
    case _:
        print("Invalid day")
Important: The _ pattern works like a default case when no other pattern matches.

Basic Syntax

The basic structure of a match statement is: 

match expression:
    case pattern1:
        # code
    case pattern2:
        # code
    case _:
        # default code
  • match evaluates an expression.
  • case defines a pattern.
  • The matching case is executed.
  • _ can be used as a default pattern.

Match with Numbers

You can use match to compare numbers. 

number = 10

match number:
    case 5:
        print("Number is 5")
    case 10:
        print("Number is 10")
    case 15:
        print("Number is 15")
    case _:
        print("Unknown number")
Output: Number is 10

Match with Strings

Match statements can also compare strings. 

command = "start"

match command:
    case "start":
        print("Starting program")
    case "stop":
        print("Stopping program")
    case "pause":
        print("Pausing program")
    case _:
        print("Unknown command")

Default Case

The underscore _ is commonly used as the default pattern. 

color = "purple"

match color:
    case "red":
        print("Red color")
    case "blue":
        print("Blue color")
    case "green":
        print("Green color")
    case _:
        print("Other color")
The _ pattern matches when none of the previous cases match.

Multiple Patterns in One Case

You can use | to match multiple patterns in one case. 

day = "Saturday"

match day:
    case "Saturday" | "Sunday":
        print("Weekend")
    case "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday":
        print("Weekday")
    case _:
        print("Invalid day")
Output: Weekend

Match Lists

Python pattern matching can also work with sequences such as lists. 

numbers = [1, 2, 3]

match numbers:
    case [1, 2, 3]:
        print("Numbers are 1, 2, 3")
    case [4, 5, 6]:
        print("Numbers are 4, 5, 6")
    case _:
        print("Different list")

Capture Values with Match

A pattern can capture values into variables. 

point = (10, 20)

match point:
    case (x, y):
        print("X =", x)
        print("Y =", y)
Here, x receives 10 and y receives 20.

Match Dictionaries

Match statements can also be used with dictionary patterns. 

student = {
    "name": "Krish",
    "age": 20
}

match student:
    case {"name": name, "age": age}:
        print("Name:", name)
        print("Age:", age)
    case _:
        print("Student data not found")

Match with Guards

A guard is an additional condition using if. 

number = 15

match number:
    case n if n > 10:
        print("Number is greater than 10")
    case n if n == 10:
        print("Number is 10")
    case _:
        print("Number is less than 10")
Output: Number is greater than 10

Match with Classes

Pattern matching can also be used with objects and classes. 

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student = Student("Krish", 20)

match student:
    case Student(name, age):
        print(name)
        print(age)

This feature is useful when working with structured objects.

Practical Example: Calculator

A match statement can be useful for creating a simple calculator. 

operator = "+"
a = 10
b = 5

match operator:
    case "+":
        print(a + b)
    case "-":
        print(a - b)
    case "*":
        print(a * b)
    case "/":
        print(a / b)
    case _:
        print("Invalid operator")
Output: 15

Practical Example: Traffic Light

light = "red"

match light:
    case "red":
        print("Stop")
    case "yellow":
        print("Wait")
    case "green":
        print("Go")
    case _:
        print("Invalid signal")

Important Rules

  • Python match statements require Python 3.10 or newer.
  • Use case inside a match block.
  • Indentation is important.
  • The first matching case is selected.
  • _ can be used as a default pattern.
  • | can combine multiple patterns.
  • Guards can be added using if.
  • Match can work with numbers and strings.
  • Match can also work with sequences and dictionaries.
