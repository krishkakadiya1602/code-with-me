C Input and Output

Learn how to take input and display output in C

What is Input and Output in C?

Input and output are important parts of almost every C program.

Input means taking data from the user, while output means displaying information to the user.

In simple words:
Input → User gives data to the program.
Output → Program displays information to the user.

<stdio.h> Header File

C provides input and output functions through the stdio.h header file.

The most commonly used functions are:

  • printf() – used to display output.
  • scanf() – used to take input.
  • getchar() – reads one character.
  • putchar() – displays one character.
Example 
#include <stdio.h>

int main() {

    printf("Hello World!");

    return 0;
}

1. printf() Function

The printf() function is used to display text, numbers, and other values on the screen.

Example 
#include <stdio.h>

int main() {

    printf("Welcome to Code With Me!");

    return 0;
}
Output:
Welcome to Code With Me!

Printing Variables

We can use format specifiers to display variables using printf().

Example 
#include <stdio.h>

int main() {

    int age = 20;

    printf("Age = %d", age);

    return 0;
}
Output:
Age = 20

2. scanf() Function

The scanf() function is used to take input from the user.

When using scanf(), we normally use the & symbol before a variable.

Example 
#include <stdio.h>

int main() {

    int age;

    printf("Enter your age: ");

    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}

Taking Integer Input

Use %d with scanf() to take an integer.

Example 
#include <stdio.h>

int main() {

    int number;

    printf("Enter a number: ");

    scanf("%d", &number);

    printf("You entered: %d", number);

    return 0;
}

Taking Float Input

Use %f to take a floating-point number.

Example 
#include <stdio.h>

int main() {

    float price;

    printf("Enter price: ");

    scanf("%f", &price);

    printf("Price = %.2f", price);

    return 0;
}

Taking Character Input

Use %c to take a single character.

Example 
#include <stdio.h>

int main() {

    char grade;

    printf("Enter your grade: ");

    scanf(" %c", &grade);

    printf("Your grade is %c", grade);

    return 0;
}
Notice the space before %c:

scanf(" %c", &grade);

This helps ignore leftover whitespace characters.

Taking Multiple Inputs

You can take multiple values using one scanf() statement.

Example 
#include <stdio.h>

int main() {

    int age;
    float marks;

    printf("Enter age and marks: ");

    scanf("%d %f", &age, &marks);

    printf("Age = %d\n", age);
    printf("Marks = %.2f", marks);

    return 0;
}

3. getchar()

The getchar() function is used to read a single character from the keyboard.

Example 
#include <stdio.h>

int main() {

    char ch;

    printf("Enter a character: ");

    ch = getchar();

    printf("You entered: %c", ch);

    return 0;
}

4. putchar()

The putchar() function is used to display a single character.

Example 
#include <stdio.h>

int main() {

    char ch = 'A';

    putchar(ch);

    return 0;
}
Output:
A

Common Format Specifiers

Specifier Used For Example
%d Integer 10
%f Float 10.50
%c Character A
%s String Hello
%lf Double 10.50

Using \n in Output

The \n escape sequence moves the cursor to a new line.

Example 
#include <stdio.h>

int main() {

    printf("Hello\n");
    printf("Welcome to C");

    return 0;
}
Output:
Hello
Welcome to C

Important Points

printf() is mainly used for output.

scanf() is mainly used for input.

getchar() reads one character.

putchar() displays one character.

<stdio.h> provides these standard input/output functions.
