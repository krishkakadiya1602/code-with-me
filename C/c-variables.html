What are Variables in C?

A variable is a named memory location used to store data in a C program.

The value stored inside a variable can normally be changed while the program is running.

Example: If you want to store a person's age, you can create an integer variable such as age.

Variable Declaration

Before using a variable, you generally declare it by specifying its data type and name. 

int age;

Here:

  • int is the data type.
  • age is the variable name.

Assigning a Value

You can assign a value to a variable using the assignment operator =. 

int age;

age = 20;

Declaration and Initialization

You can declare a variable and assign its value at the same time. 

int age = 20;

Multiple Variables

You can declare multiple variables of the same data type. 

int age = 20;
int marks = 85;
int year = 2026;

Variables with Different Data Types

C provides different data types for storing different kinds of values. 

int age = 20;

float price = 99.50;

double distance = 123.456789;

char grade = 'A';

Complete C Program Using Variables

#include <stdio.h>

int main()
{
    int age = 20;

    float marks = 85.5;

    char grade = 'A';

    printf("Age: %d\n", age);

    printf("Marks: %.2f\n", marks);

    printf("Grade: %c\n", grade);

    return 0;
}

Output

Age: 20
Marks: 85.50
Grade: A

Rules for Naming Variables

Variable names in C should follow certain rules.

  • A variable name can contain letters, digits and underscores.
  • A variable name cannot start with a digit.
  • Spaces are not allowed in variable names.
  • C variable names are case-sensitive.
  • C keywords cannot be used as variable names.

Valid Variable Names

int age;

int studentAge;

int student_age;

int marks1;

Invalid Variable Names

int 1age;        // Cannot start with a number

int student age; // Spaces are not allowed

int float;       // Keyword cannot be used

Variable vs Constant

Variable Constant
Its value can normally change. Its value should not change.
Example: int age = 20; Example: const int age = 20;
Remember: A variable has a data type, a name and a value. For example: 
int age = 20;
int → Data type
age → Variable name
20 → Value
