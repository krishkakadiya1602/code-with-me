C Functions

Learn how to create, call and use functions in C programming.

```
```

What is a Function in C?

A function in C is a block of code that performs a specific task.

Functions help divide a large program into smaller and reusable pieces of code.

Simple idea:
Create a function → Call the function → Function performs a task
```
```

Why Use Functions?

  • Functions make programs easier to understand.
  • Functions reduce code duplication.
  • Functions make code reusable.
  • Functions make debugging easier.
  • Functions divide a large program into smaller tasks.
  • Functions make programs easier to maintain.
```
```

Function Syntax

C Function Syntax 
return_type function_name(parameters)
```

{
// code
}
```
Part Description
return_type The type of value returned by the function.
function_name The name used to identify the function.
parameters Values received by the function.
function body The statements executed when the function is called.

Pass by Value

In C, arguments are passed to functions by value by default. The function receives a copy of the value.

Example 
#include <stdio.h>
```

{

}

int main()
{

```
change(number);

printf("Number = %d", number);

return 0;
```

}
```
Output:
Number = 10

Changing x inside the function does not change the original variable in main().

Important Points

  • A function performs a specific task.
  • Functions can be called multiple times.
  • A function may accept zero or more parameters.
  • A function may return a value or use void.
  • Function prototypes can be used to declare functions before their definitions.
  • C supports user-defined functions and library functions.
  • Recursive functions call themselves.
```
```

Common Mistakes

1. Forgetting the function call

Defining a function does not automatically execute it. You must call the function.

2. Wrong return type

Make sure the returned value matches the function's return type.

3. Wrong number of arguments

When calling a function, pass the required arguments with compatible types.

4. Forgetting the return statement

A non-void function should return an appropriate value.
