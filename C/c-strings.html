C Strings

Learn how to create, store, read and work with strings in C.

```
```

What is a String in C?

A string in C is a sequence of characters stored in a character array.

C does not have a separate built-in string data type. Instead, strings are represented using arrays of char.

Important: Every C string ends with a special null character \0, which tells the program where the string ends.
```
```

Simple String Example

Example 
#include <stdio.h>
```

int main()
{
char name[] = "Krish";

```
printf("%s", name);

return 0;
```

}
```
Output:
Krish
```
```

String as a Character Array

A string can be stored in a character array.

Example 
char name[] = "Krish";

Internally, the string is stored approximately like this:

Characters 
K    r    i    s    h    \0

The \0 character is called the null character.

```
```

Declaring a String

You can declare a string using a character array.

Example 
char name[20];

This creates a character array that can hold characters, including space for the terminating null character.

```
```

Initializing a String

Method 1: Using String Literal

Example 
char name[] = "Krish";

Method 2: Using Character List

Example 
char name[] = {'K', 'r', 'i', 's', 'h', '\0'};
Both examples represent the same string: Krish
```
```

String Size

When you create a character array, make sure there is enough space for all characters and the null character.

Example 
char name[6] = "Krish";

The word Krish contains 5 characters, but the array needs 6 positions because of \0.

```
```

Printing a String

The %s format specifier is used with printf() to print a string.

Example 
#include <stdio.h>
```

int main()
{
char city[] = "Ahmedabad";

```
printf("City: %s", city);

return 0;
```

}
```
Output:
City: Ahmedabad
```
```

Taking String Input Using scanf()

The %s format specifier can be used with scanf() to read a word.

Example 
#include <stdio.h>
```

int main()
{
char name[50];

```
printf("Enter your name: ");
scanf("%49s", name);

printf("Hello %s", name);

return 0;
```

}
```
Important: scanf("%s", ...) normally stops reading at whitespace, so it is suitable for a single word rather than a full sentence.
```
```

Taking Full Line Input Using fgets()

The fgets() function can read a line of text, including spaces.

Example 
#include <stdio.h>
```

int main()
{
char name[100];

```
printf("Enter your full name: ");

fgets(name, sizeof(name), stdin);

printf("Your name is: %s", name);

return 0;
```

}
```
Example input:
Krish Kakadiya
```
```

Why gets() Should Not Be Used

Older C tutorials may show the gets() function for reading strings.

However, gets() is unsafe because it does not know the size of the destination buffer and can cause a buffer overflow.

Use fgets() instead of gets() for reading a line safely.
```
```

Accessing Characters in a String

Each character in a string can be accessed using its array index.

Example

```

int main()
{
char name[] = "Krish";

```
printf("%c\n", name[0]);
printf("%c\n", name[1]);
printf("%c\n", name[2]);

return 0;
```

}
```
Output:
K
r
i
```
```

Loop Through a String

A loop can be used to access each character in a string.

Example 
#include <stdio.h>
```

int main()
{
char name[] = "Krish";
int i = 0;

```
while (name[i] != '\0')
{
    printf("%c\n", name[i]);

    i++;
}

return 0;
```

}
```

Individual characters of a character array can be changed.

Example

```

int main()

```
name[0] = 'B';

printf("%s", name);

}

Common String Functions

C provides several useful functions in the string.h header.

Function Purpose
strlen() Finds the length of a string.
strcpy() Copies one string into another.
strcat() Combines two strings.
strcmp() Compares two strings.
strchr() Finds a character in a string.
strstr() Finds a substring inside a string.
These functions are covered in more detail in the C String Functions lesson.
```
```

Combining Strings

The strcat() function can be used to append one string to another.

Example 
#include <stdio.h>
```

#include 

int main()
{
char first[50] = "Hello ";
char second[] = "World";

```
strcat(first, second);

printf("%s", first);

return 0;
```

}
```
Output:
Hello World
```

Comparing Strings

The strcmp() function can be used to compare two strings.

Example 
#include <stdio.h>
```

#include 

int main()
{
char first[] = "Hello";

if (strcmp(first, second) == 0)

    printf("Strings are equal");

else

String Literal

A string literal is text written inside double quotes.

Example 
"Hello"
```

"Code With Me"
"C Programming"
```
String literals are different from character constants. A character uses single quotes, while a string uses double quotes.

Character: 'A'
String: "A"
```
```

String vs Character

Character String
Uses single quotes. Uses double quotes.
Example: 'A' Example: "ABC"
Stores one character. Stores multiple characters.
Uses char. Usually uses a char array.
```
```

Important Points

  • C strings are stored in character arrays.
  • Every string ends with the null character \0.
  • The %s format specifier is used to print strings.
  • String functions are available through string.h.
  • Array indexes start from 0.
  • scanf("%s", ...) normally reads only one word.
  • fgets() can be used to read a line containing spaces.
  • gets() should not be used because it is unsafe.
```
```

Common Mistakes

1. Forgetting the null character

A manually created string should have enough space for the terminating \0.

2. Using the wrong format specifier

Use %s for strings and %c for individual characters.

3. Buffer overflow

Make sure the character array is large enough to store the input and its terminating null character.

4. Comparing strings with ==

Do not normally compare C strings using ==. Use strcmp() to compare their contents.
