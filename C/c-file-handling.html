What is File Handling in C?

File handling in C allows a program to create, open, read, write, append and close files stored on a computer.

Normally, data stored in variables is lost when a program finishes. Files allow data to be stored permanently.

Important: C provides file handling functions through the stdio.h header file.

Why Use File Handling?

  • Store data permanently.
  • Read previously stored information.
  • Save program results.
  • Maintain student or employee records.
  • Create configuration files.
  • Store large amounts of data.

FILE Pointer

C uses a special pointer called a FILE pointer to work with files.

Syntax
FILE *filePointer;

The FILE pointer keeps track of the file being accessed.

Opening a File using fopen()

The fopen() function is used to open a file.

Syntax
FILE *fopen(const char *filename, const char *mode);
Example
#include <stdio.h>
```

int main() {

```
FILE *file;

file = fopen("data.txt", "r");

if (file == NULL) {
    printf("Unable to open file.\n");
    return 1;
}

printf("File opened successfully.\n");

fclose(file);

return 0;
```

}
```

File Opening Modes

Mode Description
r Open an existing file for reading.
w Open a file for writing. Creates a new file or overwrites an existing file.
a Open a file for appending data at the end.
r+ Open an existing file for reading and writing.
w+ Open a file for reading and writing. Existing contents may be overwritten.
a+ Open a file for reading and appending.
rb Open a binary file for reading.
wb Open a binary file for writing.
ab Open a binary file for appending.

Closing a File using fclose()

The fclose() function closes an opened file.

Syntax
fclose(filePointer);
Example
#include <stdio.h>
```

int main() {

```
FILE *file;

file = fopen("data.txt", "r");

if (file == NULL) {
    printf("File could not be opened.");
    return 1;
}

printf("File opened successfully.");

fclose(file);

return 0;
```

}
```
Always close a file after finishing file operations.

The w mode can be used to write data to a file.

Example using fprintf()

Reading from a File

The r mode is used to open an existing file for reading.

Example using fgets()
#include <stdio.h>
```

int main() {

```
FILE *file;
char text[100];

file = fopen("data.txt", "r");

if (file == NULL) {
    printf("File could not be opened.");
    return 1;
}

while (fgets(text, sizeof(text), file) != NULL) {

    printf("%s", text);

}

fclose(file);

return 0;
```

}
```

Reading a Character using fgetc()

The fgetc() function reads one character at a time from a file.

Example
#include <stdio.h>
```

int main() {

```
FILE *file;
char ch;

file = fopen("data.txt", "r");

if (file == NULL) {
    printf("File could not be opened.");
    return 1;
}

while ((ch = fgetc(file)) != EOF) {

    printf("%c", ch);

}

fclose(file);

return 0;
```

}
```
Note: For general portable code, fgetc() should normally be stored in an int variable so that the special EOF value can be detected correctly.

Reading using fscanf()

The fscanf() function can read formatted data from a file.

Example
#include <stdio.h>
```

int main() {

```
FILE *file;

int age;
float marks;

file = fopen("student.txt", "r");

if (file == NULL) {
    printf("File could not be opened.");
    return 1;
}

fscanf(file, "%d %f", &age, &marks);

printf("Age: %d\n", age);
printf("Marks: %.2f\n", marks);

fclose(file);

return 0;
```

}
```

Appending Data to a File

The a mode is used to add new data at the end of an existing file.

Example
#include <stdio.h>
```

int main() {

```
FILE *file;

file = fopen("data.txt", "a");

if (file == NULL) {
    printf("File could not be opened.");
    return 1;
}

fprintf(file, "\nThis is new data.");

fclose(file);

printf("Data appended successfully.");

return 0;
```

}
```
Important: Append mode normally preserves the existing contents and adds new data at the end.

Complete File Handling Example

The following program writes information to a file and then reads it back.

Complete Example
#include <stdio.h>
```

int main() {

```
FILE *file;
char text[100];

/* Write to file */

file = fopen("message.txt", "w");

if (file == NULL) {
    printf("Unable to create file.");
    return 1;
}

fprintf(file, "Welcome to Code With Me!\n");
fprintf(file, "Learning C File Handling.");

fclose(file);


/* Read from file */

file = fopen("message.txt", "r");

if (file == NULL) {
    printf("Unable to open file.");
    return 1;
}

printf("File Contents:\n");

while (fgets(text, sizeof(text), file) != NULL) {

    printf("%s", text);

}

fclose(file);

return 0;
```

}

Important File Handling Functions

Function Purpose
fopen() Opens a file.
fclose() Closes a file.
fprintf() Writes formatted data to a file.
fscanf() Reads formatted data from a file.
fputs() Writes a string to a file.
fgets() Reads a line/string from a file.

fgetc() Reads one character from a file.
feof() Checks the end-of-file indicator.

ftell() Returns the current file position.
rewind() Moves the file position back to the beginning.

Checking File Errors

Always check whether fopen() returned NULL before using a file.

Example
#include <stdio.h>
```

int main() {

```
FILE *file;

file = fopen("data.txt", "r");

if (file == NULL) {

    printf("Error: File could not be opened.");

    return 1;
}

printf("File opened successfully.");

fclose(file);

return 0;
```

}
```

Text Files vs Binary Files

Text File Binary File
Stores data as text characters. Stores data as binary bytes.
Easy for humans to read. Usually not directly human-readable.
Examples: .txt, .csv Examples: images, compiled data, binary records.

Important Points

  • Include stdio.h for standard C file functions.
  • Use a FILE * pointer to work with files.
  • Use fopen() to open a file.
  • Always check whether fopen() returned NULL.
  • Use fclose() after completing file operations.
  • Use w to write to a file.
  • Use r to read an existing file.
  • Use a to append data.
  • Use fprintf() for formatted output.
  • Use fscanf() for formatted input.
  • Use fgets() to read a line of text.
  • Use fputs() to write a string.

Common Mistakes

1. Forgetting to check NULL

FILE *file = fopen("data.txt", "r");
```

if (file == NULL) {
printf("File not found.");
}
```

2. Forgetting fclose()

Always close the file when you are finished using it.

3. Using the wrong file mode

For example, opening an existing file with w can overwrite its previous contents.

4. Reading a file that does not exist

Opening a missing file with r normally fails, so always check the returned pointer.
