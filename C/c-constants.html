C Constants

Learn how to create and use constants in C programming

What are Constants in C?

A constant is a value that cannot be changed during the execution of a C program.

For example, if you have a constant value representing the number of days in a week, that value should remain unchanged.

Important: Once a constant is defined, you should not change its value during program execution.

Types of Constants in C

There are several types of constants used in C programming.

  • Integer Constants
  • Floating-Point Constants
  • Character Constants
  • String Constants
  • Symbolic Constants

1. Integer Constants

Integer constants are whole numbers without a decimal point.

Example 
#include <stdio.h>

int main() {

    int age = 20;

    printf("Age = %d", age);

    return 0;
}

2. Floating-Point Constants

Floating-point constants contain decimal values.

Example 
#include <stdio.h>

int main() {

    float pi = 3.14;

    printf("Value of pi = %.2f", pi);

    return 0;
}

3. Character Constants

A character constant represents a single character and is written inside single quotes.

Example 
#include <stdio.h>

int main() {

    char grade = 'A';

    printf("Grade = %c", grade);

    return 0;
}

4. String Constants

A string constant is a sequence of characters written inside double quotation marks.

Example 
#include <stdio.h>

int main() {

    printf("Welcome to Code With Me!");

    return 0;
}

5. Using the const Keyword

The const keyword can be used to create a variable whose value should not be modified.

Example 
#include <stdio.h>

int main() {

    const int DAYS = 7;

    printf("Days in a week = %d", DAYS);

    return 0;
}
Note: Trying to modify a const variable will result in a compilation error.

6. Using #define

The #define preprocessor directive can also be used to create symbolic constants.

Example 
#include <stdio.h>

#define PI 3.14159

int main() {

    printf("PI = %.5f", PI);

    return 0;
}

const vs #define

const #define
Uses the const keyword Uses the #define directive
Has a data type Does not have a data type
Handled by the compiler Handled by the preprocessor
Example: const int AGE = 18; Example: #define AGE 18

Important Points

const is used to create read-only variables.

#define creates symbolic constants.

Constants are useful for values that should not change.

Constants make programs easier to understand and maintain.
