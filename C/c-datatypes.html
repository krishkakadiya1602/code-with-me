What are Data Types in C?

Data types specify the type of data that a variable can store. For example, an integer variable stores whole numbers, while a character variable stores a single character.

Important: Every variable in C must have a data type.

Types of Data Types in C

C provides several built-in data types. Some of the commonly used data types are:

Data Type Used For Example
int Whole numbers 100
float Decimal numbers 10.5
double Large decimal values 123.456
char Single character 'A'
void No value void

1. int Data Type

The int data type is used to store whole numbers without decimal values.

Example
#include <stdio.h>

int main() {

    int age = 20;

    printf("Age = %d", age);

    return 0;
}

2. float Data Type

The float data type is used to store numbers containing decimal values.

Example
#include <stdio.h>

int main() {

    float price = 99.50;

    printf("Price = %.2f", price);

    return 0;
}

3. double Data Type

The double data type is used to store decimal numbers with greater precision than float.

Example
#include <stdio.h>

int main() {

    double number = 12345.6789;

    printf("Number = %lf", number);

    return 0;
}

4. char Data Type

The char data type is used to store a single character.

Example
#include <stdio.h>

int main() {

    char grade = 'A';

    printf("Grade = %c", grade);

    return 0;
}

5. void Data Type

The void data type represents the absence of a value. It is commonly used with functions that do not return a value.

Example
#include <stdio.h>

void message() {
    printf("Hello from C!");
}

int main() {

    message();

    return 0;
}

Example Using Multiple Data Types

We can use different data types in the same C program.

Complete Example
#include <stdio.h>

int main() {

    int age = 20;
    float height = 5.8;
    double salary = 25000.75;
    char grade = 'A';

    printf("Age = %d\n", age);
    printf("Height = %.1f\n", height);
    printf("Salary = %.2lf\n", salary);
    printf("Grade = %c\n", grade);

    return 0;
}

Format Specifiers

Format specifiers are used with printf() to display different types of data.

Data Type Format Specifier
int %d
float %f
double %lf
char %c
string %s
Note: A string is not a separate built-in data type in C. Strings are generally represented using arrays of characters.
