C Operators

Learn how operators are used in C programming

What are Operators in C?

Operators are special symbols that are used to perform operations on values and variables in a C program.

For example, the + operator is used to add two values.

Example:

10 + 5 = 15

Here, + is the operator and 10 and 5 are operands.

Types of Operators in C

C provides several types of operators:

  • Arithmetic Operators
  • Assignment Operators
  • Relational Operators
  • Logical Operators
  • Increment and Decrement Operators
  • Bitwise Operators
  • Conditional (Ternary) Operator
  • Other Operators

1. Arithmetic Operators

Arithmetic operators are used to perform mathematical operations.

Operator Name Example
+ Addition a + b
- Subtraction a - b
* Multiplication a * b
/ Division a / b
% Modulus a % b
Example 
#include <stdio.h>

int main() {

    int a = 10;
    int b = 3;

    printf("Addition = %d\n", a + b);
    printf("Subtraction = %d\n", a - b);
    printf("Multiplication = %d\n", a * b);
    printf("Division = %d\n", a / b);
    printf("Remainder = %d\n", a % b);

    return 0;
}

2. Assignment Operators

Assignment operators are used to assign values to variables.

Operator Example Meaning
= a = 10 Assign 10 to a
+= a += 5 a = a + 5
-= a -= 5 a = a - 5
*= a *= 5 a = a * 5
/= a /= 5 a = a / 5
%= a %= 5 a = a % 5
Example 
#include <stdio.h>

int main() {

    int number = 10;

    number += 5;

    printf("Number = %d", number);

    return 0;
}

3. Relational Operators

Relational operators are used to compare two values. They produce either 1 (true) or 0 (false).

Operator Meaning Example
== Equal to a == b
!= Not equal to a != b
> Greater than a > b
< Less than a < b
>= Greater than or equal to a >= b
<= Less than or equal to a <= b
Example 
#include <stdio.h>

int main() {

    int a = 10;
    int b = 20;

    printf("%d\n", a == b);
    printf("%d\n", a < b);
    printf("%d\n", a > b);

    return 0;
}

4. Logical Operators

Logical operators are used to combine or reverse conditions.

Operator Name Example
&& Logical AND a > 5 && b > 5
|| Logical OR a > 5 || b > 5
! Logical NOT !(a > 5)
Example 
#include <stdio.h>

int main() {

    int age = 20;

    if (age >= 18 && age <= 60) {
        printf("Age is between 18 and 60");
    }

    return 0;
}

5. Increment and Decrement Operators

The increment operator ++ increases a value by 1.

The decrement operator -- decreases a value by 1.

Operator Meaning
++ Increase by 1
-- Decrease by 1
Example 
#include <stdio.h>

int main() {

    int number = 10;

    number++;

    printf("After increment = %d\n", number);

    number--;

    printf("After decrement = %d", number);

    return 0;
}

6. Bitwise Operators

Bitwise operators perform operations on the individual bits of integer values.

Operator Name
& Bitwise AND
| Bitwise OR
^ Bitwise XOR
~ Bitwise NOT
<< Left Shift
>> Right Shift
Example 
#include <stdio.h>

int main() {

    int a = 5;
    int b = 3;

    printf("AND = %d\n", a & b);
    printf("OR = %d\n", a | b);
    printf("XOR = %d\n", a ^ b);

    return 0;
}

7. Conditional (Ternary) Operator

The conditional operator is also called the ternary operator because it uses three operands.

Its syntax is:

condition ? value_if_true : value_if_false;
Example 
#include <stdio.h>

int main() {

    int age = 20;

    const char *result;

    result = (age >= 18) ? "Adult" : "Minor";

    printf("%s", result);

    return 0;
}

8. sizeof Operator

The sizeof operator is used to find the amount of memory occupied by a data type or variable.

Example 
#include <stdio.h>

int main() {

    int number;

    printf("Size of int = %zu bytes",
           sizeof(number));

    return 0;
}

Operator Precedence

Operator precedence determines the order in which operators are evaluated in an expression.

Example 
#include <stdio.h>

int main() {

    int result;

    result = 10 + 5 * 2;

    printf("Result = %d", result);

    return 0;
}
Output: 20

Multiplication is performed before addition, so:
10 + (5 * 2) = 20

Important Points

Operators are used to perform operations on values and variables.

Arithmetic operators are mainly used for calculations.

Relational operators compare values.

Logical operators are used to combine conditions.

Assignment operators assign or update values.

The ternary operator provides a short way to write a simple conditional expression.
