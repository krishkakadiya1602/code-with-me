C if Statement

Learn how to use conditions with the if statement in C

What is an if Statement in C?

The if statement is a decision-making statement in C programming.

It allows a program to execute a block of code only when a specified condition is true.

In simple words:

If a condition is true → execute the code.
If a condition is false → skip the code.

Syntax of if Statement

Syntax 
if (condition)
{
    // code to execute
}

The condition is placed inside parentheses ( ).

If the condition evaluates to true, the statements inside the curly braces { } are executed.

How if Statement Works

Start
↓
Check the condition
↓
Is the condition true?
↓
Execute the code inside if
↓
Continue the program

Simple if Example

In this example, the message is printed only when the condition is true.

Example 
#include <stdio.h>

int main()
{
    int age = 20;

    if (age >= 18)
    {
        printf("You are an adult.");
    }

    return 0;
}
Output:
You are an adult.

Using Comparison Operators

The if statement is commonly used with relational operators.

Operator Meaning Example
== Equal to age == 18
!= Not equal to age != 18
> Greater than age > 18
< Less than age < 18
>= Greater than or equal to age >= 18
<= Less than or equal to age <= 18

if Statement with User Input

We can take input from the user and then use an if statement to make a decision.

Example 
#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    if (number > 0)
    {
        printf("The number is positive.");
    }

    return 0;
}

Check if a Number is Even

The modulus operator % can be used with an if statement to check whether a number is even.

Example 
#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    if (number % 2 == 0)
    {
        printf("The number is even.");
    }

    return 0;
}

Check Passing Marks

Here, the program checks whether a student's marks are greater than or equal to 40.

Example 
#include <stdio.h>

int main()
{
    int marks;

    printf("Enter your marks: ");
    scanf("%d", &marks);

    if (marks >= 40)
    {
        printf("You passed.");
    }

    return 0;
}

Using Multiple Conditions

Logical operators can be used to combine multiple conditions inside an if statement.

Example 
#include <stdio.h>

int main()
{
    int age = 25;

    if (age >= 18 && age <= 60)
    {
        printf("Age is between 18 and 60.");
    }

    return 0;
}

if Statement Without Curly Braces

If there is only one statement inside an if statement, curly braces can technically be omitted.

Example 
#include <stdio.h>

int main()
{
    int age = 20;

    if (age >= 18)
        printf("Adult");

    return 0;
}
Recommendation:
For beginners, using curly braces is recommended because it makes the code easier to read and helps prevent mistakes when adding more statements later.

Important Points

The if statement is used for decision making.

The condition is written inside parentheses ( ).

Code inside { } executes when the condition is true.

Relational and logical operators are commonly used with if statements.

C treats a non-zero expression as true and zero as false.

Common Mistakes

1. Using = instead of ==

Remember that = is an assignment operator, while == checks equality.

Correct 
if (number == 10)
{
    printf("Number is 10");
}

2. Forgetting the parentheses

The condition must be placed inside parentheses.

Correct 
if (age >= 18)
{
    printf("Adult");
}
