C Arrays

Learn how to store and work with multiple values using Arrays in C.

What is an Array in C?

An array in C is a collection of multiple values of the same data type stored in consecutive memory locations.

Instead of creating separate variables for many values, we can use a single array to store them.

Example: If you want to store the marks of 5 students, instead of creating five separate variables, you can use one array. 
int marks[5];

Why Do We Use Arrays?

  • To store multiple values of the same data type.
  • To reduce the number of variables.
  • To easily process large amounts of data.
  • Arrays work very well with loops.
  • They make programs more organized.

Array Syntax

The basic syntax for declaring an array is:

data_type array_name[array_size];

Example

int numbers[5];

Here:

  • int → data type
  • numbers → array name
  • 5 → number of elements

Array Initialization

You can declare and initialize an array at the same time. 

int numbers[5] = {10, 20, 30, 40, 50};

Output

10 20 30 40 50

Array Index

Array indexing starts from 0, not 1.

Index Value
0 10
1 20
2 30
3 40
4 50 
int numbers[5] = {10, 20, 30, 40, 50};

printf("%d", numbers[0]);
10

Accessing Array Elements

You can access individual elements using their index. 

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    printf("%d\n", numbers[0]);
    printf("%d\n", numbers[1]);
    printf("%d\n", numbers[2]);
    printf("%d\n", numbers[3]);
    printf("%d\n", numbers[4]);

    return 0;
}
10 20 30 40 50

Changing Array Elements

You can change an array element by assigning a new value to its index. 

#include <stdio.h>

int main()
{
    int numbers[3] = {10, 20, 30};

    numbers[1] = 100;

    printf("%d\n", numbers[0]);
    printf("%d\n", numbers[1]);
    printf("%d\n", numbers[2]);

    return 0;
}
10 100 30

Arrays with for Loop

Loops are commonly used to access all elements of an array. 

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};

    for(int i = 0; i < 5; i++)
    {
        printf("%d\n", numbers[i]);
    }

    return 0;
}
10 20 30 40 50

Taking Array Input from User

We can use a loop with scanf() to take values from the user. 

#include <stdio.h>

int main()
{
    int numbers[5];

    printf("Enter 5 numbers:\n");

    for(int i = 0; i < 5; i++)
    {
        scanf("%d", &numbers[i]);
    }

    printf("Array elements are:\n");

    for(int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    return 0;
}
Enter 5 numbers: 10 20 30 40 50 Array elements are: 10 20 30 40 50

Find Sum of Array Elements

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};
    int sum = 0;

    for(int i = 0; i < 5; i++)
    {
        sum = sum + numbers[i];
    }

    printf("Sum = %d", sum);

    return 0;
}
Sum = 150

Find Average of Array Elements

#include <stdio.h>

int main()
{
    int numbers[5] = {10, 20, 30, 40, 50};
    int sum = 0;
    float average;

    for(int i = 0; i < 5; i++)
    {
        sum = sum + numbers[i];
    }

    average = (float)sum / 5;

    printf("Average = %.2f", average);

    return 0;
}
Average = 30.00

Find Largest Element

#include <stdio.h>

One-Dimensional Array

A one-dimensional array stores elements in a single row or sequence. 

int numbers[5] = {10, 20, 30, 40, 50};

It can be visualized as:

Index:   0    1    2    3    4
Value:  10   20   30   40   50

Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It is commonly used to represent matrices and tables. 

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

The array looks like:

1  2  3
4  5  6

Example

#include <stdio.h>

int main()
{
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for(int i = 0; i < 2; i++)
    {
        for(int j = 0; j < 3; j++)
        {
            printf("%d ", matrix[i][j]);
        }

        printf("\n");
    }

    return 0;
}
1 2 3 4 5 6

Character Array

A character array can be used to store a string. 

#include <stdio.h>

int main()
{
    char name[] = "Krish";

    printf("%s", name);

    return 0;
}
Krish
In C, strings are stored as character arrays and end with a special null character \0.

Finding Array Size

The sizeof() operator can be used to find the total size of an array in bytes. 

#include <stdio.h>

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int size = sizeof(numbers) / sizeof(numbers[0]);

    printf("Number of elements = %d", size);

    return 0;
}
Number of elements = 5

Types of Arrays in C

Type Description Example
1D Array Stores data in a single sequence. int a[5];
2D Array Stores data in rows and columns. int a[2][3];
Multidimensional Array Array with more than two dimensions. int a[2][3][4];
Character Array Used to store characters and strings. char name[20];

Important Rules of Arrays

  • Array indexing starts from 0.
  • All elements normally have the same data type.
  • The array size determines the number of elements it can store.
  • Accessing an index outside the array bounds can cause undefined behavior.
  • Loops are commonly used to process arrays.
  • C does not automatically check array bounds.
Warning: If an array has 5 elements, valid indexes are only 0 to 4. 
int numbers[5] = {10, 20, 30, 40, 50};

/* Correct */
printf("%d", numbers[4]);

/* Wrong - outside the valid range */
printf("%d", numbers[5]);
