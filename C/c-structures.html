What is a Structure in C?

A structure in C is a user-defined data type that allows you to store different types of data under one name.

For example, a student may have a name, age, roll number and marks. These values have different data types, but they can be grouped together using a structure.

Important: A structure can contain members of different data types.

Why Use Structures?

Structures are useful when you want to represent a real-world object.

  • Store related data together.
  • Organize complex data.
  • Represent real-world entities.
  • Store different data types together.
  • Create arrays of records.
  • Make programs easier to manage.

Structure Syntax

The basic syntax of a structure is:

Syntax
struct structure_name {
data_type member1;
data_type member2;
data_type member3;
```

};
```
Note: Don't forget the semicolon ; after the closing curly brace.

Simple Structure Example

Example
#include <stdio.h>
```

struct Student {
int rollNo;
float marks;
};

int main() {

```
struct Student s1;

s1.rollNo = 101;
s1.marks = 85.5;

printf("Roll Number: %d\n", s1.rollNo);
printf("Marks: %.2f\n", s1.marks);

return 0;
```

}
```

Multiple Structure Variables

You can create multiple variables using the same structure.

Example
#include <stdio.h>
```

struct Student {
int rollNo;
float marks;
};

int main() {

```
struct Student s1, s2;

s1.rollNo = 101;
s1.marks = 85.5;

s2.rollNo = 102;
s2.marks = 91.5;

printf("Student 1: %d %.2f\n", s1.rollNo, s1.marks);
printf("Student 2: %d %.2f\n", s2.rollNo, s2.marks);

return 0;
```

}
```

Array of Structures

An array of structures allows you to store multiple records of the same structure type.

Example
#include <stdio.h>
```

struct Student {
int rollNo;
float marks;
};

int main() {

```
struct Student students[3] = {
    {101, 85.5},
    {102, 90.0},
    {103, 78.5}
};

for (int i = 0; i < 3; i++) {

    printf("Roll No: %d\n", students[i].rollNo);
    printf("Marks: %.2f\n\n", students[i].marks);

}

return 0;
```

}
```

Nested Structures

A structure can contain another structure as one of its members. This is called a nested structure.

Example
#include <stdio.h>
```

struct Address {
char city[30];
int pincode;
};

struct Student {
int rollNo;
struct Address address;
};

int main() {

```
struct Student s1 = {
    101,
    {"Ahmedabad", 380001}
};

printf("Roll No: %d\n", s1.rollNo);
printf("City: %s\n", s1.address.city);
printf("Pincode: %d\n", s1.address.pincode);

return 0;
```

}
```

Pointer to Structure

A pointer can store the address of a structure variable.

The arrow operator -> is used to access structure members through a pointer.

Example
#include <stdio.h>
```

struct Student {
int rollNo;
float marks;
};

int main() {

```
struct Student s1 = {101, 88.5};

struct Student *ptr;

ptr = &s1;

printf("Roll No: %d\n", ptr->rollNo);
printf("Marks: %.2f\n", ptr->marks);

return 0;
```

}
```

Dot Operator vs Arrow Operator

Structure vs Array

Structure Array
Can store different data types. Normally stores elements of the same data type.
Members can have different names. Elements are accessed using indexes.
Example: Student record. Example: List of marks.

Structure vs Union

Structure Union
Each member has separate memory. Members share the same memory.
Multiple members can contain values at the same time. Typically one member's value is used at a time.
Size is generally related to the combined member storage. Size is generally based on its largest member, subject to alignment.

Important Points

  • A structure is a user-defined data type.
  • A structure can contain different data types.
  • The struct keyword is used to define a structure.
  • The dot . operator accesses members of a structure variable.
  • The arrow -> operator accesses members through a structure pointer.
  • Structures can contain arrays and other structures.
  • You can create arrays of structures.
  • Structures can be passed to and returned from functions.
  • typedef can make structure declarations shorter.

Common Mistakes

1. Forgetting the semicolon

struct Student {
int age;
```

};
```

2. Using the wrong operator

Use . for a structure variable and -> for a pointer to a structure.

3. Accessing a member that does not exist

struct Student {
int age;
```

};

struct Student s;

s.name = "Krish";   // Error
```

The member name was not declared in the structure.

}
