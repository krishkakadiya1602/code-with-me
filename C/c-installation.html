C Installation

Learn how to install a C compiler and start programming in C.

What Do We Need to Run C?

C is a compiled programming language. This means that your C source code needs to be converted into machine code before it can run.

To write and run C programs, you need a C compiler.

Important: A compiler translates your C program into a form that the computer can execute.

Common C Compilers

  • GCC (GNU Compiler Collection)
  • Clang
  • Microsoft Visual C Compiler

Install C on Windows

One common way to get GCC on Windows is by installing a GCC-based toolchain such as MinGW-w64.

Step 1: Install a C Compiler

Install a GCC/MinGW-w64 toolchain suitable for your Windows system.

During installation, note the folder where the compiler is installed.

Step 2: Find the Compiler Folder

After installation, locate the folder containing the GCC executable.

A typical installation contains a folder similar to:

C:\mingw64\bin

The exact folder can be different depending on the toolchain you installed.

Step 3: Add GCC to PATH

Windows needs to know where the GCC compiler is located so that you can run it from Command Prompt.

  1. Open Windows Search.
  2. Search for Environment Variables.
  3. Select Edit the system environment variables.
  4. Open Environment Variables.
  5. Find the Path variable.
  6. Add the path to the compiler's bin folder.
  7. Save the changes.

Check C Installation

After installing GCC and configuring PATH, open Command Prompt.

Type:

gcc --version

Press Enter.

If GCC is installed correctly and available in PATH, the command should display information about the installed GCC compiler.
If you see:

'gcc' is not recognized as an internal or external command

then GCC may not be installed correctly or its bin directory may not be in PATH.

Create Your First C Program

Once the compiler is installed, create a file named:

hello.c

Add the following code: 

#include <stdio.h>

int main()
{
    printf("Hello, World!");

    return 0;
}

Compile Your C Program

Open Command Prompt or Terminal in the folder containing your hello.c file.

Run the following command:

gcc hello.c -o hello

This command compiles the C source file and creates an executable program.

Run the Program

On Windows, run:

hello

You should see: 

Hello, World!

Understanding the GCC Command

Command Meaning
gcc Runs the GCC compiler.
hello.c Your C source-code file.
-o Specifies the name of the output file.
hello Name of the generated executable.

Using C with Visual Studio Code

You can also use Visual Studio Code as your code editor.

Basic Setup

  1. Install a C compiler such as GCC.
  2. Install Visual Studio Code.
  3. Open your C project folder.
  4. Create a file named hello.c.
  5. Write your C program.
  6. Compile the program using GCC.
Remember: Visual Studio Code is primarily a code editor. The C compiler is a separate tool that actually compiles your C program.

Can I Learn C Without Installing a Compiler?

Yes. You can practice basic C programming using online C compilers.

However, installing a compiler on your computer helps you understand how C programs are compiled and executed locally.

For beginners: Learn the C syntax first, then practice by writing, compiling and running programs regularly.

Key Points

  • C programs require a compiler to execute.
  • GCC is a commonly used C compiler.
  • The compiler converts C source code into executable machine code.
  • The gcc --version command can be used to check GCC installation.
  • The gcc hello.c -o hello command compiles a C program.
  • Visual Studio Code can be used as a C code editor, but a compiler is still required.
