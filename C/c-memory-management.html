C Memory Management

Learn dynamic memory allocation using malloc(), calloc(), realloc() and free().

What is Memory Management in C?

Memory management means allocating, using and releasing memory during the execution of a program.

C provides functions that allow programmers to allocate memory dynamically when the required amount of memory is not known in advance.

Important: Dynamic memory allocation in C is mainly performed using functions from the <stdlib.h> header file. 
#include <stdlib.h>

Why is Memory Management Important?

  • It allows programs to allocate memory when needed.
  • It allows memory to be released when it is no longer required.
  • It helps create dynamic data structures.
  • It is useful when the amount of data is unknown at compile time.
  • It allows efficient use of available memory.

Static vs Dynamic Memory Allocation

Static Memory Dynamic Memory
Memory size is generally determined before execution. Memory can be allocated during program execution.
Example: int numbers[10]; Example: malloc(10 * sizeof(int));
Usually simpler to use. Requires careful memory management.
Size cannot be changed in the same way as dynamically allocated memory. Memory can be resized using realloc().

malloc() in C

The malloc() function allocates a block of memory of the requested size.

The allocated memory is not initialized by malloc().

Syntax

pointer = malloc(number_of_bytes);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = malloc(sizeof(int));

    if(ptr == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    *ptr = 50;

    printf("Value = %d", *ptr);

    free(ptr);

    return 0;
}
Value = 50

Using malloc() for an Array

malloc() can be used to dynamically allocate memory for multiple elements. 

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n = 5;

    int *numbers;

    numbers = malloc(n * sizeof(int));

    if(numbers == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for(int i = 0; i < n; i++)
    {
        numbers[i] = (i + 1) * 10;
    }

    for(int i = 0; i < n; i++)
    {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}
10 20 30 40 50

calloc() in C

The calloc() function allocates memory for multiple elements and initializes the allocated memory to zero.

Syntax

pointer = calloc(number_of_elements, size_of_each_element);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *numbers;

    numbers = calloc(5, sizeof(int));

    if(numbers == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for(int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}
0 0 0 0 0

malloc() vs calloc()

malloc() calloc()
Takes one main size argument. Takes number of elements and size of each element.
Memory is not initialized. Allocated memory is initialized to zero.
Example: malloc(5 * sizeof(int)) Example: calloc(5, sizeof(int))

realloc() in C

The realloc() function changes the size of previously allocated memory.

Syntax

pointer = realloc(pointer, new_size);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *numbers;

    numbers = malloc(3 * sizeof(int));

    if(numbers == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = 30;

    numbers = realloc(numbers, 5 * sizeof(int));

    if(numbers == NULL)
    {
        printf("Memory reallocation failed");
        return 1;
    }

    numbers[3] = 40;
    numbers[4] = 50;

    for(int i = 0; i < 5; i++)
    {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}
10 20 30 40 50

free() in C

The free() function releases dynamically allocated memory.

Syntax

free(pointer);

Example

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = malloc(sizeof(int));

    if(ptr == NULL)
    {
        return 1;
    }

    *ptr = 100;

    printf("Value = %d\n", *ptr);

    free(ptr);

    ptr = NULL;

    return 0;
}
Value = 100
After dynamically allocated memory is no longer required, release it using free().

Complete Dynamic Memory Example

The following program uses malloc(), stores values, prints them and finally releases the allocated memory. 

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    int *numbers = malloc(n * sizeof(int));

    if(numbers == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for(int i = 0; i < n; i++)
    {
        numbers[i] = (i + 1) * 10;
    }

    printf("Array elements:\n");

    for(int i = 0; i < n; i++)
    {
        printf("%d ", numbers[i]);
    }

    free(numbers);

    return 0;
}
Enter number of elements: 5 Array elements: 10 20 30 40 50

Using sizeof() with Dynamic Memory

The sizeof() operator helps determine the number of bytes required for a data type. 

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n = 5;

    int *numbers = malloc(n * sizeof(int));

    if(numbers == NULL)
    {
        return 1;
    }

    printf("Size of one integer = %zu bytes\n", sizeof(int));

    printf("Memory allocated = %zu bytes",
           n * sizeof(int));

    free(numbers);

    return 0;
}
Size of one integer = 4 bytes Memory allocated = 20 bytes
The exact size of C data types can depend on the compiler and platform. Do not assume that int is always 4 bytes.

What is a Memory Leak?

A memory leak occurs when dynamically allocated memory is no longer needed but the program does not release it.

Example of a Memory Leak

int *ptr;

ptr = malloc(100 * sizeof(int));

/* Memory is allocated */

/* free(ptr) is never called */

If this happens repeatedly, the program may consume more and more memory.

Important: Every successful dynamic allocation should have a suitable plan for releasing the memory when it is no longer needed.

Dangling Pointer

A dangling pointer is a pointer that refers to memory that is no longer valid. 

int *ptr = malloc(sizeof(int));

*ptr = 50;

free(ptr);

/* ptr should not be dereferenced here */

A common practice after freeing a pointer is to assign NULL to it when the pointer remains in scope. 

free(ptr);
ptr = NULL;

What is Double Free?

Double free means attempting to release the same allocated memory more than once. 

free(ptr);

/* Wrong */
free(ptr);

A safer pattern is: 

free(ptr);
ptr = NULL;
Never use or free a pointer again after its memory has been released unless it has been assigned a new valid allocation.

Dynamic Memory Functions

Function Purpose Header
malloc() Allocates a block of memory. <stdlib.h>
calloc() Allocates memory for multiple elements and initializes it to zero. <stdlib.h>
realloc() Changes the size of an allocated memory block. <stdlib.h>
free() Releases dynamically allocated memory. <stdlib.h>

Dynamic Memory Management Process

  1. Decide how much memory is required.
  2. Allocate memory using malloc() or calloc().
  3. Check whether the allocation succeeded.
  4. Use the allocated memory.
  5. Resize it with realloc() if necessary.
  6. Release it using free() when it is no longer required.

Common Memory Management Mistakes

  • Forgetting to call free().
  • Using memory after calling free().
  • Freeing the same memory twice.
  • Using an uninitialized pointer.
  • Not checking whether malloc() or calloc() returned NULL.
  • Allocating the wrong amount of memory.
  • Using realloc() incorrectly and losing the original pointer.
Remember: Dynamic memory management gives you more control over memory, but it also requires careful programming.

Summary

  • Memory management controls how memory is allocated and released.
  • malloc() allocates a block of memory.
  • calloc() allocates memory and initializes it to zero.
  • realloc() changes the size of an allocated block.
  • free() releases dynamically allocated memory.
  • Always check whether memory allocation succeeded.
  • Do not access memory after it has been freed.
  • Be careful about memory leaks and dangling pointers.
