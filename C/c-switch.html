C switch Statement

Learn how to use switch, case, break and default in C programming.

```
```

What is a switch Statement in C?

The switch statement in C is a decision-making statement used to execute one block of code from multiple choices.

It is especially useful when you need to compare one variable with several constant values.

Example: If a user enters a number from 1 to 3, you can use switch to perform a different operation for each number.
```
```

Why Use switch?

A switch statement can make programs easier to read when there are many possible choices.

  • Used for multiple choices
  • Makes decision-making code easier to understand
  • Useful for menu-driven programs
  • Uses case labels for different choices
  • Uses break to stop execution of a case
```
```

Syntax of switch

C Syntax 
switch (expression)
```

{
case value1:
// code
break;

```
case value2:
    // code
    break;

case value3:
    // code
    break;

default:
    // code
```

}
```

Parts of a switch Statement

Keyword / Part Purpose
switch Starts the switch statement.
expression The value that will be compared with cases.
case Defines a possible value.
break Stops execution of the switch statement.
default Runs when no case matches.
```
```

Simple switch Example

The following program checks the value of a number.

Example 
#include <stdio.h>
```

int main()
{
int number = 2;

```
switch (number)
{
    case 1:
        printf("You selected One");
        break;

    case 2:
        printf("You selected Two");
        break;

    case 3:
        printf("You selected Three");
        break;

    default:
        printf("Invalid choice");
}

return 0;
```

}
```
Output:
You selected Two
```

Using case

The case keyword defines a possible value that can match the switch expression.

Example 
int day = 1;
```

switch (day)
{
case 1:
printf("Monday");
break;

```
case 2:
    printf("Tuesday");
    break;
```

}
```

Using break

The break statement is commonly used at the end of every case.

It stops the switch statement after the matching case has been executed.

Example 
int number = 1;
```

switch (number)
{
case 1:
printf("One");
break;

```
case 2:
    printf("Two");
    break;
```

}
```
Without break, execution can continue into the following cases. This behavior is called fall-through.
```
```

Using default

The default case executes when none of the specified cases match the switch expression.

Example 
int number = 10;
```

switch (number)
{
case 1:
printf("One");
break;

```
case 2:
    printf("Two");
    break;

default:
    printf("Invalid number");
```

}
```
Output:
Invalid number

Menu Program Using switch

The switch statement is commonly used to create simple menu-based programs.

C Program 
#include <stdio.h>
```

int main()
{
int choice;

```
printf("1. Add\n");
printf("2. Subtract\n");
printf("3. Multiply\n");

printf("Enter your choice: ");
scanf("%d", &choice);

switch (choice)
{
    case 1:
        printf("You selected Addition");
        break;

    case 2:
        printf("You selected Subtraction");
        break;

    case 3:
        printf("You selected Multiplication");
        break;

    default:
        printf("Invalid choice");
}

return 0;
```

}
```

switch with Character

A switch statement can also be used with character values.

Example 
#include <stdio.h>
```

int main()
{
char grade = 'A';

```
switch (grade)
{
    case 'A':

        break;

    case 'C':
        printf("Average");
        break;

}

return 0;
```

}
```

Multiple Cases with Same Code

Multiple cases can execute the same block of code.

Example 
char grade = 'A';
```

switch (grade)
{
case 'A':
case 'B':
printf("Good grade");
break;

```
case 'C':
    printf("Average grade");
    break;

default:
    printf("Invalid grade");
```

}
```

Here, both A and B execute the same statement.

switch vs if-else

switch if-else
Useful for multiple fixed choices. Useful for conditions and ranges.
Uses case labels. Uses conditions.
Often easier to read for menus. More flexible for complex conditions.
Uses break to exit a case. Does not require break.
```
```

Important Points

  • The switch expression is evaluated once.
  • Each case represents a possible value.
  • Case values must be constant expressions.
  • The break statement is commonly used to stop execution after a matching case.
  • The default case is optional.
  • Multiple cases can share the same code.
  • If no case matches and there is no default case, nothing inside the switch is executed.
```
```

Common Mistakes

1. Forgetting break

Forgetting break may cause execution to continue into subsequent cases.

2. Using duplicate case values

Two cases in the same switch cannot have the same value.

3. Confusing case with a condition

A case is matched against the switch expression. It is not normally written as a general condition such as case x > 5:.
