C Syntax

Learn the basic syntax and structure of a C program.

```
```

What is C Syntax?

C syntax is the set of rules that defines how a C program should be written.

Just like English has grammar rules, C programming has syntax rules that the compiler follows.

Important: If the syntax of a C program is incorrect, the compiler may show a syntax error.
```
```

Basic Structure of a C Program

A basic C program usually contains a header file, the main function, statements and a return statement.

Basic C Program 
#include <stdio.h>
```

int main()
{
printf("Hello World!");

```
return 0;
```

}
```

Understanding the Program

1. #include <stdio.h>

This line includes the Standard Input Output library. It allows us to use functions such as printf() and scanf().

2. int main()

The main() function is the starting point of a C program.

3. Curly Braces { }

Curly braces define the beginning and end of a block of code.

4. printf()

The printf() function is used to display output on the screen.

5. return 0;

The return statement indicates that the program finished successfully.

Keywords are reserved words that have special meaning in C. They cannot normally be used as variable names.

Keyword Purpose

char Character data type

C is Case-Sensitive

C is a case-sensitive programming language. This means uppercase and lowercase letters are different.

Example 
int age = 20;
```

int Age = 30;
```

Here, age and Age are two different variables.

#include <stdio.h>
```

{

```

```

Important C Syntax Rules

  • C statements generally end with a semicolon.
  • C is case-sensitive.
  • Program execution normally starts from main().
  • Use curly braces to define blocks of code.
  • Use appropriate data types for variables.
  • Use comments to explain your code.
  • Keywords cannot normally be used as identifiers.
  • Strings are written inside double quotes.
  • Character constants are written inside single quotes.
  • Use #include to include required header files.
```
```

Common C Syntax Mistakes

1. Missing Semicolon

int age = 20

Correct: 

int age = 20;

2. Incorrect Capitalization

Printf("Hello");

Correct: 

printf("Hello");

3. Missing Header File

If you use printf(), include the appropriate standard I/O header: 

#include <stdio.h>

4. Incorrect Quotes

printf('Hello');

For a string, use double quotes: 

printf("Hello");
