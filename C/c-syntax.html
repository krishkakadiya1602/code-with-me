C Comments

Learn how to write comments in C programming

What are Comments in C?

Comments are notes written inside a C program to explain the code. Comments are ignored by the C compiler, so they do not affect the execution of the program.

Comments are very useful for making your code easier to understand, especially when working on large programs or working with other developers.

Remember: Comments are not executed by the C compiler. They are only used to explain or document your code.

Types of Comments in C

C provides two main types of comments:

  • Single-line comments
  • Multi-line comments

1. Single-Line Comments

A single-line comment starts with two forward slashes //.

Everything after // on that line is treated as a comment.

Example:

#include <stdio.h>

int main() {

    // This is a single-line comment

    printf("Hello World!");

    return 0;
}
Note: The compiler ignores the line beginning with //.

2. Multi-Line Comments

Multi-line comments are used when you want to write comments across multiple lines.

Multi-line comments start with /* and end with */.

Example:

#include <stdio.h>

int main() {

    /*
       This is a multi-line comment.
       It can contain multiple lines.
    */

    printf("Hello World!");

    return 0;
}

Comments with C Code

You can also use comments to temporarily disable a line of code. 

#include <stdio.h>

int main() {

    printf("Hello World!");

    // printf("This line will not execute");

    return 0;
}

In this example, the second printf() statement is commented out, so it will not be executed.

Why Use Comments?

  • To explain what your code does.
  • To make code easier to understand.
  • To document complex logic.
  • To temporarily disable code.
  • To make large programs easier to maintain.

Main Points

  • Comments are ignored by the C compiler.
  • Use // for single-line comments.
  • Use /* */ for multi-line comments.
  • Comments make programs easier to understand.
  • Comments can be used to temporarily disable code.
