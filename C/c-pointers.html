C Pointers

Learn how pointers store and work with memory addresses in C.

What is a Pointer in C?

A pointer is a variable that stores the memory address of another variable.

Unlike a normal variable that stores a value, a pointer stores the address where a value is located in memory.

Simple idea: A normal variable stores a value, while a pointer stores the address of that value. 
int number = 10;

int *ptr = &number;

Why Do We Use Pointers?

  • To work directly with memory addresses.
  • To modify variables through their addresses.
  • To pass values by reference to functions.
  • To work with arrays and strings.
  • To dynamically allocate memory.
  • To create data structures such as linked lists and trees.

Pointer Syntax

The basic syntax for declaring a pointer is:

data_type *pointer_name;

Example

int *ptr;

Here, ptr is a pointer that can store the address of an integer variable.

The Address-of Operator (&)

The & operator is called the address-of operator.

It is used to get the memory address of a variable. 

#include <stdio.h>

int main()
{
    int number = 10;

    printf("Value = %d\n", number);
    printf("Address = %p\n", (void*)&number);

    return 0;
}
Value = 10 Address = 0x7ffd1234...
The actual memory address will be different on different computers and program executions.

Declaring and Using a Pointer

#include <stdio.h>

int main()
{
    int number = 10;

    int *ptr = &number;

    printf("Number = %d\n", number);
    printf("Address = %p\n", (void*)ptr);

    return 0;
}
Number = 10 Address = 0x7ffd1234...

The Dereference Operator (*)

The * operator can be used to access the value stored at the address held by a pointer. 

#include <stdio.h>

int main()
{
    int number = 10;

    int *ptr = &number;

    printf("Value of number = %d\n", number);
    printf("Value using pointer = %d\n", *ptr);

    return 0;
}
Value of number = 10 Value using pointer = 10
Remember:
&variable → gives the address.
*pointer → gives the value stored at that address.

Changing a Variable Using a Pointer

A pointer can be used to change the value of the variable whose address it stores. 

#include <stdio.h>

int main()
{
    int number = 10;

    int *ptr = &number;

    *ptr = 50;

    printf("Number = %d", number);

    return 0;
}
Number = 50

Pointers and Arrays

Pointers and arrays are closely related in C. The name of an array generally represents the address of its first element when used in an expression. 

#include <stdio.h>

int main()
{
    int numbers[3] = {10, 20, 30};

    int *ptr = numbers;

    printf("%d\n", *ptr);
    printf("%d\n", *(ptr + 1));
    printf("%d\n", *(ptr + 2));

    return 0;
}
10 20 30

Pointer Arithmetic

C allows arithmetic operations on pointers. Common pointer operations include:

  • Increment: ptr++
  • Decrement: ptr--
  • Addition: ptr + n
  • Subtraction: ptr - n
#include <stdio.h>

int main()
{
    int numbers[3] = {10, 20, 30};

    int *ptr = numbers;

    printf("%d\n", *ptr);

    ptr++;

    printf("%d\n", *ptr);

    ptr++;

    printf("%d\n", *ptr);

    return 0;
}

Pointers with Functions

Pointers allow a function to modify the original variables passed to it. 

#include <stdio.h>

void changeValue(int *ptr)
{
    *ptr = 100;
}

int main()
{
    int number = 10;

    changeValue(&number);

    printf("Number = %d", number);

    return 0;
}
Number = 100

Swap Two Numbers Using Pointers

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp;

    temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 10;
    int y = 20;

    printf("Before swap: %d %d\n", x, y);

    swap(&x, &y);

    printf("After swap: %d %d", x, y);

    return 0;
}
Before swap: 10 20 After swap: 20 10

NULL Pointer

A NULL pointer is a pointer that does not point to a valid object or memory location. 

#include <stdio.h>

int main()
{
    int *ptr = NULL;

    if(ptr == NULL)
    {
        printf("Pointer is NULL");
    }

    return 0;
}
Pointer is NULL
Never dereference a NULL pointer. Doing something like *ptr when ptr == NULL can cause undefined behavior.

Pointer to Pointer

A pointer can store the address of another pointer. This is called a pointer to pointer. 

#include <stdio.h>

int main()
{
    int number = 10;

    int *ptr = &number;

    int **ptr2 = &ptr;

    printf("Number = %d\n", number);
    printf("Using ptr = %d\n", *ptr);
    printf("Using ptr2 = %d\n", **ptr2);

    return 0;
}
Number = 10 Using ptr = 10 Using ptr2 = 10

Void Pointer

A void pointer is a generic pointer that can hold the address of an object of any object type. 

#include <stdio.h>

int main()
{
    int number = 10;

    void *ptr = &number;

    printf("Value = %d", *(int *)ptr);

    return 0;
}
Value = 10

Pointers and Dynamic Memory

Pointers are important when using dynamic memory allocation functions such as:

  • malloc()
  • calloc()
  • realloc()
  • free()

These functions are provided through the <stdlib.h> header. 

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int *ptr;

    ptr = malloc(5 * sizeof(int));

    if(ptr == NULL)
    {
        printf("Memory allocation failed");
        return 1;
    }

    for(int i = 0; i < 5; i++)
    {
        ptr[i] = (i + 1) * 10;
    }

    for(int i = 0; i < 5; i++)
    {
        printf("%d ", ptr[i]);
    }

    free(ptr);

    return 0;
}

Common Pointer Mistakes

1. Using an uninitialized pointer

int *ptr;

*ptr = 10;   // Dangerous

2. Dereferencing NULL

int *ptr = NULL;

printf("%d", *ptr);   // Wrong

3. Using a pointer after freeing memory

free(ptr);

*ptr = 10;   // Wrong

4. Using the wrong pointer type

Make sure the pointer type matches the type of object whose address it stores, unless you are deliberately using a suitable generic pointer.

Important: Pointer errors can cause crashes, corrupted data, or undefined behavior. Always initialize pointers and use them carefully.
