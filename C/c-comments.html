C Comments

Learn how to use comments in C programming

What are Comments in C?

Comments are notes written inside a C program that are ignored by the compiler. They are used to explain the code and make programs easier to understand.

Important: Comments do not affect the execution of your C program.

C provides two main types of comments:

  • Single-line comments
  • Multi-line comments

1. Single-Line Comments

A single-line comment starts with two forward slashes //.

Everything written after // on that line is treated as a comment.

Example
#include <stdio.h>

int main() {

    // This is a single-line comment

    printf("Hello World!");

    return 0;
}

2. Multi-Line Comments

Multi-line comments are used when you want to write comments across multiple lines.

They start with /* and end with */.

Example
#include <stdio.h>

int main() {

    /*
       This is a multi-line comment.
       It can contain multiple lines.
    */

    printf("Hello World!");

    return 0;
}

Comments with C Code

Comments can also be used to explain individual parts of a program.

Example
#include <stdio.h>

int main() {

    int age = 20;   // Store age

    // Print the age
    printf("Age = %d", age);

    return 0;
}

Why Use Comments?

  • Comments make code easier to understand.
  • They explain what a particular section of code does.
  • They help developers maintain programs.
  • They are useful when working in a team.
  • They can temporarily disable code during testing.

Important Points

// → Used for single-line comments.

/* */ → Used for multi-line comments.

Comments are ignored by the C compiler.

Comments do not change the program output.
