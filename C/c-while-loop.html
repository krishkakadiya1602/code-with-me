C while Loop

Learn how to repeat a block of code using the while loop in C.

```
```

What is a while Loop in C?

The while loop in C is a looping statement that repeatedly executes a block of code as long as a specified condition is true.

The condition is checked before each iteration of the loop. If the condition becomes false, the loop stops.

Simple idea:
Check condition → Execute code → Update value → Check condition again
```
```

Why Use a while Loop?

  • To repeat code multiple times.
  • Useful when the number of repetitions is not known in advance.
  • Useful for input validation.
  • Useful for menu-driven programs.
  • Useful for processing data until a condition becomes false.
```
```

Syntax of while Loop

C Syntax 
while (condition)
```

{
// code to execute
}
```

The condition is checked before the statements inside the loop are executed.

```
```

How while Loop Works

  1. The condition is checked.
  2. If the condition is true, the loop body executes.
  3. The loop body updates the required variable.
  4. The condition is checked again.
  5. This continues until the condition becomes false.
If the condition is false at the beginning, the body of the while loop will not execute even once.
```
```

Simple while Loop Example

The following program prints numbers from 1 to 5.

Example 
#include <stdio.h>
```

int main()
{
int i = 1;

```
while (i <= 5)
{
    printf("%d\n", i);
    i++;
}

return 0;
```

}
```
Output:
1
2
3
4
5
```
```

Initialization in while Loop

Before starting a while loop, you normally initialize the variable used in the condition.

Example 
int i = 1;
```

while (i <= 5)
{
printf("%d\n", i);
i++;
}
```

Here, i starts with the value 1.

```
```

Updating the Loop Variable

The loop variable should normally be changed inside the loop. Otherwise, the condition may never become false.

Example 
int i = 1;
```

while (i <= 5)
{
printf("%d\n", i);

```
i++;
```

}
```
Important: The statement i++ increases the value of i after every iteration.
```
```

Decreasing Values Using while

A while loop can also be used to count down.

Example 
#include <stdio.h>
```

int main()
{
int i = 5;

```
while (i >= 1)
{
    printf("%d\n", i);
    i--;
}

return 0;
```

}
```
Output:
5
4
3
2
1

Calculate Sum Using while Loop

We can use a while loop to calculate the sum of numbers.

Example 
#include <stdio.h>
```

int main()
{
int i = 1;
int sum = 0;

```
while (i <= 5)
{
    sum = sum + i;
    i++;
}

printf("Sum = %d", sum);

return 0;
```

}
```
Output:
Sum = 15

while Loop with User Input

A while loop can continue running until the user enters a particular value.

Example 
#include <stdio.h>
```

int main()
{
int number;

```
printf("Enter a number: ");
scanf("%d", &number);

while (number != 0)
{
    printf("You entered %d\n", number);

    printf("Enter another number (0 to stop): ");
    scanf("%d", &number);
}

printf("Loop ended.");

return 0;
```

}
```

Factorial Using while Loop

The factorial of a positive integer can also be calculated using a while loop.

Example 
#include <stdio.h>
```

int main()
{
int number;
int factorial = 1;

```
printf("Enter a positive number: ");
scanf("%d", &number);

while (number > 0)
{
    factorial = factorial * number;
    number--;
}

printf("Factorial = %d", factorial);

return 0;
```

}

Infinite while Loop

An infinite loop is a loop whose condition never becomes false.

Example 
int i = 1;
```

while (i <= 5)
{
printf("%d\n", i);
}
```
In this example, i is never increased. Therefore, i remains 1 and the condition always remains true.

To avoid this problem, update the loop variable properly.

```
```

Using break with while Loop

The break statement can immediately terminate a while loop.

Example 
#include <stdio.h>
```

int main()
{
int i = 1;

```
while (i <= 10)
{
    if (i == 5)
    {
        break;
    }

    printf("%d\n", i);

    i++;
}

return 0;
```

}
```
Output:
1
2
3
4
```
```

Using continue with while Loop

The continue statement skips the remaining statements of the current iteration and moves to the next iteration.

Example 
#include <stdio.h>
```

int main()
{
int i = 0;

```
while (i < 5)
{
    i++;

    if (i == 3)
    {
        continue;
    }

    printf("%d\n", i);
}

return 0;
```

}
```
Output:
1
2
4
5
```

while Loop vs for Loop

while Loop for Loop
Useful when the number of iterations may not be known. Often useful when the number of iterations is known.
Initialization is normally written before the loop. Initialization can be written inside the for statement.
Update is normally written inside the loop body. Update can be written inside the for statement.
Syntax is simple and condition-focused. Initialization, condition and update are grouped together.
```
```

Important Points

  • A while loop checks its condition before executing the body.
  • If the condition is false initially, the loop executes zero times.
  • Always make sure the loop can eventually reach a false condition.
  • The loop variable should normally be initialized before the loop.
  • The loop variable should normally be updated inside the loop.
  • The break statement can terminate the loop early.
  • The continue statement can skip the current iteration.
```
```

Common Mistakes

1. Forgetting to update the variable

If the variable used in the condition is never updated, the loop may become infinite.

2. Incorrect condition

Make sure the condition eventually becomes false.

3. Incorrect initialization

Initialize the loop variable with a value that makes sense for your condition.

4. Creating an accidental infinite loop

Always check the initialization, condition and update together.
