JavaScript Promises

Learn how JavaScript Promises work with simple examples, states, then(), catch(), finally(), chaining and error handling.

What is a JavaScript Promise?

A Promise is an object that represents the eventual completion or failure of an asynchronous operation.

Promises are commonly used when JavaScript needs to wait for an operation such as fetching data, loading information, or performing another asynchronous task.

Simple idea: A Promise means that a result will be available later, either successfully or unsuccessfully.

Promise States

A Promise can have three states.

State Description
Pending The operation has not finished yet.
Fulfilled The operation completed successfully.
Rejected The operation failed.
A Promise starts in the pending state and eventually becomes either fulfilled or rejected.

Creating a Promise

A Promise can be created using the new Promise() constructor. 

const myPromise = new Promise(function(resolve, reject) {

    // asynchronous operation

});

The Promise constructor receives a function containing two parameters:

  • resolve - used when the operation succeeds.
  • reject - used when the operation fails.

Promise resolve()

The resolve() function is used when the asynchronous operation is successful. 

const myPromise = new Promise(function(resolve, reject) {

    resolve("Operation successful!");

});

Promise reject()

The reject() function is used when an operation fails. 

const myPromise = new Promise(function(resolve, reject) {

    reject("Something went wrong!");

});

Using then()

The then() method is used to handle a successfully fulfilled Promise. 

const myPromise = new Promise(function(resolve, reject) {

    resolve("Success!");

});

myPromise.then(function(result) {

    console.log(result);

});
Output: Success!

Using catch()

The catch() method is used to handle a rejected Promise. 

const myPromise = new Promise(function(resolve, reject) {

    reject("Something went wrong!");

});

myPromise.catch(function(error) {

    console.log(error);

});

Using finally()

The finally() method runs after the Promise has completed, regardless of whether it was fulfilled or rejected. 

const myPromise = new Promise(function(resolve, reject) {

    resolve("Success!");

});

myPromise
    .then(function(result) {

        console.log(result);

    })
    .finally(function() {

        console.log("Promise completed.");

    });

then(), catch() and finally()

These methods can be chained together. 

const myPromise = new Promise(function(resolve, reject) {

    resolve("Data loaded successfully!");

});

myPromise

    .then(function(result) {

        console.log(result);

    })

    .catch(function(error) {

        console.log(error);

    })

    .finally(function() {

        console.log("Finished!");

    });

Promise Chaining

Promise chaining allows multiple asynchronous operations to be performed one after another. 

Promise.resolve(10)

    .then(function(value) {

        return value * 2;

    })

    .then(function(value) {

        return value + 5;

    })

    .then(function(value) {

        console.log(value);

    });
Output: 25

Promise with setTimeout()

A Promise can be used with setTimeout() to simulate an asynchronous operation. 

const myPromise = new Promise(function(resolve, reject) {

    setTimeout(function() {

        resolve("Data received!");

    }, 2000);

});

myPromise.then(function(result) {

    console.log(result);

});

In this example, the Promise is resolved after approximately two seconds.

Promise Error Handling

The catch() method can be used to handle errors. 

const myPromise = new Promise(function(resolve, reject) {

    const success = false;

    if (success) {

        resolve("Operation successful!");

    } else {

        reject("Operation failed!");

    }

});

myPromise
    .then(function(result) {

        console.log(result);

    })
    .catch(function(error) {

        console.log(error);

    });

Promise.resolve()

Promise.resolve() creates a fulfilled Promise with a specified value. 

Promise.resolve("Hello!")

    .then(function(value) {

        console.log(value);

    });

Promise.reject()

Promise.reject() creates a rejected Promise. 

Promise.reject("Error!")

    .catch(function(error) {

        console.log(error);

    });

Promise.all()

Promise.all() waits for multiple Promises to complete successfully. 

const promise1 = Promise.resolve("First");
const promise2 = Promise.resolve("Second");
const promise3 = Promise.resolve("Third");

Promise.all([promise1, promise2, promise3])

    .then(function(results) {

        console.log(results);

    });
Promise.all() fulfills when all supplied Promises fulfill. If one rejects, the combined Promise rejects.

Promise vs Callback

Promise Callback
Uses then(), catch() Uses callback functions
Supports chaining Can become difficult to manage when deeply nested
Provides structured error handling Error handling depends on the callback design
Useful for asynchronous operations Also useful for asynchronous operations

Real-Life Example

Imagine ordering a product online. The order can be represented as a Promise:

  1. Order is placed - Pending
  2. Order is confirmed - Fulfilled
  3. Order fails - Rejected
const order = new Promise(function(resolve, reject) {

    const orderPlaced = true;

    if (orderPlaced) {

        resolve("Order confirmed!");

    } else {

        reject("Order failed!");

    }

});

order

    .then(function(message) {

        console.log(message);

    })

    .catch(function(error) {

        console.log(error);

    })

    .finally(function() {

        console.log("Order process finished.");

    });

Important Points

  • A Promise represents the eventual result of an asynchronous operation.
  • A Promise has three states: pending, fulfilled and rejected.
  • resolve() represents success.
  • reject() represents failure.
  • then() handles successful results.
  • catch() handles errors.
  • finally() runs after completion.
  • Promises can be chained together.
  • Promise.all() can work with multiple Promises.
