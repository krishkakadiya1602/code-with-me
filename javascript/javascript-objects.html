JavaScript Objects

Learn how to create, access, modify and use objects in JavaScript with simple examples.

What is a JavaScript Object?

A JavaScript object is a collection of related data and functionality stored as key-value pairs.

Objects are commonly used to represent real-world things such as a person, car, student, product, or computer.

Example: A student object can contain a name, age, course, and marks.

Creating an Object

You can create a JavaScript object using curly braces { }. 

const student = {
    name: "Krish",
    age: 20,
    course: "JavaScript"
};

Here:

  • name is a property.
  • age is a property.
  • course is a property.
  • The values are stored using key-value pairs.

Object Properties

Properties are the values associated with an object. 

const person = {
    name: "Krish",
    age: 20,
    city: "Vadodara"
};

This object has three properties:

  • name
  • age
  • city

Accessing Object Properties

There are two common ways to access object properties.

1. Dot Notation

const person = {
    name: "Krish",
    age: 20
};

console.log(person.name);
console.log(person.age);

2. Bracket Notation

const person = {
    name: "Krish",
    age: 20
};

console.log(person["name"]);
console.log(person["age"]);
Both dot notation and bracket notation can be used to access object properties.

Changing Object Properties

You can change the value of an existing property. 

const person = {
    name: "Krish",
    age: 20
};

person.age = 21;

console.log(person.age);
Output: 21

Adding New Properties

You can add a new property to an existing object. 

const person = {
    name: "Krish",
    age: 20
};

person.city = "Vadodara";

console.log(person);

Deleting Object Properties

The delete keyword can be used to remove a property from an object. 

const person = {
    name: "Krish",
    age: 20,
    city: "Vadodara"
};

delete person.city;

console.log(person);

Objects Can Store Different Data Types

Object properties can contain different types of values. 

const student = {

    name: "Krish",

    age: 20,

    isStudent: true,

    marks: 85,

    subjects: ["HTML", "CSS", "JavaScript"]

};

An object can contain strings, numbers, booleans, arrays, and even other objects.

JavaScript Object Methods

A function stored as an object property is called a method. 

const person = {

    name: "Krish",

    greet: function() {
        console.log("Hello!");
    }

};

person.greet();

Here, greet() is a method of the person object.

The JavaScript this Keyword

The this keyword refers to the object that is calling the method in this example. 

const person = {

    firstName: "Krish",

    lastName: "Kakadiya",

    fullName: function() {
        return this.firstName + " " + this.lastName;
    }

};

console.log(person.fullName());
Output: Krish Kakadiya

Nested Objects

An object can contain another object. This is called a nested object. 

const student = {

    name: "Krish",

    address: {

        city: "Vadodara",

        country: "India"

    }

};

console.log(student.address.city);
You can access nested properties using multiple dot operators.

Object Constructor

JavaScript also provides the new Object() syntax for creating an object. 

const person = new Object();

person.name = "Krish";
person.age = 20;

console.log(person.name);
console.log(person.age);

However, object literal syntax using { } is commonly used.

Object.keys()

The Object.keys() method returns an array containing the property names of an object. 

const person = {
    name: "Krish",
    age: 20,
    city: "Vadodara"
};

console.log(Object.keys(person));
Output: ["name", "age", "city"]

Object.values()

The Object.values() method returns an array containing the values of an object. 

const person = {
    name: "Krish",
    age: 20,
    city: "Vadodara"
};

console.log(Object.values(person));
Output: ["Krish", 20, "Vadodara"]

Object.entries()

The Object.entries() method returns an array containing key-value pairs. 

const person = {
    name: "Krish",
    age: 20
};

console.log(Object.entries(person));

Common Object Features

Feature Purpose
Object Properties Store data
Methods Store functions
Dot Notation Access properties
Bracket Notation Access properties dynamically
Object.keys() Get property names
Object.values() Get property values
Object.entries() Get key-value pairs

Real-Life Example

Objects are useful for storing information about real-world entities. 

const product = {

    name: "Laptop",

    brand: "Dell",

    price: 50000,

    available: true,

    showProduct: function() {

        return this.name + " - ₹" + this.price;

    }

};

console.log(product.showProduct());
Output: Laptop - ₹50000

Important Points

  • Objects store data using key-value pairs.
  • Object properties can contain different data types.
  • You can access properties using dot notation.
  • You can also use bracket notation.
  • Object properties can be changed.
  • New properties can be added.
  • Properties can be deleted using delete.
  • A function stored inside an object is called a method.
  • Objects can contain other objects.
