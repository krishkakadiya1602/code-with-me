JavaScript Data Types

Learn the different types of data used in JavaScript.

What are Data Types?

In JavaScript, a data type describes the kind of value stored in a variable.

For example, a variable can store a number, text, true or false, an object, or another type of value.

Example: 
let name = "Krish";
let age = 20;
let isStudent = true;
Here, name is a String, age is a Number, and isStudent is a Boolean.

JavaScript Data Types

JavaScript has several built-in data types. They can broadly be divided into primitive and non-primitive data types.

Data Type Example Description
String "Hello" Represents text.
Number 100 Represents numbers.
BigInt 12345678901234567890n Represents very large integers.
Boolean true Represents true or false.
Undefined undefined A variable without a value.
Null null Represents an intentional empty value.
Symbol Symbol("id") Represents a unique value.
Object {name: "Krish"} Represents collections of properties and values.

1. String

A String represents text. Strings can be written inside single quotes, double quotes, or backticks. 

let firstName = "Krish";

let city = 'Vadodara';

let message = `Welcome to Code With Me`;

console.log(firstName);
console.log(city);
console.log(message);

2. Number

The Number data type is used for integers and decimal numbers. 

let age = 20;

let price = 99.99;

let total = 100 + 50;

console.log(age);
console.log(price);
console.log(total);

3. BigInt

BigInt is used to represent integers larger than the safe limit of the regular Number type. 

let largeNumber = 12345678901234567890n;

console.log(largeNumber);
Note: A BigInt literal ends with the letter n.

4. Boolean

Boolean values can have only two possible values: true or false. 

let isLoggedIn = true;

let isAdmin = false;

console.log(isLoggedIn);
console.log(isAdmin);

5. Undefined

A variable has the value undefined when it has been declared but no value has been assigned to it. 

let username;

console.log(username);

The output will be:

undefined

6. Null

The value null represents an intentional absence of a value. 

let selectedUser = null;

console.log(selectedUser);

7. Symbol

Symbol creates a unique value. Symbols are often used as unique object property keys. 

let id = Symbol("userId");

console.log(id);

8. Object

An object can store multiple related values as properties and values. 

let student = {
    name: "Krish",
    age: 20,
    course: "JavaScript"
};

console.log(student.name);
console.log(student.age);
console.log(student.course);

9. Array

An Array is used to store multiple values in a single variable. 

let fruits = [
    "Apple",
    "Banana",
    "Mango"
];

console.log(fruits);
console.log(fruits[0]);
Note: Arrays are objects in JavaScript. They are commonly used to store lists of values.

Checking Data Type with typeof

JavaScript provides the typeof operator to determine the type of a value. 

let name = "Krish";
let age = 20;
let student = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof student);

Output: 

string
number
boolean

Primitive Data Types

Primitive data types represent single values.

  • String
  • Number
  • BigInt
  • Boolean
  • Undefined
  • Null
  • Symbol

Non-Primitive Data Type

Objects are non-primitive values and can contain multiple properties and values. 

let person = {
    name: "Krish",
    age: 20
};

console.log(person);

Important Points

  • JavaScript variables can store different types of values.
  • Strings are used for text.
  • Numbers are used for numeric values.
  • Boolean values are either true or false.
  • Undefined means a value has not been assigned.
  • Null represents an intentional empty value.
  • Objects can store multiple related values.
  • The typeof operator can be used to check a value's type.
