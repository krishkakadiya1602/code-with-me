JavaScript Statements

Learn how JavaScript statements tell the browser what to do.

What are JavaScript Statements?

A JavaScript statement is an instruction that tells JavaScript to perform an action.

JavaScript programs are made up of many statements. Each statement performs a particular task.

Example:

The following statement displays a message in the browser console. 

console.log("Hello World!");

Here, console.log() is used to display information in the browser console.

Simple JavaScript Statement

A simple JavaScript program can contain multiple statements. 

let name = "Krish";
let age = 20;

console.log(name);
console.log(age);

The first statement creates a variable called name.

The second statement creates a variable called age.

The next statements display their values.

JavaScript Semicolons

JavaScript statements are commonly ended with a semicolon ;. 

let name = "Krish";
let age = 20;
console.log(name);
console.log(age);
Important:

JavaScript can sometimes automatically insert semicolons, but using semicolons consistently makes your code easier to read and maintain.

Multiple JavaScript Statements

A JavaScript program can contain many statements. 

let firstName = "Krish";
let lastName = "Kakadiya";

let fullName = firstName + " " + lastName;

console.log(fullName);

JavaScript executes statements in sequence, generally from top to bottom.

Common JavaScript Statements

JavaScript has many types of statements. Some common examples are:

Statement Purpose Example
Variable Declaration Creates a variable let age = 20;
Assignment Assigns a value age = 25;
Expression Performs an operation let total = 10 + 20;
if Statement Checks a condition if (age >= 18)
for Loop Repeats code for (let i = 0; i < 5; i++)
return Returns a value from a function return result;

Variable Declaration Statements

JavaScript uses let, const, and var to declare variables. 

let name = "Krish";

const country = "India";

var age = 20;

Variables are used to store data that can be used later in the program.

Assignment Statements

An assignment statement assigns a value to a variable. 

let age;

age = 20;

console.log(age);

Here, the value 20 is assigned to the variable age.

Expression Statements

An expression produces a value. When an expression is used as a statement, it can perform an action. 

let a = 10;
let b = 20;

a + b;

Another example: 

console.log("JavaScript is easy to learn!");

if Statement

The if statement executes code when a condition is true. 

let age = 20;

if (age >= 18) {
    console.log("You are an adult.");
}

In this example, the message is displayed because the condition is true.

Loop Statements

Loop statements allow you to execute code repeatedly.

for Loop Example

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

This loop prints the numbers from 1 to 5.

JavaScript Block Statements

A block statement groups multiple statements together using curly brackets { }. 

{
    let name = "Krish";
    let age = 20;

    console.log(name);
    console.log(age);
}

Blocks are commonly used with if, loops, and functions.

Order of JavaScript Statements

JavaScript generally executes statements in the order in which they appear. 

console.log("First");

console.log("Second");

console.log("Third");
Output:

First
Second
Third

Statements with Comments

Comments can be used to explain JavaScript statements. Comments are ignored when JavaScript executes the code. 

// Create a variable
let name = "Krish";

// Display the name
console.log(name);

Best Practices for JavaScript Statements

  • Write one logical statement per line.
  • Use meaningful variable names.
  • Use semicolons consistently.
  • Use indentation to make code readable.
  • Use comments when an explanation is necessary.
  • Keep your code simple and organized.

Key Points

  • JavaScript programs are made up of statements.
  • A statement tells JavaScript to perform an action.
  • Statements are commonly ended with a semicolon.
  • JavaScript executes statements generally from top to bottom.
  • Statements can include variables, expressions, conditions, loops and functions.
  • Curly brackets are used to create blocks of statements.
