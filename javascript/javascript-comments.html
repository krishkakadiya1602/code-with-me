JavaScript Comments

Learn how to write comments in JavaScript.

What are JavaScript Comments?

Comments are notes written inside JavaScript code. They are ignored by the JavaScript engine and are not executed as code.

Comments help programmers explain what the code does and make programs easier to understand and maintain.

Important: Comments do not affect the execution of your JavaScript program.

Why Use Comments?

  • To explain difficult code.
  • To make code easier to understand.
  • To document your program.
  • To temporarily disable code.
  • To help other developers understand your code.

1. Single-Line Comments

A single-line comment starts with two forward slashes: //

Everything after // on that line is treated as a comment. 

// This is a JavaScript comment

let name = "Krish";

console.log(name);

The comment will not be executed. Only the JavaScript statement will run.

Comment After a Statement

You can also place a comment after a JavaScript statement. 

let age = 20; // Store the user's age

console.log(age);
Tip: Short comments can be placed at the end of a line to explain what that particular line does.

2. Multi-Line Comments

Multi-line comments start with /* and end with */. 

/*
    This is a multi-line comment.

    It can contain multiple lines
    of text.
*/

let message = "Hello JavaScript!";

console.log(message);

Multi-Line Comment Example

/*
    Student Information
    Name: Krish
    Course: JavaScript
    Website: Code With Me
*/

let student = "Krish";

console.log(student);

Using Comments to Disable Code

Comments can also be used to temporarily prevent JavaScript code from running. 

let firstName = "Krish";

// let lastName = "Kakadiya";

console.log(firstName);

The lastName line will not execute because it has been commented out.

Single-Line vs Multi-Line Comments

Type Syntax Use
Single-Line // comment Used for a single line.
Multi-Line /* comment */ Used for multiple lines.

Important Points

  • JavaScript comments are ignored by the browser.
  • Use // for single-line comments.
  • Use /* */ for multi-line comments.
  • Comments make code easier to read.
  • Comments can be used to temporarily disable code.
