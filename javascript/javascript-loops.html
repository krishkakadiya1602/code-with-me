JavaScript Loops

Learn how to repeat code using JavaScript loops such as for, while, do...while, break and continue.

What are JavaScript Loops?

A loop is used to execute a block of code repeatedly while a particular condition is true.

Loops are useful when you need to perform the same operation multiple times.

Example:

Instead of writing console.log() 10 times, you can use a loop to repeat it 10 times.

Types of JavaScript Loops

JavaScript provides several types of loops:

  • for loop - repeats code a specific number of times.
  • while loop - repeats code while a condition is true.
  • do...while loop - executes the code at least once.
  • for...of loop - loops through values of an iterable.
  • for...in loop - loops through object properties.

JavaScript for Loop

The for loop is commonly used when you know how many times the loop should run.

Syntax

for (initialization; condition; increment) {
    // code to execute
}

Example

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output:

1
2
3
4
5

Parts of a for Loop

Part Description
Initialization Creates or initializes the loop variable.
Condition Determines whether the loop should continue.
Increment Changes the loop variable after each iteration. 
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

JavaScript while Loop

The while loop executes a block of code as long as the condition is true.

Syntax

while (condition) {
    // code to execute
}

Example

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Output:

1
2
3
4
5
Important:

Make sure the condition eventually becomes false. Otherwise, you may create an infinite loop.

JavaScript do...while Loop

The do...while loop executes the code first and checks the condition afterward.

Syntax

do {
    // code to execute
} while (condition);

Example

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

Output:

1
2
3
4
5

JavaScript for...of Loop

The for...of loop is used to iterate over values in arrays, strings and other iterable objects.

Example with Array

const fruits = ["Apple", "Banana", "Mango"];

for (const fruit of fruits) {
    console.log(fruit);
}

Output:

Apple
Banana
Mango

JavaScript for...in Loop

The for...in loop is used to iterate over the properties of an object.

Example

const student = {
    name: "Krish",
    age: 20,
    course: "JavaScript"
};

for (const key in student) {
    console.log(key + ": " + student[key]);
}

Output:

name: Krish
age: 20
course: JavaScript

JavaScript break Statement

The break statement stops the loop immediately.

Example

for (let i = 1; i <= 10; i++) {

    if (i === 6) {
        break;
    }

    console.log(i);
}

Output:

1
2
3
4
5

JavaScript continue Statement

The continue statement skips the current iteration and continues with the next one.

Example

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}

Output:

1
2
4
5

JavaScript Nested Loops

A loop inside another loop is called a nested loop.

Example

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 2; j++) {

        console.log("i = " + i + ", j = " + j);

    }
}

Output:

i = 1, j = 1
i = 1, j = 2
i = 2, j = 1
i = 2, j = 2
i = 3, j = 1
i = 3, j = 2

Loop Through an Array

You can use a loop to access every item in an array. 

const students = [
    "Krish",
    "Rahul",
    "Amit",
    "Priya"
];

for (let i = 0; i < students.length; i++) {
    console.log(students[i]);
}

Practical Example

The following example prints the multiplication table of 5. 

let number = 5;

for (let i = 1; i <= 10; i++) {

    console.log(number + " × " + i + " = " + (number * i));

}

Output:

5 × 1 = 5
5 × 2 = 10
5 × 3 = 15
5 × 4 = 20
5 × 5 = 25
5 × 6 = 30
5 × 7 = 35
5 × 8 = 40
5 × 9 = 45
5 × 10 = 50

for vs while vs do...while

Loop When to Use
for When you know approximately how many times to repeat.
while When the number of repetitions depends on a condition.
do...while When the code must execute at least once.
for...of When you want to loop through values.
for...in When you want to loop through object properties.

JavaScript Loop Best Practices

  • Always make sure the loop can eventually stop.
  • Use for when the number of iterations is known.
  • Use while when the condition controls the loop.
  • Use for...of for array values.
  • Use for...in mainly for object properties.
  • Avoid unnecessary nested loops because they can reduce performance.
  • Use meaningful variable names.
