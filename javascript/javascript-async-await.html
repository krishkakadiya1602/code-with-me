JavaScript Async / Await

Learn how to write asynchronous JavaScript using async and await with simple examples.

What is Async / Await?

Async and Await are JavaScript keywords used to work with asynchronous operations in a cleaner and easier way.

They are commonly used with Promises.

Simple idea:
async makes a function asynchronous, while await waits for a Promise to finish.

Async/await makes asynchronous code look more like normal synchronous code, which can make it easier to read and understand.

The async Keyword

The async keyword is placed before a function. 

async function hello() {
    return "Hello JavaScript!";
}

An async function always returns a Promise.

Example

async function message() {
    return "Hello!";
}

message().then(function(result) {
    console.log(result);
});
Important:

Even if an async function returns a normal value, JavaScript automatically wraps that value inside a Promise.

The await Keyword

The await keyword is used to wait for a Promise to complete. 

async function getData() {

    let result = await somePromise;

    console.log(result);
}

Normally, await is used inside an async function.

Basic Async/Await Example

function getMessage() {

    return new Promise(function(resolve) {

        setTimeout(function() {
            resolve("Data received!");
        }, 2000);

    });

}


async function showMessage() {

    const message = await getMessage();

    console.log(message);

}

showMessage();

In this example, the function waits until the Promise finishes before continuing.

Async/Await with Promise

Async/await is commonly used with Promises. 

function getData() {

    return new Promise(function(resolve) {

        setTimeout(function() {
            resolve("Data loaded successfully!");
        }, 1500);

    });

}


async function loadData() {

    const data = await getData();

    console.log(data);

}

loadData();

Using Multiple await Statements

You can use multiple await statements inside the same async function. 

function firstTask() {

    return new Promise(function(resolve) {

        setTimeout(function() {
            resolve("First task completed");
        }, 1000);

    });

}


function secondTask() {

    return new Promise(function(resolve) {

        setTimeout(function() {
            resolve("Second task completed");
        }, 1000);

    });

}


async function runTasks() {

    const first = await firstTask();

    console.log(first);

    const second = await secondTask();

    console.log(second);

}

runTasks();

The second task starts after the first awaited Promise has completed.

Error Handling with try...catch

Errors in async/await code can be handled using try...catch. 

async function getData() {

    try {

        const response = await fetch(
            "https://example.com/data"
        );

        console.log(response);

    } catch (error) {

        console.log("Something went wrong:", error);

    }

}

getData();
try: Contains code that may produce an error.

catch: Handles the error if something goes wrong.

Async/Await with fetch()

Async/await is frequently used with the JavaScript fetch() API. 

async function getUsers() {

    try {

        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users"
        );

        const users = await response.json();

        console.log(users);

    } catch (error) {

        console.log("Error:", error);

    }

}

getUsers();

Here there are two await operations:

  • Wait for the HTTP response.
  • Wait for the response to be converted to JSON.

Returning Values from Async Functions

An async function returns a Promise. 

async function calculate() {

    return 100;

}

calculate().then(function(result) {

    console.log(result);

});

The returned value is automatically available through the Promise.

Async Arrow Functions

You can also use async with arrow functions. 

const getMessage = async () => {

    return "Hello from async function!";

};


getMessage().then(function(result) {

    console.log(result);

});

Sequential Async Operations

When multiple await statements are written one after another, the operations run sequentially. 

async function processData() {

    const first = await taskOne();

    const second = await taskTwo();

    const third = await taskThree();

    console.log(first);
    console.log(second);
    console.log(third);

}

The next operation waits until the previous operation finishes.

Async/Await with Promise.all()

If multiple independent asynchronous operations can run at the same time, you can use Promise.all(). 

async function loadData() {

    const results = await Promise.all([

        getUsers(),
        getProducts(),
        getOrders()

    ]);

    console.log(results);

}
Tip:

Use Promise.all() when multiple asynchronous operations do not depend on each other.

Promise vs Async/Await

Promise Async/Await
Uses .then() Uses await
Can become difficult with many operations Usually easier to read
Uses .catch() for errors Can use try...catch
Works with asynchronous operations Works with Promises

Practical Delay Example

The following example creates a delay using a Promise and await. 

function delay(time) {

    return new Promise(function(resolve) {

        setTimeout(resolve, time);

    });

}


async function start() {

    console.log("Starting...");

    await delay(2000);

    console.log("2 seconds completed!");

}

start();

The program waits for two seconds before printing the second message.

Important Rules of Async/Await

  • async is used to create an async function.
  • An async function always returns a Promise.
  • await waits for a Promise to settle.
  • Normally, await is used inside an async function.
  • Use try...catch for error handling.
  • Use Promise.all() for independent asynchronous operations.

Async/Await Best Practices

  • Use meaningful function names.
  • Handle errors using try...catch.
  • Avoid unnecessary await statements.
  • Use Promise.all() when tasks can run concurrently.
  • Keep asynchronous functions small and readable.
  • Check HTTP responses when using fetch().
