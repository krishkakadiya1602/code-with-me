JavaScript Arrays

Learn how to create, access, change and work with arrays in JavaScript.

What is a JavaScript Array?

An array is a special variable that can store multiple values in a single variable.

For example, instead of creating separate variables for different fruits, you can store all the fruits inside one array. 

const fruits = ["Apple", "Banana", "Mango"];
Example:

The array above contains three values: Apple, Banana and Mango.

Creating an Array

You can create an array using square brackets []. 

const cars = ["BMW", "Audi", "Toyota"];

Each value inside the array is called an element.

JavaScript Array Index

Array indexes start from 0.

Index Value
0 Apple
1 Banana
2 Mango 
const fruits = ["Apple", "Banana", "Mango"];

console.log(fruits[0]);
console.log(fruits[1]);
console.log(fruits[2]);

Output:

Apple
Banana
Mango

Accessing Array Elements

You can access an array element by using its index. 

const colors = ["Red", "Green", "Blue"];

console.log(colors[0]);

Output:

Red

Changing Array Elements

You can change an array element by assigning a new value to its index. 

const fruits = ["Apple", "Banana", "Mango"];

fruits[1] = "Orange";

console.log(fruits);

Output:

["Apple", "Orange", "Mango"]

JavaScript Array Length

The length property returns the number of elements in an array. 

const fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.length);

Output:

3

Adding Elements to an Array

Using push()

The push() method adds an element to the end of an array. 

const fruits = ["Apple", "Banana"];

fruits.push("Mango");

console.log(fruits);

Output:

["Apple", "Banana", "Mango"]

Removing Elements from an Array

Using pop()

The pop() method removes the last element from an array. 

const fruits = ["Apple", "Banana", "Mango"];

fruits.pop();

console.log(fruits);

Output:

["Apple", "Banana"]

Adding an Element at the Beginning

The unshift() method adds an element to the beginning of an array. 

const fruits = ["Banana", "Mango"];

fruits.unshift("Apple");

console.log(fruits);

Output:

["Apple", "Banana", "Mango"]

Removing the First Element

The shift() method removes the first element from an array. 

const fruits = ["Apple", "Banana", "Mango"];

fruits.shift();

console.log(fruits);

Output:

["Banana", "Mango"]

Looping Through an Array

You can use a for loop to access every element in an array. 

const fruits = ["Apple", "Banana", "Mango"];

for (let i = 0; i < fruits.length; i++) {

    console.log(fruits[i]);

}

Output:

Apple
Banana
Mango

Using for...of with Arrays

The for...of loop makes it easy to access array values. 

const fruits = ["Apple", "Banana", "Mango"];

for (const fruit of fruits) {

    console.log(fruit);

}

Array of Numbers

Arrays can store numbers as well. 

const numbers = [10, 20, 30, 40, 50];

console.log(numbers[2]);

Output:

30

Array with Different Data Types

JavaScript arrays can contain different types of values. 

const data = [
    "Krish",
    20,
    true,
    25.5
];

console.log(data);

Nested Arrays

An array can contain another array. This is called a nested array. 

const numbers = [
    [1, 2, 3],
    [4, 5, 6]
];

console.log(numbers[0][1]);

Output:

2

Array of Objects

Arrays can also contain objects. 

const students = [
    {
        name: "Krish",
        age: 20
    },
    {
        name: "Rahul",
        age: 21
    }
];

console.log(students[0].name);

Output:

Krish

Common JavaScript Array Methods

Method Description
push() Adds an element to the end.
pop() Removes the last element.
shift() Removes the first element.
unshift() Adds an element to the beginning.
length Returns the number of elements.
includes() Checks whether an element exists.
indexOf() Returns the index of an element.
join() Converts array elements into a string.

Checking if an Element Exists

The includes() method checks whether an array contains a particular value. 

const fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.includes("Banana"));
console.log(fruits.includes("Orange"));

Output:

true
false

Finding an Array Element

The indexOf() method returns the index of an element. 

const fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.indexOf("Mango"));

Output:

2

Joining Array Elements

The join() method combines array elements into a string. 

const fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.join(", "));

Output:

Apple, Banana, Mango

Practical Example

Here is a simple student list using a JavaScript array. 

const students = [
    "Krish",
    "Rahul",
    "Amit",
    "Priya"
];

let output = "";

for (let i = 0; i < students.length; i++) {

    output += (i + 1) + ". " + students[i] + "<br>";

}

document.getElementById("students").innerHTML = output;

Key Points

  • An array stores multiple values in one variable.
  • Array indexes start from 0.
  • Use length to find the number of elements.
  • Use push() to add an element at the end.
  • Use pop() to remove the last element.
  • Use unshift() to add an element at the beginning.
  • Use shift() to remove the first element.
  • Use includes() to check whether a value exists.
  • Use indexOf() to find an element's index.
  • Arrays can contain strings, numbers, booleans, objects and other arrays.
  • You can use loops to process array elements.
