JavaScript Introduction

Learn the basics of JavaScript and discover how JavaScript makes websites interactive and dynamic.

1. What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic.

HTML is used to create the structure of a webpage, CSS is used to design the webpage, and JavaScript is used to add behavior and interaction.

Simple way to remember:

HTML → Structure
CSS → Design
JavaScript → Behavior and Interaction
JavaScript can run directly in modern web browsers such as Chrome, Edge, Firefox and Safari.

2. Why Learn JavaScript?

JavaScript is one of the most widely used programming languages for web development.

It allows developers to create interactive websites and web applications.

JavaScript can be used to:

  • Change HTML content.
  • Change CSS styles.
  • Respond to user actions.
  • Validate forms.
  • Create animations.
  • Create interactive applications.
  • Work with APIs.
  • Store data in the browser.

3. JavaScript with HTML

JavaScript can change HTML content using JavaScript code.

For example, JavaScript can change the text inside an HTML element. 

<!DOCTYPE html>

<html>

<body>

<h2 id="demo">Hello</h2>

<script>

document.getElementById("demo").innerHTML =
"Hello JavaScript!";

</script>

</body>

</html>
In this example, getElementById() finds the HTML element and innerHTML changes its content.

4. JavaScript can Change HTML

JavaScript can change the content of HTML elements. 

document.getElementById("demo").innerHTML =
"New Content";

Example

JavaScript changes the text from "Hello" to "Hello JavaScript!"

5. JavaScript can Change CSS

JavaScript can also change the CSS style of an HTML element. 

document.getElementById("demo").style.color =
"blue";

JavaScript can change properties such as:

  • color
  • backgroundColor
  • fontSize
  • display
  • width
  • height

6. JavaScript Events

JavaScript can respond to events performed by the user.

Examples of events include:

  • Clicking a button
  • Moving the mouse
  • Typing on the keyboard
  • Submitting a form
  • Loading a page
<button onclick="showMessage()">
    Click Me
</button>

<script>

function showMessage() {

    alert("Hello JavaScript!");

}

</script>

7. JavaScript Variables

Variables are used to store information.

JavaScript provides let, const and var for creating variables. 

let name = "Krish";

const age = 20;

var city = "Gujarat";
Example:

The variable name stores the value "Krish".

8. JavaScript Functions

A function is a block of code designed to perform a particular task. 

function greet() {

    alert("Welcome to Code With Me!");

}

greet();

The function can be called whenever you need to execute its code.

9. JavaScript Output

JavaScript provides different ways to display information.

Using innerHTML

document.getElementById("demo").innerHTML =
"Hello";

Using alert()

alert("Hello JavaScript!");

Using console.log()

console.log("Hello JavaScript!");

10. JavaScript Where is Used?

JavaScript is used in many different areas of modern web development.

Area Example
Websites Interactive web pages
Web Applications Dashboards and online applications
Frontend Development Interactive user interfaces
Backend Development Server-side applications with JavaScript runtimes
APIs Working with external data
Games Browser-based games
