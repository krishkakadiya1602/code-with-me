JavaScript Form Validation

Learn how to validate user input in HTML forms using JavaScript.

What is Form Validation?

Form validation is the process of checking whether the information entered by a user is correct and complete before the form is submitted.

For example, a website may require the user to enter a name, valid email address and password.

Example:

If a user leaves an email field empty, JavaScript can display an error message instead of allowing the form to continue.

Why is Form Validation Important?

  • Prevents empty fields.
  • Checks whether data has the correct format.
  • Improves the user experience.
  • Helps prevent invalid data from being submitted.
  • Provides immediate feedback to users.
Important:

Client-side validation improves usability, but important data should also be validated on the server before being trusted or stored.

Checking Required Fields

You can check whether an input contains a value using JavaScript. 

const name =
    document.getElementById("name").value;

if (name.trim() === "") {

    alert("Name is required.");

}

The trim() method removes spaces from the beginning and end of text.

Validating an Email Address

JavaScript can check whether an email looks like a valid email address. 

const email =
    document.getElementById("email").value;

const emailPattern =
    /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

if (!emailPattern.test(email)) {

    alert("Please enter a valid email address.");

}

Password Validation

You can check the length of a password before accepting it. 

const password =
    document.getElementById("password").value;

if (password.length < 8) {

    alert("Password must contain at least 8 characters.");

}

Confirm Password Validation

A registration form can compare two password fields to make sure they match. 

const password =
    document.getElementById("password").value;

const confirmPassword =
    document.getElementById("confirmPassword").value;

if (password !== confirmPassword) {

    alert("Passwords do not match.");

}

Number Validation

JavaScript can check whether a number is within a particular range. 

const age =
    Number(document.getElementById("age").value);

if (age < 18) {

    alert("Age must be 18 or above.");

}

Minimum and Maximum Values

You can check whether a number is between a minimum and maximum value. 

const age = 25;

if (age >= 18 && age <= 60) {

    console.log("Valid age.");

} else {

    console.log("Age is outside the allowed range.");

}

Using Regular Expressions

Regular expressions, also called regex, can be used to check whether text follows a specific pattern.

For example, you can use regex to validate emails, phone numbers and other formatted input. 

const phone =
    "9876543210";

const phonePattern =
    /^[0-9]{10}$/;

if (phonePattern.test(phone)) {

    console.log("Valid phone number.");

} else {

    console.log("Invalid phone number.");

}

Preventing Form Submission

The preventDefault() method can stop the browser's default form submission. 

form.addEventListener("submit", function(event) {

    event.preventDefault();

    console.log("Form validation started.");

});

Displaying Error Messages

Instead of using only an alert, you can display an error message directly on the page. 

const error =
    document.getElementById("error");

error.textContent =
    "Please enter your name.";

Displaying a Success Message

const success =
    document.getElementById("success");

success.textContent =
    "Form submitted successfully!";

Form Validation Flow

Step Action
1 User enters information.
2 JavaScript reads the form values.
3 JavaScript checks the values.
4 Error messages are displayed if necessary.
5 The form is submitted when validation passes.

Complete Form Validation Example

This example validates name, email and password. 

<form id="myForm">

    <input id="name" type="text">

    <input id="email" type="email">

    <input id="password" type="password">

    <button type="submit">
        Submit
    </button>

</form>

<script>

const form =
    document.getElementById("myForm");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    const name =
        document.getElementById("name").value.trim();

    const email =
        document.getElementById("email").value.trim();

    const password =
        document.getElementById("password").value;

    if (name === "") {

        alert("Name is required.");
        return;

    }

    if (email === "") {

        alert("Email is required.");
        return;

    }

    if (password.length < 8) {

        alert("Password must be at least 8 characters.");
        return;

    }

    alert("Form is valid!");

});

</script>

Form Validation Best Practices

  • Always validate required fields.
  • Show clear and useful error messages.
  • Check email formats when an email is required.
  • Use appropriate input types such as email and number.
  • Validate passwords according to the application's requirements.
  • Use preventDefault() when handling forms with JavaScript.
  • Do not rely only on client-side validation for security.
  • Validate important data again on the server.

Key Points

  • Form validation checks user input before processing it.
  • Use trim() to check text input while ignoring surrounding spaces.
  • Email addresses can be checked using patterns or suitable input types.
  • Password validation can check minimum length and other requirements.
  • Passwords can be compared using !==.
  • preventDefault() can stop the browser's default form submission.
  • Error messages should clearly tell users what needs to be corrected.
  • Client-side validation should not replace server-side validation.
