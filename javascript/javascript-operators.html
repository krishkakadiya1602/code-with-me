JavaScript Operators

Learn how JavaScript operators are used to calculate, compare and work with values.

What are JavaScript Operators?

Operators are special symbols or keywords used to perform operations on values and variables.

For example: 

let a = 10;
let b = 20;

let result = a + b;

console.log(result);

Here, + is an arithmetic operator.

Simple idea:

Operators perform actions on values and variables.

Types of JavaScript Operators

JavaScript provides many types of operators.

Operator Type Examples Purpose
Arithmetic + - * / % ** Perform calculations
Assignment = += -= *= /= Assign values
Comparison == === != !== > < Compare values
Logical && || ! Combine conditions
Increment / Decrement ++ -- Increase or decrease values
Ternary ? : Short conditional expression

Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Operator Name Example Result
+ Addition 10 + 5 15
- Subtraction 10 - 5 5
* Multiplication 10 * 5 50
/ Division 10 / 5 2
% Modulus 10 % 3 1
** Exponentiation 2 ** 3 8

Addition

let a = 10;
let b = 20;

let result = a + b;

console.log(result);

Subtraction

let a = 20;
let b = 5;

console.log(a - b);

Multiplication

let a = 10;
let b = 5;

console.log(a * b);

Division

let a = 20;
let b = 5;

console.log(a / b);

Modulus

let remainder = 10 % 3;

console.log(remainder);

Assignment Operators

Assignment operators are used to assign values to variables.

Operator Example Equivalent
= x = 10 x = 10
+= x += 5 x = x + 5
-= x -= 5 x = x - 5
*= x *= 5 x = x * 5
/= x /= 5 x = x / 5
%= x %= 5 x = x % 5

Example

let score = 10;

score += 5;

console.log(score);

The result is 15.

Comparison Operators

Comparison operators compare two values and return either true or false.

Operator Meaning Example
== Equal value 5 == 5
=== Equal value and type 5 === 5
!= Not equal value 5 != 10
!== Not equal value or type 5 !== "5"
> Greater than 10 > 5
< Less than 5 < 10
>= Greater than or equal 10 >= 10
<= Less than or equal 5 <= 10

Example

let age = 20;

console.log(age >= 18);

Output: 

true

== vs ===

The == operator compares values after possible type conversion. 

console.log(5 == "5");

The === operator checks both value and type. 

console.log(5 === "5");
Important:

In modern JavaScript, using === is often preferred when you want strict comparison.

Logical Operators

Logical operators are commonly used to combine conditions.

Operator Name Example
&& AND age >= 18 && age <= 60
|| OR age < 18 || age > 60
! NOT !isLoggedIn

AND Operator

let age = 25;

console.log(age >= 18 && age <= 60);

OR Operator

let age = 15;

console.log(age < 18 || age > 60);

NOT Operator

let isLoggedIn = true;

console.log(!isLoggedIn);

Increment and Decrement Operators

The increment operator ++ increases a value by 1. 

let count = 5;

count++;

console.log(count);

The decrement operator -- decreases a value by 1. 

let count = 5;

count--;

console.log(count);

Ternary Operator

The ternary operator provides a short way to write a simple conditional expression.

Syntax: 

condition ? valueIfTrue : valueIfFalse;

Example

let age = 20;

let message =
    age >= 18
        ? "Adult"
        : "Minor";

console.log(message);

String Operator

The + operator can also be used to join strings together. 

let firstName = "Krish";
let lastName = "Kakadiya";

let fullName = firstName + " " + lastName;

console.log(fullName);
Output:

Krish Kakadiya

Operator Precedence

When an expression contains multiple operators, JavaScript follows rules that determine which operation is performed first. 

let result = 10 + 5 * 2;

console.log(result);

Multiplication is performed before addition, so the result is 20.

Using Parentheses

let result = (10 + 5) * 2;

console.log(result);

Parentheses make the addition happen first, producing 30.

Practical Example

Operators can be combined to create useful programs. 

let price = 1000;

let discount = 100;

let finalPrice = price - discount;

let isAffordable = finalPrice <= 1000;

console.log("Final Price: " + finalPrice);

console.log("Affordable: " + isAffordable);

JavaScript Operator Best Practices

  • Use parentheses when they make an expression easier to understand.
  • Use === when strict equality is intended.
  • Keep complex expressions readable.
  • Use meaningful variable names.
  • Avoid unnecessarily complicated expressions.
  • Test calculations and conditions with different values.
