JavaScript Output

JavaScript can display information in different ways. Output is useful when you want to show text, numbers, messages, calculations, or results to the user.

Important: JavaScript provides several methods to display output, including innerHTML, document.write(), window.alert(), and console.log().

Main Points

  • Use innerHTML to change HTML content.
  • Use document.write() to write directly into the HTML document.
  • Use window.alert() to display an alert.
  • Use console.log() to display information in the browser console.

1. Using innerHTML

The innerHTML property is commonly used to change the content of an HTML element. 

<!DOCTYPE html>
<html>

<body>

<h2 id="demo"></h2>

<script>

document.getElementById("demo").innerHTML =
    "Hello JavaScript!";

</script>

</body>

</html>

In this example, JavaScript finds the element with the ID demo and changes its content.

2. Using document.write()

The document.write() method writes content directly into the HTML document. 

<script>

document.write("Hello JavaScript!");

</script>
Note: Using document.write() after the page has finished loading can replace the entire HTML document. Therefore, it is mainly useful for simple examples.

3. Using window.alert()

The window.alert() method displays a message in an alert box. 

<script>

window.alert("Welcome to Code With Me!");

</script>

You can also write alert() instead of window.alert(). 

alert("Hello World!");

4. Using console.log()

The console.log() method displays output in the browser's developer console. 

<script>

console.log("Hello JavaScript!");

</script>
How to see the output: Open your browser's Developer Tools and select the Console tab.

In Chrome, you can press: F12 or Ctrl + Shift + J

JavaScript Output Methods

Method Purpose
innerHTML Changes the content of an HTML element.
document.write() Writes content directly to the HTML document.
window.alert() Displays a message in an alert box.
console.log() Displays output in the browser console.

Example: Display a Calculation

JavaScript can also display the result of calculations. 

let a = 10;
let b = 20;

let result = a + b;

document.getElementById("demo").innerHTML = result;

The output will be:

30
