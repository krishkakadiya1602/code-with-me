JavaScript if Statement

Learn how to make decisions using conditions in JavaScript.

What is an if Statement?

The JavaScript if statement is used to execute a block of code only when a specified condition is true.

It is one of the most important concepts used for making decisions in JavaScript programs.

Example: If a person's age is 18 or greater, the program can display a message saying that the person is an adult.

Syntax of if Statement

if (condition) {

    // code to execute

}

If the condition evaluates to true, the code inside the curly braces will execute.

Basic if Example

let age = 20;

if (age >= 18) {

    console.log("You are an adult.");

}

Since 20 >= 18 is true, the message will be displayed.

Using Comparison Operators

Conditions commonly use comparison operators.

Operator Meaning Example
== Equal value age == 18
=== Equal value and type age === 18
!= Not equal age != 18
!== Not equal value or type age !== 18
> Greater than age > 18
< Less than age < 18
>= Greater than or equal to age >= 18
<= Less than or equal to age <= 18

if...else Statement

The if...else statement executes one block of code when the condition is true and another block when the condition is false. 

let age = 16;

if (age >= 18) {

    console.log("You are an adult.");

} else {

    console.log("You are not an adult.");

}

else if Statement

The else if statement is used when you need to check multiple conditions. 

let marks = 75;

if (marks >= 90) {

    console.log("Grade A+");

} else if (marks >= 75) {

    console.log("Grade A");

} else if (marks >= 60) {

    console.log("Grade B");

} else {

    console.log("Grade C");

}

Using Multiple Conditions

You can combine conditions using logical operators such as && and ||. 

let age = 20;
let hasID = true;

if (age >= 18 && hasID === true) {

    console.log("Access allowed.");

}

Nested if Statement

An if statement can also be placed inside another if statement. This is called a nested if statement. 

let age = 20;
let isStudent = true;

if (age >= 18) {

    if (isStudent) {

        console.log("You are an adult student.");

    }

}

Real-Life Example

Here is a simple example of checking whether a user can access a website. 

let loggedIn = true;

if (loggedIn) {

    console.log("Welcome to Code With Me!");

} else {

    console.log("Please login first.");

}

Important Points

  • Use if to check a condition.
  • Use else when the if condition is false.
  • Use else if to check multiple conditions.
  • Conditions normally produce a true or false result.
  • Comparison operators are commonly used with if statements.
  • Logical operators can combine multiple conditions.
  • An if statement can be placed inside another if statement.
