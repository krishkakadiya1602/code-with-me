JavaScript Events

Learn how JavaScript responds to user actions such as clicks, mouse movements, keyboard input and form actions.

What are JavaScript Events?

An event is an action or occurrence that happens in the browser.

JavaScript can detect these events and execute code when they happen.

Examples of Events:
  • Clicking a button
  • Moving the mouse
  • Pressing a keyboard key
  • Submitting a form
  • Loading a webpage
  • Changing an input value

Common JavaScript Events

Event Description
click Occurs when an element is clicked.
dblclick Occurs when an element is double-clicked.
mouseover Occurs when the mouse moves over an element.
mouseout Occurs when the mouse leaves an element.
keydown Occurs when a keyboard key is pressed.
keyup Occurs when a keyboard key is released.
submit Occurs when a form is submitted.
change Occurs when an input value changes.
load Occurs when a page or resource finishes loading.

onclick Event

The onclick event occurs when an element is clicked. 

<button onclick="showMessage()">
    Click Me
</button>

<script>

function showMessage() {

    alert("Hello!");

}

</script>

When the button is clicked, the showMessage() function runs.

Inline Event Handler

You can directly write JavaScript inside an HTML event attribute. 

<button onclick="alert('Hello World!')">
    Click Me
</button>
Inline event handlers are simple for learning, but larger projects commonly use addEventListener().

addEventListener()

The addEventListener() method allows you to attach an event handler to an element. 

const button = document.getElementById("myButton");

button.addEventListener("click", function() {

    alert("Button clicked!");

});

The first argument specifies the event type. The second argument contains the function that should run.

Click Event Example

<button id="btn">
    Click Me
</button>

<p id="message"></p>

<script>

const btn = document.getElementById("btn");

btn.addEventListener("click", function() {

    document.getElementById("message").innerHTML =
        "You clicked the button!";

});

</script>

Mouse Events

JavaScript provides several events for mouse actions.

mouseover

element.addEventListener("mouseover", function() {

    console.log("Mouse is over the element.");

});

mouseout

element.addEventListener("mouseout", function() {

    console.log("Mouse left the element.");

});

dblclick

element.addEventListener("dblclick", function() {

    console.log("Double clicked!");

});

Keyboard Events

Keyboard events happen when the user interacts with the keyboard.

keydown

document.addEventListener("keydown", function(event) {

    console.log("Key pressed: " + event.key);

});

keyup

document.addEventListener("keyup", function(event) {

    console.log("Key released: " + event.key);

});

JavaScript Event Object

When an event occurs, JavaScript can provide information about that event through an event object. 

document.addEventListener("click", function(event) {

    console.log(event);

});

The event object can provide useful information such as the event type and the element that triggered it.

Form Events

JavaScript can respond to form-related events.

submit Event

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    alert("Form submitted!");

});
event.preventDefault() prevents the browser's default form submission behavior.

Input Event

The input event occurs whenever the value of an input element changes. 

const input = document.getElementById("name");

input.addEventListener("input", function() {

    console.log(input.value);

});

Change Event

The change event occurs when the value of an input or select element changes. 

const select = document.getElementById("course");

select.addEventListener("change", function() {

    console.log(select.value);

});

Load Event

The load event occurs when a page or resource has finished loading. 

window.addEventListener("load", function() {

    console.log("Page loaded!");

});

Event Handler

An event handler is a function that runs when a particular event occurs. 

function handleClick() {

    console.log("Button was clicked!");

}

document
    .getElementById("btn")
    .addEventListener("click", handleClick);

Real-Life Example

Events are commonly used in websites for interactive features such as buttons, menus and forms. 

<button id="loginButton">
    Login
</button>

<p id="result"></p>

<script>

document
    .getElementById("loginButton")
    .addEventListener("click", function() {

        document.getElementById("result").innerHTML =
            "Login button clicked!";

    });

</script>

Important Points

  • Events are actions that happen in the browser.
  • JavaScript can respond to these events.
  • click is used for click actions.
  • mouseover is used for mouse movement.
  • keydown is used for keyboard input.
  • submit is used for form submission.
  • addEventListener() is commonly used to attach event handlers.
  • The event object provides information about an event.
  • Events make websites interactive.
