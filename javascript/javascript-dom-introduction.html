JavaScript DOM Introduction

Learn how JavaScript uses the Document Object Model (DOM) to access and change HTML elements and web pages.

What is the DOM?

DOM stands for Document Object Model.

When a web page loads, the browser creates a model of the HTML document. JavaScript can use this model to access, change, add and remove HTML elements.

Simple Definition:

The DOM is a programming interface that allows JavaScript to interact with the HTML document.

HTML and the DOM

Consider this HTML: 

<html>

    <body>

        <h1>Hello World</h1>

        <p>Welcome to Code With Me.</p>

    </body>

</html>

The browser converts this HTML document into a DOM tree. JavaScript can then access the elements in that tree.

DOM Tree

The DOM represents an HTML document as a tree of objects.

📄 Document
└── html
├── head
└── body
├── h1
└── p

Each HTML element becomes an object or node in the DOM.

The document Object

JavaScript provides a special document object that represents the current HTML document.

You can use the document object to access HTML elements. 

console.log(document);

This displays information about the current HTML document in the browser console.

Selecting HTML Elements

JavaScript provides several methods for selecting HTML elements.

Method Purpose
getElementById() Selects an element by its ID.
getElementsByClassName() Selects elements by class name.
getElementsByTagName() Selects elements by tag name.
querySelector() Selects the first matching element.
querySelectorAll() Selects all matching elements.

getElementById()

The getElementById() method selects an HTML element using its ID. 

<h1 id="title">Hello World</h1>

<script>

    const heading =
        document.getElementById("title");

    console.log(heading);

</script>

Changing HTML Content

You can use innerHTML to change the HTML content of an element. 

document.getElementById("demo").innerHTML =
    "Hello JavaScript!";

This changes the content of the element with the ID demo.

Using textContent

The textContent property can be used to change or read text content. 

document.getElementById("demo").textContent =
    "Welcome to JavaScript DOM!";
Tip:

Use textContent when you want to work with text without inserting HTML.

Changing CSS with JavaScript

JavaScript can also change the CSS style of an HTML element. 

document.getElementById("demo").style.color = "blue";

document.getElementById("demo").style.fontSize = "30px";

The style property allows JavaScript to modify inline CSS styles.

Changing HTML Attributes

JavaScript can change HTML attributes using methods such as setAttribute(). 

document.getElementById("myImage")
    .setAttribute("src", "image.jpg");

Creating HTML Elements

JavaScript can create new HTML elements using createElement(). 

const paragraph =
    document.createElement("p");

paragraph.textContent =
    "This paragraph was created using JavaScript.";

document.body.appendChild(paragraph);

Removing HTML Elements

JavaScript can also remove elements from the page. 

const element =
    document.getElementById("demo");

element.remove();

DOM Events

JavaScript can respond to user actions such as:

  • Clicking a button
  • Moving the mouse
  • Typing in an input
  • Submitting a form
  • Loading a page

Example

button.addEventListener("click", function() {

    alert("Button clicked!");

});

Simple DOM Example

Here is a simple example that changes text when a button is clicked. 

<h2 id="title">Hello World</h2>

<button onclick="changeText()">
    Change Text
</button>

<script>

function changeText() {

    document.getElementById("title").innerHTML =
        "Hello JavaScript DOM!";

}

</script>

Why is the DOM Important?

The DOM is important because it allows JavaScript to make web pages interactive and dynamic.

  • Change HTML content.
  • Change CSS styles.
  • Add new elements.
  • Remove elements.
  • Change HTML attributes.
  • Respond to user events.
  • Create interactive web applications.

HTML vs DOM

HTML DOM
Defines the structure of a web page. Represents the page as objects and nodes.
Written by the developer. Created by the browser.
Static document structure. Can be changed using JavaScript.

Key Points

  • DOM stands for Document Object Model.
  • The browser creates the DOM from the HTML document.
  • JavaScript uses the DOM to interact with HTML.
  • The document object represents the current page.
  • getElementById() selects an element by ID.
  • querySelector() selects the first matching element.
  • innerHTML can change HTML content.
  • textContent can change text content.
  • JavaScript can change CSS styles.
  • JavaScript can create and remove HTML elements.
  • DOM events allow JavaScript to respond to user actions.
