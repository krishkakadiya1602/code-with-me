JavaScript Syntax

Learn the basic rules and structure used to write JavaScript code.

What is JavaScript Syntax?

JavaScript syntax is the set of rules that define how JavaScript code should be written.

Just like human languages have grammar rules, programming languages have syntax rules.

Example:

This is a valid JavaScript statement: 

let message = "Hello World!";

JavaScript Values

JavaScript mainly works with two types of values: literals and variables.

Literal Values

A literal is a fixed value written directly in the code. 

10
"Hello"
true
false

Variables

Variables are used to store values. 

let age = 20;
let name = "Krish";

JavaScript Variables

Variables store information that can be used later. 

let name = "Krish";
let age = 20;

console.log(name);
console.log(age);
Tip:

Use meaningful variable names so that your code is easier to understand.

JavaScript Operators

Operators are symbols used to perform operations on values and variables. 

let a = 10;
let b = 5;

let sum = a + b;

console.log(sum);

Here, the + operator adds two values.

Common Operators

Operator Meaning Example
+ Addition 10 + 5
- Subtraction 10 - 5
* Multiplication 10 * 5
/ Division 10 / 5
% Remainder 10 % 3

JavaScript Expressions

An expression is a combination of values, variables and operators that produces a value. 

5 + 5

The expression above produces the value 10. 

let x = 10;
let y = 20;

let result = x + y;

console.log(result);

JavaScript Comments

Comments are used to explain JavaScript code. JavaScript does not execute comments.

Single-Line Comment

// This is a comment

let name = "Krish";

Multi-Line Comment

/*
   This is a
   multi-line comment
*/

let age = 20;

JavaScript Identifiers

Identifiers are names used for variables, functions, objects and other elements in JavaScript. 

let firstName = "Krish";

let studentAge = 20;

Identifier Rules

  • Identifiers can contain letters.
  • Identifiers can contain numbers.
  • Identifiers can contain underscore _.
  • Identifiers can contain dollar sign $.
  • Identifiers cannot start with a number.
  • JavaScript identifiers are case-sensitive.

JavaScript is Case Sensitive

JavaScript considers uppercase and lowercase letters to be different. 

let name = "Krish";

let Name = "Rahul";

console.log(name);
console.log(Name);
Important:

name and Name are two different variables.

JavaScript Statements

JavaScript programs are made up of statements. 

let name = "Krish";
let age = 20;

console.log(name);
console.log(age);

Each statement gives JavaScript an instruction.

JavaScript Semicolons

Semicolons are commonly used at the end of JavaScript statements. 

let x = 10;
let y = 20;

console.log(x + y);
Good Practice:

Using semicolons consistently can make your JavaScript code easier to read.

JavaScript Code Blocks

Code blocks are created using curly brackets { }.

They are commonly used with conditions, loops and functions. 

if (age >= 18) {

    console.log("Adult");

}

JavaScript Strings

Strings are text values. They can be written using single quotes, double quotes, or backticks. 

let name1 = "Krish";

let name2 = 'Krish';

let name3 = `Krish`;

console.log(name1);
console.log(name2);
console.log(name3);

JavaScript Boolean Values

Boolean values can be either true or false. 

let isStudent = true;

let isAdmin = false;

console.log(isStudent);
console.log(isAdmin);

JavaScript Objects

Objects can store multiple related values as properties. 

let student = {
    name: "Krish",
    age: 20,
    course: "JavaScript"
};

console.log(student.name);
console.log(student.age);

JavaScript Syntax Best Practices

  • Use meaningful variable and function names.
  • Keep your code properly indented.
  • Use comments to explain complex code.
  • Use consistent semicolons.
  • Remember that JavaScript is case-sensitive.
  • Keep statements short and readable.
  • Test your code regularly.

Key Points

  • JavaScript syntax defines the rules for writing JavaScript.
  • JavaScript uses variables to store values.
  • Operators are used to perform calculations and comparisons.
  • Expressions produce values.
  • JavaScript is case-sensitive.
  • Comments are ignored when the program runs.
  • Curly brackets are used to create code blocks.
  • Strings are used to represent text.
  • Boolean values are either true or false.
