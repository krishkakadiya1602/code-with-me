JavaScript Variables

Learn how to create, store, change and use values with JavaScript variables.

What are JavaScript Variables?

A variable is a named container used to store a value. JavaScript variables can store information such as names, numbers, text and Boolean values.

For example: 

let name = "Krish";

Here, name is the variable and "Krish" is the value stored in it.

Simple idea:

Variable = Name + Stored Value

Why Do We Use Variables?

Variables allow us to store information and use that information later in our program. 

let name = "Krish";
let age = 20;

console.log(name);
console.log(age);

Without variables, it would be difficult to work with information that changes during program execution.

Creating JavaScript Variables

JavaScript provides three keywords for declaring variables:

  • var
  • let
  • const 
var name = "Krish";

let age = 20;

const country = "India";

The let Keyword

The let keyword is used to declare a variable whose value can be changed later. 

let age = 20;

age = 21;

console.log(age);
Output:

21

The const Keyword

The const keyword is used when a variable should not be reassigned. 

const country = "India";

console.log(country);
Important:

A const variable cannot be reassigned after it has been initialized.

The var Keyword

var is an older way to declare JavaScript variables. 

var name = "Krish";

console.log(name);

Modern JavaScript generally uses let and const instead of var.

var vs let vs const

Keyword Can Reassign? Scope Recommended
var Yes Function Scope Usually avoid in modern code
let Yes Block Scope Yes
const No reassignment Block Scope Yes

Reassigning Variables

A variable declared with let can be assigned a new value. 

let score = 50;

score = 75;

score = 100;

console.log(score);

The final value of score is 100.

Different Types of Values

JavaScript variables can store different types of values. 

let name = "Krish";

let age = 20;

let price = 99.99;

let isStudent = true;

let result = null;

These variables store strings, numbers, Boolean values and null.

Variables with Strings

Strings are used to store text. 

let firstName = "Krish";

let lastName = "Kakadiya";

console.log(firstName);
console.log(lastName);

Variables with Numbers

Numbers can be stored in variables and used in calculations. 

let a = 10;

let b = 20;

let total = a + b;

console.log(total);
Output:

30

Variables with Boolean Values

Boolean variables contain either true or false. 

let isLoggedIn = true;

let isAdmin = false;

console.log(isLoggedIn);
console.log(isAdmin);

Declaring a Variable Without a Value

You can declare a variable without assigning a value. 

let username;

console.log(username);

The variable has the value undefined until a value is assigned. 

let username;

username = "Krish";

console.log(username);

Declaring Multiple Variables

You can declare multiple variables using separate statements. 

let firstName = "Krish";
let age = 20;
let city = "Gujarat";

console.log(firstName);
console.log(age);
console.log(city);

JavaScript Variable Naming Rules

Variable names must follow certain rules.

  • Variable names can contain letters.
  • Variable names can contain numbers.
  • Variable names can contain underscore _.
  • Variable names can contain dollar sign $.
  • A variable name cannot start with a number.
  • Variable names are case-sensitive.
  • JavaScript reserved keywords cannot be used as variable names.

Valid Variable Names

let name = "Krish";

let age1 = 20;

let first_name = "Krish";

let $price = 100;

let studentName = "Krish";

Invalid Variable Names

// Invalid
let 1name = "Krish";

// Invalid
let first-name = "Krish";

Variables are Case-Sensitive

JavaScript treats uppercase and lowercase letters as different. 

let name = "Krish";

let Name = "Rahul";

console.log(name);

console.log(Name);
Remember:

name and Name are different variables.

When Should You Use const?

Use const when you do not want to reassign a variable. 

const websiteName = "Code With Me";

const country = "India";

console.log(websiteName);

console.log(country);

This helps communicate that these variables are not intended to be reassigned.

let and const Example

let score = 50;

const passingScore = 35;

score = 80;

console.log(score);

console.log(passingScore);

Here, score can change, while passingScore is not reassigned.

JavaScript Variable Best Practices

  • Prefer const when a variable will not be reassigned.
  • Use let when a variable needs to change.
  • Avoid using var in new code unless you specifically need its behavior.
  • Use meaningful variable names.
  • Follow camelCase for multi-word variable names.
  • Avoid unnecessary global variables.

Example

const websiteName = "Code With Me";

let visitorCount = 10;

visitorCount = visitorCount + 1;

console.log(websiteName);

console.log(visitorCount);

  • Variable names are case-sensitive.
  • Variable names cannot start with a number.
  • Meaningful variable names make code easier to understand.
