JavaScript Where To

Learn where and how JavaScript can be added to an HTML page.

1. Where Can JavaScript Be Added?

JavaScript can be added to an HTML document in different ways.

The three common methods are:

  • Inline JavaScript
  • Internal JavaScript
  • External JavaScript
Important: All three methods allow JavaScript to run in a webpage, but they are useful in different situations.

2. Inline JavaScript

Inline JavaScript is written directly inside an HTML element using an event attribute.

For example, JavaScript can be written inside the onclick attribute. 

<button onclick="alert('Hello JavaScript!')">

    Click Me

</button>

Example

Inline JavaScript can be useful for small examples, but larger websites are usually easier to maintain when JavaScript is kept separate from HTML.

3. Internal JavaScript

Internal JavaScript is written inside a <script> element in the same HTML file.

The script can be placed in the <head> or <body> section. 

<script>

function showMessage() {

    alert("Hello JavaScript!");

}

</script>

Complete Example

<!DOCTYPE html>

<html>

<body>

<button onclick="showMessage()">

    Click Me

</button>


<script>

function showMessage() {

    alert("Hello JavaScript!");

}

</script>

</body>

</html>

4. JavaScript in the <head>

JavaScript can be placed inside the <head> section of an HTML document. 

<!DOCTYPE html>

<html>

<head>

<script>

function showMessage() {

    alert("Hello from the head!");

}

</script>

</head>

<body>

<button onclick="showMessage()">

    Click Me

</button>

</body>

</html>
When scripts need access to HTML elements, the timing of script execution matters. Using defer or placing scripts appropriately can help avoid timing problems.

5. JavaScript in the <body>

JavaScript can also be placed near the end of the <body>. 

<body>

<h1 id="demo">Hello</h1>


<script>

document.getElementById("demo").innerHTML =
"Hello JavaScript!";

</script>

</body>

This allows the HTML content above the script to already exist when the script runs.

6. External JavaScript

External JavaScript means JavaScript code is stored in a separate .js file.

The external JavaScript file is connected to HTML using the <script src> element.

HTML File

<script src="script.js"></script>

script.js

function showMessage() {

    alert("Hello from external JavaScript!");

}
External JavaScript is especially useful when the same JavaScript code is needed by multiple HTML pages.

7. External JavaScript File Structure

Suppose your website has this structure: 

website/
│
├── index.html
│
├── about.html
│
└── js/
    └── script.js

From index.html, you can connect the JavaScript file like this: 

<script src="js/script.js"></script>

If your HTML page is inside a folder, the path may need to use ../. 

<script src="../js/script.js"></script>

8. Using defer

The defer attribute tells the browser to download the script while parsing the HTML and execute it after the document has been parsed. 

<script
    src="script.js"
    defer>
</script>
Common usage: External scripts that need to work with elements in the HTML document can often use defer.

9. Using async

The async attribute allows an external script to download independently and execute as soon as it is ready. 

<script
    src="script.js"
    async>
</script>
Important: Async scripts may execute before or after other page resources are ready, so they are generally used when the script does not depend on a specific execution order.

10. Inline vs Internal vs External

Method Location Example
Inline Inside HTML element onclick="..."
Internal Inside <script> <script>...</script>
External Separate .js file <script src="script.js">

11. Multiple External JavaScript Files

A website can use more than one JavaScript file. 

<script src="js/main.js" defer></script>

<script src="js/navigation.js" defer></script>

<script src="js/form.js" defer></script>

This can help organize JavaScript code into separate files based on their responsibilities.

12. Best Practice for Websites

For a multi-page website such as Code With Me, keeping reusable JavaScript in external files can make the project easier to organize. 

code-with-me/
│
├── index.html
│
├── css/
│
├── javascript/
│
└── js/
    ├── main.js
    ├── rating.js
    └── navigation.js
Recommended approach: Keep page-specific examples inside the lesson, while reusable JavaScript can be placed in separate .js files.

🎯 Key Points to Remember

  • JavaScript can be written inline.
  • JavaScript can be written inside a <script> element.
  • JavaScript can be stored in an external .js file.
  • External JavaScript can be connected using src.
  • defer is useful when a script should execute after HTML parsing.
  • async allows an external script to execute as soon as it is ready.
  • External JavaScript is useful for reusable code across multiple pages.
