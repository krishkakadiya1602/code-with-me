JavaScript Functions

Learn how to create and use functions in JavaScript with simple examples and an interactive code editor.

What is a Function?

A function is a block of reusable code designed to perform a particular task.

Instead of writing the same code multiple times, you can put the code inside a function and call the function whenever you need it.

Example: A function can be used to calculate a sum, display a message, validate a form, or perform any other task.

Why Use Functions?

Functions are useful because they help you:

  • Reuse code
  • Reduce duplicate code
  • Organize your program
  • Make code easier to understand
  • Make debugging easier
  • Divide a large program into smaller tasks

JavaScript Function Syntax

A normal JavaScript function can be created using the function keyword. 

function functionName() {
    // code to execute
}

Calling the Function

functionName();
The function code runs when you call the function.

Basic Function Example

function greet() {
    console.log("Hello World!");
}

greet();

In this example, greet() is the function name.

When we call greet(), the message "Hello World!" is displayed.

Function Parameters

Parameters allow us to pass information into a function. 

function greet(name) {
    console.log("Hello " + name);
}

greet("Krish");

Here, name is a parameter.

The value "Krish" is passed to the function when it is called.

Multiple Parameters

A function can have more than one parameter. 

function add(a, b) {
    console.log(a + b);
}

add(10, 20);

In this example, the values 10 and 20 are passed to the parameters a and b.

JavaScript Return Statement

The return statement sends a value back from a function. 

function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);

The result of the function is stored in the result variable.

Output: 30

Function Expression

A function can also be stored inside a variable. This is called a function expression. 

const greet = function() {
    console.log("Hello!");
};

greet();

Arrow Functions

Arrow functions provide a shorter syntax for writing functions. 

const greet = () => {
    console.log("Hello World!");
};

greet();

Arrow Function with Parameters

const add = (a, b) => {
    return a + b;
};

console.log(add(10, 20));

Short Arrow Function

const add = (a, b) => a + b;

console.log(add(5, 10));

Default Parameters

You can provide a default value for a function parameter. 

function greet(name = "Guest") {
    console.log("Hello " + name);
}

greet();
greet("Krish");

If no value is provided, the default value "Guest" is used.

Function Scope

Variables created inside a function are generally accessible only inside that function. 

function test() {

    let message = "Hello";

    console.log(message);
}

test();
A variable declared inside a function cannot normally be accessed from outside that function.

Common Types of JavaScript Functions

Function Type Example
Regular Function function greet() { }
Function with Parameters function add(a, b) { }
Function with Return return a + b;
Function Expression const x = function() { }
Arrow Function const x = () => { }

Real-Life Example

Suppose we want to calculate the area of a rectangle. We can create a reusable function. 

function rectangleArea(length, width) {

    return length * width;

}

let area = rectangleArea(10, 5);

console.log("Area = " + area);
Output: Area = 50

Important Points

  • Functions are reusable blocks of code.
  • Functions are created using the function keyword.
  • A function can accept parameters.
  • A function can return a value.
  • Functions can be stored in variables.
  • Arrow functions provide shorter syntax.
  • Functions help organize large programs.
  • A function runs when it is called.
