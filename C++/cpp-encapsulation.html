C++ Encapsulation

Learn how to protect data and control access using encapsulation

What is Encapsulation in C++?

Encapsulation is one of the important concepts of Object-Oriented Programming (OOP).

Encapsulation means combining data and functions into a single unit, usually a class, and controlling access to that data.

Simple Definition: Encapsulation means wrapping data and the functions that operate on that data together inside a class and restricting direct access when needed.

Why is Encapsulation Used?

  • To protect data from unwanted direct access.
  • To control how data is changed.
  • To improve code security and organization.
  • To hide internal implementation details.
  • To make programs easier to maintain.

Simple Encapsulation Example

#include <iostream>
using namespace std;

class Student
{
private:

    int marks;

public:

    void setMarks(int m)
    {
        marks = m;
    }

    int getMarks()
    {
        return marks;
    }
};

int main()
{
    Student s;

    s.setMarks(90);

    cout << s.getMarks();

    return 0;
}

Output

90
Here, marks is private, so it cannot be accessed directly from outside the class. The value is accessed through setMarks() and getMarks().

Encapsulation and Data Hiding

Data hiding means preventing direct access to internal data from outside the class.

In C++, the private access specifier is commonly used for data hiding. 

class Account
{
private:

    double balance;

public:

    void setBalance(double amount)
    {
        balance = amount;
    }

    double getBalance()
    {
        return balance;
    }
};
The outside code cannot directly access balance. It must use the public functions provided by the class.

Private Members

A private member can only be accessed from inside the class or through permitted mechanisms such as member functions. 

#include <iostream>
using namespace std;

class Person
{
private:

    int age;

public:

    void setAge(int a)
    {
        age = a;
    }

    void showAge()
    {
        cout << "Age = " << age;
    }
};

int main()
{
    Person p;

    p.setAge(20);

    p.showAge();

    return 0;
}

Output

Age = 20

Why Direct Access Can Be a Problem

Suppose we have a bank account balance. If the balance is publicly accessible, outside code could assign an invalid value directly. 

class BankAccount
{
public:

    double balance;
};

Code outside the class could then do: 

BankAccount account;

account.balance = -5000;
This allows outside code to change the data without the class checking whether the value is valid.

Controlled Access with Encapsulation

We can make the balance private and validate values through a public function. 

#include <iostream>
using namespace std;

class BankAccount
{
private:

    double balance = 0;

public:

    void deposit(double amount)
    {
        if (amount > 0)
        {
            balance += amount;
        }
    }

    double getBalance()
    {
        return balance;
    }
};

int main()
{
    BankAccount account;

    account.deposit(5000);

    cout << "Balance = "
         << account.getBalance();

    return 0;
}

Output

Balance = 5000
The class controls how the balance is modified instead of allowing direct modification.

Getter Function

A getter is a function used to read the value of a private data member. 

int getAge()
{
    return age;
}

A getter normally starts with the word get, although this is only a naming convention.

Setter Function

A setter is a function used to change the value of a private data member. 

void setAge(int a)
{
    age = a;
}

Setters can also validate data before storing it. 

void setAge(int a)
{
    if (a >= 0)
    {
        age = a;
    }
}

Getter and Setter Example

#include <iostream>
using namespace std;

class Employee
{
private:

    string name;
    int salary;

public:

    void setName(string n)
    {
        name = n;
    }

    string getName()
    {
        return name;
    }

    void setSalary(int s)
    {
        if (s >= 0)
        {
            salary = s;
        }
    }

    int getSalary()
    {
        return salary;
    }
};

int main()
{
    Employee e;

    e.setName("Krish");
    e.setSalary(30000);

    cout << "Name: "
         << e.getName()
         << endl;

    cout << "Salary: "
         << e.getSalary();

    return 0;
}

Output

Name: Krish
Salary: 30000

Access Specifiers

C++ provides three main access specifiers:

  • public
  • private
  • protected
Access Specifier Inside Class Outside Class Derived Class
public Yes Yes Yes
private Yes No No
protected Yes No Yes

Public Members

Public members can be accessed from outside the class. 

class Student
{
public:

    string name;

    void show()
    {
        cout << name;
    }
};

int main()
{
    Student s;

    s.name = "Krish";

    s.show();
}

Private Members

Private members cannot be accessed directly from outside the class. 

class Student
{
private:

    int marks;

public:

    void setMarks(int m)
    {
        marks = m;
    }
};

This would be invalid: 

Student s;

s.marks = 90;
Error: marks is private and cannot be accessed directly from outside the class.

Protected Members

Protected members can be accessed inside the class and by derived classes. 

#include <iostream>
using namespace std;

class Parent
{
protected:

    int number = 100;
};

class Child : public Parent
{
public:

    void show()
    {
        cout << number;
    }
};

int main()
{
    Child c;

    c.show();

    return 0;
}

Output

100

How Encapsulation Works

Private Data
↓
Getter / Setter
↓
Outside Code

The outside code interacts with the class through the public interface instead of directly accessing private data.

Advantages of Encapsulation

  • Data Protection: Private data cannot be directly modified from outside.
  • Controlled Access: Public methods can control how data is read or changed.
  • Validation: Setter functions can reject invalid values.
  • Maintainability: Internal implementation can change without changing the public interface.
  • Organization: Related data and functions stay together inside a class.

Real-Life Example of Encapsulation

A bank account is a useful real-world example.

  • Account balance is private.
  • Deposit is performed through a function.
  • Withdrawal is performed through a function.
  • The class can check whether a transaction is valid. 
#include <iostream>
using namespace std;

class BankAccount
{
private:

    double balance = 0;

public:

    void deposit(double amount)
    {
        if (amount > 0)
        {
            balance += amount;
        }
    }

    void withdraw(double amount)
    {
        if (amount > 0 && amount <= balance)
        {
            balance -= amount;
        }
    }

    double getBalance()
    {
        return balance;
    }
};

int main()
{
    BankAccount account;

    account.deposit(10000);
    account.withdraw(2500);

    cout << "Balance = "
         << account.getBalance();

    return 0;
}

Output

Balance = 7500

Encapsulation vs Data Hiding

Encapsulation Data Hiding
Combines data and functions into a class. Restricts direct access to internal data.
Focuses on organizing and controlling access. Focuses specifically on hiding implementation details or data.

Encapsulation with Inheritance

Encapsulation can also be used when working with inheritance. Private members of a base class are not directly accessible by derived classes. 

#include <iostream>
using namespace std;

class Person
{
private:

    string name;

public:

    void setName(string n)
    {
        name = n;
    }

    string getName()
    {
        return name;
    }
};

class Student : public Person
{
public:

    void showStudent()
    {
        cout << "Student: "
             << getName();
    }
};

int main()
{
    Student s;

    s.setName("Krish");

    s.showStudent();

    return 0;
}

Output

Student: Krish
The derived class uses the public functions of the base class to work with its private data.

Practical Example: Student Marks

#include <iostream>
using namespace std;

class Student
{
private:

    int marks;

public:

    void setMarks(int m)
    {
        if (m >= 0 && m <= 100)
        {
            marks = m;
        }
        else
        {
            cout << "Invalid marks" << endl;
        }
    }

    int getMarks()
    {
        return marks;
    }
};

int main()
{
    Student student;

    student.setMarks(85);

    cout << "Marks = "
         << student.getMarks();

    return 0;
}

Output

Marks = 85
The setter checks that marks are between 0 and 100 before storing the value.

Important Points to Remember

  1. Encapsulation is an OOP concept.
  2. Data and functions can be grouped inside a class.
  3. Private members cannot be accessed directly from outside.
  4. Getters can be used to read private data.
  5. Setters can be used to modify private data.
  6. Setters can validate data before changing it.
  7. Public functions can provide controlled access.
  8. Encapsulation improves organization and maintainability.
