What is an Array in C++?

An array is a collection of multiple values of the same data type stored in a single variable.

Arrays are useful when you need to store many related values, such as marks, numbers, prices, or names.

Important: Array indexing in C++ starts from 0.

Why Use Arrays?

Suppose you want to store the marks of five students.

Without an Array

C++ Example 
int mark1 = 80;
```

int mark2 = 75;
int mark3 = 90;
int mark4 = 85;
int mark5 = 70;
```

With an Array

C++ Example 
int marks[5] = {80, 75, 90, 85, 70};

An array makes the program shorter, cleaner, and easier to manage.

Array Syntax

The basic syntax of an array is:

Syntax 
dataType arrayName[arraySize];

Example

int numbers[5];

Here:

  • int → data type
  • numbers → array name
  • 5 → number of elements

Finding the Number of Elements

You can use the sizeof() operator to calculate the number of elements in an array.

Example 
#include <iostream>
```

using namespace std;

int main() {

```
int numbers[] = {10, 20, 30, 40, 50};

int size = sizeof(numbers) / sizeof(numbers[0]);

cout << "Number of elements = " << size;

return 0;
```

}
```

Output:

Number of elements = 5
Important:
sizeof(numbers) gives the total size of the array in bytes.

sizeof(numbers[0]) gives the size of one element.

Important Array Rules

  • Array indexing starts from 0.
  • All elements normally have the same data type.
  • The array size determines how many elements it can store.
  • Do not access an index outside the valid range.
  • For an array of size 5, valid indexes are 0 to 4.
  • Loops are commonly used to process arrays.

Common Mistakes with Arrays

1. Using an Invalid Index

int numbers[5];
```

numbers[5] = 100;
```

This is incorrect because the valid indexes are 0 to 4.

2. Using the Wrong Loop Condition

for(int i = 0; i <= 5; i++) {
cout << numbers[i];
```

}
```

This can access an invalid index. For an array of 5 elements, use i < 5.

3. Forgetting the Array Size

int numbers[];

An array declared this way needs an initializer or an explicit size.
