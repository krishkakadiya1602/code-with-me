C++ Variables

Learn how to create, store and use variables in C++.

What are Variables in C++?

A variable is a named memory location used to store data in a C++ program.

The value stored inside a variable can usually be changed during the execution of the program.

Example: If you create a variable called age, it can store a person's age.

C++ Variable Syntax

The basic syntax for creating a variable is:

Syntax 
dataType variableName = value;

Example

int age = 20;

In this example:

  • int is the data type.
  • age is the variable name.
  • 20 is the value stored in the variable.

Declaring Variables

You can declare a variable first and assign a value later.

Example 
#include <iostream>
using namespace std;

int main() {

    int age;

    age = 20;

    cout << age;

    return 0;
}

Output

20

Variable Initialization

Initialization means giving a variable its first value when it is created. 

int age = 20;
float price = 99.50;
char grade = 'A';
string name = "Krish";
bool isStudent = true;

Variables with Different Data Types

C++ provides different data types for storing different kinds of values.

Data Type Example Used For
int int age = 20; Whole numbers
float float price = 25.5; Decimal numbers
double double pi = 3.14159; More precise decimal values
char char grade = 'A'; Single character
string string name = "Krish"; Text
bool bool active = true; True or false

Multiple Variables

You can create multiple variables in a C++ program. 

#include <iostream>
using namespace std;

int main() {

    string name = "Krish";
    int age = 20;
    float marks = 85.5;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Marks: " << marks;

    return 0;
}

Output

Name: Krish Age: 20 Marks: 85.5

Changing Variable Values

The value of a variable can be changed after it has been created. 

#include <iostream>
using namespace std;

int main() {

    int age = 20;

    cout << age << endl;

    age = 21;

    cout << age;

    return 0;
}

Output

20 21

Constant Variables

If you do not want the value of a variable to change, you can use the const keyword. 

#include <iostream>
using namespace std;

int main() {

    const double PI = 3.14159;

    cout << PI;

    return 0;
}
Important: A const variable cannot be changed after it has been initialized.

C++ Variable Naming Rules

Follow these rules when creating variable names:

  • Variable names can contain letters, numbers and underscores.
  • A variable name cannot start with a number.
  • Spaces are not allowed in variable names.
  • C++ variable names are case-sensitive.
  • C++ keywords cannot be used as variable names.

Valid Variable Names

int age;
int studentAge;
int student_age;
int marks1;
int totalMarks;

Invalid Variable Names

int 1age;
int student age;
int class;
int total-marks;

C++ Variables are Case-Sensitive

C++ treats uppercase and lowercase letters as different. 

int age = 20;
int Age = 30;

cout << age << endl;
cout << Age;

Output

20 30

Here, age and Age are two different variables.

Practical Example

Let's create a simple C++ program using different variables. 

#include <iostream>
using namespace std;

int main() {

    string name = "Krish";
    int age = 20;
    double salary = 25000.50;
    char grade = 'A';
    bool student = true;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Salary: " << salary << endl;
    cout << "Grade: " << grade << endl;
    cout << "Student: " << student << endl;

    return 0;
}

Output

Name: Krish Age: 20 Salary: 25000.5 Grade: A Student: 1

C++ Variables - Summary

  • C++ variable names are case-sensitive.
  • Variable names must follow C++ naming rules.
