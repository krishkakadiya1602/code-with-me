C++ Polymorphism

Learn Compile-Time and Run-Time Polymorphism in C++

What is Polymorphism in C++?

Polymorphism is one of the important concepts of Object-Oriented Programming (OOP) in C++.

The word polymorphism means "many forms".

In C++, polymorphism allows the same function, operator, or interface to behave differently depending on the situation.

Simple Definition:
Polymorphism means one name can have multiple forms or behaviors.

Real-Life Example of Polymorphism

Consider the word "sound".

A dog can make a bark sound, while a cat can make a meow sound.

The same action "make sound" has different behaviors.

Dog → Bark
Cat → Meow
Cow → Moo

This is similar to polymorphism in programming.

Why Use Polymorphism?

  • It makes programs flexible.
  • It improves code reusability.
  • It supports Object-Oriented Programming.
  • It allows one interface to have different implementations.
  • It makes large programs easier to maintain.
  • It helps implement inheritance-based designs.

Types of Polymorphism in C++

C++ mainly supports two types of polymorphism:

Type Also Called When Decided
Compile-Time Polymorphism Static Polymorphism Compile Time
Run-Time Polymorphism Dynamic Polymorphism Run Time

1. Compile-Time Polymorphism

Compile-time polymorphism is resolved by the compiler during compilation.

Common examples include:

  • Function Overloading
  • Operator Overloading

Function Overloading

Function overloading means having multiple functions with the same name but different parameters.

Example: Function Overloading 
#include <iostream>
```

using namespace std;

class Calculator {

public:

```
int add(int a, int b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}
```

};

int main() {

```
Calculator obj;

cout << obj.add(10, 20) << endl;

cout << obj.add(10, 20, 30) << endl;

return 0;
```

}
```

Here, both functions have the same name add(), but they have different parameters.

Output

Program Output 
30
```

60
```

Operator Overloading

Operator overloading allows operators such as +, -, ==, etc. to work with user-defined objects.

Example 
#include <iostream>
```

using namespace std;

class Number {

public:

```
int value;

Number(int v) {
    value = v;
}

Number operator+(Number obj) {

    return Number(value + obj.value);
}
```

};

int main() {

```
Number n1(10);
Number n2(20);

Number result = n1 + n2;

cout << result.value;

return 0;
```

}
```

2. Run-Time Polymorphism

Run-time polymorphism is resolved while the program is running.

It is commonly achieved using:

  • Inheritance
  • Function Overriding
  • Virtual Functions

Function Overriding

Function overriding occurs when a derived class provides its own implementation of a function that already exists in the base class.

Example: Function Overriding 
#include <iostream>
```

using namespace std;

class Animal {

public:

```
void sound() {

    cout << "Animal makes a sound";

}
```

};

class Dog : public Animal {

public:

```
void sound() {

    cout << "Dog barks";

}
```

};

int main() {

```
Dog obj;

obj.sound();

return 0;
```

}
```

The Dog class provides its own version of the sound() function.

Virtual Function

A virtual function is a member function in a base class that can be overridden by a derived class.

The virtual keyword enables dynamic dispatch when using a base-class pointer or reference.

Example: Virtual Function 
#include <iostream>
```

using namespace std;

class Animal {

public:

```
virtual void sound() {

    cout << "Animal makes a sound" << endl;

}
```

};

class Dog : public Animal {

public:

```
void sound() override {

    cout << "Dog barks" << endl;

}
```

};

int main() {

```
Animal* animal;

Dog dog;

animal = &dog;

animal->sound();

return 0;
```

}
```

Output

Program Output 
Dog barks
Because sound() is virtual, the derived class version is called at run time.

What Happens Without virtual?

If the function is not virtual, calling through a base-class pointer normally uses the base-class version.

Example 
#include <iostream>
```

using namespace std;

class Animal {

public:

```
void sound() {

    cout << "Animal sound";

}
```

};

class Dog : public Animal {

public:

```
void sound() {

    cout << "Dog barks";

}
```

};

int main() {

```
Animal* animal;

Dog dog;

animal = &dog;

animal->sound();

return 0;
```

}
```
Output:

Animal sound

This happens because sound() is not virtual.

With virtual vs Without virtual

Feature Without virtual With virtual
Binding Static Dynamic
Decision Compile time Run time
Base pointer Base version normally called Overridden version can be called
Polymorphism Not dynamic Run-time polymorphism

override Keyword

The override keyword tells the compiler that a derived class function is intended to override a virtual function from the base class.

Example 
class Animal {
```

public:

```
virtual void sound() {
    cout << "Animal sound";
}
```

};

class Dog : public Animal {

public:

```
void sound() override {
    cout << "Dog barks";
}
```

};
```
Using override is recommended because the compiler can detect mistakes in the function signature.

Polymorphism Using Base Class Pointer

A base-class pointer can point to different derived-class objects.

Example 
#include <iostream>
```

using namespace std;

class Animal {

public:

```
virtual void sound() {

    cout << "Animal sound" << endl;

}
```

};

class Dog : public Animal {

public:

```
void sound() override {

    cout << "Dog barks" << endl;

}
```

};

class Cat : public Animal {

public:

```
void sound() override {

    cout << "Cat meows" << endl;

}
```

};

int main() {

```
Animal* animals[2];

Dog dog;
Cat cat;

animals[0] = &dog;
animals[1] = &cat;

animals[0]->sound();
animals[1]->sound();

return 0;
```

}
```

The same sound() call produces different results depending on the object.

Polymorphism and Abstract Classes

Polymorphism is also commonly used with abstract classes.

An abstract class can contain a pure virtual function.

Example 
#include <iostream>
```

using namespace std;

class Shape {

public:

```
virtual void draw() = 0;
```

};

class Circle : public Shape {

public:

```
void draw() override {

    cout << "Drawing Circle";

}
```

};

int main() {

```
Circle c;

c.draw();

return 0;
```

}
```
virtual void draw() = 0;

This is called a pure virtual function.

Compile-Time vs Run-Time Polymorphism

Feature Compile-Time Run-Time
Other Name Static Polymorphism Dynamic Polymorphism
Decision Compile time Run time
Examples Function / Operator Overloading Virtual Functions / Overriding
Inheritance Required? Not necessarily Usually
Main Purpose Multiple forms at compile time Dynamic behavior at run time

Important Points

  • Polymorphism means "many forms".
  • C++ supports compile-time and run-time polymorphism.
  • Function overloading is compile-time polymorphism.
  • Operator overloading is compile-time polymorphism.
  • Function overriding is commonly used for run-time polymorphism.
  • Virtual functions enable dynamic dispatch through base-class pointers or references.
  • The override keyword helps verify that a function actually overrides a base virtual function.
  • Polymorphism is an important feature of OOP.

Common Mistakes

1. Forgetting virtual

If you want dynamic dispatch through a base pointer, remember to make the base function virtual.

2. Wrong Function Signature

The derived function must correctly match the virtual function it is overriding.

3. Forgetting override

Using override is recommended because it helps the compiler detect accidental mismatches.

4. Trying to Create an Abstract Class Object

A class containing a pure virtual function cannot be instantiated directly.

Complete Polymorphism Example

C++ Program 
#include <iostream>
```

using namespace std;

class Animal {

public:

```
virtual void sound() {

    cout << "Animal makes a sound" << endl;

}

virtual ~Animal() = default;
```

};

class Dog : public Animal {

public:

```
void sound() override {

    cout << "Dog barks" << endl;

}
```

};

class Cat : public Animal {

public:

```
void sound() override {

    cout << "Cat meows" << endl;

}
```

};

int main() {

```
Animal* animal1 = new Dog();
Animal* animal2 = new Cat();

animal1->sound();
animal2->sound();

delete animal1;
delete animal2;

return 0;
```

}
```
