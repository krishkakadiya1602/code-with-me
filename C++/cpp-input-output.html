C++ Input and Output

Learn how to display output and take input from users in C++.

What is Input and Output in C++?

Input and output are important parts of almost every C++ program.

Output means displaying information on the screen, while input means taking information from the user.

C++ mainly uses cout for output and cin for input.

The <iostream> Header

To use standard input and output in C++, we normally include the <iostream> header. 

#include <iostream>

The iostream library provides objects such as cout and cin.

Using cout for Output

The cout object is used to display output on the screen.

Example 
#include <iostream>
using namespace std;

int main() {

    cout << "Hello World!";

    return 0;
}

Output

Hello World!

Displaying Multiple Values

You can use multiple insertion operators << to display multiple values. 

#include <iostream>
using namespace std;

int main() {

    int age = 20;
    string name = "Krish";

    cout << "Name: " << name << endl;
    cout << "Age: " << age;

    return 0;
}

Output

Name: Krish Age: 20

Using endl

The endl manipulator is used to move the output to a new line. 

#include <iostream>
using namespace std;

int main() {

    cout << "Hello" << endl;
    cout << "Welcome to C++" << endl;
    cout << "Code With Me";

    return 0;
}

Output

Hello Welcome to C++ Code With Me

Using cin for Input

The cin object is used to take input from the user.

The extraction operator >> is used with cin. 

#include <iostream>
using namespace std;

int main() {

    int age;

    cout << "Enter your age: ";

    cin >> age;

    cout << "Your age is: " << age;

    return 0;
}

Example Output

Enter your age: 20 Your age is: 20

Taking String Input

You can use cin to read a single word from the user. 

#include <iostream>
using namespace std;

int main() {

    string name;

    cout << "Enter your name: ";

    cin >> name;

    cout << "Hello " << name;

    return 0;
}
Note: cin >> normally stops reading a string when it encounters whitespace.

Using getline()

The getline() function can be used to read an entire line, including spaces. 

#include <iostream>
using namespace std;

int main() {

    string fullName;

    cout << "Enter your full name: ";

    getline(cin, fullName);

    cout << "Your name is: " << fullName;

    return 0;
}

Example

Enter your full name: Krish Kakadiya Your name is: Krish Kakadiya

Taking Multiple Inputs

You can take multiple values from the user using multiple variables and cin. 

#include <iostream>
using namespace std;

int main() {

    string name;
    int age;

    cout << "Enter your name: ";
    cin >> name;

    cout << "Enter your age: ";
    cin >> age;

    cout << endl;

    cout << "Name: " << name << endl;
    cout << "Age: " << age;

    return 0;
}

Example Output

Enter your name: Krish Enter your age: 20 Name: Krish Age: 20

Input with Different Data Types

C++ allows you to take input into variables of different data types. 

#include <iostream>
using namespace std;

int main() {

    int age;
    float marks;
    char grade;

    cout << "Enter age: ";
    cin >> age;

    cout << "Enter marks: ";
    cin >> marks;

    cout << "Enter grade: ";
    cin >> grade;

    cout << endl;

    cout << "Age: " << age << endl;
    cout << "Marks: " << marks << endl;
    cout << "Grade: " << grade;

    return 0;
}

Input and Arithmetic Operations

You can take numbers from the user and perform calculations. 

#include <iostream>
using namespace std;

int main() {

    int a, b;

    cout << "Enter first number: ";
    cin >> a;

    cout << "Enter second number: ";
    cin >> b;

    cout << "Addition: " << a + b << endl;
    cout << "Subtraction: " << a - b << endl;
    cout << "Multiplication: " << a * b << endl;

    if (b != 0) {
        cout << "Division: "
             << static_cast<double>(a) / b
             << endl;
    }

    return 0;
}

Example Output

Enter first number: 10 Enter second number: 5 Addition: 15 Subtraction: 5 Multiplication: 50 Division: 2

Important Input and Output Commands

Command Purpose Example
cout Display output cout << "Hello";
cin Take input cin >> age;
endl Move to a new line cout << endl;
getline() Read an entire line getline(cin, name);
<< Insertion operator cout << age;
>> Extraction operator cin >> age;

Practical Example: Student Information

Let's create a program that takes student information from the user and displays it. 

#include <iostream>
using namespace std;

int main() {

    string name;
    int age;
    float marks;

    cout << "Enter student name: ";
    getline(cin, name);

    cout << "Enter age: ";
    cin >> age;

    cout << "Enter marks: ";
    cin >> marks;

    cout << endl;

    cout << "----- Student Information -----" << endl;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Marks: " << marks << endl;

    return 0;
}

Example Output

Enter student name: Krish Kakadiya Enter age: 20 Enter marks: 85.5 ----- Student Information ----- Name: Krish Kakadiya Age: 20 Marks: 85.5

C++ Input and Output - Summary

  • cout is used to display output.
  • cin is used to take input.
  • << is used with cout.
  • >> is used with cin.
  • endl moves output to a new line.
  • getline() can read a complete line containing spaces.
  • Input can be stored in variables of different data types.
