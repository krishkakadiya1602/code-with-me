C++ Exception Handling

Learn how to handle runtime errors in C++ using try, catch, and throw.

What is Exception Handling in C++?

Exception handling is a mechanism used in C++ to handle runtime errors without stopping the entire program suddenly.

For example, dividing a number by zero or receiving an invalid value can cause problems during program execution.

Important: C++ exception handling mainly uses three keywords: try, catch, and throw.

Why Use Exception Handling?

Exception handling helps you:

  • Handle runtime errors.
  • Prevent unexpected program termination.
  • Separate error-handling code from normal code.
  • Make programs more reliable.
  • Display meaningful error messages.

Three Important Keywords

Keyword Purpose
try Contains code that may generate an exception.
throw Used to generate an exception.
catch Handles the exception.

Basic Syntax

try
{
    // Code that may cause an exception

    throw exception;
}
catch (type variable)
{
    // Handle the exception
}

The try block contains risky code. If an exception occurs, the throw statement sends it to the appropriate catch block.

Simple Exception Example

#include <iostream>
using namespace std;

int main()
{
    try
    {
        throw 10;
    }
    catch (int error)
    {
        cout << "Exception caught: " << error;
    }

    return 0;
}
Output:
Exception caught: 10

The throw Keyword

The throw keyword is used to generate an exception. 

throw 10;

You can throw different types of values such as integers, strings, characters, and objects. 

throw 10;

throw 'A';

throw "Something went wrong";

The catch Keyword

The catch block receives and handles the exception thrown by the throw statement. 

try
{
    throw 100;
}
catch (int number)
{
    cout << "Number: " << number;
}
Output:
Number: 100

Exception Handling with Division

We can use exception handling to check whether the user is trying to divide by zero. 

#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 0;

    try
    {
        if (b == 0)
        {
            throw "Cannot divide by zero";
        }

        cout << a / b;
    }
    catch (const char* message)
    {
        cout << message;
    }

    return 0;
}
Output:
Cannot divide by zero

Multiple catch Blocks

C++ allows multiple catch blocks for handling different types of exceptions. 

#include <iostream>
using namespace std;

int main()
{
    try
    {
        throw 10;
    }

    catch (int number)
    {
        cout << "Integer exception: " << number;
    }

    catch (char character)
    {
        cout << "Character exception: " << character;
    }

    return 0;
}

Throwing a String

#include <iostream>
using namespace std;

int main()
{
    try
    {
        throw "Invalid input!";
    }

    catch (const char* message)
    {
        cout << message;
    }

    return 0;
}
Output:
Invalid input!

Generic Catch Block

The catch(...) syntax can be used to catch exceptions of any type. 

try
{
    throw 100;
}

catch (...)
{
    cout << "Some exception occurred.";
}
Note: The ellipsis ... means that the catch block can handle an exception of any type.

Standard Exceptions

C++ provides standard exception classes through the <stdexcept> header. 

#include <iostream>
#include <stdexcept>
using namespace std;

int main()
{
    try
    {
        throw runtime_error("Runtime error occurred!");
    }

    catch (runtime_error& error)
    {
        cout << error.what();
    }

    return 0;
}
Output:
Runtime error occurred!

The what() Function

Standard exception objects provide the what() function to return an error message. 

catch (exception& error)
{
    cout << error.what();
}

The what() function returns a description of the exception.

Exception Handling with User Input

#include <iostream>
using namespace std;

int main()
{
    int age;

    cout << "Enter your age: ";
    cin >> age;

    try
    {
        if (age < 0)
        {
            throw "Age cannot be negative";
        }

        cout << "Your age is: " << age;
    }

    catch (const char* message)
    {
        cout << message;
    }

    return 0;
}
This technique allows the program to validate input and handle invalid values safely.

Practical Example: Bank Withdrawal

#include <iostream>
using namespace std;

int main()
{
    double balance = 5000;
    double amount;

    cout << "Enter withdrawal amount: ";
    cin >> amount;

    try
    {
        if (amount <= 0)
        {
            throw "Invalid withdrawal amount";
        }

        if (amount > balance)
        {
            throw "Insufficient balance";
        }

        balance = balance - amount;

        cout << "Withdrawal successful\n";
        cout << "Remaining balance: " << balance;
    }

    catch (const char* message)
    {
        cout << message;
    }

    return 0;
}
Example Output:
Withdrawal successful
Remaining balance: 3000

How Exception Handling Works

Step What Happens?
1 Program enters the try block.
2 An error or exceptional condition occurs.
3 The throw statement generates the exception.
4 C++ searches for a matching catch block.
5 The catch block handles the exception.
6 Program continues after exception handling.

Important Points

  • Use try for code that may cause an exception.
  • Use throw to generate an exception.
  • Use catch to handle an exception.
  • Multiple catch blocks can be used.
  • catch(...) can catch any exception type.
  • Standard exceptions are available through C++ libraries.
  • The what() function can provide an error message.
  • Exception handling improves program reliability.

Keyword Meaning Example
try Tests code that may produce an exception. try { }
throw Generates an exception. throw 10;
catch Handles an exception. catch(int x) { }
