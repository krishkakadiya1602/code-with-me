C++ Inheritance

Learn how one class can inherit properties and functions from another class

What is Inheritance in C++?

Inheritance is an important feature of Object-Oriented Programming (OOP).

It allows one class to acquire the properties and functions of another class.

Simple Definition: Inheritance allows a new class to reuse the data members and member functions of an existing class.

The existing class is called the base class or parent class.

The new class is called the derived class or child class.

Basic Structure of Inheritance

class Base
{
    // Base class members
};

class Derived : public Base
{
    // Derived class members
};

The colon : is used to specify inheritance.

Base Class
↓
Derived Class

Simple Inheritance Example

#include <iostream>
using namespace std;

class Animal
{
public:

    void eat()
    {
        cout << "Animal is eating" << endl;
    }
};

class Dog : public Animal
{
public:

    void bark()
    {
        cout << "Dog is barking" << endl;
    }
};

int main()
{
    Dog d;

    d.eat();
    d.bark();

    return 0;
}

Output

Animal is eating
Dog is barking
The Dog class inherits the eat() function from the Animal class.

Base Class and Derived Class

Term Meaning
Base Class The class whose members are inherited.
Derived Class The class that inherits from another class.
Parent Class Another name for the base class.
Child Class Another name for the derived class.

1. Single Inheritance

In single inheritance, one derived class inherits from one base class.

Parent
↓
Child 
#include <iostream>
using namespace std;

class Vehicle
{
public:

    void start()
    {
        cout << "Vehicle started" << endl;
    }
};

class Car : public Vehicle
{
public:

    void drive()
    {
        cout << "Car is driving" << endl;
    }
};

int main()
{
    Car c;

    c.start();
    c.drive();

    return 0;
}

Output

Vehicle started
Car is driving

2. Multilevel Inheritance

In multilevel inheritance, a class is derived from another derived class.

Grandparent
↓
Parent
↓
Child 
#include <iostream>
using namespace std;

class Animal
{
public:

    void eat()
    {
        cout << "Animal eats" << endl;
    }
};

class Dog : public Animal
{
public:

    void bark()
    {
        cout << "Dog barks" << endl;
    }
};

class Puppy : public Dog

public:

        cout << "Puppy plays" << endl;

3. Multiple Inheritance

In multiple inheritance, one derived class inherits from more than one base class.

Base A Base B
↓
Derived 
#include <iostream>
using namespace std;

class Father
{
public:

    void fatherProperty()
    {
        cout << "Father property" << endl;
    }
};

class Mother
{
public:

    void motherProperty()
    {
        cout << "Mother property" << endl;
    }
};

class Child : public Father, public Mother
{
public:

    void childAction()
    {
        cout << "Child action" << endl;
    }
};

int main()
{
    Child c;

    c.fatherProperty();
    c.motherProperty();
    c.childAction();

    return 0;
}

Output

Father property
Mother property
Child action

4. Hierarchical Inheritance

In hierarchical inheritance, multiple derived classes inherit from the same base class.

Animal
↓
Dog Cat 
#include <iostream>
using namespace std;

class Animal
{
public:

    void eat()
    {
        cout << "Animal eats" << endl;
    }
};

class Dog : public Animal
{
public:

    void bark()
    {
        cout << "Dog barks" << endl;
    }
};

class Cat : public Animal
{
public:

    void meow()
    {
        cout << "Cat meows" << endl;
    }
};

int main()
{
    Dog d;
    Cat c;

    d.eat();
    d.bark();

    c.eat();
    c.meow();

    return 0;
}

Output

Animal eats
Dog barks
Animal eats
Cat meows

5. Hybrid Inheritance

Hybrid inheritance is a combination of two or more types of inheritance.

Hybrid inheritance can combine structures such as multiple inheritance and multilevel inheritance.

Inheritance Access Modes

C++ supports three inheritance access modes:

  • public
  • protected
  • private
class Child : public Parent
{
};

The access mode affects how inherited members are accessible through the derived class.

Public Inheritance

In public inheritance, public members of the base class remain public in the derived class. 

#include <iostream>
using namespace std;

class Parent
{
public:

    void show()
    {
        cout << "Parent function";
    }
};

class Child : public Parent
{
};

int main()
{
    Child c;

    c.show();

    return 0;
}

Output

Parent function

Protected Members and Inheritance

A protected member cannot normally be accessed directly from outside the class hierarchy, but it can be accessed by derived classes. 

#include <iostream>
using namespace std;

class Parent
{
protected:

    int number = 100;
};

class Child : public Parent
{
public:

    void show()
    {
        cout << number;
    }
};

int main()
{
    Child c;

    c.show();

    return 0;
}

Output

100

Inheritance and Constructors

When a derived object is created, the base class constructor is initialized before the derived class constructor. 

#include <iostream>
using namespace std;

class Parent
{
public:

    Parent()
    {
        cout << "Parent constructor" << endl;
    }
};

class Child : public Parent
{
public:

    Child()
    {
        cout << "Child constructor" << endl;
    }
};

int main()
{
    Child c;

    return 0;
}

Output

Parent constructor
Child constructor

Function Overriding

A derived class can provide its own version of a function that already exists in the base class. 

#include <iostream>
using namespace std;

class Animal
{
public:

    void sound()
    {
        cout << "Animal makes a sound" << endl;
    }
};

class Dog : public Animal
{
public:

    void sound()
    {
        cout << "Dog barks" << endl;
    }
};

int main()
{
    Dog d;

    d.sound();

    return 0;
}

Output

Dog barks

Accessing Base Class Function

If a derived class has a function with the same name as the base class, the scope resolution operator can be used to access the base class version. 

#include <iostream>
using namespace std;

class Animal
{
public:

    void sound()
    {
        cout << "Animal sound" << endl;
    }
};

class Dog : public Animal
{
public:

    void sound()
    {
        cout << "Dog barks" << endl;
    }
};

int main()
{
    Dog d;

    d.sound();

    d.Animal::sound();

    return 0;
}

Output

Dog barks
Animal sound

Advantages of Inheritance

  • Code reusability
  • Reduces duplicate code
  • Makes programs easier to organize
  • Supports object-oriented programming
  • Allows derived classes to extend existing classes
  • Helps create relationships between classes

Types of C++ Inheritance

Type Description
Single One derived class inherits from one base class.
Multiple One derived class inherits from multiple base classes.
Multilevel A derived class becomes a base class for another class.
Hierarchical Multiple derived classes inherit from one base class.
Hybrid Combination of multiple inheritance types.

Practical Example: Employee System

#include <iostream>
using namespace std;

class Employee
{
public:

    string name;
    int salary;

    void showEmployee()
    {
        cout << "Name: " << name << endl;
        cout << "Salary: " << salary << endl;
    }
};

class Developer : public Employee
{
public:

    string language;

    void showDeveloper()
    {
        cout << "Programming Language: "
             << language << endl;
    }
};

int main()
{
    Developer d;

    d.name = "Krish";
    d.salary = 30000;
    d.language = "C++";

    d.showEmployee();
    d.showDeveloper();

    return 0;
}

Output

Name: Krish
Salary: 30000
Programming Language: C++
