What are Data Types in C++?

A data type specifies what kind of value a variable can store. It also tells the compiler how much memory may be required to store that value and how the value should be interpreted.

Example:
If you want to store a person's age, you can use int.
If you want to store a person's name, you can use string.
Example
``` 
#include <iostream>
#include <string>
using namespace std;

int main() {

    int age = 20;
    string name = "Krish";

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;

    return 0;
}
```

Types of Data Types in C++

C++ data types can generally be divided into several categories.

Category Examples
Basic / Fundamental int, float, double, char, bool, void
String string
Derived Arrays, Pointers, References
User-defined struct, class, enum, union

1. int

The int data type is used to store whole numbers.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int age = 20;
    int marks = 85;

    cout << age << endl;
    cout << marks << endl;

    return 0;
}
```
Examples: -10, 0, 25, 100, 500

2. float

The float data type is used to store decimal numbers with single precision.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    float price = 99.50f;
    float temperature = 36.5f;

    cout << price << endl;
    cout << temperature << endl;

    return 0;
}
```

3. double

The double data type is used to store decimal numbers with more precision than float.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    double pi = 3.14159265359;

    cout << pi << endl;

    return 0;
}
```
Tip:
Use double when you need more decimal precision.

4. char

The char data type stores a single character.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    char grade = 'A';
    char symbol = '#';

    cout << grade << endl;
    cout << symbol << endl;

    return 0;
}
```
Important:
Character values use single quotes:
'A'

A string uses double quotes:
"Hello"

5. bool

The bool data type stores one of two values: true or false.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    bool isStudent = true;
    bool isPassed = false;

    cout << isStudent << endl;
    cout << isPassed << endl;

    return 0;
}
```

By default, cout usually displays true as 1 and false as 0.

6. string

The string type is used to store text. It is provided by the C++ standard library.

Example
``` 
#include <iostream>
#include <string>
using namespace std;

int main() {

    string name = "Krish";
    string city = "Gujarat";

    cout << name << endl;
    cout << city << endl;

    return 0;
}
```
Remember to include:

#include <string>

7. void

The void type means that there is no value. It is commonly used with functions that do not return a value.

Example
``` 
#include <iostream>
using namespace std;

void message() {

    cout << "Hello C++!" << endl;
}

int main() {

    message();

    return 0;
}
```

Here, the function message() does not return any value, so its return type is void.

Declaring Multiple Variables

You can declare multiple variables of the same data type.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int x = 10, y = 20, z = 30;

    cout << x << endl;
    cout << y << endl;
    cout << z << endl;

    return 0;
}
```

Finding the Size of a Data Type

C++ provides the sizeof operator to find the amount of memory occupied by a type or variable.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    cout << "int: " << sizeof(int) << " bytes" << endl;
    cout << "float: " << sizeof(float) << " bytes" << endl;
    cout << "double: " << sizeof(double) << " bytes" << endl;
    cout << "char: " << sizeof(char) << " byte" << endl;
    cout << "bool: " << sizeof(bool) << " byte" << endl;

    return 0;
}
```
Note:
The exact size of some C++ data types can depend on the compiler and platform. Use sizeof() when you need to know the size in your current environment.

Signed and Unsigned Types

Integer types can also use modifiers such as signed and unsigned.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    signed int temperature = -10;
    unsigned int students = 50;

    cout << temperature << endl;
    cout << students << endl;

    return 0;
}
```

An unsigned integer is intended for non-negative values.

short and long

C++ also provides integer type modifiers such as short and long.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    short smallNumber = 100;
    long largeNumber = 1000000;

    cout << smallNumber << endl;
    cout << largeNumber << endl;

    return 0;
}
```

Data Type Conversion

Sometimes you need to convert one data type into another. C++ supports different forms of type conversion.

Example: int to double

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int number = 10;

    double result = number;

    cout << result << endl;

    return 0;
}
```

Here, the integer value is automatically converted to a double.

Explicit Type Casting

You can explicitly convert a value using a cast. One common C++ style is static_cast.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    double price = 99.99;

    int number = static_cast<int>(price);

    cout << number << endl;

    return 0;
}
```
The decimal part is removed when converting 99.99 to an integer.

Common Mistakes

1. Using double quotes for char

``` 
// Wrong
char grade = "A";

// Correct
char grade = 'A';
```

2. Forgetting string header

``` 
#include <iostream>
#include <string>

using namespace std;
```

3. Using an unsuitable data type

``` 
// Whole number
int age = 20;

// Decimal number
double price = 99.99;

// Character
char grade = 'A';

// Text
string name = "Krish";
```

Important Points to Remember

  • int is commonly used for whole numbers.
  • float stores decimal values with single precision.
  • double provides more floating-point precision than float.
  • char stores a single character.
  • bool stores true or false.
  • string stores text.
  • void represents no value.
  • sizeof() can be used to check the size of a type or object.
  • Use single quotes for character literals.
  • Use double quotes for string literals.
  • Use static_cast for clear explicit conversions.

Complete C++ Data Types Example

Complete Program
``` 
#include <iostream>
#include <string>

using namespace std;

int main() {

    int age = 20;

    float height = 5.8f;

    double salary = 25000.75;

    char grade = 'A';

    bool isStudent = true;

    string name = "Krish";

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Height: " << height << endl;
    cout << "Salary: " << salary << endl;
    cout << "Grade: " << grade << endl;
    cout << "Student: " << isStudent << endl;

    return 0;
}
```
