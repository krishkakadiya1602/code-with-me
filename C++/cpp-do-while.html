What is a do-while Loop?

A do-while loop is used to repeatedly execute a block of code while a condition is true.

The main difference between a do-while loop and a while loop is that the do-while loop executes its code block at least once.

Important:

In a do-while loop, the code executes first and the condition is checked afterward.

Syntax of do-while Loop

Syntax
``` 
do {

    // code to execute

} while (condition);
```
Important:
Notice the semicolon ; after while (condition).

Simple do-while Example

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int i = 1;

    do {

        cout << i << endl;

        i++;

    } while (i <= 5);

    return 0;
}
```
Output: ``` 
1
2
3
4
5
```

How do-while Works

  1. The program starts with the do block.
  2. The statements inside the block are executed.
  3. The condition after while is checked.
  4. If the condition is true, the loop runs again.
  5. If the condition is false, the loop stops.
Flow:

Start → Execute Code → Check Condition → True → Repeat

False → Stop

do-while Executes at Least Once

One of the most important features of a do-while loop is that its code executes at least once, even if the condition is false from the beginning.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int i = 10;

    do {

        cout << "Hello C++";

    } while (i < 5);

    return 0;
}
```
Output:
Hello C++

The condition i < 5 is false, but the message is still printed once because the condition is checked after the loop body.

do-while with User Input

A do-while loop is useful when you want the user to perform an action at least once.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int number;

    do {

        cout << "Enter a positive number: ";
        cin >> number;

    } while (number <= 0);

    cout << "You entered: " << number;

    return 0;
}
```
The user is repeatedly asked to enter a number until a positive number is entered.

Factorial Using do-while

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int number;
    int i = 1;
    long long factorial = 1;

    cout << "Enter a positive number: ";
    cin >> number;

    if (number < 0) {

        cout << "Factorial is not defined for negative numbers.";

    }
    else {

        do {

            factorial *= i;

            i++;

        } while (i <= number);

        cout << "Factorial = " << factorial;

    }

    return 0;
}
```

Menu Program Using do-while

One of the most common uses of do-while loops is creating menu-driven programs.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int choice;

    do {

        cout << "\n--- Menu ---" << endl;
        cout << "1. Say Hello" << endl;
        cout << "2. Say Welcome" << endl;
        cout << "3. Exit" << endl;

        cout << "Enter your choice: ";
        cin >> choice;

        if (choice == 1) {

            cout << "Hello!" << endl;

        }
        else if (choice == 2) {

            cout << "Welcome!" << endl;

        }
        else if (choice == 3) {

            cout << "Program ended." << endl;

        }
        else {

            cout << "Invalid choice." << endl;

        }

    } while (choice != 3);

    return 0;
}
```

Using break with do-while

The break statement immediately stops the loop.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int i = 1;

    do {

        if (i == 5) {

            break;

        }

        cout << i << " ";

        i++;

    } while (i <= 10);

    return 0;
}
```
Output:
1 2 3 4

Using continue with do-while

The continue statement skips the current iteration and moves to the next iteration.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int i = 0;

    do {

        i++;

        if (i == 5) {

            continue;

        }

        cout << i << " ";

    } while (i < 10);

    return 0;
}
```
Output:
1 2 3 4 6 7 8 9 10
When using continue in a do-while loop, make sure the loop variable is updated before the continue statement when necessary. Otherwise, you can accidentally create an infinite loop.

while vs do-while

while Loop do-while Loop
Condition is checked before the loop body. Condition is checked after the loop body.
May execute zero times. Executes at least once.
Syntax starts with while. Syntax starts with do.
No semicolon after the condition in normal syntax. Semicolon is required after while(condition);.

Difference Example

while Loop

``` 
#include <iostream>
using namespace std;

int main() {

    int i = 10;

    while (i < 5) {

        cout << "Hello";

    }

    return 0;
}
```

Here the condition is false before the loop starts, so Hello is not printed.

do-while Loop

``` 
#include <iostream>
using namespace std;

int main() {

    int i = 10;

    do {

        cout << "Hello";

    } while (i < 5);

    return 0;
}
```

Here Hello is printed once because the do-while loop executes the body before checking the condition.

Infinite do-while Loop

A do-while loop can become infinite if its condition always remains true.

Example
``` 
do {

    cout << "Hello";

} while (true);
```
Warning: This loop will continue running until the program is stopped.

Common Mistakes

1. Forgetting the semicolon

``` 
// Wrong
do {

    cout << "Hello";

} while (i < 5)

// Correct
do {

    cout << "Hello";

} while (i < 5);
```

2. Forgetting to update the variable

``` 
// Can create an infinite loop
int i = 1;

do {

    cout << i;

} while (i <= 5);
```

3. Wrong condition

``` 
int i = 1;

do {

    cout << i;

    i++;

} while (i <= 5);
```

4. Infinite loop with continue

``` 
// Be careful with updates
int i = 1;

do {

    if (i == 3) {

        continue;

    }

    i++;

} while (i <= 5);
```

In this example, when i == 3, the continue statement skips the update, which can cause an infinite loop.

Important Points to Remember

  • A do-while loop executes its body at least once.
  • The condition is checked after the loop body.
  • A semicolon ; is required after the while condition.
  • It is useful for menu-driven programs.
  • It is useful when an operation must happen at least once.
  • break can be used to stop the loop.
  • continue can be used to skip an iteration.
  • Always make sure the loop condition can eventually become false when you do not intend an infinite loop.

Complete do-while Example

Number Input Program
``` 
#include <iostream>
using namespace std;

int main() {

    int number;

    do {

        cout << "Enter a number between 1 and 10: ";
        cin >> number;

        if (number < 1 || number > 10) {

            cout << "Invalid number. Try again."
                 << endl;

        }

    } while (number < 1 || number > 10);

    cout << "Valid number entered: "
         << number;

    return 0;
}
```
This program continues asking the user for input until a valid number between 1 and 10 is entered.
