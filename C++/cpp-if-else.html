What is if-else in C++?

The if-else statement is used to make decisions in a C++ program.

It checks a condition. If the condition is true, the if block executes. Otherwise, the else block executes.

Simple idea:

If condition is TRUE → execute if
If condition is FALSE → execute else

Syntax of if-else

Syntax
``` 
if (condition) {

    // code if condition is true

}
else {

    // code if condition is false

}
```

Example

``` 
int age = 20;

if (age >= 18) {

    cout << "You are an adult.";

}
else {

    cout << "You are not an adult.";

}
```

How if-else Works

  1. The program evaluates the condition.
  2. If the condition is true, the if block executes.
  3. If the condition is false, the else block executes.
  4. After that, the program continues with the next statement.
Example:

age = 20
age >= 18 → TRUE
Therefore: You are an adult.

Simple if-else Example

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int number = 10;

    if (number > 0) {

        cout << "Positive number";

    }
    else {

        cout << "Zero or negative number";

    }

    return 0;
}
```
Output:
Positive number

Check Even or Odd

We can use the modulus operator % with if-else to check whether a number is even or odd.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int number = 15;

    if (number % 2 == 0) {

        cout << "Even number";

    }
    else {

        cout << "Odd number";

    }

    return 0;
}
```
Output:
Odd number

Find the Greater Number

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int a, b;

    cout << "Enter first number: ";
    cin >> a;

    cout << "Enter second number: ";
    cin >> b;

    if (a > b) {

        cout << a << " is greater.";

    }
    else {

        cout << b << " is greater.";

    }

    return 0;
}
```
Note: If both numbers are equal, this program will print the second number as greater. For handling equality separately, use an if - else if - else structure.

Using Logical Operators

You can combine multiple conditions using logical operators.

AND Operator &&

``` 
#include <iostream>
using namespace std;

int main() {

    int age = 25;
    bool hasLicense = true;

    if (age >= 18 && hasLicense) {

        cout << "You can drive.";

    }
    else {

        cout << "You cannot drive.";

    }

    return 0;
}
```

OR Operator ||

``` 
#include <iostream>
using namespace std;

int main() {

    int age = 17;

    if (age < 18 || age > 60) {

        cout << "Special category.";

    }
    else {

        cout << "Normal category.";

    }

    return 0;
}
```

Nested if-else

An if-else statement can be placed inside another if or else block. This is called nested if-else.

Example
``` 
#include <iostream>
using namespace std;

int main() {

    int age = 20;
    bool citizen = true;

    if (age >= 18) {

        if (citizen) {

            cout << "Eligible.";

        }
        else {

            cout << "Not eligible because of citizenship.";

        }

    }
    else {

        cout << "Not eligible because of age.";

    }

    return 0;
}
```

Common Mistakes

1. Using = instead of ==

``` 
// Wrong
if (age = 18) {
    cout << "Adult";
}

// Correct
if (age == 18) {
    cout << "Adult";
}
```

2. Forgetting braces

``` 
if (age >= 18) {

    cout << "Adult";

}
else {

    cout << "Minor";

}
```

3. Incorrect condition

``` 
// Example
if (marks >= 40) {

    cout << "Pass";

}
else {

    cout << "Fail";

}
```

if vs if-else

if if-else
Executes code when condition is true. Executes one block when true and another when false.
No alternative block. Has an alternative else block.
Useful for one-sided decisions. Useful when there are two possible paths.

Important Points to Remember

  • if checks a condition.
  • else executes when the if condition is false.
  • Conditions normally produce a true or false result.
  • Use == for comparison.
  • Use = for assignment.
  • Multiple conditions can be combined using &&, ||, and !.
  • An if-else statement can be nested inside another condition.
  • Curly braces { } are recommended for readable and safer code.

Complete if-else Example

Student Result Program
``` 
#include <iostream>
using namespace std;

int main() {

    int marks;

    cout << "Enter your marks: ";
    cin >> marks;

    if (marks >= 90) {

        cout << "Grade A+";

    }
    else if (marks >= 75) {

        cout << "Grade A";

    }
    else if (marks >= 60) {

        cout << "Grade B";

    }
    else if (marks >= 40) {

        cout << "Grade C";

    }
    else {

        cout << "Fail";

    }

    return 0;
}
```
This example also introduces the else if structure, which is useful when there are more than two possible conditions.
