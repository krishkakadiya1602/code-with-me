C++ Switch Statement

Learn how to use switch, case, break and default in C++.

What is a Switch Statement?

The switch statement is a control statement used to execute one block of code from multiple possible choices.

It is useful when you want to compare one expression with several fixed values.

Example: A menu program can use switch to perform different operations based on the option selected by the user.

C++ Switch Syntax

The basic syntax of a switch statement is:

Syntax 
switch (expression) {

    case value1:
        // code
        break;

    case value2:
        // code
        break;

    default:
        // code

}

The expression is compared with each case value. When a matching case is found, its code executes.

Simple Switch Example

Here is a simple example using a number from 1 to 3. 

#include <iostream>
using namespace std;

int main() {

    int number = 2;

    switch (number) {

        case 1:
            cout << "One";
            break;

        case 2:
            cout << "Two";
            break;

        case 3:
            cout << "Three";
            break;

        default:
            cout << "Invalid number";
    }

    return 0;
}

Output

Two

Using case

The case keyword defines a possible value that the switch expression can match. 

int choice = 1;

switch (choice) {

    case 1:
        cout << "You selected Option 1";
        break;

    case 2:
        cout << "You selected Option 2";
        break;

}

If choice is 1, the first case runs. If it is 2, the second case runs.

Using break

The break statement stops the switch after a matching case has been executed. 

#include <iostream>
using namespace std;

int main() {

    int number = 2;

    switch (number) {

        case 1:
            cout << "One";
            break;

        case 2:
            cout << "Two";
            break;

        case 3:
            cout << "Three";
            break;
    }

    return 0;
}
Important: If you leave out break, execution can continue into the following cases.

Using default

The default block runs when none of the cases match the switch expression. 

#include <iostream>
using namespace std;

int main() {

    int number = 5;

    switch (number) {

        case 1:
            cout << "One";
            break;

        case 2:
            cout << "Two";
            break;

        case 3:
            cout << "Three";
            break;

        default:
            cout << "Invalid number";
    }

    return 0;
}

Output

Invalid number

Example: Days of the Week

A switch statement can be used to display the day according to a number. 

#include <iostream>
using namespace std;

int main() {

    int day = 3;

    switch (day) {

        case 1:
            cout << "Monday";
            break;

        case 2:
            cout << "Tuesday";
            break;

        case 3:
            cout << "Wednesday";
            break;

        case 4:
            cout << "Thursday";
            break;

        case 5:
            cout << "Friday";
            break;

        case 6:
            cout << "Saturday";
            break;

        case 7:
            cout << "Sunday";
            break;

        default:
            cout << "Invalid day";
    }

    return 0;
}

Output

Wednesday

Switch with Characters

A switch statement can also be used with a character. 

#include <iostream>
using namespace std;

int main() {

    char grade = 'A';

    switch (grade) {

        case 'A':
            cout << "Excellent";
            break;

        case 'B':
            cout << "Very Good";
            break;

        case 'C':
            cout << "Good";
            break;

        case 'D':
            cout << "Pass";
            break;

        default:
            cout << "Invalid grade";
    }

    return 0;
}

Output

Excellent

Multiple Cases with the Same Code

Multiple cases can be used together when they should execute the same code. 

#include <iostream>
using namespace std;

int main() {

    int day = 6;

    switch (day) {

        case 6:
        case 7:
            cout << "Weekend";
            break;

        default:
            cout << "Weekday";
    }

    return 0;
}

Output

Weekend

Example: Simple Calculator

Switch statements are useful for creating menu-based programs such as calculators. 

#include <iostream>
using namespace std;

int main() {

    double num1, num2;
    char operation;

    cout << "Enter first number: ";
    cin >> num1;

    cout << "Enter operator (+, -, *, /): ";
    cin >> operation;

    cout << "Enter second number: ";
    cin >> num2;

    switch (operation) {

        case '+':
            cout << "Result: " << num1 + num2;
            break;

        case '-':
            cout << "Result: " << num1 - num2;
            break;

        case '*':
            cout << "Result: " << num1 * num2;
            break;

        case '/':
            if (num2 != 0) {
                cout << "Result: "
                     << num1 / num2;
            } else {
                cout << "Cannot divide by zero";
            }
            break;

        default:
            cout << "Invalid operator";
    }

    return 0;
}

Example Output

Enter first number: 10 Enter operator (+, -, *, /): + Enter second number: 5 Result: 15

Example: Menu Program

A switch statement is commonly used for menu-driven applications. 

#include <iostream>
using namespace std;

int main() {

    int choice;

    cout << "----- MENU -----" << endl;
    cout << "1. Start" << endl;
    cout << "2. Settings" << endl;
    cout << "3. Exit" << endl;

    cout << "Enter your choice: ";
    cin >> choice;

    switch (choice) {

        case 1:
            cout << "Starting program...";
            break;

        case 2:
            cout << "Opening settings...";
            break;

        case 3:
            cout << "Exiting program...";
            break;

        default:
            cout << "Invalid choice";
    }

    return 0;
}

Example Output

----- MENU ----- 1. Start 2. Settings 3. Exit Enter your choice: 1 Starting program...

Important Switch Keywords

Keyword Purpose
switch Starts the switch statement.
case Defines a possible matching value.
break Stops execution of the switch.
default Runs when no case matches.

Switch vs If-Else

Switch If-Else
Useful for multiple fixed choices. Useful for conditions and ranges.
Uses case values. Uses conditions.
Uses break to stop cases. Does not require break.
Good for menus and fixed options. Good for comparisons and complex conditions.

C++ Switch Statement - Summary

  • The switch statement is used for multiple fixed choices.
  • Each possible value is written using case.
  • break stops execution of the switch after a matching case.
  • default executes when no case matches.
  • Multiple cases can share the same code.
  • Switch statements are commonly used for menus, calculators and fixed options.
