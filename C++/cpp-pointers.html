C++ Pointers

Learn pointers, memory addresses, dereferencing and pointer operations

What is a Pointer in C++?

A pointer is a variable that stores the memory address of another variable.

Unlike a normal variable that stores a value, a pointer stores the location where that value is stored in memory.

Simple Definition: A pointer is a variable that stores the address of another variable.

Example

int number = 10;

int *ptr = &number;

Here:

  • number stores the value 10.
  • &number gives the memory address of number.
  • ptr stores the address of number.

Understanding Memory Address

Every variable is stored at a location in computer memory. That location has an address.

Variable: number
Value: 10
Address: 0x7ffe1234
↑
Pointer: ptr
Stores: 0x7ffe1234
Note: The actual memory address will normally be different every time the program runs.

Pointer Declaration

A pointer is declared using the * symbol. 

int *ptr;

This declares a pointer named ptr that can store the address of an integer variable.

Other Pointer Types

int *intPtr;

float *floatPtr;

double *doublePtr;

char *charPtr;

Address-of Operator (&)

The & operator is called the address-of operator.

It returns the memory address of a variable. 

#include <iostream>
using namespace std;

int main()
{
    int number = 10;

    cout << &number;

    return 0;
}

The output will be a memory address similar to: 

0x7ffe1234
The exact address is not fixed. It depends on where the operating system places the variable in memory.

Dereferencing a Pointer

The * operator can also be used to access the value stored at the address held by a pointer. 

#include <iostream>
using namespace std;

int main()
{
    int number = 10;

    int *ptr = &number;

    cout << *ptr;

    return 0;
}

Output

10
Remember:
  • &number → address of number
  • ptr → stores the address
  • *ptr → value at that address

Pointer Example

#include <iostream>
using namespace std;

int main()
{
    int number = 50;

    int *ptr = &number;

    cout << "Value = " << number << endl;
    cout << "Address = " << &number << endl;
    cout << "Pointer stores = " << ptr << endl;
    cout << "Value using pointer = " << *ptr << endl;

    return 0;
}

Possible Output

Value = 50
Address = 0x7ffe1234
Pointer stores = 0x7ffe1234
Value using pointer = 50

Changing a Variable Using a Pointer

A pointer can be used to modify the value of the original variable. 

#include <iostream>
using namespace std;

int main()
{
    int number = 10;

    int *ptr = &number;

    *ptr = 100;

    cout << number;

    return 0;
}

Output

100

When we write *ptr = 100;, we change the value stored in the original variable.

Pointer and Variable Relationship

Expression Meaning
number Value stored in number
&number Address of number
ptr Address stored inside pointer
*ptr Value located at the pointer's address

Initializing a Pointer

It is good practice to initialize a pointer before using it. 

int number = 20;

int *ptr = &number;

You can also initialize a pointer with nullptr. 

int *ptr = nullptr;
nullptr means that the pointer is currently not pointing to a valid object.

Null Pointer

A null pointer does not point to an object. 

#include <iostream>
using namespace std;

int main()
{
    int *ptr = nullptr;

    if (ptr == nullptr)
    {
        cout << "Pointer is null";
    }

    return 0;
}

Output

Pointer is null
Never dereference a null pointer. 
*ptr = 10;
The above code is invalid when ptr is null and can cause a program failure.

Pointer Arithmetic

Pointers can be increased or decreased. This is especially useful when working with arrays. 

#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30};

    int *ptr = numbers;

    cout << *ptr << endl;

    ptr++;

    cout << *ptr << endl;

    return 0;
}

Output

10
20

When the pointer is incremented, it moves to the next element of the appropriate type.

Pointers and Arrays

The name of an array can be used as a pointer to its first element in many expressions. 

#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int *ptr = numbers;

    cout << *ptr << endl;
    cout << *(ptr + 1) << endl;
    cout << *(ptr + 2) << endl;

    return 0;
}

Output

10
20
30

Pointers and Functions

Pointers can be passed to functions so that the function can modify the original data. 

#include <iostream>
using namespace std;

void changeValue(int *ptr)
{
    *ptr = 100;
}

int main()
{
    int number = 10;

    changeValue(&number);

    cout << number;

    return 0;
}

Output

100

Swapping Two Numbers Using Pointers

#include <iostream>
using namespace std;

void swapNumbers(int *a, int *b)
{
    int temp = *a;

    *a = *b;

    *b = temp;
}

int main()
{
    int x = 10;
    int y = 20;

    swapNumbers(&x, &y);

    cout << "x = " << x << endl;
    cout << "y = " << y << endl;

    return 0;
}

Output

x = 20
y = 10

Pointer to Pointer

A pointer can also store the address of another pointer. This is called a pointer to pointer. 

#include <iostream>
using namespace std;

int main()
{
    int number = 10;

    int *ptr = &number;

    int **ptr2 = &ptr;

    cout << **ptr2;

    return 0;
}

Output

10

Here:

  • number stores 10.
  • ptr stores the address of number.
  • ptr2 stores the address of ptr.
  • **ptr2 accesses the value 10.

Pointer to Constant

A pointer can point to a constant value that should not be modified through that pointer. 

int number = 10;

const int *ptr = &number;

You cannot change the value through ptr. 

// Not allowed through ptr

*ptr = 20;

Common Pointer Mistakes

1. Using an uninitialized pointer

int *ptr;

*ptr = 10;

This pointer does not point to a valid known location.

2. Dereferencing nullptr

int *ptr = nullptr;

*ptr = 10;

This can cause undefined behavior.

3. Using a pointer after its target is gone

A pointer should not be used after the object it points to has been destroyed or gone out of scope.

Important: Pointers are powerful but must be used carefully because incorrect pointer operations can cause crashes or undefined behavior.

Pointer vs Normal Variable

Normal Variable Pointer Variable
Stores a value Stores a memory address
Example: int x = 10; Example: int *ptr = &x;
Access value directly Use * to dereference
Does not normally represent another variable's address Can point to another variable

Important Pointer Operators

Operator Name Purpose
& Address-of operator Gets the address of a variable
* Dereference operator Accesses the value at an address
++ Increment Moves pointer to the next element
-- Decrement Moves pointer to the previous element

Practical Example: Find Array Values Using Pointer

#include <iostream>
using namespace std;

int main()
{
    int numbers[] = {10, 20, 30, 40, 50};

    int *ptr = numbers;

    for (int i = 0; i < 5; i++)
    {
        cout << *(ptr + i) << " ";
    }

    return 0;
}

Output

10 20 30 40 50

C++ Pointers Summary

  • A pointer stores the memory address of another variable.
  • The & operator gets an address.
  • The * operator dereferences a pointer.
  • Pointers can modify the value of another variable.
  • Pointers are commonly used with arrays and functions.
  • nullptr represents a null pointer.
  • Pointer arithmetic is useful when working with arrays.
  • A pointer can also point to another pointer.
  • Uninitialized and invalid pointers should be avoided.
