What is a String in C++?

A string is a sequence of characters used to store text. For example, a person's name, city, sentence or message can be stored in a string.

Example:

"Hello"
"Code With Me"
"C++ Programming"

In modern C++, the string class from the <string> header is commonly used to work with text.

```
```

Common Mistakes with Strings

1. Using Single Quotes for a String

string name = 'Krish';

This is incorrect. Strings use double quotes. 

string name = "Krish";

2. Using cin for a Full Sentence

string name;
```

cin >> name;
```

This reads only one word. Use getline() when you need spaces.

3. Invalid Index

string text = "Hello";
```

cout << text[10];
```

The index should be within the valid range of the string.

Complete C++ String Example

Complete Program

```

int main() {

```

string lastName;

cout << "Enter your first name: ";
cin >> firstName;

cout << "Enter your last name: ";

string fullName = firstName + " " + lastName;

cout << "Full Name: " << fullName << endl;

cout << "Length: "
     << fullName.length()
     << endl;

cout << "First Character: "
     << fullName[0]
     << endl;

```

}
