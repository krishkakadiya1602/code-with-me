C++ Projects

Practice C++ with Real-World Beginner and Intermediate Projects

Why Build C++ Projects?

Learning C++ syntax is only the beginning. Building projects helps you understand how different programming concepts work together in a complete application.

These projects can help you practice variables, conditions, loops, functions, arrays, strings, classes, file handling and Object-Oriented Programming.

Tip:
Start with small projects and gradually increase the complexity of your programs.

Project 1: Simple Calculator

Beginner

Calculator using switch

Create a calculator that performs addition, subtraction, multiplication and division.

Concepts Used: Variables, operators, switch statement and conditions.

C++ Code 
#include <iostream>
```

using namespace std;

int main() {

```
double num1, num2;
char operation;

cout << "Enter first number: ";
cin >> num1;

cout << "Enter operator (+, -, *, /): ";
cin >> operation;

cout << "Enter second number: ";
cin >> num2;

switch (operation) {

    case '+':
        cout << "Result = " << num1 + num2;
        break;

    case '-':
        cout << "Result = " << num1 - num2;
        break;

    case '*':
        cout << "Result = " << num1 * num2;
        break;

    case '/':
        if (num2 != 0)
            cout << "Result = " << num1 / num2;
        else
            cout << "Cannot divide by zero.";
        break;

    default:
        cout << "Invalid operator.";
}

return 0;
```

}

The computer generates a random number and the user tries to guess it.

Concepts Used: Loops, conditions, random numbers and user input.

C++ Code 
#include <iostream>
```

#include 
#include 

using namespace std;

int main() {

```
srand(time(0));

int secretNumber = rand() % 100 + 1;
int guess;
int attempts = 0;

cout << "Guess a number between 1 and 100." << endl;

do {

    cout << "Enter your guess: ";
    cin >> guess;

    attempts++;

    if (guess > secretNumber) {

        cout << "Too high!" << endl;

    }
    else if (guess < secretNumber) {

        cout << "Too low!" << endl;

    }
    else {

        cout << "Correct!" << endl;
        cout << "Attempts: " << attempts << endl;

    }

} while (guess != secretNumber);

Project 3: Student Grade Calculator

Beginner

Calculate Average and Grade

Create a program that accepts marks for multiple subjects and calculates the average and grade.

Concepts Used: Arrays, loops, conditions and arithmetic operators.

C++ Code 
#include <iostream>
```

using namespace std;

int main() {

```
int marks[5];
int total = 0;

for (int i = 0; i < 5; i++) {

    cout << "Enter marks for subject "
         << i + 1 << ": ";

    cin >> marks[i];

    total += marks[i];
}

double average = total / 5.0;

cout << endl;
cout << "Total Marks = " << total << endl;
cout << "Average = " << average << endl;

if (average >= 90)
    cout << "Grade: A+";
else if (average >= 80)
    cout << "Grade: A";
else if (average >= 70)
    cout << "Grade: B";
else if (average >= 60)
    cout << "Grade: C";
else if (average >= 50)
    cout << "Grade: D";
else
    cout << "Grade: F";

return 0;
```

}

Project 5: ATM System

Intermediate

Simple ATM Simulation

Create an ATM system that allows the user to check balance, deposit money and withdraw money.

Concepts Used: Functions, switch, loops, conditions and variables.

C++ Code 
#include <iostream>
```

using namespace std;

int main() {

```
double balance = 5000;
double amount;

int choice;

do {

    cout << endl;
    cout << "===== ATM MENU =====" << endl;

    cout << "1. Check Balance" << endl;
    cout << "2. Deposit Money" << endl;
    cout << "3. Withdraw Money" << endl;
    cout << "4. Exit" << endl;

    cout << "Enter choice: ";
    cin >> choice;

    switch (choice) {

        case 1:

            cout << "Balance = ₹"
                 << balance;

            break;


        case 2:

            cout << "Enter deposit amount: ";
            cin >> amount;

            if (amount > 0) {

                balance += amount;

                cout << "Deposit successful.";

            }
            else {

                cout << "Invalid amount.";

            }

            break;


        case 3:

            cout << "Enter withdrawal amount: ";
            cin >> amount;

            if (amount > 0 && amount <= balance) {

                balance -= amount;

                cout << "Withdrawal successful.";

            }
            else {

                cout << "Invalid amount or insufficient balance.";

            }

            break;


        case 4:

            cout << "Thank you.";

            break;


        default:

            cout << "Invalid choice.";
    }

} while (choice != 4);

return 0;
```

}

Project 8: To-Do List

Intermediate

Simple To-Do Application

Build a program that allows users to add and display tasks.

Concepts Used: Vectors, strings, loops and switch statements.

C++ Code 
#include <iostream>
```

#include 
#include 

using namespace std;

int main() {

```
vector<string> tasks;

int choice;
string task;

do {

    cout << endl;
    cout << "===== TO-DO LIST =====" << endl;

    cout << "1. Add Task" << endl;
    cout << "2. Show Tasks" << endl;
    cout << "3. Exit" << endl;

    cout << "Enter choice: ";
    cin >> choice;

    cin.ignore();

    switch (choice) {

        case 1:

            cout << "Enter task: ";

            getline(cin, task);

            tasks.push_back(task);

            cout << "Task added.";

            break;


        case 2:

            if (tasks.empty()) {

                cout << "No tasks available.";

            }
            else {

                cout << endl;
                cout << "Your Tasks:" << endl;

                for (int i = 0;
                     i < tasks.size();
                     i++) {

                    cout << i + 1
                         << ". "
                         << tasks[i]
                         << endl;

                }
            }

            break;


        case 3:

            cout << "Goodbye.";

            break;


        default:

            cout << "Invalid choice.";

    }

} while (choice != 3);

return 0;
```

}

Project 9: Bank Account System

Intermediate

Object-Oriented Bank Account

Create a bank account class with deposit, withdrawal and balance functions.

Concepts Used: Classes, encapsulation, constructors and functions.

C++ Code 
#include <iostream>
```

using namespace std;

class BankAccount {

private:

```
double balance;
```

public:

```
BankAccount(double initialBalance) {

    balance = initialBalance;

}

void deposit(double amount) {

    if (amount > 0) {

        balance += amount;

        cout << "Deposit successful." << endl;

    }

}

void withdraw(double amount) {

    if (amount > 0 && amount <= balance) {

        balance -= amount;

        cout << "Withdrawal successful." << endl;

    }
    else {

        cout << "Invalid amount or insufficient balance."
             << endl;

    }

}

void showBalance() {

    cout << "Balance: ₹"
         << balance
         << endl;

}
```

};

int main() {

```
BankAccount account(5000);

account.showBalance();

account.deposit(2000);

account.showBalance();

account.withdraw(1000);

account.showBalance();

return 0;
```

}

How to Build Your Own C++ Project

  1. Choose a simple problem to solve.
  2. Write down the required features.
  3. Decide what data the program needs.
  4. Break the program into functions or classes.
  5. Write the code step by step.
  6. Test each feature separately.
  7. Fix errors and improve the program.
  8. Add additional features after the basic version works.
