What is C++?

C++ is a general-purpose programming language used to develop software, applications, games, operating systems, embedded systems and many other types of programs.

C++ was developed as an extension of the C programming language. It supports procedural programming as well as object-oriented programming.

Simple Definition: C++ is a powerful programming language that combines features of C with object-oriented and other modern programming features.
```
```

History of C++

C++ was created by Bjarne Stroustrup at Bell Labs. Development began in the early 1980s.

The language was originally developed as an extension of the C language and was initially known as "C with Classes".

Over time, it became the programming language known as C++ and gained many features for object-oriented and generic programming.

```
```

Why Learn C++?

C++ is still widely used in many areas of software development.

  • Learn object-oriented programming.

  • Build high-performance applications.

  • Understand concepts useful for systems programming.

Understanding the First Program

1. #include <iostream>

The iostream header provides standard input and output functionality such as cout and cin.

2. using namespace std;

This allows us to use names from the standard library without writing std:: every time.

3. int main()

The main() function is the entry point of a normal C++ program.

4. cout

The cout object is used to display output on the screen.

5. return 0;

This returns a value from the main function and normally indicates successful program completion.

C vs C++

C C++
Procedural programming language. Supports procedural and object-oriented programming.
Does not have classes and objects as core language features. Supports classes and objects.
Uses printf() for common output. Commonly uses cout for stream output.
Uses scanf() for common input. Commonly uses cin for stream input.
Supports structures. Supports structures and classes.
