C++ While Loop

Learn how to repeat code using the C++ while loop.

What is a While Loop?

A while loop is a control structure used to repeatedly execute a block of code while a condition is true.

The condition is checked before every iteration of the loop.

Simple idea:
Check condition → Execute code → Update value → Check condition again.

While Loop Syntax

The basic syntax of a C++ while loop is:

Syntax 
while (condition) {

    // code to execute

}

The loop continues as long as the condition evaluates to true.

Simple While Loop Example

Let's print numbers from 1 to 5 using a while loop. 

#include <iostream>
using namespace std;

int main() {

    int i = 1;

    while (i <= 5) {

        cout << i << endl;

        i++;
    }

    return 0;
}

Output

1 2 3 4 5

How Does a While Loop Work?

Consider the following program: 

int i = 1;

while (i <= 5) {

    cout << i << endl;

    i++;
}

The execution happens like this:

Step Value of i Condition Result
1 1 1 <= 5 Print 1
2 2 2 <= 5 Print 2
3 3 3 <= 5 Print 3
4 4 4 <= 5 Print 4
5 5 5 <= 5 Print 5
6 6 6 <= 5 Stop

Printing Numbers in Reverse

A while loop can also be used to print numbers in descending order. 

#include <iostream>
using namespace std;

int main() {

    int i = 5;

    while (i >= 1) {

        cout << i << endl;

        i--;
    }

    return 0;
}

Output

5 4 3 2 1

Example: Sum of Numbers

We can use a while loop to calculate the sum of numbers from 1 to 10. 

#include <iostream>
using namespace std;

int main() {

    int i = 1;
    int sum = 0;

    while (i <= 10) {

        sum = sum + i;

        i++;
    }

    cout << "Sum = " << sum;

    return 0;
}

Output

Sum = 55

Example: Print Even Numbers

A while loop can be used to print even numbers. 

#include <iostream>
using namespace std;

int main() {

    int i = 2;

    while (i <= 10) {

        cout << i << endl;

        i = i + 2;
    }

    return 0;
}

Output

2 4 6 8 10

While Loop with User Input

A while loop can continue running based on user input. 

#include <iostream>
using namespace std;

int main() {

    int number;

    cout << "Enter a number: ";
    cin >> number;

    while (number > 0) {

        cout << number << endl;

        number--;
    }

    return 0;
}

Example Output

Enter a number: 5 5 4 3 2 1

Example: Multiplication Table

A while loop can be used to generate a multiplication table. 

#include <iostream>
using namespace std;

int main() {

    int number;
    int i = 1;

    cout << "Enter a number: ";
    cin >> number;

    while (i <= 10) {

        cout << number
             << " x "
             << i
             << " = "
             << number * i
             << endl;

        i++;
    }

    return 0;
}

Example Output

Enter a number: 5 5 x 1 = 5 5 x 2 = 10 5 x 3 = 15 5 x 4 = 20 5 x 5 = 25 5 x 6 = 30 5 x 7 = 35 5 x 8 = 40 5 x 9 = 45 5 x 10 = 50

Infinite While Loop

If the condition of a while loop never becomes false, the loop can continue indefinitely. 

int i = 1;

while (i <= 5) {

    cout << i;

}
Warning: In the example above, i is never changed, so the condition remains true. This can create an infinite loop.

A common solution is to update the loop variable: 

i++;

While Loop with break

The break statement can immediately stop a while loop. 

#include <iostream>
using namespace std;

int main() {

    int i = 1;

    while (i <= 10) {

        if (i == 6) {
            break;
        }

        cout << i << endl;

        i++;
    }

    return 0;
}

Output

1 2 3 4 5

While Loop with continue

The continue statement skips the current iteration and continues with the next one. 

#include <iostream>
using namespace std;

int main() {

    int i = 0;

    while (i < 10) {

        i++;

        if (i == 5) {
            continue;
        }

        cout << i << endl;
    }

    return 0;
}

Output

1 2 3 4 6 7 8 9 10

While Loop vs For Loop

While Loop For Loop
Useful when the number of iterations is not always known. Useful when the number of iterations is known.
Initialization is usually written before the loop. Initialization is usually inside the loop.
Update is normally written inside the loop. Update is usually written in the loop header.

Practical Example: Password Attempts

A while loop can be used to repeat an action until a condition is satisfied. 

#include <iostream>
using namespace std;

int main() {

    int password;
    int attempts = 0;

    while (attempts < 3) {

        cout << "Enter password: ";
        cin >> password;

        if (password == 1234) {

            cout << "Login successful!";
            break;
        }

        cout << "Incorrect password." << endl;

        attempts++;
    }

    if (attempts == 3) {
        cout << "Too many attempts.";
    }

    return 0;
}
This is only a basic programming example. Real applications should not store passwords directly in source code.

Important Points About While Loops

  • A while loop checks the condition before executing the loop body.
  • If the condition is false initially, the loop may execute zero times.
  • The loop variable should normally be updated.
  • Forgetting to update the variable can create an infinite loop.
  • break can terminate the loop.
  • continue can skip an iteration.
