C++ Installation

Learn how to install a C++ compiler and start programming.

```
```

Introduction

Before writing and running C++ programs, you need a C++ compiler on your computer.

A compiler converts C++ source code into a form that the computer can execute.

For Windows beginners: A common setup is a C++ compiler such as GCC/MinGW together with a code editor such as Visual Studio Code.
```
```

What Do You Need?

Software Purpose
C++ Compiler Compiles C++ source code.
Visual Studio Code Used to write and manage C++ source code.
Terminal / Command Prompt Used to compile and run programs from the command line.
```
```

What is a C++ Compiler?

A compiler translates C++ source code into machine code or another executable form that can run on your computer.

One commonly used compiler toolchain is GCC. On Windows, GCC can be provided through environments such as MinGW-w64.

Important: Installing VS Code alone does not install a C++ compiler. You need a compiler/toolchain separately.
```
```

Step 1: Install a C++ Compiler

1 Download a GCC/MinGW-w64 Toolchain

Install a Windows-compatible GCC/MinGW-w64 toolchain from a trusted source.

2 Choose the Installation Folder

Install the compiler in a simple folder path. For example:

Example Folder 
C:\mingw64

The exact folder depends on the compiler package you install.

3 Locate the bin Folder

The compiler executable files are normally inside the toolchain's bin folder.

Example 
C:\mingw64\bin
```
```

Step 2: Add Compiler to PATH

Adding the compiler's bin folder to the Windows PATH allows you to run compiler commands from Command Prompt or PowerShell.

1 Open Environment Variables

Search for:

Windows Search 
Environment Variables

2 Open Path Settings

Open the Environment Variables window and find the Path variable under the appropriate user or system variables.

3 Add the bin Folder

Add the path to your compiler's bin directory.

Example 
C:\mingw64\bin
```
```

Step 3: Check the Compiler

Open Command Prompt or PowerShell and type:

Command 
g++ --version

If the compiler is installed and PATH is configured correctly, you should see version information.

If you see: 
'g++' is not recognized...
then the compiler may not be installed correctly or its bin folder may not have been added to PATH.
```
```

Step 4: Install Visual Studio Code

Visual Studio Code is a source-code editor that can be used to write C++ programs.

  1. Download and install Visual Studio Code.
  2. Open Visual Studio Code.
  3. Create a folder for your C++ programs.
  4. Open that folder in VS Code.
  5. Create a file with the .cpp extension.
Example File 
hello.cpp
```
```

Step 5: Install the C++ Extension

In VS Code, open the Extensions section and search for the official Microsoft C/C++ extension.

This extension provides C++ language support such as syntax highlighting, code completion and debugging integration.

Tip: Make sure you install the C/C++ extension from Microsoft.
```
```

Step 6: Create Your First C++ Program

Create a file named:

File Name 
hello.cpp

Then write the following program:

hello.cpp 
#include <iostream>
```

using namespace std;

int main()
{
cout << "Hello, World!";

```
return 0;
```

}
```

Step 7: Compile the C++ Program

Open the terminal in the folder containing hello.cpp.

Use the following command:

Compile Command 
g++ hello.cpp -o hello

This command asks g++ to compile the source file and create an executable named hello.

```
```

Step 8: Run the Program

On Windows, after successful compilation, run:

Command Prompt / PowerShell 
hello

In some shells, you can use: 

.\hello.exe
Output 
Hello, World!
```
```

C++ File Extension

C++ source files commonly use the .cpp extension.

Extension Meaning
.cpp Common C++ source file
.h Common header file extension
.hpp Common C++ header file extension
```
```

Common Installation Problems

1. g++ is not recognized

Check whether the compiler is installed and whether its bin directory has been added to PATH.

2. VS Code cannot find the compiler

Check your compiler installation and make sure g++ can be run from the terminal.

3. Program does not compile

Check the source code for syntax errors and make sure the file has a .cpp extension.

4. Command Prompt was already open

After changing PATH, close and reopen Command Prompt or PowerShell so the new PATH can be loaded.

```
```

Important Points to Remember

  • VS Code is an editor, not the C++ compiler itself.
  • You need a C++ compiler/toolchain to compile C++ programs.
  • GCC provides the commonly used g++ compiler command.
  • The compiler's bin directory may need to be added to PATH.
  • C++ source files commonly use the .cpp extension.
  • You can check the compiler using g++ --version.
  • You can compile a simple file using g++ hello.cpp -o hello.
