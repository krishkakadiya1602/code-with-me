C++ Functions

Learn how to create and use functions in C++

What is a Function in C++?

A function is a block of code that performs a specific task.

Functions help us divide a large program into smaller and reusable parts.

Simple Definition: A function is a reusable block of code designed to perform a particular task.

Why Use Functions?

  • Functions make programs easier to understand.
  • Functions reduce code repetition.
  • Functions make code reusable.
  • Functions make debugging easier.
  • Functions help divide large programs into smaller parts.

Basic C++ Function

Here is a simple function named myFunction(). 

#include <iostream>
using namespace std;

void myFunction()
{
    cout << "Hello from function!";
}

int main()
{
    myFunction();

    return 0;
}

Output

Hello from function!

C++ Function Syntax

returnType functionName(parameters)
{
    // code to execute
}

Example

void greet()
{
    cout << "Hello!";
}

Here:

  • void → return type
  • greet → function name
  • () → parameters
  • { } → function body

Calling a Function

Creating a function does not automatically execute it. We need to call the function. 

#include <iostream>
using namespace std;

void greet()
{
    cout << "Welcome to C++!";
}

int main()
{
    greet();

    return 0;
}

The statement greet(); calls the function.

Function Parameters

Parameters allow us to pass data into a function. 

#include <iostream>
using namespace std;

void greet(string name)
{
    cout << "Hello " << name;
}

int main()
{
    greet("Krish");

    return 0;
}

Output

Hello Krish

Multiple Parameters

A function can have more than one parameter. 

#include <iostream>
using namespace std;

void add(int a, int b)
{
    cout << "Sum = " << a + b;
}

int main()
{
    add(10, 20);

    return 0;
}

Output

Sum = 30

Function with Return Value

A function can return a value to the code that called it. 

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result = add(10, 20);

    cout << "Result = " << result;

    return 0;
}

Output

Result = 30
The return statement sends a value back to the caller.

Void Function

A void function does not return a value. 

#include <iostream>
using namespace std;

void message()
{
    cout << "Welcome to Code With Me!";
}

int main()
{
    message();

    return 0;
}

Function Declaration

A function declaration tells the compiler about a function before the function is actually defined. 

#include <iostream>
using namespace std;

// Function declaration
int add(int, int);

int main()
{
    cout << add(5, 10);

    return 0;
}

// Function definition
int add(int a, int b)
{
    return a + b;
}

Function Definition

The function definition contains the actual code that performs the task. 

int multiply(int a, int b)
{
    return a * b;
}

Pass by Value

In pass by value, a copy of the variable is passed to the function. 

#include <iostream>
using namespace std;

void change(int x)
{
    x = 100;
}

int main()
{
    int number = 10;

    change(number);

    cout << number;

    return 0;
}

Output

10
The original variable does not change because the function receives a copy of its value.

Pass by Reference

In pass by reference, the function works with the original variable. 

#include <iostream>
using namespace std;

void change(int &x)
{
    x = 100;
}

int main()
{
    int number = 10;

    change(number);

    cout << number;

    return 0;
}

Output

100

Default Parameters

A function parameter can have a default value. 

#include <iostream>
using namespace std;

void greet(string name = "User")
{
    cout << "Hello " << name;
}

int main()
{
    greet();

    return 0;
}

Output

Hello User

If we provide a value, that value will be used instead. 

greet("Krish");

Function Overloading

Function overloading allows multiple functions to have the same name but different parameters. 

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

double add(double a, double b)
{
    return a + b;
}

int main()
{
    cout << add(10, 20) << endl;
    cout << add(5.5, 2.5);

    return 0;
}

Output

30
8

Recursive Function

A recursive function is a function that calls itself. 

#include <iostream>
using namespace std;

void countDown(int n)
{
    if (n > 0)
    {
        cout << n << " ";
        countDown(n - 1);
    }
}

int main()
{
    countDown(5);

    return 0;
}

Output

5 4 3 2 1
Important: A recursive function should have a stopping condition. Without one, it can continue calling itself indefinitely.

Types of Functions

Type Description Example
No parameters, no return value Performs a task without input or output value void greet()
Parameters, no return value Receives values but does not return a value void add(int a, int b)
No parameters, return value Returns a value without receiving parameters int getNumber()
Parameters and return value Receives values and returns a result int add(int a, int b)

Practical Example: Calculator Using Functions

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int subtract(int a, int b)
{
    return a - b;
}

int multiply(int a, int b)
{
    return a * b;
}

int divide(int a, int b)
{
    return a / b;
}

int main()
{
    int a = 20;
    int b = 5;

    cout << "Addition = " << add(a, b) << endl;
    cout << "Subtraction = " << subtract(a, b) << endl;
    cout << "Multiplication = " << multiply(a, b) << endl;
    cout << "Division = " << divide(a, b) << endl;

    return 0;
}

Output

Addition = 25
Subtraction = 15
Multiplication = 100
Division = 4
Functions make the calculator program easier to organize because each operation has its own function.
