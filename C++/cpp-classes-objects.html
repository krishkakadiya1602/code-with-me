C++ Classes and Objects

Learn the foundation of Object-Oriented Programming in C++.

```
```

What are Classes and Objects?

Classes and objects are one of the most important concepts in C++ Object-Oriented Programming (OOP).

A class is a blueprint or template used to create objects.

An object is an instance of a class.

Simple Example:

Class = Car design
Object = Actual car created from that design
```
```

Why Use Classes and Objects?

Classes and objects help us organize data and functions together.

  • They make programs easier to organize.
  • They help represent real-world entities.
  • They support Object-Oriented Programming.
  • They improve code reusability.
  • They provide data protection using access specifiers.
  • They make large programs easier to maintain.
```
```

Private Access Specifier

Members declared under private cannot be accessed directly from outside the class.

Example 
class Student {
```

private:

```
int marks;
```

public:

```
void setMarks(int m) {

    marks = m;

}

int getMarks() {

    return marks;

}
```

};
```

Protected Access Specifier

The protected access specifier is mainly used when working with inheritance.

Example 
class Parent {
```

protected:

```
int value;
```

};
```

Protected members can be accessed inside the class and by derived classes.

```
```

Specifier Same Class Outside Class Derived Class
public Yes Yes Yes
private Yes No No
protected Yes No Yes

Common Mistakes

1. Forgetting the Semicolon

class Car {
```

public:

```
string brand;
```

}   // Wrong
```

A semicolon is required after the class definition. 

class Car {
```

public:

```
string brand;
```

};
```

2. Accessing Private Members Directly

class Student {
```

private:

```
int age;
```

};

Student student;

student.age = 20;
```

This is not allowed because age is private. Use a public setter or member function.

3. Forgetting to Create an Object

class Car {
```

public:

```
void drive() {

    cout << "Driving";

}
```

};
```

The class definition alone does not call the function. You need an object such as: 

Car car;
```

car.drive();
```
