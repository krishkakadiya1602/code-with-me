C++ Comments

Learn how to write comments in C++ programs.

```
```

What are Comments in C++?

Comments are notes written inside a C++ program to explain what the code does.

Comments are ignored by the C++ compiler, which means they do not affect the execution of the program.

Simple Definition: A comment is a piece of text in source code that is written for developers and is not executed as program code.
```
```

Why Use Comments?

Comments make code easier to understand, especially when programs become large.

  • Explain what a section of code does.
  • Make code easier to read.
  • Help developers understand complex logic.
  • Document important information.
  • Help while maintaining large projects.
  • Temporarily disable code during testing.
```
```

Types of Comments in C++

C++ mainly supports two common types of comments:

Type Syntax Use
Single-Line Comment // Used for comments on one line
Multi-Line Comment /* ... */ Used for comments spanning multiple lines
```
```

1. Single-Line Comments

A single-line comment starts with two forward slashes: //

Everything after // on that line is treated as a comment.

Example 
// This is a single-line comment
```

#include 

using namespace std;

int main()
{
cout << "Hello World!";

```
return 0;
```

}
```

Comment After a Statement

You can also place a single-line comment after a statement.

Example 
#include <iostream>
```

using namespace std;

int main()
{
int age = 20; // Store the user's age

```
cout << age; // Display the age

return 0;
```

}
```

Multiple Single-Line Comments

You can write multiple single-line comments by using // on each line.

Example 
// Create two variables
```

int a = 10;
int b = 20;

// Add the values
int sum = a + b;

// Display the result
cout << sum;
```

2. Multi-Line Comments

Multi-line comments start with /* and end with */.

They can contain one or multiple lines.

Example 
/*
```

multiple lines.
*/

#include

{

```
return 0;
```

}

Multi-Line Comment in a Program

Example 
#include <iostream>
```

using namespace std;

int main()
{
/*
Create two numbers
and calculate their sum.
*/

```

int b = 20;

```

}
```

Using Comments to Disable Code

Comments can also be used to temporarily prevent a line of code from being compiled.

Example 
#include <iostream>
```

using namespace std;

int main()
{
cout << "Hello";

```
// cout << "This line is disabled";

return 0;
```

}
```

The commented-out statement will not be executed.

```
```

Disable Multiple Lines

You can temporarily disable multiple lines using a multi-line comment.

Example 
#include <iostream>
```

using namespace std;

int main()
{
cout << "Start";

```
/*
cout << "Line 1";
cout << "Line 2";
cout << "Line 3";
*/

cout << "End";

return 0;
```

}
```

Good Comments

Good comments explain why something is being done or clarify code that may not be obvious.

Example 
// Calculate the final price after applying the discount
```

double finalPrice = price - discount;
```

Avoid Unnecessary Comments

Comments should provide useful information. Avoid comments that simply repeat obvious code.

Less Useful 
int age = 20; // Set age to 20

In simple code, the statement may already be clear. Comments become more useful when they explain non-obvious logic or decisions.

Important Rules for C++ Comments

  • Use // for a single-line comment.
  • Use /* */ for a multi-line comment.
  • Comments are ignored by the compiler.
  • Comments do not normally affect program output.
  • Use comments to make code easier to understand.
  • Avoid writing unnecessary comments everywhere.
  • Comments can temporarily disable code during testing.
```
```
