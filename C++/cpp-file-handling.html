C++ File Handling

Learn How to Create, Write, Read and Manage Files in C++

What is File Handling in C++?

File handling is used to store data permanently in files.

Normally, data stored in variables is lost when a program ends. File handling allows a program to save data in a file so that it can be used later.

Simple Definition:
File handling means creating, opening, reading, writing, updating and closing files using a C++ program.

Why Use File Handling?

  • To permanently store data.
  • To read previously saved information.
  • To create files using a program.
  • To update existing data.
  • To store large amounts of information.
  • To maintain records such as students, employees and products.

File Handling Header

C++ provides file handling functionality through the <fstream> header.

Include fstream 
#include <fstream>

The fstream header provides classes for working with files.

C++ File Handling Classes

Class Purpose
ofstream Used to create and write to files.
ifstream Used to read data from files.
fstream Used for both reading and writing.

ofstream

ofstream stands for output file stream.

It is mainly used to write data into a file.

Example 
#include <fstream>
```

using namespace std;

int main() {

```
ofstream file("example.txt");

file << "Hello, C++ File Handling!";

file.close();

return 0;
```

}
```

This program creates a file named example.txt and writes text into it.

Closing a File

After completing file operations, you should close the file.

Syntax 
file.close();
Closing a file releases the associated resources and ensures pending output is properly written.

ifstream stands for input file stream.

It is used to read data from a file.

Opening a File

A file can be opened directly when creating a stream object.

Method 1 
ofstream file("example.txt");

Or you can use the open() function.

Method 2 
ofstream file;
```

file.open("example.txt");
```

File Opening Modes

C++ provides different file opening modes.

Mode Meaning
ios::in Open for reading.
ios::out Open for writing.
ios::app Append data at the end of the file.
ios::ate Open and initially position at the end.
ios::trunc Truncate existing file contents when opening for output.
ios::binary Open in binary mode.

Checking File State

C++ stream objects provide functions for checking the state of file operations.

Function Purpose
is_open() Checks whether the file is open.
good() Checks whether the stream is in a good state.
fail() Checks whether an operation has failed.
eof() Checks whether the end-of-file condition is reached.
bad() Checks for a serious stream error.

Reading Until End of File

A common and safe pattern for reading text files line by line is to make getline() the loop condition.

Example 
#include <iostream>
```

#include 
#include 

using namespace std;

int main() {

```
ifstream file("example.txt");

string line;

while (getline(file, line)) {

    cout << line << endl;

}

file.close();

return 0;
```

}
```
Prefer while (getline(file, line)) instead of using while (!file.eof()) for line-based text reading.

Binary File Handling

Binary mode is used when working with binary data.

The ios::binary flag can be combined with file streams.

Example 
#include <fstream>
```

using namespace std;

int main() {

```
ofstream file(
    "data.bin",
    ios::binary
);

if (!file.is_open()) {

    return 1;
}

int number = 100;

file.write(
    reinterpret_cast<const char*>(&number),
    sizeof(number)
);

file.close();

return 0;
```

}
```
Binary file handling is useful for raw data and applications where binary representation is required.

File Pointers

C++ streams maintain positions used for reading and writing data.

Function Purpose
seekg() Moves the input/read position.
seekp() Moves the output/write position.
tellg() Returns the current input position.
tellp() Returns the current output position.

Example of seekg()

C++ Program 
#include <iostream>
```

#include 

using namespace std;

int main() {

```
ifstream file("example.txt");

if (!file.is_open()) {

    return 1;
}

file.seekg(0);

char ch;

file.get(ch);

cout << ch;

file.close();

return 0;
```

}
```

Important File Handling Points

  • Include <fstream> for file streams.
  • Use ofstream for writing.
  • Use ifstream for reading.
  • Use fstream for reading and writing.
  • Use ios::app to append data.
  • Use getline() to read complete lines.
  • Check is_open() before performing operations.
  • Close files after completing operations.
  • Use ios::binary for binary file operations.

Common Mistakes

1. Forgetting <fstream>

Make sure to include: 

#include <fstream>

2. Not Checking the File

Always check whether the file opened successfully.
