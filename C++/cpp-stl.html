C++ STL

Learn the Standard Template Library in C++ with containers, iterators, algorithms and practical examples.

What is C++ STL?

STL stands for Standard Template Library. It is a collection of ready-to-use template classes and functions provided by C++.

STL helps programmers perform common programming tasks without writing everything from scratch.

STL mainly contains: Containers, Iterators, Algorithms and Function Objects.

Why Use STL?

  • Reduces the amount of code you need to write.
  • Provides reusable data structures.
  • Provides useful searching and sorting algorithms.
  • Makes programs easier to develop.
  • Works with different data types using templates.
  • Provides efficient and commonly used implementations.

Main Components of STL

Component Purpose Examples
Containers Store collections of data. vector, list, map, set
Iterators Access and move through container elements. begin(), end()
Algorithms Perform operations on data. sort(), find(), reverse()
Function Objects Objects that can behave like functions. greater<>, less<>

1. Vector

A vector is a dynamic array that can automatically change its size. 

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> numbers = {10, 20, 30, 40};

    for (int number : numbers)
    {
        cout << number << " ";
    }

    return 0;
}
Output:
10 20 30 40

Common Vector Functions

Function Purpose
push_back() Adds an element at the end.
pop_back() Removes the last element.
size() Returns the number of elements.
front() Returns the first element.
back() Returns the last element.
empty() Checks whether the vector is empty. 
vector<int> numbers;

numbers.push_back(10);
numbers.push_back(20);
numbers.push_back(30);

cout << numbers.size();

2. List

A list stores elements in a sequence and supports efficient insertion and removal at known positions. 

#include <iostream>
#include <list>
using namespace std;

int main()
{
    list<int> numbers = {10, 20, 30};

    numbers.push_front(5);
    numbers.push_back(40);

    for (int number : numbers)
    {
        cout << number << " ";
    }

    return 0;
}
Output:
5 10 20 30 40

3. Stack

A stack follows the LIFO principle.

LIFO means Last In, First Out. 

#include <iostream>
#include <stack>
using namespace std;

int main()
{
    stack<int> numbers;

    numbers.push(10);
    numbers.push(20);
    numbers.push(30);

    cout << numbers.top();

    return 0;
}
Output:
30

4. Queue

A queue generally follows the FIFO principle.

FIFO means First In, First Out. 

#include <iostream>
#include <queue>
using namespace std;

int main()
{
    queue<int> numbers;

    numbers.push(10);
    numbers.push(20);
    numbers.push(30);

    cout << numbers.front();

    return 0;
}
Output:
10

5. Priority Queue

A priority_queue gives access to the highest-priority element according to its ordering. 

#include <iostream>
#include <queue>
using namespace std;

int main()
{
    priority_queue<int> numbers;

    numbers.push(10);
    numbers.push(50);
    numbers.push(30);

    cout << numbers.top();

    return 0;
}
Output:
50

6. Set

A set stores unique elements and keeps them ordered according to its comparison rules. 

#include <iostream>
#include <set>
using namespace std;

int main()
{
    set<int> numbers;

    numbers.insert(30);
    numbers.insert(10);
    numbers.insert(20);
    numbers.insert(10);

    for (int number : numbers)
    {
        cout << number << " ";
    }

    return 0;
}
Output:
10 20 30
Notice that the duplicate value 10 appears only once.

7. Map

A map stores data in key-value pairs. Keys in a map are unique. 

#include <iostream>
#include <map>
using namespace std;

int main()
{
    map<string, int> marks;

    marks["Krish"] = 90;
    marks["Rahul"] = 85;
    marks["Amit"] = 80;

    cout << marks["Krish"];

    return 0;
}
Output:
90

8. Unordered Map

An unordered_map stores key-value pairs using hashing and does not maintain elements in sorted key order. 

#include <iostream>
#include <unordered_map>
using namespace std;

int main()
{
    unordered_map<string, int> age;

    age["Krish"] = 20;
    age["Rahul"] = 21;

    cout << age["Krish"];

    return 0;
}

9. Iterators

Iterators are objects used to access elements inside STL containers. 

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> numbers = {10, 20, 30};

    vector<int>::iterator it;

    for (it = numbers.begin(); it != numbers.end(); ++it)
    {
        cout << *it << " ";
    }

    return 0;
}
Output:
10 20 30

10. STL Algorithms

The C++ STL provides many ready-to-use algorithms.

sort()

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    vector<int> numbers = {40, 10, 30, 20};

    sort(numbers.begin(), numbers.end());

    for (int number : numbers)
    {
        cout << number << " ";
    }

    return 0;
}
Output:
10 20 30 40

reverse()

The reverse() algorithm reverses the elements in a range. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    vector<int> numbers = {10, 20, 30, 40};

    reverse(numbers.begin(), numbers.end());

    for (int number : numbers)
    {
        cout << number << " ";
    }

    return 0;
}
Output:
40 30 20 10

find()

The find() algorithm searches for a value in a range. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    vector<int> numbers = {10, 20, 30, 40};

    auto result = find(
        numbers.begin(),
        numbers.end(),
        30
    );

    if (result != numbers.end())
    {
        cout << "Element found";
    }
    else
    {
        cout << "Element not found";
    }

    return 0;
}
Output:
Element found

count()

The count() algorithm counts how many times a value occurs in a range. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    vector<int> numbers = {
        10, 20, 10, 30, 10
    };

    int result = count(
        numbers.begin(),
        numbers.end(),
        10
    );

    cout << result;

    return 0;
}
Output:
3

Practical Example: Student Marks

STL can make it easy to store and sort student marks. 

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    vector<int> marks = {
        78, 92, 65, 88, 95
    };

    sort(marks.begin(), marks.end());

    cout << "Sorted Marks:\n";

    for (int mark : marks)
    {
        cout << mark << " ";
    }

    return 0;
}
Output:
Sorted Marks:
65 78 88 92 95

Advantages of STL

  • Reusable components.
  • Less development time.
  • Powerful containers.
  • Useful built-in algorithms.
  • Supports generic programming.
  • Works with many different data types.
  • Makes code shorter and easier to maintain.

Important STL Points

1. Containers store data.

2. Iterators help access container elements.

3. Algorithms perform operations on data.

4. Templates allow STL components to work with different data types.
