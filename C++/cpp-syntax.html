Learn the basic rules and structure of C++ programs.

```
```

What is C++ Syntax?

C++ syntax is the set of rules that tells us how C++ programs should be written.

Just like human languages have grammar rules, programming languages have syntax rules.

Important: If the syntax of a C++ program is incorrect, the compiler may report an error.
```
```

Basic Structure of a C++ Program

A simple C++ program can contain header files, a main function, statements and a return statement.

Basic C++ Program 
#include <iostream>
```

using namespace std;

int main()
{
cout << "Hello World!";

```
return 0;
```

}
```

Understanding the Program

1. #include <iostream>

This includes the input/output stream library. It provides functionality such as cout and cin.

2. using namespace std;

This allows us to use standard library names such as cout and cin without writing std:: before them.

3. int main()

The main() function is the normal entry point of a C++ program.

4. Curly Braces { }

Curly braces define the beginning and end of a block of code.

5. cout

The cout object is commonly used to display output.

6. return 0;

This returns a value from the main function and normally indicates successful completion.

Common C++ Syntax Mistakes

1. Missing Semicolon

int age = 20

Correct: 

int age = 20;

2. Incorrect Capitalization

Cout << "Hello";

Correct: 

cout << "Hello";

3. Missing Curly Brace

if (age >= 18)
```

{
cout << "Adult";
```

Make sure every opening brace has the appropriate closing brace.

4. Wrong String Quotes

cout << 'Hello';

For a string, use double quotes: 

cout << "Hello";
```
```

Important C++ Syntax Rules

  • Most C++ statements end with a semicolon.
  • C++ is case-sensitive.
  • Program execution normally starts from main().
  • Use curly braces to define code blocks.
  • Use appropriate data types for variables.
  • Keywords have special meanings and cannot be used freely as identifiers.
  • Use double quotes for strings.
  • Use single quotes for character literals.
  • Use #include to include required headers.
  • Use cout for common output and cin for common input.
