8. HTML Forms

Learn how to create forms, input fields, buttons, checkboxes, radio buttons, dropdowns and more.

What is an HTML Form?

An HTML form is used to collect information from users. Forms are commonly used for login pages, registration pages, contact forms, search boxes and feedback forms.

The main HTML element used to create a form is <form>.

Example: 
<form>

    <label>Name:</label>
    <input type="text">

    <button type="submit">
        Submit
    </button>

</form>

1. The <form> Element

The <form> element is the container for form controls. 

<form>

    Form elements go here.

</form>

Important Form Attributes

Attribute Purpose
action Specifies where form data should be sent.
method Specifies how the data should be sent.
autocomplete Controls browser autocomplete.
target Specifies where the response should be displayed.

2. The <label> Element

The <label> element provides a text description for an input field. 

<label for="username">
    Username:
</label>

<input type="text" id="username">
Tip: Always try to use labels with form inputs. They make forms easier to understand and use.

3. Text Input

The type="text" input creates a single-line text field. 

<label>Full Name:</label>

<input type="text"
       placeholder="Enter your name">

4. Email Input

The email input is used to collect an email address. 

<label>Email:</label>

<input
    type="email"
    placeholder="Enter your email">

5. Password Input

The password input hides the characters typed by the user. 

<label>Password:</label>

<input
    type="password"
    placeholder="Enter password">

6. Number Input

The number input is used to enter numbers. 

<label>Age:</label>

<input
    type="number"
    min="1"
    max="100">

9. Dropdown List

The <select> element creates a dropdown list. 

<label>Choose a Course:</label>

<select>

    <option>HTML</option>
    <option>CSS</option>
    <option>JavaScript</option>
    <option>Python</option>

</select>

10. Textarea

The <textarea> element is used when the user needs to enter multiple lines of text. 

<label>Message:</label>

<textarea
    rows="5"
    cols="40"
    placeholder="Enter your message">
</textarea>

11. Date Input

The date input allows users to select a date. 

<label>Date of Birth:</label>

<input type="date">

12. File Input

The file input allows users to select a file from their device. 

<label>Upload File:</label>

<input type="file">

13. Telephone Input

The tel input is commonly used for phone numbers. 

<label>Phone Number:</label>

<input
    type="tel"
    placeholder="Enter phone number">

14. URL Input

The url input is used for website addresses. 

<label>Website:</label>

<input
    type="url"
    placeholder="https://example.com">

15. Submit Button

A submit button is used to submit the form. 

<button type="submit">
    Submit
</button>

You can also use: 

<input type="submit" value="Submit">

16. Reset Button

A reset button clears the form fields and returns them to their initial values. 

<button type="reset">
    Reset
</button>

17. Placeholder

The placeholder attribute displays a hint inside an input field. 

<input
    type="text"
    placeholder="Enter your name">

18. Required Attribute

The required attribute makes a form field mandatory. 

<input
    type="text"
    required>
Tip: If the user tries to submit the form without entering a required value, the browser will ask them to complete it.

19. Name Attribute

The name attribute identifies form data when it is submitted. 

<input
    type="text"
    name="username">

20. Value Attribute

The value attribute specifies an initial or submitted value. 

<input
    type="text"
    name="country"
    value="India">

HTML Form Best Practices

  1. Always use meaningful labels.
  2. Use the correct input type.
  3. Use required for mandatory fields.
  4. Use meaningful name attributes.
  5. Use placeholder text when it helps the user.
  6. Group related radio buttons correctly.
  7. Keep forms simple and easy to understand.

Common Mistakes

  • Forgetting the <form> element.
  • Not using labels for input fields.
  • Using different name values for radio buttons that should belong to the same group.
  • Forgetting the name attribute when form data needs to be submitted.
  • Using type="text" for every input instead of using appropriate input types.

HTML Forms Summary

HTML forms are used to collect information from users.

  • <form> creates a form.
  • <label> describes an input.
  • <input> creates different types of input fields.
  • <textarea> creates a multi-line text field.
  • <select> creates a dropdown list.
  • <option> creates options inside a dropdown.
  • <button> creates buttons.
  • required makes a field mandatory.
