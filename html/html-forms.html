HTML Forms

Learn how to create forms in HTML with simple examples

⭐ Main Points

  • HTML Forms are used to collect user information.
  • The <form> element creates a form.
  • <input> is used for different types of user input.
  • <label> provides a name for an input field.
  • Radio buttons allow the user to select one option.
  • Checkboxes allow the user to select multiple options.
  • <select> creates a dropdown list.
  • <textarea> creates a multi-line input area.
  • <button> creates a clickable button.
  • <fieldset> and <legend> can group form elements.

1. HTML Form

The <form> element is used to create a form where users can enter information.

Example:
<form>

    Name:
    <input type="text">

</form>
Output:
Name:

⭐ Main Points

  • Creates an HTML form.
  • Form elements are placed inside it.

2. Form Action

The action attribute specifies where the form data should be sent after submission.

Example:
<form action="submit.html">

    <input type="text" name="username">

    <input type="submit">

</form>
Output:

⭐ Main Points

  • action defines the destination.
  • It is commonly used when submitting form data.

3. Form Method

The method attribute defines how form data is sent.

Example:
<form method="post">

    <input type="text" name="username">

    <input type="submit">

</form>
Output:

⭐ Main Points

  • GET sends data through the URL.
  • POST sends data in the request body.

9. Radio Buttons

Radio buttons allow the user to select one option from a group of options.

Example:
<input type="radio" name="gender" value="male"> Male

<input type="radio" name="gender" value="female"> Female

⭐ Main Points

  • Used when selecting one option.
  • Use the same name for the group.

19. Fieldset and Legend

<fieldset> groups related form elements and <legend> gives the group a title.

Example:
<fieldset>

    <legend>Personal Information</legend>

    <label>Name:</label>

    <input type="text">

</fieldset>
Output:
Personal Information

⭐ Main Points

  • fieldset groups related fields.
  • legend provides a caption.

20. Complete HTML Form

We can combine different HTML form elements to create a complete registration form.

Example:
<form>

    <label>Name:</label>
    <input type="text">

    <br><br>

    <label>Email:</label>
    <input type="email">

    <br><br>

    <label>Password:</label>
    <input type="password">

    <br><br>

    <label>Gender:</label>

    <input type="radio" name="gender"> Male
    <input type="radio" name="gender"> Female

    <br><br>

    <label>Skills:</label>

    <input type="checkbox"> HTML
    <input type="checkbox"> CSS
    <input type="checkbox"> JavaScript

    <br><br>

    <label>Country:</label>

    <select>
        <option>India</option>
        <option>USA</option>
        <option>Canada</option>
    </select>

    <br><br>

    <label>Message:</label>

    <br>

    <textarea rows="5"></textarea>

    <br><br>

    <input type="submit" value="Register">

    <input type="reset" value="Clear">

</form>
Output:






Male Female

HTML CSS JavaScript






⭐ Main Points

  • Different form controls can be combined.
  • Labels improve form structure and usability.
  • Input types provide different controls.
  • Forms are commonly used for registration and login pages.
