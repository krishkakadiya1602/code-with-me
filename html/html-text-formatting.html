3. HTML Text Formatting

Learn how to format and give meaning to text using HTML formatting elements.

Introduction to Text Formatting

Text formatting means changing or marking text so that its appearance or meaning is communicated clearly.

HTML provides several elements for representing important, emphasized, highlighted, deleted, inserted and other types of text.

Important: HTML elements should be selected based on the meaning and purpose of the content, not only its visual appearance.

1. Bold Text - <b>

The <b> element draws attention to text without adding special importance to its meaning. 

<b>This is bold text.</b>

Example Output:

This is bold text.

2. Important Text - <strong>

The <strong> element represents text with strong importance, seriousness or urgency. 

<strong>Warning! Save your work.</strong>

Example Output:

Warning! Save your work.

Remember: <strong> is semantic. It communicates importance rather than simply requesting bold styling.

3. Italic Text - <i>

The <i> element represents text in an alternate voice or mood, such as a technical term, foreign phrase or other text that is conventionally presented in italics. 

<i>HTML is interesting.</i>

Example Output:

HTML is interesting.

4. Emphasized Text - <em>

The <em> element represents emphasis. 

<em>Practice HTML every day.</em>

Example Output:

Practice HTML every day.

<em> is semantic and can communicate emphasis to assistive technologies.

5. Highlighted Text - <mark>

The <mark> element represents text that is highlighted or marked because it is relevant in the current context. 

<p>
Learn <mark>HTML</mark> first.
</p>

Example Output:

Learn HTML first.

6. Smaller Text - <small>

The <small> element represents side comments, small print or other text that is less prominent. 

<p>
Main content
<small>Terms and conditions apply.</small>
</p>

Example Output:

Main content Terms and conditions apply.

7. Deleted Text - <del>

The <del> element represents content that has been deleted from a document. 

<p>
Price:
<del>₹1000</del>
₹799
</p>

Example Output:

Price: ₹1000 ₹799

8. Inserted Text - <ins>

The <ins> element represents content that has been inserted into a document. 

<p>
This is
<ins>new content</ins>.
</p>

Example Output:

This is new content.

9. Subscript - <sub>

The <sub> element displays text as subscript.

It is commonly used for chemical formulas. 

<p>
H<sub>2</sub>O
</p>

Example Output:

H2O

10. Superscript - <sup>

The <sup> element displays text as superscript.

It can be useful for mathematical expressions, powers and other notation. 

<p>
x<sup>2</sup>
</p>

Example Output:

x2

11. Underlined Text - <u>

The <u> element represents text with an unarticulated annotation and is typically displayed with an underline. 

<p>
<u>Important text</u>
</p>

Example Output:

Important text

Do not use underlining just to make ordinary text look like a link. Users commonly expect underlined text to be clickable.

12. No Longer Accurate Text - <s>

The <s> element represents content that is no longer accurate, relevant or appropriate. 

<p>
<s>Sale ends today</s>
</p>

Example Output:

Sale ends today

13. Computer Code - <code>

The <code> element represents a fragment of computer code. 

<p>
Use <code>console.log()</code>
in JavaScript.
</p>

Example Output:

Use console.log() in JavaScript.

14. Preformatted Text - <pre>

The <pre> element represents preformatted text. Whitespace and line breaks inside the element are preserved. 

<pre>
Hello
    World
        HTML
</pre>

Example Output:

Hello
    World
        HTML

<b> vs <strong>

Both elements are commonly displayed with bold styling in browsers, but they have different meanings. 

<b>Important-looking text</b>

<strong>Important information</strong>
<b> → draws attention without conveying extra importance.

<strong> → represents strong importance, seriousness or urgency.

<i> vs <em>

Both can appear italic in a browser, but their meanings are different. 

<i>Technical term</i>

<em>Really important emphasis</em>
<i> → alternate voice, mood or conventionally italic text.

<em> → emphasis.

Common Mistakes

  1. Using formatting elements only for visual styling instead of considering their meaning.
  2. Using <br> repeatedly to create page layout.
  3. Using underlined ordinary text in a way that makes users think it is a link.
  4. Using <strong> everywhere when the content is not actually important.
  5. Forgetting to close elements where a closing tag is required.

HTML Text Formatting Summary

In this lesson, you learned how HTML can represent different types of formatted and meaningful text.

  • <b> → Attention without added importance
  • <strong> → Strong importance
  • <i> → Alternate voice or mood
  • <em> → Emphasis
  • <mark> → Highlighted text
  • <small> → Small print or side comments
  • <del> → Deleted content
  • <ins> → Inserted content
  • <sub> → Subscript
  • <sup> → Superscript
  • <u> → Unarticulated annotation
  • <s> → No longer accurate/relevant
  • <code> → Computer code
  • <pre> → Preformatted text
