3. HTML Text Formatting

Learn how to make text bold, italic, important, emphasized, highlighted and more using HTML.

1. Bold Text - <b>

The <b> tag makes text bold. 

<p>
This is <b>bold text</b>.
</p>
This is bold text.

2. Important Text - <strong>

The <strong> tag indicates that the text is important. 

<p>
This is <strong>important text</strong>.
</p>
This is important text.

3. Italic Text - <i>

The <i> tag displays text in italic style. 

<p>
This is <i>italic text</i>.
</p>
This is italic text.

4. Emphasized Text - <em>

The <em> tag is used to emphasize text. 

<p>
This is <em>emphasized text</em>.
</p>
This is emphasized text.

5. Highlighted Text - <mark>

The <mark> tag highlights text. 

<p>
This is <mark>highlighted text</mark>.
</p>
This is highlighted text.

6. Smaller Text - <small>

The <small> tag displays smaller text. 

<p>
This is <small>small text</small>.
</p>
This is small text.

7. Deleted Text - <del>

The <del> tag displays deleted text with a line through it. 

<p>
Old price:
<del>₹1000</del>
</p>
Old price: ₹1000

8. Inserted Text - <ins>

The <ins> tag represents inserted text. 

<p>
New price:
<ins>₹800</ins>
</p>
New price: ₹800

9. Subscript - <sub>

The <sub> tag displays subscript text. 

<p>
H<sub>2</sub>O
</p>
H2O

10. Superscript - <sup>

The <sup> tag displays superscript text. 

<p>
X<sup>2</sup>
</p>
X2
