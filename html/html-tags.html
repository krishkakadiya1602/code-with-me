HTML Basic Tags

HTML tags are used to create the structure and content of a webpage. In this lesson, we will learn some basic HTML tags.

⭐ Main Points

  • HTML tags are used to structure webpage content.
  • Heading tags range from <h1> to <h6>.
  • The <p> tag is used to create paragraphs.
  • The <br> tag creates a line break.
  • The <hr> tag creates a horizontal line.
  • HTML tags are an important foundation of web development.

1. Heading Tags

HTML provides six heading tags from <h1> to <h6>.

  • <h1> - Largest heading
  • <h2> - Second-level heading
  • <h3> - Third-level heading
  • <h4> - Fourth-level heading
  • <h5> - Fifth-level heading
  • <h6> - Smallest heading

2. Paragraph Tag

The <p> tag is used to create a paragraph.

3. Line Break Tag

The <br> tag is used to create a line break.

4. Horizontal Line

The <hr> tag creates a horizontal line on the webpage.

Basic HTML Tags

Tag Purpose
<h1> Creates a heading
<p> Creates a paragraph
<br> Creates a line break
<hr> Creates a horizontal line
