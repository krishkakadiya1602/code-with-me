HTML Basic Tags

Learn the most commonly used HTML tags with simple examples.

⭐ Main Points

  • HTML tags are used to create the structure of a webpage.
  • Most HTML elements have an opening and closing tag.
  • <h1> to <h6> are used for headings.
  • <p> is used for paragraphs.
  • <br> creates a line break.
  • <hr> creates a horizontal line.
  • <strong> and <b> are used for bold text.
  • <i> and <em> are used for italic/emphasized text.

1. HTML Heading Tags

HTML provides six heading tags from <h1> to <h6>.

<h1> is the largest heading and <h6> is the smallest heading.

Example:

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
Output:

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

2. Paragraph Tag <p>

The <p> tag is used to create paragraphs in HTML.

Example:

<p>This is my first paragraph.</p>

<p>This is my second paragraph.</p>
Output:

This is my first paragraph.

This is my second paragraph.

3. Line Break Tag <br>

The <br> tag is used to create a line break.

Example:

<p>
Hello World!<br>
Welcome to Code With Me.
</p>
Output:

Hello World!
Welcome to Code With Me.

4. Horizontal Line Tag <hr>

The <hr> tag creates a horizontal line on a webpage.

Example:

<h2>HTML Course</h2>

<hr>

<p>Learn HTML step by step.</p>
Output:

HTML Course

Learn HTML step by step.

5. Bold Tag <b>

The <b> tag makes text bold.

Example:

<p>This is <b>bold text</b>.</p>
Output:

This is bold text.

6. Strong Tag <strong>

The <strong> tag indicates that the text is important.

Example:

<p>
<strong>Important information</strong>
</p>
Output:

Important information

7. Italic Tag <i>

The <i> tag displays text in italic style.

Example:

<p>
This is <i>italic text</i>.
</p>
Output:

This is italic text.

8. Emphasis Tag <em>

The <em> tag is used to emphasize text.

Example:

<p>
This is <em>emphasized text</em>.
</p>
Output:

This is emphasized text.

9. Underline Tag <u>

The <u> tag underlines text.

Example:

<p>
This is <u>underlined text</u>.
</p>
Output:

This is underlined text.

10. Small Text Tag <small>

The <small> tag displays smaller text.

Example:

<p>
Normal text
<small>Small text</small>
</p>
Output:

Normal text Small text

11. Mark Tag <mark>

The <mark> tag highlights text.

Example:

<p>
Learn <mark>HTML</mark> easily.
</p>
Output:

Learn HTML easily.

12. Deleted Text Tag <del>

The <del> tag represents deleted text.

Example:

<p>
Old Price: <del>₹1000</del>
</p>
Output:

Old Price: ₹1000

13. Inserted Text Tag <ins>

The <ins> tag represents inserted text.

Example:

<p>
New Price:
<ins>₹800</ins>
</p>
Output:

New Price: ₹800

14. Subscript Tag <sub>

The <sub> tag displays text below the normal line.

Example:

<p>
H<sub>2</sub>O
</p>
Output:

H2O

15. Superscript Tag <sup>

The <sup> tag displays text above the normal line.

Example:

<p>
X<sup>2</sup>
</p>
Output:

X2

16. Preformatted Text <pre>

The <pre> tag displays text exactly as it is written, including spaces and line breaks.

Example:

<pre>
Hello
    Welcome
        To HTML
</pre>
Output:
Hello
    Welcome
        To HTML

17. Code Tag <code>

The <code> tag is used to represent computer code.

Example:

<p>
Use <code>console.log()</code>
in JavaScript.
</p>
Output:

Use console.log() in JavaScript.

18. Quotation Tag <q>

The <q> tag is used for short quotations.

Example:

<p>
HTML is <q>easy to learn</q>.
</p>
Output:

HTML is easy to learn.

19. Blockquote Tag <blockquote>

The <blockquote> tag is used for longer quotations.

Example:

<blockquote>
Learning HTML is the first step
towards web development.
</blockquote>
Output:
Learning HTML is the first step towards web development.

20. Abbreviation Tag <abbr>

The <abbr> tag is used for abbreviations.

Example:

<p>
<abbr title="HyperText Markup Language">
HTML
</abbr>
</p>
Output:

HTML

21. Address Tag <address>

The <address> tag is used for contact information.

Example:

<address>
Code With Me<br>
Gujarat, India
</address>
Output:
Code With Me
Gujarat, India

22. Citation Tag <cite>

The <cite> tag is used to represent the title of a work.

Example:

<p>
<cite>The Web Development Guide</cite>
is a useful book.
</p>
Output:

The Web Development Guide is a useful book.

23. Keyboard Input Tag <kbd>

The <kbd> tag represents keyboard input.

Example:

<p>
Press <kbd>Ctrl</kbd> +
<kbd>C</kbd> to copy.
</p>
Output:

Press Ctrl + C to copy.

24. Sample Output Tag <samp>

The <samp> tag represents sample output from a computer program.

Example:

<p>
<samp>Hello World!</samp>
</p>
Output:

Hello World!
