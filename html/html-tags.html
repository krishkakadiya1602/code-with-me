2. HTML Basic Tags

Learn the most important HTML tags used to create headings, paragraphs, line breaks, horizontal lines and basic webpage content.

Introduction to HTML Tags

HTML uses tags to define the structure and meaning of content on a webpage.

Tags are written inside angle brackets < >.

For example: 

<h1>Hello World</h1>

In this example, <h1> is used to create a main heading.

Remember: HTML tags tell the browser what type of content an element represents.

Opening and Closing Tags

Many HTML elements have an opening tag and a closing tag. 

<p>This is a paragraph.</p>

Here:

  • <p> is the opening tag.
  • This is a paragraph. is the content.
  • </p> is the closing tag.

1. HTML Headings

HTML provides six heading levels: <h1> through <h6>.

<h1> represents the highest level heading, while <h6> represents a lower level heading. 

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Example Output

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6
Tip: Use headings according to the structure of your content rather than choosing them only because of their visual size.

2. HTML Paragraph

The <p> tag is used to create a paragraph. 

<p>
HTML is used to create webpages.
</p>

Browsers normally display paragraphs as separate blocks of text.

Example

This is my first paragraph.

This is my second paragraph.

3. HTML Line Break

The <br> tag creates a line break within text. 

<p>
Hello<br>
Welcome to Code With Me.
</p>

Example Output

Hello
Welcome to Code With Me.

Note: The <br> element does not need a closing tag.

4. HTML Horizontal Line

The <hr> element represents a thematic break between sections of content. 

<h2>About HTML</h2>

<p>
HTML is a markup language.
</p>

<hr>

<h2>About CSS</h2>

Example Output

HTML is a markup language.

CSS is used for presentation and design.

5. HTML Comments

Comments allow developers to leave notes inside HTML source code.

Comments are not normally displayed as webpage content. 

<!-- This is an HTML comment -->

<p>Hello World</p>
Why use comments?
  • To explain code.
  • To organize large HTML files.
  • To leave notes for other developers.
  • To temporarily comment out code.

6. Basic Text Containers

HTML also provides elements for organizing and grouping content.

<div>

The <div> element is a generic container used to group content. 

<div>

    <h2>My Website</h2>

    <p>Welcome to my website.</p>

</div>

<span>

The <span> element is a generic inline container. 

<p>
This is <span>important</span> text.
</p>

Common HTML Basic Tags

<h1> Main heading <h1>Title</h1>
<p> Paragraph <p>Hello</p>

<hr> Thematic break <hr>
<!-- --> Comment <!-- Note -->

Complete Basic HTML Example

The following example combines several basic HTML tags together. 

<!DOCTYPE html>

<html>

<head>

    <title>My Website</title>

</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        This is my first webpage.
    </p>

    <hr>

    <h2>About Me</h2>

    <p>
        I am learning HTML.
    </p>

    <p>
        HTML is easy to learn.<br>
        Practice makes you better.
    </p>

</body>

</html>

Common Mistakes

  1. Forgetting the closing tag where one is required.
  2. Incorrectly nesting elements.
  3. Using too many line breaks instead of structuring content with appropriate elements.
  4. Forgetting to close quotation marks around attribute values.
  5. Writing tag names incorrectly.
Practice Tip: Do not only read HTML tags. Write the code yourself, run it in the browser and experiment with different values.
