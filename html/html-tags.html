2. HTML Basic Tags

Learn headings, paragraphs, line breaks, horizontal lines and other basic HTML tags.

1. HTML Headings

HTML provides six heading tags from <h1> to <h6>. 

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

2. HTML Paragraph

The <p> tag is used to create a paragraph. 

<p>
This is my first HTML paragraph.
</p>

3. HTML Line Break

The <br> tag is used to create a line break. 

<p>
Hello<br>
Welcome to Code With Me
</p>

4. HTML Horizontal Line

The <hr> tag creates a horizontal line on the webpage. 

<h2>About HTML</h2>

<hr>

<p>
HTML is used to create web pages.
</p>

5. HTML Div

The <div> tag is used to group HTML elements together. 

<div>

    <h2>My Website</h2>

    <p>
        Welcome to my website.
    </p>

</div>

6. HTML Span

The <span> tag is used to style or group a small part of text. 

<p>
My name is
<span>Krish</span>.
</p>
