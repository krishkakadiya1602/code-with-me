HTML Projects

Practice your HTML skills by building simple real-world projects from scratch.

1. Introduction to HTML Projects

Learning HTML becomes easier when you build real projects instead of only reading theory.

HTML projects help you practice headings, paragraphs, links, images, lists, tables, forms, semantic elements and multimedia.

Tip: Start with small projects and gradually build more complete webpages.

2. Beginner HTML Projects

Project 1 - Personal Profile Page

Create a webpage containing your name, profile information, hobbies and contact details.

Project 2 - Student Resume

Create a simple resume using headings, paragraphs, lists and tables.

Project 3 - Registration Form

Build a student registration form using text fields, email, password, radio buttons, checkboxes and dropdowns.

Project 4 - Simple Portfolio

Create a portfolio webpage with About, Skills, Projects and Contact sections.

Project 5 - College Timetable

Create a weekly college timetable using HTML tables.

3. Project 1 - Personal Profile Page

In this project, we will create a basic personal profile webpage.

Complete Code

<!DOCTYPE html>

<html>

<head>

    <title>My Profile</title>

</head>

<body>

    <h1>My Profile</h1>

    <h2>About Me</h2>

    <p>
        Hello! My name is Krish.
        I am learning HTML and web development.
    </p>

    <h2>My Hobbies</h2>

    <ul>
        <li>Coding</li>
        <li>Reading</li>
        <li>Gaming</li>
    </ul>

    <h2>Contact</h2>

    <p>
        Email: example@email.com
    </p>

</body>

</html>

5. Project 3 - Registration Form

Forms are commonly used for collecting information from website users. 

<!DOCTYPE html>

<html>

<head>

    <title>Student Registration</title>

</head>

<body>

    <h1>Student Registration Form</h1>

    <form>

        <label>Full Name:</label>

        <input type="text"
               name="name"
               required>

        <br><br>


        <label>Email:</label>

        <input type="email"
               name="email"
               required>

        <br><br>


        <label>Password:</label>

        <input type="password"
               name="password"
               required>

        <br><br>


        <label>Gender:</label>

        <input type="radio"
               name="gender"
               value="male">

        Male

        <input type="radio"
               name="gender"
               value="female">

        Female

        <br><br>


        <label>Course:</label>

        <select name="course">

            <option>HTML</option>

            <option>CSS</option>

            <option>JavaScript</option>

        </select>

        <br><br>


        <button type="submit">
            Register
        </button>

    </form>

</body>

</html>

6. Project 4 - Personal Portfolio

A portfolio website can contain your introduction, skills, projects and contact information. 

<!DOCTYPE html>

<html>

<head>

    <title>My Portfolio</title>

</head>

<body>

    <header>

        <h1>My Portfolio</h1>

        <nav>

            <a href="#about">About</a>

            <a href="#skills">Skills</a>

            <a href="#projects">Projects</a>

            <a href="#contact">Contact</a>

        </nav>

    </header>


    <main>

        <section id="about">

            <h2>About Me</h2>

            <p>
                I am a student learning web development.
            </p>

        </section>


        <section id="skills">

            <h2>My Skills</h2>

            <ul>

                <li>HTML</li>

                <li>CSS</li>

                <li>JavaScript</li>

            </ul>

        </section>


        <section id="projects">

            <h2>My Projects</h2>

            <ul>

                <li>Personal Website</li>

                <li>Registration Form</li>

                <li>Student Resume</li>

            </ul>

        </section>


        <section id="contact">

            <h2>Contact Me</h2>

            <p>
                Email: example@email.com
            </p>

        </section>

    </main>


    <footer>

        <p>
            © 2026 My Portfolio
        </p>

    </footer>

</body>

</html>

10. Project Building Tips

  • Start with a simple page structure.
  • Use semantic HTML elements where appropriate.
  • Keep your HTML code properly indented.
  • Use meaningful headings.
  • Add alt text to images.
  • Use labels with form inputs.
  • Test your webpage in a browser.
  • Gradually add CSS after completing the HTML structure.
