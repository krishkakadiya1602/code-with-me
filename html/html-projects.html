HTML Projects

Practice your HTML skills by building simple real-world projects.

⭐ Main Points

  • Projects help you practice HTML concepts.
  • Start with simple projects before building larger websites.
  • Use headings, paragraphs, links, images and lists.
  • Practice forms, tables and multimedia.
  • Try changing the examples and creating your own designs.
  • Use CSS later to improve the appearance of your projects.
PROJECT 1

👤 Personal Profile Page

Create a simple personal profile page containing your name, introduction, skills and hobbies.

What You Will Practice:

  • Headings
  • Paragraphs
  • Lists
  • Horizontal line
Example Code:
<!DOCTYPE html>

<html>

<head>
    <title>My Profile</title>
</head>

<body>

    <h1>My Profile</h1>

    <hr>

    <h2>About Me</h2>

    <p>
        Hello! My name is Krish.
        I am learning web development.
    </p>

    <h2>My Skills</h2>

    <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
    </ul>

    <h2>My Hobbies</h2>

    <p>Coding and learning new technologies.</p>

</body>

</html>
Output:

My Profile

About Me

Hello! My name is Krish. I am learning web development.

My Skills

  • HTML
  • CSS
  • JavaScript

⭐ Main Points

  • Good beginner project.
  • Practice basic HTML tags.

PROJECT 5

📝 Registration Form

Build a student registration form using different HTML form elements.

What You Will Practice:

  • Input
  • Label
  • Radio buttons
  • Checkboxes
  • Select
  • Textarea
  • Submit button
Example Code:
<h1>Registration Form</h1>

<form>

    <label>Name:</label>

    <input type="text">

    <br><br>

    <label>Email:</label>

    <input type="email">

    <br><br>

    <label>Gender:</label>

    <input type="radio" name="gender">
    Male

    <input type="radio" name="gender">
    Female

    <br><br>

    <label>Course:</label>

    <select>

        <option>HTML</option>
        <option>CSS</option>
        <option>JavaScript</option>

    </select>

    <br><br>

    <textarea
        placeholder="Your message">
    </textarea>

    <br><br>

    <input type="submit"
           value="Register">

</form>
Output:

Registration Form





Male Female





⭐ Main Points

  • Combines many form elements.
  • Excellent practice project for HTML Forms.
PROJECT 6

📊 Student Marks Table

Create a table to display student names, subjects and marks.

What You Will Practice:

  • Table
  • Table rows
  • Table headers
  • Table data
Example Code:

<table border="1">

        <th>HTML</th>
        <th>CSS</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>85</td>
        <td>80</td>
    </tr>

    <tr>
        <td>Amit</td>
        <td>90</td>
        <td>88</td>
    </tr>

</table>
Output:

Student Marks

Name HTML CSS
Rahul 85 80
Amit 90 88

⭐ Main Points

  • Practice HTML table structure.
  • Can be expanded with more subjects.
PROJECT 7

🖼️ Photo Gallery

Create a simple photo gallery using multiple images.

What You Will Practice:

  • Images
  • Image attributes
  • Links
  • Figure captions
Example Code:
<h1>My Photo Gallery</h1>

<figure>

    <img src="photo1.jpg"
         alt="Nature"
         width="250">

    <figcaption>
        Nature
    </figcaption>

</figure>

<figure>

    <img src="photo2.jpg"
         alt="Mountain"
         width="250">

    <figcaption>
        Mountain
    </figcaption>

</figure>
Output:

My Photo Gallery

Add your own images using the <img> element.

⭐ Main Points

  • Practice displaying multiple images.
  • Use meaningful alt text.
