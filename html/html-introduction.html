HTML Introduction

Learn the basics of HTML and start building websites.

What is HTML?

HTML stands for HyperText Markup Language.

HTML is the standard markup language used to create and structure web pages.

HTML tells the browser what content should appear on a webpage.

Important: HTML is not a programming language. It is a markup language used to structure web content.

What Can HTML Do?

HTML can be used to create different types of content on a webpage.

  • Headings
  • Paragraphs
  • Links
  • Images
  • Lists
  • Tables
  • Forms
  • Videos and Audio
  • Buttons

Basic HTML Document

A basic HTML document looks like this: 

<!DOCTYPE html>

<html>

<head>

    <title>
        My First Webpage
    </title>

</head>

<body>

    <h1>
        Hello World
    </h1>

    <p>
        Welcome to my website.
    </p>

</body>

</html>

HTML Document Structure

<!DOCTYPE html>

This declaration tells the browser that the document is an HTML5 document.

<html>

This is the root element of the HTML document.

<head>

The head contains information about the webpage such as title, metadata, CSS and other resources.

<body>

The body contains the visible content of the webpage.

HTML Tags

HTML uses tags to define elements on a webpage.

For example: 

<h1>
    Hello World
</h1>

Here, <h1> is a heading tag.

HTML Elements

An HTML element normally contains an opening tag, content and a closing tag. 

<p>
    This is a paragraph.
</p>

The complete structure above is called an HTML element.

HTML Attributes

Attributes provide additional information about HTML elements. 

<a href="https://example.com">
    Visit Website
</a>

In this example, href is an attribute.
