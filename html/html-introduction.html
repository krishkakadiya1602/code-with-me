What is HTML?

HTML stands for HyperText Markup Language. It is used to create and structure content on web pages.

HTML uses different elements and tags to tell the browser how the content should be displayed.

Basic Structure of HTML

Every HTML document generally contains a basic structure. The main parts are:

1. DOCTYPE

The <!DOCTYPE html> declaration tells the browser that the document is an HTML5 document.

2. HTML Element

The <html> element is the root element of an HTML document.

3. Head

The <head> section contains information about the webpage such as title and meta information.

4. Body

The <body> section contains the visible content of the webpage.

What are HTML Elements?

HTML elements are used to define different parts of a webpage.

For example:

<h1> is used for a main heading.

<p> is used for a paragraph.

<br> is used to create a line break.
