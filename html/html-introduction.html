What is HTML?

HTML stands for HyperText Markup Language. HTML is the standard markup language used to create and structure web pages.

HTML tells the browser how the content of a webpage should be structured.

Simple Definition: HTML is used to create the structure of a website.

Why Learn HTML?

HTML is one of the first technologies you should learn if you want to become a web developer.

  • HTML creates the structure of websites.
  • HTML is easy for beginners to learn.
  • HTML works together with CSS and JavaScript.
  • HTML is used on almost every website.
  • HTML is the foundation of web development.

Basic HTML Structure

Every basic HTML page normally contains elements such as the document type, html, head and body.

<!DOCTYPE html> <html> <head> <title>My Website</title> </head> <body> <h1>Hello World!</h1> <p>Welcome to my website.</p> </body> </html>

Important HTML Terms

1. HTML Tag

A tag is written using angle brackets.

<h1>Hello World</h1>

2. HTML Element

An HTML element generally consists of an opening tag, content and a closing tag.

<p>This is a paragraph.</p>

3. HTML Attribute

Attributes provide additional information about an HTML element.

<a href="https://example.com"> Visit Website </a>
