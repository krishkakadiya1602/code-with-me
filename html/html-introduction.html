HTML Introduction

Learn the basics of HTML and understand how web pages are created.

1. What is HTML?

HTML stands for HyperText Markup Language.

HTML is the standard markup language used to create and structure web pages.

HTML tells the browser how different parts of a webpage should be structured.

Example

<h1>Hello World</h1>

<p>Welcome to my website.</p>

Output

Hello World

Welcome to my website.

2. Why Do We Use HTML?

HTML is used to create the basic structure of websites.

HTML can be used to create:

  • Headings
  • Paragraphs
  • Links
  • Images
  • Lists
  • Tables
  • Forms
  • Audio and Video
  • Webpage layouts

3. Basic HTML Document Structure

A basic HTML document contains several important parts.

Example

<!DOCTYPE html>

<html>

<head>

    <title>My Website</title>

</head>

<body>

    <h1>Hello World</h1>

    <p>This is my webpage.</p>

</body>

</html>

Output

Hello World

This is my webpage.

4. <!DOCTYPE html>

<!DOCTYPE html> tells the browser that the document uses modern HTML.

Example

<!DOCTYPE html>

⭐ Main Point

  • It should normally be the first line of an HTML document.

5. HTML Element

An HTML element generally consists of an opening tag, content and a closing tag.

Example

<p>
    Hello World
</p>

Here <p> is the opening tag and </p> is the closing tag.

6. HTML Tags

HTML tags are keywords enclosed inside angle brackets.

Examples

<h1>
<p>
<a>
<img>
<table>
<form>

7. HTML Headings

HTML provides six levels of headings, from <h1> to <h6>.

Example

<h1>Heading 1</h1>

<h2>Heading 2</h2>

<h3>Heading 3</h3>

<h4>Heading 4</h4>

<h5>Heading 5</h5>

<h6>Heading 6</h6>

Output

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

8. HTML Paragraph

The <p> element is used to create a paragraph.

Example

<p>
    HTML is easy to learn.
</p>

Output

HTML is easy to learn.

9. HTML Attributes

Attributes provide additional information about HTML elements.

Example

<a href="https://example.com">
    Visit Website
</a>

Here href is an attribute.

10. HTML Comments

Comments are used to write notes inside HTML code. They are not displayed on the webpage.

Example

<!-- This is an HTML comment -->

<p>Hello World</p>

11. HTML Links

The <a> element is used to create hyperlinks.

Example

<a href="https://www.google.com">
    Visit Google
</a>

Output

Visit Google

12. HTML Images

The <img> element is used to display images.

Example

<img src="image.jpg"
     alt="My Image"
     width="300">

Important Attributes

  • src - image location
  • alt - alternative text
  • width - image width
  • height - image height

13. HTML Lists

HTML provides ordered and unordered lists.

Unordered List

<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>

Output

  • HTML
  • CSS
  • JavaScript

14. HTML Forms

HTML forms are used to collect information from users.

Example

<form>

    <label>Name:</label>

    <input type="text">

    <button>
        Submit
    </button>

</form>

Output

15. HTML Semantic Elements

Semantic elements describe the meaning and purpose of their content.

Examples

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>

16. HTML with CSS

HTML creates the structure of a webpage, while CSS is used to style that structure.

Example

<h1 style="color: blue;">
    Welcome
</h1>

Output

Welcome

17. HTML with JavaScript

JavaScript can be used to add behavior and interactivity to HTML pages.

Example

<button onclick="alert('Hello!')">

    Click Me

</button>

Output

18. How Does HTML Work?

When you create an HTML file and open it in a web browser, the browser reads the HTML code and renders the webpage.

Simple Process

  1. Write HTML code.
  2. Save the file with .html extension.
  3. Open the file in a web browser.
  4. Browser interprets the HTML.
  5. Webpage appears on the screen.

19. HTML File Extension

HTML files normally use the .html extension.

Examples

index.html

about.html

contact.html

html-introduction.html

⭐ Main Points

  • HTML stands for HyperText Markup Language.
  • HTML is used to create the structure of webpages.
  • HTML uses tags and elements.
  • HTML attributes provide additional information about elements.
  • <h1> to <h6> are heading elements.
  • <p> creates paragraphs.
  • <a> creates links.
  • <img> displays images.
  • HTML files normally use the .html extension.
  • CSS is used for styling and JavaScript is used for webpage behavior.

21. HTML Quick Reference

Tag Purpose

<head> Document information
<title> Page title
<body> Visible page content
<h1> Main heading
<p> Paragraph
<a> Link
<img> Image
<ul> Unordered list
<form> Form
