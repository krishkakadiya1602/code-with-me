1. HTML Introduction

Learn HTML from the beginning and understand how web pages are created, structured and displayed in a web browser.

What is HTML?

HTML stands for HyperText Markup Language. HTML is the standard markup language used to structure content on web pages.

HTML allows developers to define different types of content such as headings, paragraphs, images, links, lists, tables, forms, videos and more.

Important: HTML is a markup language, not a programming language. HTML describes the structure and meaning of web content.

Why Do We Need HTML?

A web browser needs a structured document to understand what content should appear on a webpage.

HTML provides that structure.

HTML can be used to create:

  • Headings
  • Paragraphs
  • Links
  • Images
  • Lists
  • Tables
  • Forms
  • Audio and video
  • Navigation menus
  • Webpage sections

Brief History of HTML

HTML was created for sharing and linking documents over the early World Wide Web.

Over time, HTML evolved and gained support for more features and richer web applications.

Important stages

  • Early HTML provided basic document structure and hyperlinks.
  • Later versions introduced additional elements and improved capabilities.
  • HTML5 introduced many modern elements and APIs used by today's web applications.
Today: Modern HTML is developed as a living standard and works together with CSS and JavaScript to build modern websites and web applications.

How Does HTML Work?

When you create an HTML file, the browser reads the HTML markup and builds a representation of the document.

The browser then uses that structure to display the webpage.

Basic process

  1. You create an HTML file.
  2. The browser loads the file.
  3. The browser parses the HTML.
  4. The browser creates the document structure.
  5. The browser displays the content.

Basic HTML Document Structure

A typical HTML document contains a document type declaration, an HTML root element, a head section and a body section.

Basic Structure:

Understanding DOCTYPE

The declaration <!DOCTYPE html> tells the browser that the document uses the modern HTML standard.

It appears at the beginning of an HTML document.

The HTML Element

The <html> element is the root element of the document.

Other HTML elements are placed inside it. 

<html>

    ...

</html>

The <head> Section

The head section contains information about the document that is generally not displayed as the main page content.

Common elements inside head:

  • <title>
  • <meta>
  • <link>
  • <style>
  • <script>

The <body> Section

The body contains the content that users normally see and interact with on the webpage.

Examples include headings, paragraphs, images, buttons, links, forms and other visible content.

HTML Tags

HTML uses tags to describe elements in a document.

For example: 

<h1>Welcome</h1>

<p>This is a paragraph.</p>

Here, <h1> represents a heading element and <p> represents a paragraph element.

HTML Elements

An HTML element generally consists of an opening tag, content and a closing tag. 

<p>Hello World</p>

In this example:

  • <p> is the opening tag.
  • Hello World is the content.
  • </p> is the closing tag.

HTML Attributes

Attributes provide additional information about an HTML element. 

<a href="https://example.com">
    Visit Website
</a>

Here, href is an attribute of the anchor element.

What is HTML5?

HTML5 is the modern generation of HTML and includes many elements and capabilities useful for modern websites and applications.

Examples of modern HTML elements:

  • <header>
  • <nav>
  • <main>
  • <section>
  • <article>
  • <aside>
  • <footer>
  • <video>
  • <audio>
  • <canvas>

Semantic HTML

Semantic elements communicate the meaning or role of content more clearly. 

<header>

<nav>

<main>

<section>

<article>

<footer>

Semantic HTML can make documents easier for people, search engines and assistive technologies to understand.

HTML, CSS and JavaScript

Modern websites commonly use three core technologies.

Technology Main Purpose
HTML Structure and content
CSS Design and presentation
JavaScript Behavior and interactivity
Think of it simply as:

HTML = Structure
CSS = Design
JavaScript = Behavior

What is the DOM?

DOM stands for Document Object Model.

When a browser loads an HTML document, it creates an object-based representation of the document. JavaScript can use this representation to read and modify webpage content and structure. 

HTML Document
      ↓
Browser parses HTML
      ↓
DOM
      ↓
JavaScript can interact with it

HTML and SEO

HTML structure can also provide important information that helps search engines understand webpage content.

Examples:

  • Meaningful page titles
  • Proper heading structure
  • Descriptive links
  • Semantic HTML
  • Alternative text for meaningful images

HTML and Accessibility

Accessible HTML helps people using assistive technologies navigate and understand webpages.

Using appropriate elements, labels, headings, link text and image alternative text can improve the accessibility of a webpage.

Common Beginner Mistakes

  1. Forgetting to close elements when a closing tag is required.
  2. Incorrectly nesting HTML elements.
  3. Using headings only for visual size instead of document structure.
  4. Forgetting meaningful alternative text for informative images.
  5. Writing incorrect file paths for links and images.
  6. Forgetting the viewport meta tag for responsive pages.
Tip: Always keep your HTML properly structured and indented. Clean HTML is easier to read, debug and maintain.
