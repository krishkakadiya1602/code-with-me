HTML Attributes

Learn how to add extra information and properties to HTML elements using attributes.

1. What are HTML Attributes?

HTML attributes provide additional information about HTML elements.

Attributes are normally written inside the opening tag.

Syntax

<element attribute="value">
    Content
</element>

Example

<p title="This is a paragraph">
    Hello World
</p>

Output

Hello World

Hover your mouse over the text.

2. href Attribute

The href attribute specifies the destination of a link.

Example

<a href="https://www.google.com">
    Visit Google
</a>

Output

Visit Google

3. src Attribute

The src attribute specifies the path or URL of an external resource such as an image.

Example

<img src="image.jpg"
     alt="My Image">

Output

The browser loads the image from the path specified in src.

4. alt Attribute

The alt attribute provides alternative text for an image.

Example

<img src="logo.png"
     alt="Code With Me Logo">

Output

If the image cannot load, the alt text can provide a text alternative.

5. title Attribute

The title attribute provides additional information about an element.

Example

<p title="Welcome Message">
    Welcome to Code With Me
</p>

Output

Welcome to Code With Me

Hover over the text to see the title.

6. style Attribute

The style attribute is used to apply inline CSS to an HTML element.

Example

<p style="color: blue;">
    Blue Text
</p>

Output

Blue Text

7. id Attribute

The id attribute gives a unique identifier to an HTML element.

Example

<p id="intro">
    This is the introduction.
</p>

Output

This is the introduction.

8. class Attribute

The class attribute is used to assign one or more classes to an element.

Example

<p class="highlight">
    Important Text
</p>

Output

Important Text

9. width Attribute

The width attribute can specify the width of certain HTML elements such as images.

Example

<img src="image.jpg"
     width="300"
     alt="Example Image">

Output

Width: 300px

10. height Attribute

The height attribute can specify the height of certain HTML elements such as images.

Example

<img src="image.jpg"
     height="200"
     alt="Example Image">

Output

Height: 200px

11. target Attribute

The target attribute specifies where a linked document should open.

Example

<a href="https://www.google.com"
   target="_blank">

    Open Google

</a>

Output

Open Google in New Tab

12. disabled Attribute

The disabled attribute disables an HTML form control.

Example

<button disabled>
    Disabled Button
</button>

Output

13. readonly Attribute

The readonly attribute makes an input value uneditable by the user.

Example

<input type="text"
       value="Code With Me"
       readonly>

Output

14. required Attribute

The required attribute specifies that a form field must be filled before submitting.

Example

<input type="text"
       required>

Output

15. placeholder Attribute

The placeholder attribute displays a temporary hint inside an input field.

Example

<input type="text"
       placeholder="Enter your name">

Output

16. value Attribute

The value attribute specifies the initial value of an input element.

Example

<input type="text"
       value="Krish">

Output

17. lang Attribute

The lang attribute specifies the language of the document or element.

Example

<html lang="en">

Output

lang="en" specifies English as the document language.

18. data-* Attributes

Custom data-* attributes allow developers to store custom data on HTML elements.

Example

<button data-course="HTML"
        data-level="beginner">

    Learn HTML

</button>

Output

19. draggable Attribute

The draggable attribute specifies whether an element can be dragged.

Example

<p draggable="true">
    Drag this text
</p>

Output

Try dragging this text.

20. hidden Attribute

The hidden attribute hides an element from the rendered page.

Example

<p hidden>
    This text is hidden.
</p>

Output

The hidden paragraph is not displayed.

21. Boolean Attributes

Boolean attributes represent true/false states. Their presence generally means true.

Examples

<input type="checkbox" checked>

<input type="text" readonly>

<button disabled>
    Button
</button>

Output





22. Multiple Attributes

An HTML element can contain multiple attributes.

Example

<img src="logo.png"
     alt="Code With Me Logo"
     width="200"
     height="100"
     title="Code With Me">

Important

Each attribute provides different information or behavior for the element.

23. Attribute Values

Most attributes use a value after an equals sign.

Example

<p class="text">
    Hello
</p>

Here:

  • class = attribute
  • "text" = attribute value

24. Global Attributes

Global attributes can generally be used on many HTML elements.

Common Global Attributes

id
class
style
title
lang
hidden
data-*
tabindex
contenteditable
draggable

⭐ Main Points

  • Attributes provide additional information about HTML elements.
  • Attributes are written inside the opening tag.
  • Most attributes use the format attribute="value".
  • href is commonly used with links.
  • src specifies a resource URL.
  • alt provides alternative text for images.
  • id identifies an element.
  • class assigns one or more classes.
  • style adds inline CSS.
  • Boolean attributes such as disabled, checked and required represent states.
