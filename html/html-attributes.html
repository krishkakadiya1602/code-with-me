10. HTML Attributes

Learn how HTML attributes provide additional information about HTML elements.

What are HTML Attributes?

HTML attributes provide additional information about HTML elements.

Attributes are written inside the opening tag and normally follow this structure: 

<element attribute="value">

    Content

</element>
Example: 
<a href="https://example.com">
    Visit Website
</a>

Here, href is an attribute and https://example.com is its value.

HTML Attribute Syntax

The general syntax of an HTML attribute is: 

<element attribute="value">

For example: 

<img src="photo.jpg" alt="My Photo">
  • img → HTML element
  • src → Attribute
  • "photo.jpg" → Attribute value
  • alt → Another attribute

1. href Attribute

The href attribute specifies the destination of a link. 

<a href="https://www.google.com">
    Visit Google
</a>
Visit Google

2. src Attribute

The src attribute specifies the source of an external resource such as an image. 

<img src="image.jpg" alt="Example Image">

The browser uses the value of src to locate the image.

3. alt Attribute

The alt attribute provides alternative text for an image. 

<img
    src="student.jpg"
    alt="Student learning HTML">
Tip: Use meaningful alt text for images. It can help users who cannot see the image and can also provide useful context if an image cannot load.

4. title Attribute

The title attribute provides additional information about an element. 

<p title="This is additional information">

    Move your mouse over this text.

</p>

Move your mouse over this text.

5. id Attribute

The id attribute gives an HTML element a unique identifier. 

<p id="intro">

    This is an introduction.

</p>

An id can be used with CSS, JavaScript and links.

6. class Attribute

The class attribute assigns one or more class names to an element. 

<p class="highlight">

    This text is highlighted.

</p>

This text has a class named highlight.

7. style Attribute

The style attribute allows you to apply CSS directly to an HTML element. 

<p style="color: blue;">

    This text is blue.

</p>

This text is blue.

8. target Attribute

The target attribute specifies where a linked document should open. 

<a
    href="https://example.com"
    target="_blank">

    Open Website

</a>

Common value:

  • _blank → Opens the link in a new browsing context.
  • _self → Opens the link in the current browsing context.

9. width and height Attributes

The width and height attributes can specify dimensions for certain HTML elements. 

<img
    src="image.jpg"
    alt="Example"
    width="300"
    height="200">

10. Common Input Attributes

HTML form elements support many useful attributes. 

<input
    type="text"
    name="username"
    id="username"
    placeholder="Enter your name"
    required>
Attribute Purpose
type Specifies the type of input.
name Gives a name to the form control.
placeholder Displays a hint inside the input.
required Makes the field required.
value Specifies an initial value.
disabled Disables the form control.
readonly Makes the value read-only.

11. placeholder Attribute

The placeholder attribute displays a short hint inside an input field. 

<input
    type="text"
    placeholder="Enter your name">

12. required Attribute

The required attribute specifies that a value must be entered before the form can be submitted. 

<input
    type="email"
    required>

13. disabled Attribute

The disabled attribute disables an element. 

<input
    type="text"
    value="Disabled field"
    disabled>

14. readonly Attribute

The readonly attribute makes the value of a form control read-only. 

<input
    type="text"
    value="You cannot edit this"
    readonly>

Using Multiple Attributes

An HTML element can have multiple attributes. 

<input
    type="text"
    id="username"
    class="input-box"
    name="username"
    placeholder="Enter username"
    required>

Here, the input element has several attributes:

  • type
  • id
  • class
  • name
  • placeholder
  • required

Boolean Attributes

Some HTML attributes are boolean attributes. Their presence represents a true state.

Examples include:

  • required
  • disabled
  • readonly
  • checked
  • multiple
  • autofocus
<input
    type="checkbox"
    checked>

Custom data-* Attributes

HTML allows custom data attributes that begin with data-.

They can be useful for storing custom information that scripts can access. 

<button
    data-course="html"
    data-level="beginner">

    Learn HTML

</button>

HTML Attribute Best Practices

  1. Use meaningful attribute values.
  2. Use descriptive alt text for images.
  3. Use unique values for id attributes within a page.
  4. Use class when the same styling or behavior applies to multiple elements.
  5. Use quotes around attribute values.
  6. Use the correct attribute for the correct HTML element.
  7. Avoid unnecessary attributes.

Common Mistakes

  • Forgetting quotation marks around attribute values.
  • Using duplicate id values on the same page.
  • Forgetting the alt attribute on important images.
  • Typing attribute names incorrectly.
  • Putting attributes outside the opening HTML tag.
Incorrect: 
<p> id="intro" Hello </p>
Correct: 
<p id="intro">
    Hello
</p>

HTML Attributes Summary

HTML attributes provide additional information about HTML elements.

  • href → Link destination
  • src → Resource source
  • alt → Alternative image text
  • id → Unique identifier
  • class → Class name
  • style → Inline styling
  • title → Additional information
  • target → Link browsing target
  • required → Required form field
  • placeholder → Input hint
Remember: Attributes are written inside the opening HTML tag and provide additional information or behavior for an element.
