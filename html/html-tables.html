7. HTML Tables

Learn how to create and style tables in HTML

What are HTML Tables?

HTML tables are used to display data in rows and columns.

Tables are useful for displaying information such as:

  • Student marks
  • Product information
  • Employee details
  • Prices
  • Schedules
  • Statistics

A basic HTML table is created using the <table> element.

1. Basic HTML Table

The basic structure of a table contains rows and cells. 

<table>

    <tr>

        <td>HTML</td>
        <td>CSS</td>

    </tr>

    <tr>

        <td>JavaScript</td>
        <td>Python</td>

    </tr>

</table>

2. <tr> Table Row

The <tr> element creates a table row. 

<tr>

    <td>HTML</td>
    <td>CSS</td>

</tr>

Every row in a table is normally created using <tr>.

3. <td> Table Data

The <td> element defines a normal data cell. 

<td>HTML</td>
HTML CSS
JavaScript Python

4. <th> Table Header

The <th> element defines a header cell. 

<tr>

    <th>Name</th>
    <th>Age</th>

</tr>
Name Age
Rahul 20
Priya 21

6. Adding Borders with CSS

CSS is commonly used to add borders to tables. 

table,
th,
td {

    border: 1px solid black;

}

To combine adjacent borders, use: 

table {

    border-collapse: collapse;

}
Tip: Modern HTML websites normally use CSS for table styling instead of old HTML presentation attributes.

7. <caption> Tag

The <caption> element adds a title or caption to a table. 

<table>

    <caption>
        Student Marks
    </caption>

    ...

</table>
Student Marks
Name Marks
Amit 95

8. <thead> Element

The <thead> element groups the header rows of a table. 

<table>

    <thead>

        <tr>

            <th>Name</th>
            <th>Marks</th>

        </tr>

    </thead>

</table>

9. <tbody> Element

The <tbody> element groups the main data rows of a table. 

<tbody>

    <tr>

        <td>Rahul</td>
        <td>90</td>

    </tr>

</tbody>

10. <tfoot> Element

The <tfoot> element groups footer rows of a table. 

<tfoot>

    <tr>

        <td>Total</td>
        <td>270</td>

    </tr>

</tfoot>

12. colspan

The colspan attribute allows one cell to span multiple columns. 

<tr>

    <td colspan="2">
        Total
    </td>

</tr>

13. rowspan

The rowspan attribute allows one cell to span multiple rows. 

<td rowspan="2">
    Web Development
</td>
Course Student

14. Aligning Table Content with CSS

CSS can be used to control the alignment of table content. 

th,
td {

    text-align: center;

}

Other common values include:

  • left
  • center
  • right

15. Table Width

CSS can control the width of a table. 

table {

    width: 100%;

}

Using width: 100% allows the table to use the available container width.

16. Responsive Tables

Tables can become difficult to view on small screens when they contain many columns.

A common solution is to allow horizontal scrolling. 

.table-container {

    overflow-x: auto;

}

Then place your table inside: 

<div class="table-container">

    <table>

        ...

    </table>

</div>
This technique helps tables remain usable on mobile devices.

17. Important HTML Table Elements

Element Purpose
<table> Creates a table
<tr> Creates a table row
<th> Creates a header cell
<td> Creates a data cell
<caption> Adds a table caption
<thead> Groups header rows
<tbody> Groups main data rows
<tfoot> Groups footer rows

18. colspan vs rowspan

Attribute Purpose
colspan Makes a cell span multiple columns
rowspan Makes a cell span multiple rows

19. HTML Table Best Practices

  • Use tables for tabular data.
  • Use <th> for table headings.
  • Use <caption> when a table needs a descriptive title.
  • Use <thead>, <tbody> and <tfoot> to organize larger tables.
  • Use CSS for visual styling.
  • Make wide tables usable on small screens.

22. Common Mistakes

Mistake 1: Forgetting <tr>

Table cells should normally be placed inside table rows. 

<table>

    <td>HTML</td>

</table>

Correct: 

<table>

    <tr>

        <td>HTML</td>

    </tr>

</table>

Mistake 2: Mixing Up colspan and rowspan

Remember:

  • colspan → spans columns
  • rowspan → spans rows

Mistake 3: Using Tables for Page Layout

Tables should generally be used for tabular data rather than building the overall layout of a webpage.

23. HTML Tables Summary

In this lesson you learned how to create and organize tables using HTML.

  • <table> – Creates a table
  • <tr> – Creates a row

  • <thead> – Groups table headers
  • <tbody> – Groups table body

  • rowspan – Spans rows
