HTML Tables

Learn how to create and design tables using HTML.

⭐ Main Points

  • The <table> tag creates an HTML table.
  • The <tr> tag creates a table row.
  • The <th> tag creates a table header cell.
  • The <td> tag creates a normal table cell.
  • The border property can visually separate table cells.
  • colspan can combine multiple columns.
  • rowspan can combine multiple rows.
  • <caption> adds a table caption.
  • <thead>, <tbody> and <tfoot> organize table sections.
  • CSS can be used to make tables responsive and attractive.

1. HTML Table

The <table> element is used to create a table in HTML.

Example

<table border="1">

    <tr>
        <td>HTML</td>
        <td>CSS</td>
    </tr>

</table>

Output

HTML CSS

2. Table Row - <tr>

The <tr> element defines a row inside an HTML table.

Example

<table>

    <tr>
        <td>HTML</td>
        <td>CSS</td>
    </tr>

</table>

Output

HTML CSS

3. Table Header - <th>

The <th> element defines a header cell in a table.

Example

<table border="1">

    <tr>

        <th>Name</th>
        <th>Age</th>

    </tr>

</table>

Output

Name Age

4. Table Data - <td>

The <td> element defines a normal data cell in a table.

Example

<table border="1">

    <tr>

        <td>Krish</td>
        <td>20</td>

    </tr>

</table>

Output

Krish 20

5. Complete Table

A basic table usually contains rows, header cells and data cells.

Example

<table border="1">

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>HTML</td>
    </tr>

</table>

Output

Name Course
Rahul HTML

6. Table Border

CSS can be used to add borders to tables, rows and cells.

Example

<table style="border-collapse:collapse;">

    <tr>

        <td style="border:1px solid black;">
            HTML
        </td>

        <td style="border:1px solid black;">
            CSS
        </td>

    </tr>

</table>

Output

HTML CSS

7. Table Caption

The <caption> element adds a title or caption to a table.

Example

<table border="1">

    <caption>
        Student Information
    </caption>

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

</table>

Output

Student Information
Name Course

8. Colspan

The colspan attribute allows a cell to span across multiple columns.

Example

<table border="1">

    <tr>

        <th colspan="2">
            Student Details
        </th>

    </tr>

    <tr>

        <td>Krish</td>
        <td>HTML</td>

    </tr>

</table>

Output

Student Details
Krish HTML

9. Rowspan

The rowspan attribute allows a cell to span across multiple rows.

Example

<table border="1">

    <tr>

        <th rowspan="2">
            Student
        </th>

        <td>HTML</td>

    </tr>

    <tr>

        <td>CSS</td>

    </tr>

</table>

Output

Student HTML
CSS

10. Table Head - <thead>

The <thead> element groups the header rows of a table.

Example

<table>

    <thead>

        <tr>
            <th>Name</th>
            <th>Marks</th>
        </tr>

    </thead>

</table>

Output

Name Marks

11. Table Body - <tbody>

The <tbody> element groups the main data rows of a table.

Example

<table>

    <tbody>

        <tr>

            <td>Krish</td>
            <td>90</td>

        </tr>

    </tbody>

</table>

Output

Krish 90

12. Table Footer - <tfoot>

The <tfoot> element groups footer rows such as totals or summaries.

Example

<table border="1">

    <tfoot>

        <tr>

            <td>Total</td>
            <td>100</td>

        </tr>

    </tfoot>

</table>

Output

Total 100

13. Cell Padding

CSS padding adds space between the content and the cell border.

Example

<td style="padding:20px;">
    HTML
</td>

Output

HTML CSS

14. Cell Text Alignment

CSS text-align can control horizontal alignment inside table cells.

Example

<td style="text-align:center;">
    HTML
</td>

Output

Center Right

15. Table Width

CSS width can control the width of a table.

Example

<table style="width:100%;">

    <tr>
        <td>HTML</td>
        <td>CSS</td>
    </tr>

</table>

Output

HTML CSS

16. Border Collapse

The CSS property border-collapse: collapse; combines adjacent table borders.

Example

<table style="border-collapse:collapse;">

    <tr>

        <td style="border:1px solid black;">
            HTML
        </td>

        <td style="border:1px solid black;">
            CSS
        </td>

    </tr>

</table>

Output

HTML CSS

17. Zebra Striped Table

CSS can create alternating row styles, often called a zebra-striped table.

Example

<style>

tr:nth-child(even) {
    background:#f1f5f9;
}

</style>

Output

Name Course
Rahul HTML
Krish CSS
Amit Python

18. Complete Structured Table

A well-structured table can use <caption>, <thead>, <tbody> and <tfoot>.

Example

<table border="1">

    <caption>
        Student Marks
    </caption>

    <thead>

        <tr>
            <th>Name</th>
            <th>Marks</th>
        </tr>

    </thead>

    <tbody>

        <tr>
            <td>Krish</td>
            <td>90</td>
        </tr>

        <tr>
            <td>Rahul</td>
            <td>85</td>
        </tr>

    </tbody>

    <tfoot>

        <tr>
            <td>Total</td>
            <td>175</td>
        </tr>

    </tfoot>

</table>

Output

Student Marks
Name Marks
Krish 90
Rahul 85
Total 175
