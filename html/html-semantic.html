HTML Semantic Elements

Learn how to use semantic HTML elements to create meaningful and well-structured web pages.

1. What are Semantic Elements?

Semantic elements are HTML elements that clearly describe the meaning and purpose of their content.

Examples include <header>, <nav>, <main>, <section>, <article>, <aside> and <footer>.

Example

<header>
    Website Header
</header>

<main>
    Main Content
</main>

<footer>
    Website Footer
</footer>

Output

Website Header
Main Content
Website Footer

2. <header> Element

The <header> element represents introductory content or a group of navigation links.

Example

<header>
    <h1>My Website</h1>
    <p>Welcome to my website</p>
</header>

Output

My Website

Welcome to my website

3. <nav> Element

The <nav> element is used for navigation links.

Example

<nav>
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
</nav>

Output

Home | About | Contact

4. <main> Element

The <main> element contains the main content of a webpage.

Example

<main>
    <h1>HTML Course</h1>
    <p>Learn HTML step by step.</p>
</main>

Output

HTML Course

Learn HTML step by step.

5. <section> Element

The <section> element represents a section of related content.

Example

<section>
    <h2>About HTML</h2>
    <p>HTML is used to create web pages.</p>
</section>

Output

About HTML

HTML is used to create web pages.

6. <article> Element

The <article> element represents independent and self-contained content.

Example

<article>
    <h2>HTML Tutorial</h2>
    <p>Learn HTML from beginner to advanced.</p>
</article>

Output

HTML Tutorial

Learn HTML from beginner to advanced.

7. <aside> Element

The <aside> element contains additional content related to the main content.

Example

<aside>
    <h3>Related Topics</h3>
    <p>HTML CSS JavaScript</p>
</aside>

Output

Related Topics

HTML, CSS, JavaScript

8. <footer> Element

The <footer> element represents the footer of a webpage or section.

Example

<footer>
    <p>© 2026 Code With Me</p>
</footer>

Output

© 2026 Code With Me

9. <figure> Element

The <figure> element is used for self-contained content such as images, diagrams or illustrations.

Example

<figure>

    <img src="image.jpg"
         alt="HTML Logo"
         width="200">

</figure>

Output

10. <figcaption> Element

The <figcaption> element provides a caption or description for a figure.

Example

<figure>

    <img src="html.jpg"
         alt="HTML">

    <figcaption>
        HTML Logo
    </figcaption>

</figure>

Output

11. <details> Element

The <details> element creates expandable content.

Example

<details>

    <summary>
        What is HTML?
    </summary>

    <p>
        HTML is the standard markup language
        for creating web pages.
    </p>

</details>

Output

What is HTML?

HTML is the standard markup language for creating web pages.

12. <summary> Element

The <summary> element defines the visible heading inside a details element.

Example

<details>

    <summary>
        Click Here
    </summary>

    <p>
        This is hidden content.
    </p>

</details>

Output

Click Here

This is hidden content.

13. <time> Element

The <time> element represents a specific time or date.

Example

<p>
    Website launched on
    <time datetime="2026-09-18">
        September 18, 2026
    </time>.
</p>

Output

Website launched on September 18, 2026 .

14. <address> Element

The <address> element is used for contact information.

Example

<address>

    Code With Me<br>
    Gujarat, India<br>
    Email: example@email.com

</address>

Output

Code With Me
Gujarat, India
Email: example@email.com

15. <search> Element

The <search> element represents a section containing search controls.

Example

<search>

    <form>

        <input type="search"
               placeholder="Search...">

        <button>
            Search
        </button>

    </form>

</search>

Output

16. Semantic vs Non-Semantic Elements

Semantic elements clearly describe their purpose, while non-semantic elements do not clearly describe the meaning of their content.

Semantic Elements

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>

Non-Semantic Elements

<div>
<span>

17. Complete Semantic HTML Layout

Semantic elements can be combined to create a complete and well-structured webpage.

Example

<header>

    <h1>My Website</h1>

    <nav>
        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Contact</a>
    </nav>

</header>


<main>

    <section>

        <h2>About Us</h2>

        <p>
            Welcome to my website.
        </p>

    </section>


    <article>

        <h2>HTML Tutorial</h2>

        <p>
            Learn HTML step by step.
        </p>

    </article>


    <aside>

        <h3>Related Topics</h3>

        <p>CSS and JavaScript</p>

    </aside>

</main>


<footer>

    <p>
        © 2026 My Website
    </p>

</footer>

18. Why Use Semantic HTML?

Semantic HTML makes your website structure easier to understand for developers, browsers and assistive technologies.

⭐ Main Points

  • Semantic elements clearly describe content.
  • They make HTML code easier to read.
  • They improve webpage structure.
  • They help accessibility.
  • They are useful for search engines.
  • Common elements include header, nav, main, section, article, aside and footer.

19. Semantic Elements Quick Reference

Element Purpose
<header> Header content
<nav> Navigation links
<main> Main webpage content
<section> Related content section
<article> Independent content
<aside> Related additional content
<footer> Footer information
<figure> Self-contained visual content
<figcaption> Figure caption
<details> Expandable content
<summary> Heading for details
<time> Date or time
<address> Contact information
