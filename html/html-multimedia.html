HTML Multimedia

Learn how to add images, audio, video and other multimedia content to your HTML website.

⭐ Main Points

  • HTML supports different types of multimedia content.
  • The <img> element displays images.
  • The <audio> element adds audio.
  • The <video> element adds video.
  • The <source> element provides media files.
  • The controls attribute displays media controls.
  • The autoplay attribute can start media automatically.
  • The loop attribute repeats media.
  • The muted attribute starts media without sound.
  • The <iframe> element can embed external content.

1. HTML Multimedia

Multimedia means adding content such as images, audio, video and external media to a webpage.

Example:
<img src="image.jpg" alt="My Image">

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

<video controls width="400">
    <source src="video.mp4" type="video/mp4">
</video>
Output:
Multimedia can include images, audio and video.

⭐ Main Points

  • Multimedia makes websites more interactive.
  • HTML provides built-in elements for media.

13. Multiple Media Sources

Multiple <source> elements can be provided so the browser can select a supported format.

The browser can choose a supported source.

⭐ Main Points

  • Multiple formats can be provided.
  • Improves browser compatibility.

14. YouTube Video using iframe

The <iframe> element can be used to embed a YouTube video on a webpage.

Example:
<iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="YouTube video"
    allowfullscreen>
</iframe>
Output:

Replace VIDEO_ID with the ID of a YouTube video to embed it.

⭐ Main Points

  • iframe embeds external content.
  • YouTube provides embed URLs for videos.

15. iframe

Output:

An external page can be displayed inside an iframe when the external site permits embedding.

⭐ Main Points

18. Track and Subtitles

The <track> element can add subtitles, captions or other timed text to a video.

Example:
<video controls width="400">

    <source src="video.mp4"
            type="video/mp4">

    <track
        src="subtitles.vtt"
        kind="subtitles"
        srclang="en"
        label="English">

</video>
Output:

A valid WebVTT subtitle file can provide captions for the video.

⭐ Main Points

  • track provides timed text.
  • Useful for subtitles and captions.
  • The subtitle file commonly uses the .vtt format.

  • Useful for mobile-friendly websites.

⭐ Main Points
