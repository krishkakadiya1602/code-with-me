What is HTML Text Formatting?

HTML provides different elements that can change the appearance, meaning, or presentation of text on a webpage.

Text formatting can be used to make text bold, italic, highlighted, underlined, deleted, inserted and more.

⭐ Main Points

  • HTML provides different elements for text formatting.
  • <b> and <strong> are used for bold text.
  • <i> and <em> are used for italic/emphasized text.
  • <mark> is used to highlight text.
  • <del> represents deleted text.
  • <ins> represents inserted text.
  • <sub> and <sup> are used for subscript and superscript.
  • <code>, <kbd>, <pre> and <samp> are useful for computer-related content.
  • <q>, <blockquote> and <cite> are useful for quotations and references.

1. Bold Text - <b>

The <b> element makes text visually bold without adding special importance.

<b>This is bold text.</b>
Output:
This is bold text.

2. Important Text - <strong>

The <strong> element indicates that the text has strong importance.

<strong>This is important text.</strong>
Output:
This is important text.

3. Italic Text - <i>

The <i> element is used for text that is visually different or in an alternate voice.

<i>This is italic text.</i>
Output:
This is italic text.

4. Emphasized Text - <em>

The <em> element adds emphasis to text.

<em>This text is emphasized.</em>
Output:
This text is emphasized.

5. Underlined Text - <u>

The <u> element represents text with an underline.

<u>This is underlined text.</u>
Output:
This is underlined text.

6. Highlighted Text - <mark>

The <mark> element highlights text for reference or attention.

<mark>This text is highlighted.</mark>
Output:
This text is highlighted.

7. Smaller Text - <small>

The <small> element represents smaller text, such as side comments.

<small>This is smaller text.</small>
Output:
This is smaller text.

8. Deleted Text - <del>

The <del> element represents text that has been deleted.

<del>Old Price: ₹500</del>
Output:
Old Price: ₹500

9. Inserted Text - <ins>

The <ins> element represents text that has been inserted.

<ins>New Price: ₹400</ins>
Output:
New Price: ₹400

10. Subscript - <sub>

The <sub> element displays text below the normal line.

H<sub>2</sub>O
Output:
H2O

11. Superscript - <sup>

The <sup> element displays text above the normal line.

X<sup>2</sup>
Output:
X2

12. Strikethrough - <s>

The <s> element represents content that is no longer accurate or relevant.

<s>Old information</s>
Output:
Old information

13. Keyboard Input - <kbd>

The <kbd> element represents keyboard input.

<p> Press <kbd>Ctrl</kbd> + <kbd>C</kbd> to copy. </p>
Output:

Press Ctrl + C to copy.

14. Computer Code - <code>

The <code> element represents a short piece of computer code.

<p> Use <code>console.log()</code> in JavaScript. </p>
Output:

Use console.log() in JavaScript.

15. Preformatted Text - <pre>

The <pre> element preserves spaces and line breaks in the text.

<pre> Hello World! Welcome to HTML. Learning is fun! </pre>
Output:
Hello World!
    Welcome to HTML.
        Learning is fun!

16. Short Quotation - <q>

The <q> element is used for a short inline quotation.

<p> He said, <q>HTML is easy to learn.</q> </p>
Output:

He said, HTML is easy to learn.

17. Block Quotation - <blockquote>

The <blockquote> element is used for longer quotations.

<blockquote> Learning HTML is the first step toward web development. </blockquote>
Output:
Learning HTML is the first step toward web development.

18. Abbreviation - <abbr>

The <abbr> element represents an abbreviation or acronym.

<p> <abbr title="HyperText Markup Language">HTML</abbr> is used to create webpages. </p>
Output:

HTML is used to create webpages.

19. Contact Information - <address>

The <address> element represents contact information for a person or organization.

<address> Code With Me Gujarat, India </address>
Output:
Code With Me
Gujarat, India

20. Citation - <cite>

The <cite> element is used to identify the title of a creative work.

<p> <cite>HTML and CSS</cite> are web technologies. </p>
Output:

HTML and CSS are web technologies.

21. Bidirectional Isolation - <bdi>

The <bdi> element isolates text that might have a different text direction.

<p> User: <bdi>Ali</bdi> </p>
Output:

User: Ali

22. Text Direction - <bdo>

The <bdo> element overrides the normal text direction.

<bdo dir="rtl"> Hello World </bdo>
Output:
Hello World

23. Variable - <var>

The <var> element represents a variable in a mathematical or programming expression.

<p> The area is <var>l</var> × <var>w</var>. </p>
Output:

The area is l × w.

24. Sample Output - <samp>

The <samp> element represents sample output from a computer program.

<p> <samp>File not found.</samp> </p>
Output:

File not found.
