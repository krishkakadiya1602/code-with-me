4. HTML Links

Learn how to create links between webpages, websites, files, email addresses and different sections of a webpage.

What are HTML Links?

Links allow users to navigate from one resource to another. In HTML, links are commonly created using the <a> element, also called the anchor element.

A link can point to another webpage, another section of the same page, a file, an email address, a phone number and more.

Basic syntax: 
<a href="URL">Link Text</a>

1. Anchor Tag - <a>

The <a> element is used to create a hyperlink. 

<a href="https://example.com">
    Visit Example
</a>

Example:

Visit Example Website

2. href Attribute

The href attribute specifies the destination of the link. 

<a href="https://example.com">
    Example
</a>

Without an appropriate destination, the link does not provide the intended navigation.

3. External Links

An external link points to a page on another website. 

<a href="https://www.google.com">
    Google
</a>

Example:

Open Google

4. Internal Links

An internal link points to another page within your own website.

For example, your website has: 

index.html
html/
    html-introduction.html
    html-tags.html
    html-text-formatting.html
    html-links.html

From html-links.html, you can link to another HTML page in the same folder. 

<a href="html-images.html">
    HTML Images
</a>
Important: File names and folder paths must match your actual website structure.

5. Open Link in a New Tab

The target="_blank" attribute requests that the linked resource open in a new browsing context, commonly a new tab. 

<a href="https://example.com"
   target="_blank"
   rel="noopener noreferrer">

    Open Example

</a>
Tip: When using target="_blank" for external links, using rel="noopener noreferrer" is a good security and privacy practice.

6. Email Links

You can use the mailto: URL scheme to create a link that opens the user's configured email application. 

<a href="mailto:example@gmail.com">
    Send Email
</a>

Example:

Send Email

7. Phone Links

The tel: URL scheme can be used to create a link for contacting a phone number. 

<a href="tel:+911234567890">
    Call Us
</a>

Example:

Call Us

8. Link to a Section of the Same Page

You can create a link that moves the user to a specific element on the same webpage.

First, give the destination element an id. 

<h2 id="contact">
    Contact Section
</h2>

Then create a link using #id. 

<a href="#contact">
    Go to Contact
</a>

Example:

Go to Contact Section

9. Download Links

The download attribute can be used to indicate that a linked resource is intended to be downloaded rather than navigated to. 

<a href="files/example.pdf"
   download>

    Download PDF

</a>
Note: The actual download behavior can depend on the browser and server response. Make sure the file path points to a real file.

10. Relative URLs

A relative URL describes a resource using a path relative to the current page.

Same folder:

<a href="html-images.html">
    HTML Images
</a>

One folder up:

<a href="../index.html">
    Home
</a>

The .. means the parent directory.

11. Absolute URLs

An absolute URL contains the complete web address of a resource. 

<a href="https://example.com/about.html">
    About
</a>

Absolute URLs are commonly used when linking to resources on other websites.

12. Image as a Link

An image can be placed inside an anchor element to make the image clickable. 

<a href="https://example.com">

    <img src="image.jpg"
         alt="Example">

</a>

In this example, clicking the image navigates to the link destination.

13. title Attribute

The title attribute can provide additional advisory information about a link. 

<a href="https://example.com"
   title="Visit Example Website">

    Example

</a>

14. Important Link Attributes

Attribute Purpose
href Specifies the destination.
target Specifies where to open the linked resource.
rel Describes the relationship between the current document and linked resource.
download Indicates that the linked resource is intended for download.
title Provides additional advisory information.

15. Good Link Text

Link text should clearly describe where the link will take the user.

Less descriptive:

<a href="html-images.html">
    Click here
</a>

More descriptive:

<a href="html-images.html">
    Learn HTML Images
</a>
Tip: Descriptive link text can help users understand navigation and can also provide useful context to search engines and assistive technologies.

Common Mistakes

  1. Writing the wrong file path.
  2. Forgetting the href attribute.
  3. Using incorrect file names or capitalization.
  4. Linking to a file that does not exist.
  5. Using vague link text when a descriptive label would be clearer.
  6. Forgetting rel="noopener noreferrer" when using target="_blank" for external links.

HTML Links Summary

  • <a> creates a hyperlink.
  • href specifies the destination.
  • Internal links connect pages within your website.
  • External links point to other websites.
  • target="_blank" can open a link in a new tab.
  • mailto: creates an email link.
  • tel: creates a phone link.
  • #id can link to a section on the same page.
  • download can indicate that a linked resource is intended for downloading.
  • Descriptive link text improves navigation clarity.
