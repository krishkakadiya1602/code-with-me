HTML Links

Learn how to create links and connect webpages using HTML.

⭐ Main Points

  • The <a> tag is used to create links.
  • The href attribute specifies the destination.
  • You can link websites, pages, files, email addresses and phone numbers.
  • The target="_blank" attribute opens a link in a new tab.
  • Relative URLs are useful for connecting pages inside your website.
  • Absolute URLs are used for external websites.
  • Good link text improves usability and accessibility.

1. HTML Anchor Tag

The <a> tag is called the Anchor tag. It is used to create a clickable link.

Example

<a href="https://www.google.com">
    Visit Google
</a>

Output

Visit Google

2. href Attribute

The href attribute tells the browser where the link should go.

Example

<a href="https://www.example.com">
    Example Website
</a>

Output

Example Website

3. Link to Another Website

You can use an absolute URL to link to another website.

Example

<a href="https://www.wikipedia.org">
    Visit Wikipedia
</a>

Output

Visit Wikipedia

4. Link to Another HTML Page

Relative paths are used to connect pages inside your website.

Example

<a href="about.html">
    About Us
</a>

Output

About Us

5. Open Link in New Tab

Use target="_blank" to open a link in a new browser tab.

Example

<a href="https://www.google.com"
   target="_blank">
    Open Google
</a>

Output

Open Google

6. Email Link

The mailto: scheme creates a link that opens the user's email application.

Example

<a href="mailto:example@gmail.com">
    Send Email
</a>

Output

Send Email

7. Telephone Link

The tel: scheme can be used to create a clickable telephone number, especially on mobile devices.

Example

<a href="tel:+911234567890">
    Call Us
</a>

Output

Call Us

8. Link to a Section on the Same Page

You can move the user to a specific section of the same page by using an ID.

Example

<a href="#contact">
    Go to Contact
</a>

<h2 id="contact">
    Contact Us
</h2>

Output

Go to Contact

Contact Us

9. Download Link

The download attribute tells the browser to download the linked resource instead of navigating to it.

Example

<a href="sample.txt" download>
    Download File
</a>

Output

Download File

Note: The file must exist for the download to work.

10. Image as a Link

An image can also be placed inside an anchor tag to make the image clickable.

Example

<a href="https://www.google.com">

    <img src="image.jpg"
         alt="Google"
         width="150">

</a>

Output

Click Image

11. Title Attribute

The title attribute can provide additional information when the user hovers over a link.

Example

<a href="https://www.google.com"
   title="Open Google Website">

    Google

</a>

Output

Google

12. Link with target="_self"

target="_self" opens the link in the same browser tab. This is the default behavior.

Example

<a href="https://www.google.com"
   target="_self">

    Open in Same Tab

</a>

Output

Open in Same Tab

13. Link with target="_blank"

target="_blank" opens the destination in a new tab or browsing context.

Example

<a href="https://www.youtube.com"
   target="_blank"
   rel="noopener">

    Open YouTube

</a>

Output

Open YouTube

14. Relative URL

A relative URL points to a file or page within your own website.

Example

<a href="html-tags.html">
    HTML Tags
</a>

Output

HTML Tags
Important: Since this file is inside the html/ folder, use:

html-tags.html

to open another file inside the same folder.

15. Absolute URL

An absolute URL contains the complete web address, including the protocol such as HTTPS.

Example

<a href="https://www.google.com">
    Google
</a>

Output

Google
