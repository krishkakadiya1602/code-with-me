9. HTML Semantic Elements

Learn how to structure webpages using meaningful HTML elements.

What are Semantic Elements?

Semantic HTML elements clearly describe the meaning and purpose of the content inside them.

For example, <header> represents the header of a page or section, while <footer> represents the footer.

Example: 
<header>
    <h1>My Website</h1>
</header>

<main>
    <p>This is the main content.</p>
</main>

<footer>
    <p>Copyright 2026</p>
</footer>

Why Use Semantic Elements?

Semantic elements make your HTML structure easier to understand for developers, browsers and assistive technologies.

  • Makes HTML code easier to read.
  • Gives content a meaningful structure.
  • Helps accessibility.
  • Helps search engines understand page structure.
  • Makes websites easier to maintain.

1. <header>

The <header> element represents introductory content for a page or section. 

<header>

    <h1>Code With Me</h1>

    <p>Learn Coding Online</p>

</header>

A header can contain headings, logos, navigation links or introductory information.

2. <nav>

The <nav> element represents a section containing navigation links. 

<nav>

    <a href="index.html">Home</a>

    <a href="about.html">About</a>

    <a href="contact.html">Contact</a>

</nav>

3. <main>

The <main> element contains the main content of a webpage. 

<main>

    <h1>HTML Tutorial</h1>

    <p>
        Learn HTML from beginner to advanced.
    </p>

</main>
Note: A page should normally have one main <main> element.

4. <section>

The <section> element represents a thematic grouping of content. 

<section>

    <h2>HTML Course</h2>

    <p>
        Learn HTML step by step.
    </p>

</section>

A section usually has a heading that describes its content.

5. <article>

The <article> element represents independent content that can stand on its own.

Examples include blog posts, news articles, forum posts and product reviews. 

<article>

    <h2>What is HTML?</h2>

    <p>
        HTML is the standard language used
        to create webpages.
    </p>

</article>

6. <aside>

The <aside> element represents content that is related to the main content but is separate from it. 

<aside>

    <h3>Related Topics</h3>

    <ul>

        <li>HTML Links</li>
        <li>HTML Images</li>
        <li>HTML Tables</li>

    </ul>

</aside>

7. <footer>

The <footer> element represents footer information for a page or section. 

<footer>

    <p>
        © 2026 Code With Me
    </p>

</footer>

A footer can contain copyright information, contact details, links and other related information.

8. <figure>

The <figure> element is used for self-contained content such as images, diagrams or illustrations. 

<figure>

    <img
        src="image.jpg"
        alt="HTML code">

    <figcaption>
        Example of HTML code
    </figcaption>

</figure>

9. <figcaption>

The <figcaption> element provides a caption for content inside a <figure>. 

<figure>

    <p>
        HTML Structure Diagram
    </p>

    <figcaption>
        Basic structure of an HTML page
    </figcaption>

</figure>

10. <details>

The <details> element creates content that the user can open and close. 

<details>

    <summary>
        What is HTML?
    </summary>

    <p>
        HTML is used to structure webpages.
    </p>

</details>
Click to learn about HTML

HTML stands for HyperText Markup Language and is used to structure webpages.

11. <summary>

The <summary> element provides the visible heading for a <details> element. 

<details>

    <summary>
        Learn More
    </summary>

    <p>
        More information goes here.
    </p>

</details>

12. <time>

The <time> element represents a specific time or date. 

<p>

    Course starts on
    <time datetime="2026-10-01">
        October 1, 2026
    </time>

</p>

Semantic Elements List

Element Purpose
<header> Header or introductory content
<nav> Navigation links
<main> Main content of the page
<section> Thematic section of content
<article> Independent content
<aside> Related or secondary content
<footer> Footer information
<figure> Self-contained media/content
<figcaption> Caption for a figure
<details> Expandable content
<summary> Heading for details
<time> Represents a date or time

Complete Semantic HTML Structure

A common webpage structure using semantic elements looks like this: 

<!DOCTYPE html>

<html>

<head>

    <title>My Website</title>

</head>

<body>

    <header>

        <h1>My Website</h1>

    </header>


    <nav>

        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Contact</a>

    </nav>


    <main>

        <section>

            <h2>Latest Articles</h2>

            <article>

                <h3>Learning HTML</h3>

                <p>
                    HTML is used to create webpages.
                </p>

            </article>

        </section>


        <aside>

            <h3>Related Topics</h3>

            <p>
                Learn CSS and JavaScript next.
            </p>

        </aside>

    </main>


    <footer>

        <p>
            © 2026 My Website
        </p>

    </footer>

</body>

</html>

Semantic vs Non-Semantic Elements

Semantic Non-Semantic
<header> <div>
<nav> <div>
<main> <div>
<article> <div>
<footer> <div>
Important: The <div> element is not wrong. It is a generic container. Semantic elements should be preferred when they accurately describe the purpose of the content.

Semantic HTML Best Practices

  1. Use <header> for introductory content.
  2. Use <nav> for major navigation links.
  3. Use <main> for the main page content.
  4. Use <section> to group related content.
  5. Use <article> for independent content.
  6. Use <aside> for related secondary content.
  7. Use <footer> for footer information.
  8. Use headings such as <h1> and <h2> to organize content.

Common Mistakes

  • Using <div> for every part of a webpage.
  • Using semantic elements where their meaning does not match the content.
  • Creating multiple unnecessary <main> elements.
  • Using <section> without a clear thematic purpose.
  • Forgetting meaningful headings for sections.
