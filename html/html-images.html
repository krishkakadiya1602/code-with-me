HTML Images

Learn how to add, resize, style and link images using HTML.

⭐ Main Points

  • The <img> tag is used to display images.
  • The src attribute specifies the image location.
  • The alt attribute provides alternative text.
  • You can control image width and height.
  • Images can be used inside links.
  • CSS can be used to make images responsive and stylish.
  • Always use meaningful alt text for important images.

1. HTML <img> Tag

The <img> tag is used to display an image on a webpage.

Example

<img src="image.jpg"
     alt="My Image">

Output

Image

2. src Attribute

The src attribute specifies the location or path of the image.

Example

<img src="photo.jpg"
     alt="Photo">

Output

The browser loads the image from photo.jpg.

3. alt Attribute

The alt attribute provides alternative text for an image if the image cannot be displayed.

Example

<img src="student.jpg"
     alt="Student studying HTML">

Output

If the image cannot load, the alt text can describe the missing image.

Tip: Always write useful and meaningful alt text for important images.

4. Image Width

The width attribute can specify the width of an image.

Example

<img src="image.jpg"
     alt="Image"
     width="300">

Output

Width: 300px

5. Image Height

The height attribute can specify the height of an image.

Example

<img src="image.jpg"
     alt="Image"
     height="200">

Output

Height: 200px

6. Width and Height Together

You can specify both width and height for an image.

Example

<img src="image.jpg"
     alt="Image"
     width="300"
     height="200">

Output

300 × 200

7. Image from Another Folder

You can use a relative path to load an image from another folder.

Example

<img src="images/photo.jpg"
     alt="My Photo">

Output

The browser looks for the image inside the images folder.

Folder structure: 
html/
    html-images.html

images/
    photo.jpg

8. Image from Parent Folder

The ../ notation moves one folder level up.

Example

<img src="../images/photo.jpg"
     alt="Photo">

Output

Since html-images.html is inside the html folder, ../ moves to the parent folder.

9. Image as a Link

You can make an image clickable by placing the <img> tag inside an <a> tag.

Example

<a href="https://www.google.com">

    <img src="image.jpg"
         alt="Google">

</a>

Output

Click Image

10. Image Border

CSS can be used to add a border around an image.

Example

<img src="image.jpg"
     alt="Image"
     style="border: 5px solid black;">

Output

Image Border

11. Rounded Image

The CSS border-radius property can make image corners rounded.

Example

<img src="image.jpg"
     alt="Image"
     style="border-radius:20px;">

Output

Rounded Image

12. Circular Image

Using border-radius: 50% can create a circular image when the image is square.

Example

<img src="profile.jpg"
     alt="Profile"
     style="border-radius:50%;">

Output

Profile

13. Responsive Image

A responsive image adjusts to the available screen width.

Example

<img src="image.jpg"
     alt="Responsive Image"
     style="max-width:100%;height:auto;">

Output

Responsive Image

14. Image Figure and Caption

The <figure> element can group an image with a caption.

Example

<figure>

    <img src="photo.jpg"
         alt="Nature">

    <figcaption>
        Beautiful Nature
    </figcaption>

</figure>

Output

15. Image with Title

The title attribute can provide additional information when the user hovers over an image.

Example

<img src="logo.png"
     alt="Code With Me Logo"
     title="Code With Me">

Output

Hover Me
