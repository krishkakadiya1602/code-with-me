5. HTML Images

Learn how to add and control images in HTML

What are HTML Images?

Images make a website more attractive and easier to understand. HTML provides the <img> element to display images on a webpage.

Unlike many HTML elements, <img> does not have a closing tag. It is an empty element.

Basic Syntax

<img src="image.jpg" alt="My Image">

1. The <img> Tag

The <img> tag is used to display an image. 

<img src="photo.jpg" alt="A beautiful photo">

Important Attributes

  • src – Specifies the image location.
  • alt – Provides alternative text for the image.
  • width – Sets the image width.
  • height – Sets the image height.

2. The src Attribute

The src attribute tells the browser where the image is located. 

<img src="flower.jpg" alt="Flower">

If the image is inside an images folder: 

<img src="images/flower.jpg" alt="Flower">

3. The alt Attribute

The alt attribute provides alternative text for an image. 

<img src="cat.jpg" alt="A white cat">
Important: Always use meaningful alt text for important images.

If an image cannot load, the browser can display the alternative text instead.

4. Image Width and Height

You can control an image's dimensions using width and height. 

<img src="photo.jpg"
     alt="Photo"
     width="500"
     height="300">

Here the image has a width of 500 pixels and a height of 300 pixels.

5. Image Example

You can use an online image URL for demonstration.

Example of an image displayed using HTML. 

<img
    src="https://images.unsplash.com/photo-1516321318423-f06f85e504b3"
    alt="Computer and coding workspace">

6. Local Image

You can also use an image stored inside your website folder.

Example folder structure: 

website/
│
├── index.html
│
├── html/
│   └── html-images.html
│
└── images/
    └── coding.jpg

From html-images.html, you can access the image using: 

<img src="../images/coding.jpg"
     alt="Coding">
Remember: ../ means go one folder back.

7. Image as a Link

You can make an image clickable by placing the <img> tag inside an <a> tag. 

<a href="https://www.google.com">

    <img src="logo.jpg"
         alt="Google">

</a>

When the user clicks the image, they will be taken to the specified link.

8. Figure and Figcaption

HTML also provides <figure> and <figcaption> for images with captions. 

<figure>

    <img src="coding.jpg"
         alt="Coding on a computer">

    <figcaption>
        Learning Web Development
    </figcaption>

</figure>

9. Responsive Images

A responsive image automatically adjusts according to the screen size.

A common CSS technique is: 

img {
    max-width: 100%;
    height: auto;
}

This helps prevent large images from overflowing on mobile screens.

10. Common Image Formats

Format Common Use
JPG / JPEG Photos and complex images
PNG Images requiring transparency
GIF Simple animations
SVG Logos, icons and vector graphics
WebP Modern web images with good compression

11. Important Image Attributes

Attribute Purpose Example
src Image location src="photo.jpg"
alt Alternative text alt="My photo"
width Image width width="500"
height Image height height="300"
title Additional information title="Coding Image"
loading Controls loading behavior loading="lazy"

12. Lazy Loading

The loading="lazy" attribute tells the browser that an image can be loaded when it gets close to the user's screen. 

<img
    src="large-image.jpg"
    alt="Large image"
    loading="lazy">

This can be useful for pages containing many images.

13. HTML Image Best Practices

  • Always provide useful alt text for meaningful images.
  • Use appropriate image formats.
  • Avoid unnecessarily large image files.
  • Make images responsive.
  • Use descriptive file names.
  • Keep images organized inside an images folder.

15. Common Mistakes

Mistake 1: Wrong Image Path

<img src="photo.jpg">

If the image is actually inside an images folder, use: 

<img src="images/photo.jpg">

Mistake 2: Missing alt Attribute

<img src="photo.jpg">

Better: 

<img src="photo.jpg"
     alt="My photo">

Mistake 3: Incorrect File Extension

If your actual file is photo.png, don't write photo.jpg.

16. HTML Images Summary

The <img> element is used to display images in HTML.

The most important attributes are:

  • src – image location
  • alt – alternative text
  • width – image width
  • height – image height
  • loading – loading behavior

You can also use images as links and combine images with <figure> and <figcaption>.
