6. HTML Lists

Learn how to create different types of lists in HTML

What are HTML Lists?

HTML lists are used to display related items in an organized way.

For example, a website can use lists to display:

  • Programming languages
  • Navigation menus
  • Shopping items
  • Steps of a process
  • Features of a product

HTML provides three main types of lists:

  1. Unordered List
  2. Ordered List
  3. Description List

1. Unordered List

An unordered list displays items using bullets.

It is created using the <ul> element.

Each item is created using the <li> element.

Syntax

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>

Output

  • HTML
  • CSS
  • JavaScript

2. Unordered List Bullet Styles

CSS can be used to change the bullet style. 

ul {
    list-style-type: square;
}

Common Values

Value Description
disc Filled circular bullets
circle Hollow circular bullets
square Square bullets
none No bullets

3. Ordered List

An ordered list displays items in a specific order.

It is created using the <ol> element.

Example

<ol>

    <li>Open your computer</li>
    <li>Open VS Code</li>
    <li>Create an HTML file</li>

</ol>

Output

  1. Open your computer
  2. Open VS Code
  3. Create an HTML file

4. Ordered List Types

The type attribute can change the numbering style. 

<ol type="A">

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ol>
Type Example
1 1, 2, 3
A A, B, C
a a, b, c
I I, II, III
i i, ii, iii

5. Starting an Ordered List

The start attribute allows an ordered list to start from a specific number. 

<ol start="5">

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ol>
  1. HTML
  2. CSS
  3. JavaScript

6. Reversed Ordered List

The reversed attribute makes an ordered list count backwards. 

<ol reversed>

    <li>Third</li>
    <li>Second</li>
    <li>First</li>

</ol>
  1. Third
  2. Second
  3. First

7. Description List

A description list is used to display terms and their descriptions.

It uses three elements:

  • <dl> – Description List
  • <dt> – Description Term
  • <dd> – Description Details

Example

<dl>

    <dt>HTML</dt>

    <dd>
        HyperText Markup Language
    </dd>


    <dt>CSS</dt>

    <dd>
        Cascading Style Sheets
    </dd>

</dl>

Output

HTML
HyperText Markup Language
CSS
Cascading Style Sheets

8. Nested Lists

A list inside another list is called a nested list.

Example

<ul>

    <li>
        Frontend

        <ul>

            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>

        </ul>

    </li>

    <li>
        Backend
    </li>

</ul>

Output

  • Frontend
    • HTML
    • CSS
    • JavaScript
  • Backend

9. The <li> Element

The <li> element represents a single item inside an ordered or unordered list. 

<ul>

    <li>Apple</li>
    <li>Banana</li>
    <li>Mango</li>

</ul>
Remember: The <li> element is normally used inside <ul> or <ol>.

10. Lists for Navigation Menus

Lists are commonly used to create website navigation menus. 

<ul>

    <li>
        <a href="index.html">Home</a>
    </li>

    <li>
        <a href="about.html">About</a>
    </li>

    <li>
        <a href="contact.html">Contact</a>
    </li>

</ul>
Lists are very useful when building navigation menus, especially when combined with CSS.

11. Types of HTML Lists

List Tag Purpose
Unordered List <ul> Items without a specific order
Ordered List <ol> Items with a specific order
Description List <dl> Terms and descriptions

12. Styling Lists with CSS

CSS can be used to change the appearance of HTML lists. 

ul {
    list-style-type: square;
    padding-left: 30px;
}

li {
    margin-bottom: 10px;
}

You can also remove bullets completely: 

ul {
    list-style-type: none;
}

13. Complete HTML Lists Example

<!DOCTYPE html>

<html>

<head>

    <title>My Lists</title>

</head>

<body>

    <h1>My Programming Courses</h1>

    <h2>Unordered List</h2>

    <ul>

        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>

    </ul>


    <h2>Ordered List</h2>

    <ol>

        <li>Learn HTML</li>
        <li>Learn CSS</li>
        <li>Learn JavaScript</li>

    </ol>


    <h2>Description List</h2>

    <dl>

        <dt>HTML</dt>

        <dd>
            Structure of a webpage
        </dd>

        <dt>CSS</dt>

        <dd>
            Styling of a webpage
        </dd>

    </dl>

</body>

</html>

15. Common Mistakes

Mistake 1: Forgetting <li>

Incorrect: 

<ul>

    HTML
    CSS
    JavaScript

</ul>

Correct: 

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>

Mistake 2: Incorrect Closing Tags

Make sure every list element is properly closed. 

<li>HTML</li>

Mistake 3: Confusing <ul> and <ol>

Use <ul> when the order does not matter.

Use <ol> when the order matters.

16. HTML Lists Summary

HTML provides three main types of lists:

  • <ul> – Unordered List
  • <ol> – Ordered List
  • <dl> – Description List

The <li> element is used for individual list items.

Lists can also be nested and styled using CSS.
