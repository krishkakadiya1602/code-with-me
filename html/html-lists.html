HTML Lists

Learn how to create ordered, unordered, nested and description lists.

⭐ Main Points

  • The <ul> tag creates an unordered list.
  • The <ol> tag creates an ordered list.
  • The <li> tag defines a list item.
  • You can create nested lists inside other lists.
  • The type attribute can change ordered-list numbering styles.
  • The start attribute can change where an ordered list begins.
  • The reversed attribute displays an ordered list in reverse order.
  • The <dl>, <dt> and <dd> tags create description lists.
  • CSS can be used to customize list appearance.

1. Unordered List

An unordered list displays list items using bullet points. It is created using the <ul> tag.

Example

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>

Output

  • HTML
  • CSS
  • JavaScript

2. Ordered List

An ordered list displays list items in a numbered sequence. It is created using the <ol> tag.

Example

<ol>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ol>

Output

  1. HTML
  2. CSS
  3. JavaScript

3. List Item

The <li> tag defines an individual item inside an ordered or unordered list.

Example

<ul>

    <li>Apple</li>
    <li>Banana</li>
    <li>Mango</li>

</ul>

Output

  • Apple
  • Banana
  • Mango

4. Unordered List Type

CSS is recommended for styling unordered-list markers. The list-style-type property can change the bullet style.

Example

<ul style="list-style-type:square;">

    <li>HTML</li>
    <li>CSS</li>
    <li>Python</li>

</ul>

Output

  • HTML
  • CSS
  • Python

5. Ordered List Type

The type attribute can specify the numbering style of an ordered list.

Example

<ol type="A">

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ol>

Output

  1. HTML
  2. CSS
  3. JavaScript
Common values:
1 → Numbers
A → Uppercase letters
a → Lowercase letters
I → Uppercase Roman numerals
i → Lowercase Roman numerals

6. Start Attribute

The start attribute specifies the starting number of an ordered list.

Example

<ol start="5">

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ol>

Output

  1. HTML
  2. CSS
  3. JavaScript

7. Reversed Ordered List

The reversed attribute displays an ordered list in descending order.

Example

<ol reversed>

    <li>Third</li>
    <li>Second</li>
    <li>First</li>

</ol>

Output

  1. Third
  2. Second
  3. First

8. Nested List

A nested list is a list placed inside another list item.

Example

<ul>

    <li>Frontend

        <ul>

            <li>HTML</li>
            <li>CSS</li>

        </ul>

    </li>

    <li>Backend</li>

</ul>

Output

  • Frontend
    • HTML
    • CSS
  • Backend

9. Nested Ordered List

You can also place an ordered list inside another ordered or unordered list.

Example

<ol>

    <li>Learn HTML

        <ol>

            <li>Tags</li>
            <li>Attributes</li>

        </ol>

    </li>

    <li>Learn CSS</li>

</ol>

Output

  1. Learn HTML
    1. Tags
    2. Attributes
  2. Learn CSS

10. Description List

A description list is used to display terms and their descriptions. It uses <dl>, <dt> and <dd>.

Example

<dl>

    <dt>HTML</dt>

    <dd>
        HyperText Markup Language
    </dd>

    <dt>CSS</dt>

    <dd>
        Cascading Style Sheets
    </dd>

</dl>

Output

HTML
HyperText Markup Language

CSS
Cascading Style Sheets

11. Multiple Description Terms

One description can be associated with multiple terms.

Example

<dl>

    <dt>HTML</dt>
    <dt>HyperText Markup Language</dt>

    <dd>
        A markup language for webpages.
    </dd>

</dl>

Output

HTML
HyperText Markup Language
A markup language for webpages.

12. List Inside Navigation

Lists are commonly used to create navigation menus on websites.

Example

<nav>

    <ul>

        <li><a href="#">Home</a></li>
        <li><a href="#">About</a></li>
        <li><a href="#">Contact</a></li>

    </ul>

</nav>

Output

  • Home
  • About
  • Contact

13. Remove List Bullets

CSS list-style-type: none; can remove the default bullets or numbers.

Example

<ul style="list-style-type:none;">

    <li>Home</li>
    <li>About</li>
    <li>Contact</li>

</ul>

Output

  • Home
  • About
  • Contact

14. Custom List Marker

CSS can be used to customize the appearance of list markers.

Example

<ul style="list-style-type:square;">

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>

Output

  • HTML
  • CSS
  • JavaScript

15. List with Links

List items can contain links. This is commonly used in menus and course navigation.

Example

<ul>

    <li>
        <a href="html-tags.html">
            HTML Tags
        </a>
    </li>

    <li>
        <a href="html-links.html">
            HTML Links
        </a>
    </li>

</ul>

Output

  • HTML Tags
  • HTML Links
